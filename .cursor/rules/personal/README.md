# Personal rules

Put your own preferences here (tone, reply language, private checklists, machine-specific paths) as `*.mdc` files, or use `.cursor/rules/*.local.mdc`.

Team guardrails stay in `.cursor/rules/agents.mdc` and root `AGENTS.md`. Do not move security, Ask First, or shared verify commands into personal rules.

The generator does not write personal rule content for you.
