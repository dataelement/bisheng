| 场景 | 修订规格要求 | 追溯 | 结论 |

| 首发预检无资源 | 预检失败，无新审批单、无正式版本、无审批后待上线态；清理后重新发布 | AC-08 | 一致 |
| 审批后无资源 | 已通过审批不变，保留版本，进入待上线，资源恢复后原单手动上线 | AC-08 | 一致 |
| 候选停止未确认 | 不提前释放可能仍活动的资源或写入归属，不制造第二写入者 | AC-08、AC-49、AC-52 | 一致 |
| 准备操作结束后实例冷重建，manager 不在线 | 初始化身份按有效部署及冻结材料重新授权，不重新激活已完成准备操作 | AC-07、AC-15、AC-44、AC-47、AC-48 | 一致 |
| 运行初始化短期票据过期 | 旧票据不能直接下载；backend 重新核验归属和冻结范围后才能签发新凭据 | AC-15、AC-47 | 一致 |
| 应用停用、归属撤销、跨范围或重放 | 材料请求拒绝；初始化身份、任务票据和管理密钥不进入业务容器 | AC-15、AC-47、AC-53 | 一致 |
| 必需隔离缺失、不生效或无法确认 | 不因配置或告警记录而放行；诊断能力可保留，重新验证通过才恢复新执行 | AC-12、AC-21、AC-23、AC-30、AC-31 | 一致 |
| 可选强沙箱不可用 | 明确记录实际档位，只回退到满足必需隔离的默认档 | AC-19、AC-20、AC-23、AC-31、AC-32 | 一致 |
| 无动态存储供应器但有合格预置卷 | 可发布；本地卷节点绑定持续可见，不借单节点结果承诺跨节点恢复 | AC-31、AC-33、AC-34、AC-55 | 一致 |
