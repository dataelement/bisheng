# Release Contract — v3.1.0-alpha1

> 本文件是版本级领域归属与全局约束的权威来源。
> **所有 spec.md 在动笔前必须先阅读本文件。**
> 每次 spec 评审时，必须对照本文件检查一致性。
>
> 分支：`feat/3.1.0-alpha1`（2026-11-19 从 `feat/3.1.0-beta2` 拉出）。本版本沿用 v3.0.0 / v3.1.0-beta1 / v3.1.0-beta2 已登记的领域归属与不变量；下表只登记本版本新增或改变的部分。

## 表 1：领域对象归属

| 领域对象 | Owner Feature | 说明 |
|---------|--------------|------|
| 托管应用（`app`）及其版本、发布记录 | v3.0.0 F054 / F055（不变） | F001 只读取，不新增写入路径；去掉 F130 加的桌面发布写入路径 |
| 托管应用的员工端展示与入口（发现广场卡片、「应用」页、桌面列表） | F001-hosted-app-entry | 取代 v3.0.0 F130 的「云端工作台」目录页与桌面专用通道 |

**规则**：
- 非 Owner Feature 的 AC 中不得出现其他对象的"创建/修改/删除"行为，只能"读取"或"调用" Owner 的 Service
- 新增领域对象时必须先更新本表

## 表 2：跨 Feature 不变量（INV-N）

| ID | 不变量描述 | 涉及领域对象 | 来源 spec |
|----|-----------|------------|---------|
| INV-1 | 托管应用只经既有发布管线（扫描、构建、启动检查、审批、上线）进入「已上线」，不存在绕过审批或客户端专用的发布入口 | 托管应用 | F001 |
| INV-2 | 员工在任何入口（网页发现广场、「应用」页、桌面客户端）看到的托管应用来自同一范围：同租户、本人可见；网页显示已上线和已下线（已下线不可打开），桌面只列已上线；草稿与已删除不出现 | 托管应用 | F001 |

**规则**：
- 新增不变量：先在此表追加，再写 AC
- 修改不变量：必须列出 Impacted Specs 清单，逐一回写并重新评审
- 冲突检测：若 AC 与不变量矛盾，spec 评审不通过
