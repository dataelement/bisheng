### 0.2 本次纳入

- 昆联自然人进入独立工作流页面、统一登录、登录失败提示、业务页面回跳、退出及到期重新授权。
- 昆联身份有效性与毕昇本地会话、用户状态、租户资格及工作流权限共同决定访问结果。
- 全租户目录的完整同步、稳定身份关联、状态处理、失败恢复、重复执行和运行结果查询。
- 目录范围与登录范围分离，昆联角色与毕昇菜单／工作流对象权限分离。
- 保留既有身份通道及业务资产；本特性新增的外部集成事实由 F118 负责，本地领域对象通过原 Owner 能力协调。

### 0.3 本次明确排除

- 平台 Agent 节点、模型／知识／工具接入、Workflow 工具化和工作流权限镜像接口。
- 昆联后端代用户调用毕昇、Worker 对外服务委托及通用 Token Exchange；浏览器登录不替代这些契约。
- 上游当前未提供的完整组织树、用户组成员、身份事件推送、更新时间增量及 SCIM／账号写回。
- 自动合并历史账号、跨租户迁移身份或资源、复制旧授权、批量授予菜单或工作流权限。
- 首期刷新授权和后端退出通知的启用；若以后纳入，需要先更新规格并确认对应客户端授权范围。
- 已运行工作流的自动取消、历史输出清理及统一后台任务撤权框架。新的交互提交、恢复或查询若属于受保护访问，仍受本规格约束。

### 1.3 术语与准入范围

- **外部身份**：由昆联签发方、稳定租户身份标识及外部租户共同确定的登录主体；名称、邮箱、入口短码均不用于自动合并。
- **目录成员**：某租户内的成员记录；其成员标识与登录身份标识不同，二者必须正确关联。
- **身份已确认**：可信认证结果已核验，不意味着用户具有毕昇菜单、工作流或数据访问权。
- **已确认不可用**：受信状态证据表明身份、成员或租户不可用；从系统已接受该证据起，后续新访问不得放行。上游变更传播上界属于 §5 的交付约定，不等于系统可以在接受停用后继续放行。
- **受保护访问**：以昆联浏览器会话身份读取或执行受保护业务的请求，包括 HTTP 访问、WebSocket 建连及连接上的新业务动作；不含登录／退出协议步骤、公开静态内容和独立服务凭据通道。其他长连接上的新业务动作适用同一规则。
- 已开始执行的业务或已输出的数据不被追溯撤销；后续新业务动作不得因复用连接而免除准入。后台任务和在途运行的额外复核／取消策略不在本次范围。

| 情形 | 期望行为及边界 | 对应 AC |
| --- | --- | --- |
| 门户已登录但身份服务尚无登录态 | 允许用户按昆联身份服务要求再次登录或确认同意，不承诺现有门户登录必然无感；门户桥接单独登记验收 | AC-01、AC-02 |
| 未初始化、目录无该身份或映射冲突 | 拒绝当前登录；未就绪触发受控补同步，冲突需要纠正，不以姓名或默认租户消除冲突 | AC-03、AC-04、AC-16 |
| 多次点击登录或多个请求同时发现目录未就绪 | 每个登录事务独立处理，补同步不得造成重复身份、无界排队或重复发布；本次不会等待同步后自动放行已失败登录 | AC-02、AC-04、AC-06 |
| 一轮目录缺失、详情未找到或列表随遍历变化 | 不能仅凭这些证据直接硬删除本地身份或业务资产；当前接口不提供一致性快照，不宣称其具有快照或增量语义 | AC-06、AC-23 |
| 上游用户列表未覆盖无成员租户 | 不虚构空租户；完整性只针对当前接口实际返回的获准目录，若要求所有空租户也可发现，须先补契约 | AC-05、AC-15；§5 |
| 租户为 ACTIVE 但没有到期事实 | 不据此声称租户尚未到期，也不自行产生到期状态；到期即阻断是否由在线准入覆盖，需上游明确 | AC-07、AC-09；§5 |
| 目录同步失败但上一轮目录和在线身份仍有效 | 不把同步失败当成空目录或全体停用；继续保留上轮副本，受保护访问仍需逐次在线验证及本地资格。是否超过允许陈旧上限由交付约定确定，未约定不承诺固定窗口 | AC-06、AC-07、AC-19；§5 |
| 停用时存在人工授权或正在运行的工作流 | 保留人工授权记录和业务资产，阻断新受保护访问、失效旧会话；不据此取消已运行任务或删除历史结果 | AC-09、AC-18、AC-23 |
| 令牌到期但本地 Cookie 尚未过期 | 拒绝业务访问并重新授权；新授权不跳过目录、租户和业务权限判断 | AC-07、AC-11 |
| 只有远端退出通知未交付 | 不依赖通知保证正确性；已确认在线失效的新请求仍拒绝，不承诺自动清理所有其他会话。用户重新发起并完整通过的新授权可以建立新会话，这与恢复已失效旧会话不同 | AC-07、AC-10、AC-21 |
