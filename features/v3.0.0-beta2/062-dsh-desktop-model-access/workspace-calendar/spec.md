# 工作台 DSH 年度用量

## 用户确认的行为

- 工作台 DSH 弹窗保留打开与下载按钮。下载按钮读取管理员保存的系统配置。
- 弹窗直接呈现入口和模型用量，移除原解释文案、设备授权管理和月度额度表。
- 模型用量复刻当前管理后台年度模块：北京时间最近 365 天、每日一格、12px 方格与 3px 间距、相同色阶和悬浮提示，支持 Token 与消息数切换及对应总量。
- 当前登录用户查看本人用量；无数据、加载、错误重试和缺失用量状态分别显示。

## 实现与验证

- `GET /api/v1/dsh/me/usage-summary` 从浏览器登录态取得用户和租户，校验自然人有效身份，在租户作用域调用现有 `read_usage_time_summary`。
- 工作台独立 SPA 按部署中的年度绘制实现复刻。客户端适配主题语义 token、翻译入口和个人查询。
- 服务端范围由服务器时间生成；输入参数无法选择其他用户或租户。响应沿用 DSH `no-store`。
- 自动验证覆盖身份隔离、匿名和禁用状态、365 个日期格、尺寸、指标切换、下载配置、错误重试与缺失用量。
- 登录态浏览器验收单独记录。
