# 中粮 1028 → 1111 升级说明

**需要维护窗口，统一更新前后端和全部 Worker；正常 1028 基线无需新增数据库迁移、权限模型发布或数据回填。**

比较基线：`feat/cofco-1028-3.0.0-beta1`（`bda4b112ba`）→ `feat/cofco-1111-3.0.0-beta1`（`00720a9c69`）。现场镜像须核对对应提交，不能只看标签名称。

## 升级影响

| 变化 | 影响 |
| --- | --- |
| 文件夹删除状态 | 删除中提示可跨刷新保留；新旧后端不能混跑 |
| 问答失败与重试 | 增加故障来源和定位信息，修复日常问答关联、任务重试租户及模型传递；已卡住的历史任务需单独处理 |
| 任务生成与展示 | 增加网页报告、网页幻灯片及 HTML 检查；检索步骤显示知识空间名称，改进任务执行稳定性 |
| 技能加载 | API 启动自动写入或更新内置技能；任务可使用全部已启用技能，取消勾选不等于禁用，需到技能管理中关闭 |

生产配置继续沿用，检查旧源码热补丁是否覆盖新镜像。E+ 机器人本次无独立功能变更，仍需验证共享后端更新后的问答。

## 升级步骤

1. **准备镜像。** 核对目标前后端镜像的提交、架构和 digest，确认镜像构建检查通过；保留旧镜像、配置和各服务原副本数。

2. **停入口、排空任务。** 进入维护模式，暂停用户及外部写入、定时任务和机器人新消息；保留必要消费者，等问答、上传、删除及审批执行结束。记录无法结束的遗留任务。

3. **停旧服务并备份。** 停止旧 API、全部 Worker、Beat、E+ 及独立调试服务，确认旧进程退出。备份业务库、OpenFGA 数据、对象存储、Redis 数据/队列和配置，确认可恢复；不清空队列或索引。

4. **统一替换镜像。** API、Celery、Linsight、Beat、E+ 及实际部署的调试服务均换目标后端镜像，前端换配套镜像。K8s 先将相关业务 Deployment 缩到 0，确认旧 Pod 退出后再启动新版，避免滚动更新混跑。

5. **先启动一个新 API。** 启动脚本照常执行 `alembic upgrade head`；数据库当前版本和代码迁移头应同为 `f076_subject_id_search_indexes`。检查权限初始化、存储连接及内置技能发布日志，确认网页报告技能可用。版本不符或启动失败时停止升级。

6. **启动其余服务并验收。** 恢复目标 Worker、前端及原副本数，确认无旧镜像残留、各队列有消费者、Beat 不重复。先开放验收人员，检查通过后再恢复机器人、定时任务、外部入口及用户流量。

## 上线验收

- **基础：** 登录、租户与权限正常；上传、解析、下载、知识检索及 E+ 问答正常。
- **删除：** 测试目录显示“删除中”，刷新后状态仍在，完成后消失；审批流程正常。
- **重试：** 日常问答失败后能重试并持续输出；任务重试使用所选模型，能正常结束，历史可恢复。
- **生成：** 网页报告和网页幻灯片实际可打开；检索步骤名称正确，已禁用技能不可用。
- **运行：** 无持续报错或队列积压。Pod 健康不代表技能发布和业务验收通过。

## 回退注意

先关闭入口、排空任务；保留新版 API，核对并处理完“删除中”及结果未知的目录，**不能直接用 SQL 重置状态后回退**。

确认状态与数据兼容后，统一恢复旧前后端镜像、配置和副本数；本次不执行数据库降级或权限模型回退。新增或更新的技能不会随镜像自动撤销，须核对兼容性，必要时停用。若必须恢复备份，应同步恢复关联数据，并明确会丢失备份后的新增业务数据。
