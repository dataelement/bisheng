# Feature: MinerU 4.0 文档解析接入

> 本文只定义需求与验收结果。实现选择和上游协议见 [design.md](./design.md)。
> 状态：已确认（2026-10-13）；后续需求变更须重新确认。

**关联需求**：2026-10-12 至 2026-10-13 本任务对话中关于独立提供方、旧版兼容和评审意见的决定；[技术方案草案](../../../docs/architecture/proposals/2026-10-12-mineru-v4-integration.md) 仅作背景材料。
**优先级**：P1
**所属版本**：v3.0.0
**依赖**：既有知识文件解析、预览和引用能力；可访问的 MinerU 4.0 服务。
**版本契约**：[release-contract.md](../release-contract.md)

## 范围

- **本次纳入**：可显式选择 MinerU 4.0 解析 PDF、图片、OFD；保留旧 MinerU；让知识文件入库、预览和引用能消费新结果；修正 OFD 的专用队列路由。
- **本次明确排除**：历史文件批量重解析；Office、HTML、表格等文件改走 MinerU 4.0；提供方自动探测或失败回退；按知识库或租户分别选择提供方；中断的预览任务恢复。

## 1. 用户故事

作为**系统管理员**，我希望在保留旧 MinerU 接入的同时显式启用 MinerU 4.0，以便按部署环境逐步升级和回退。

作为**知识库维护者**，我希望 PDF、图片和 OFD 文件能正确解析、预览并入库，以便分块正文、图片和定位信息可用于检索与引用。

作为**知识库使用者**，我希望在引用中打开对应文件的可用预览，以便核对答案来源。

## 2. 验收标准

### 2.1 提供方选择和兼容

- **AC-01** — WHEN 管理员显式选择 MinerU 4.0 且服务可用，THE SYSTEM SHALL 使用该提供方解析新提交的受支持文件，并标识解析来源。
- **AC-02** — WHILE 管理员未选择 MinerU 4.0，THE SYSTEM SHALL 保持当前默认提供方和旧 MinerU 的可用行为，升级应用本身不得自动切换解析版本。
- **AC-03** — WHEN 管理员把提供方从 MinerU 4.0 切回旧 MinerU，THE SYSTEM SHALL 让此后执行解析的任务使用当前选择；已保存文件的正文和解析来源不得因此被改写。

### 2.2 文件解析与消费

- **AC-04** — WHEN 用户用 MinerU 4.0 处理 PDF、受支持图片或 OFD，THE SYSTEM SHALL 为成功文件提供可读正文、正确页序，以及上游实际提供的有效定位信息和图片素材。
- **AC-05** — WHEN 解析结果包含标题、表格、公式或多张图片，THE SYSTEM SHALL 保留可读内容及有效素材引用，不得把这些内容静默丢弃或生成失效链接。
- **AC-06** — IF 解析服务失败、返回部分完成、缺少必需结果或结果无法安全消费，THEN THE SYSTEM SHALL 将该文件标记为解析失败，不得把部分正文当作成功文件入库。
- **AC-07** — WHEN 用户预览或查看由新提供方解析的文件，THE SYSTEM SHALL 展示可用文件预览、分块及可用的定位和图片；平台与客户端的聊天引用均能打开该文件。旧 MinerU 文件的引用预览也须可用。
- **AC-08** — WHEN 用户接受已有文件预览并提交入库，THE SYSTEM SHALL 沿用用户所见的预览正文；即使提交前管理员切换了解析提供方，也不强制重新解析该预览。

### 2.3 队列与运行边界

- **AC-09** — WHERE OCR 专用队列已启用且当前外部解析提供方已配置，THE SYSTEM SHALL 将 OFD 文件与 PDF 文件一样送入专用队列；未启用专用队列或未配置外部解析提供方时，OFD 仍进入普通知识队列。
- **AC-10** — IF MinerU 4.0 不可用或配置无效，THEN THE SYSTEM SHALL 明确报告解析失败，不得自动改用旧 MinerU 或本地解析器。
- **AC-11** — WHEN 已排队文件实际开始解析，THE SYSTEM SHALL 按当时生效的全局提供方处理该文件；不要求与文件提交时的选择相同。

## 3. 边界情况

- 历史文件保持原正文、素材及解析来源；只有用户显式重解析时才按当时生效的提供方生成新结果。
- 图片或定位信息若上游未提供，系统只能展示确实可用的结果；所需素材缺失时按 AC-06 失败。
- 用户刷新预览页面后可重新发起预览并获得新的任务；本次不要求恢复已中断的预览任务。
- OCR 专用队列关闭时，PDF、OFD 和图片文件继续沿用普通知识队列；其他文件类型不因本特性改道。
