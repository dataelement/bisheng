## 依据与范围

依据用户 2026-11-17 最终指示及[修复设计](knowledge-delete-processing-cancellation-20261117.md) DEL-01～DEL-05。目标为当前修复分支，尚无部署构建。本地自动化不等于以下实机用例已执行。

## 环境、账号与测试数据

使用专用租户和 `e2e-delete-processing-` 前缀空间，仅清理本批数据。准备有空间删除权限的普通用户 A，无删除权限的用户 B，另一个租户 C；管理员只用于造数。准备小 txt、大 PDF、可控延迟解析/索引测试服务；测试机需 MySQL 或 DM8、Redis、MinIO、ES、Milvus、FGA 和正常 Beat。根据测试服务请求日志确认阶段，不靠手工改文件 status 伪造运行状态。控制消息重复投递、Worker 重启和超时应在隔离测试环境进行。
