# 聊天首页推荐案例

用户可以从新会话输入框下方选择案例，将提示词填入草稿后按需调整并发送。BiSheng Web 维护该区域，Desktop 的 Chat 通过嵌入同一网页展示。

| ID | 场景 | 验收标准 |
| --- | --- | --- |
| AC-01 | 进入 Chat 新会话 | 独立 Web 和 Desktop 嵌入页各显示一份推荐案例，兼容带原案例注入的 Desktop 版本。标题、彩色图标、换批按钮及四行列表对齐 Desktop 样式。会话历史和分享页中不出现案例。 |
| AC-02 | 切换案例批次 | 复用 Desktop 的 10 条 Chat 案例及 3 批顺序，每批 4 条，第三批之后回到第一批。中英文标题和提示词与 Desktop 一致，日文界面显示日文标题。 |
| AC-03 | 选择案例 | 将完整提示词填入可编辑草稿并聚焦输入框，等待用户发送。带引用的草稿保留引用，提示词追加至草稿末尾。 |
| AC-04 | 选择普通聊天或深度研究案例 | 按案例切换模式。有附件或引用时，停止自动退出深度研究并给出提示。无深度研究权限或输入框暂不可编辑时给出提示，保留草稿。 |
| AC-05 | 使用窄窗口或触屏 | 案例列表及换批按钮可操作，标题可换行，页面可滚动查看完整列表。已有推荐应用显示在案例区下方。 |
