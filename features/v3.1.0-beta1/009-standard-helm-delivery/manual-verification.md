# F009 真实新集群验收清单（本轮未执行）

本轮用户仅授权源码与部署文件，不构建镜像、不部署。下列步骤应在配套新镜像/真实官方 catalog 发布后，于独立测试集群、专用 release/库/桶/卷执行；不能拿源码模板成功或现有生产服务的健康结果替代。默认不触发环境预检。

- [ ] 从正式 Chart 新装：基础组件、初始化 Job、API/Workers、沙箱、控制面按实际依赖就绪；无额外 installer 特权、预检 Job 或 CronJob。
- [ ] 第一个用户正常注册为超管；确认没有脚本预建管理员；普通用户不能管理官方全局运行环境。
- [ ] 无诊断报告即可发布 Python、Node、Static；使用镜像预置外的依赖，查看实际下载、完整安装、构建和启动结果。
- [ ] 在线下载经 Egress；安装/编译直连拒绝，运行按既有域名规则出网；离线缺包明确失败，无自动公网回退。
- [ ] 不可达镜像、错误凭据、非法模板、实际 API/挂载失败分别拒绝，不被历史诊断通过覆盖。
- [ ] 在允许的运维身份运行可选手动诊断：正对照、否定探测、报告独立、原 UID 安全回收；报告大于24小时不阻断新操作。
- [ ] Code Runner 执行 Python/代码任务，逐副本端点和有状态会话保持；不测试本期延期的“使用后热关闭沙箱”。
- [ ] 企业外部 MySQL/Redis/MinIO/ES/Milvus/OpenFGA 及混用；无外部 root 初始化、无其他 release 变更。
- [ ] Gateway 关闭、启用且许可证有效两种部署；DSH 基本登录/刷新独立于 Gateway 开关，验证 WS/流式 API。
- [ ] 默认/指定 StorageClass、静态无 class、已有 PVC；真实测试容量边界、锁、重启、恢复和未知写入者不清卷/不释放预约。
- [ ] 调整 Helper/资源/调度/阶段和总期限，确认真实 Pod、意图和预约一致；重启不重置操作期限。
- [ ] 正常升级保留签名根/公钥/TLS、用户 false、语言默认、运行/审批组合；真实保护变化后旧路由不因心跳恢复自动复活。
- [ ] 双 release 及共享控制 namespace；选择器、Webhook、数据和 Secret 不交叉，不修改其他 namespace 的安全标签。
- [ ] 正常停止后卸载控制面，数据/凭据/执行隔离保留；未知写入者不得强删或移除围栏。
- [ ] 根据发行合同完成 amd64/arm64 原生运行、CNI/CSI/企业包源适配及真实恢复计时，保存脱敏日志/事件/UID/卷与版本证据。
