## 根因及修复

1. 前端仅按需解析选中的文件，但按钮额外要求 `strategy.rules.fileList` 全部有 completed 预览。两文件只预览首个时分段已显示，下一步仍禁用；切换预览第二个后恢复。原设计明确允许未预览条目按确认规则正常处理，因此移除全批预览前置要求。已有预览处理中、失败、保存未完成和规则不一致仍由现有门禁阻止提交。
2. Worker 与 API 并行首次启动，Worker 在 `permission_catalog_release` 建表前初始化权限运行时，`celeryd_after_setup` 信号失败后继续运行，后续模型读取运行时没有注册。文件处理因此报 `knowledge_model_read_runtime_unconfigured`。API 健康后重启 Worker 恢复；Compose 增加 `backend_worker -> backend: service_healthy`，后续启动等待 API 完成首次初始化和迁移。
