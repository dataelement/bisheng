# Release Contract — v3.1.0-beta1

> 本版本在 v3.0.0 发版线基础上演进。既有领域归属、全局不变量和错误码占用继续以 [v3.0.0 release contract](../v3.0.0/release-contract.md) 及其继承的版本契约为准；本文只登记本版本增量。

## 表 1：领域对象归属

F004 扩展既有工作流的删除语义；F005/F006 扩展幻灯片检查与技能包；F007 新增账号私有项目与对话归属，保留对话正文和企业身份的既有写入权。

| 增量界面范围 | Owner Feature | 边界 |
| --- | --- | --- |
| 工作台浏览器窄屏全局导航呈现 | F001-client-mobile-navigation（本版本） | 负责小于 768px 时的全局菜单及工具与技能首页排版；消费现有菜单、项目和会话能力，不取得这些业务对象的写入权 |
| 审计记录的组织归属快照，以及审计页的部门数据范围 | F003-audit-optimization（本版本） | 负责审计来源表上记录发生时的操作者主部门与路径，以及审计列表、候选、详情、导出的部门范围；只读部门、主部门和用户组，不取得它们的写入权；不改变 17 类结构化动作的业务写入点 |
| 工作流逻辑删除 | F004-workflow-soft-delete（本版本） | 保留主记录和版本，封闭普通查询与新操作；沿用既有授权、审计及历史数据归属，不新增在途协调 |
| 深度研究 check_html 的分页逐页溢出测量与主图编辑提示词 | F005-taskmode-slide-overflow（本版本） | 扩展既有 check_html 工具的渲染检查与报告格式，并修改主图系统提示词；不新增领域对象、接口或错误码，不改变 ERROR 阻断交付的既有规则 |
| 内置技能 html-report 的网页幻灯片分支（主题与版式模板、构建脚本、自检） | F006-html-report-slides（本版本） | 只改技能包内容；主题配色与「PPT 制作」技能的模板目录保持一致（测试校验），不修改后者的模板；分页标记沿用 F005 |
| 账号私有项目及项目—对话归属 | F007-chat-project-sync（本版本，规格与设计已确认，源码及本地验收完成） | 定义跨 Web/Desktop 的项目和归属写入、同步及本机迁移；只引用现有对话，保留 chat_session 对正文与会话生命周期的写入权；替代 F002 的本机数据来源边界，保留其交互 |
| 管理目标一致性与人员策略生效 | F009-managed-tenant-consistency（本版本，最小修复范围/设计已确认并实施，集成待验） | 扩展既有 user/role/department 的策略绑定与生效规则，接入菜单、审批标签、DSH与配额消费者；资源写入/恢复仍由 tool/workflow/knowledge/channel 各所属业务模块执行，不接管 F007 项目或资源权限PDP |

## 表 2：跨 Feature 不变量

沿用 v3.0.0 及其引用版本的既有不变量。F001 不新增全局业务不变量。F009 对身份、管理目标、组织归属和普通策略生效的拟明确规则见其 spec，原完整规格已确认，用户要求重新收敛最小修复；已确认范围见F009 scope-revision，设计已实施，不新增业务操作表或DSH按人刷新；不修改平台身份或 F048 唯一资源权限判定，也不改变普通配额允许轻微并发超额的保证。

## 已分配模块编码（MMMEE）

F007 使用既有 chat 130 段的 13011–13018：项目不可用、输入无效、快照变化、幂等冲突、会话不归属、同步不可用、导入无效、首条请求已创建。实现前已核对代码占用；其余占用沿用 v3.0.0 契约。

F009 最小修复已实现并核查错误码占用：24006（有效政策不可确定）、19404–19405（统计未知/预算责任迁出）、15090/10590（工具/工作流创建未就绪）。原七表稿的其余候选未分配到代码，不作为本批新增项。所有新错误已补三语文案并通过生成/i18n检查。

F009 不新增领域操作/明细表。DDL仅为Flow.creation_state、GptsToolsType.creation_state、Knowledge.copy_source_id/copy_target_id四列；权限投影/DSH沿原所有权。完整40条AC的部分恢复/收敛保证按已确认scope-revision延期，不能以此宣布原AC全部完成。
