# 自定义联网搜索规格

**状态**：已确认（2026-11-05；保存校验调整于 2026-11-08 确认）

**关联需求**：本次对话中的自定义联网搜索需求

**所属版本**：v3.0.0；正式功能编号待分配
**依赖**：现有联网搜索工具及网页引用能力

## 范围

- 纳入：在现有联网搜索设置中配置一个自定义搜索服务；通过 OpenAPI 描述选择接口、设置认证和搜索词参数；配置搜索结果字段映射；测试、保存和使用该配置。
- 排除：自动兼容所有 OpenAPI 描述和任意响应格式；同时启用或负载均衡多个搜索服务；改造现有服务商或网页读取工具。

## 用户故事

作为管理联网搜索的用户，我希望接入自己的搜索服务并验证搜索结果，以便现有联网搜索场景使用该服务及其网页来源。

## 验收标准

- **AC-01** — WHEN 用户打开联网搜索服务商选择，THE SYSTEM SHALL 提供自定义选项，同时保留已有选项。
- **AC-02** — WHEN 用户选择自定义，THE SYSTEM SHALL 提供粘贴或通过 URL 导入 OpenAPI 描述、选择搜索接口和搜索词参数的方式。
- **AC-03** — WHEN 用户配置自定义搜索，THE SYSTEM SHALL 允许配置无认证或 API Key 认证，以及搜索结果列表、标题、链接和摘要的映射。
- **AC-04** — WHEN 用户提供可选的来源、图标或发布时间映射，THE SYSTEM SHALL 在结果中保留对应信息。
- **AC-05** — WHEN 用户输入测试搜索词并执行测试，THE SYSTEM SHALL 展示原始响应及映射后的搜索结果；测试不改变已保存配置。
- **AC-06** — IF 描述无法解析、接口或参数不受支持、必填配置缺失或映射配置格式无效，THEN THE SYSTEM SHALL 指出失败并阻止保存；保存不强制在线测试。IF 测试或运行时请求失败或实际响应不符合映射，THEN THE SYSTEM SHALL 报告失败。
- **AC-07** — WHEN 用户保存有效的自定义配置并重新打开设置，THE SYSTEM SHALL 保留配置，且不以明文展示已保存密钥；用户可保留或替换密钥。
- **AC-08** — WHEN 已保存的自定义服务被选为联网搜索服务并收到搜索词，THE SYSTEM SHALL 调用该服务，并向现有联网搜索调用方提供映射后的结果。
- **AC-09** — WHEN 搜索结果包含有效网页链接和可用内容，THE SYSTEM SHALL 保留网页来源，使现有引用展示与历史回放可使用该来源。
- **AC-10** — IF 搜索成功但没有结果，THEN THE SYSTEM SHALL 表示空结果；IF 请求或映射失败，THEN THE SYSTEM SHALL 报告失败而非伪装为空结果。
- **AC-11** — WHEN 用户切换或保存联网搜索服务商，THE SYSTEM SHALL 保留其他服务商配置，且不改变网页读取工具设置。
- **AC-12** — THE SYSTEM SHALL 限制自定义搜索的配置和测试能力给现有联网搜索设置中有相应权限的用户；测试预览及映射结果须对当前请求中已知密钥及可明确生成的常见编码形式进行脱敏，错误提示不得包含密钥、上游错误正文或请求 URL 查询串。保留原始响应预览交互；不可信上游对密钥任意变形、拆分或回显未知秘密可能无法识别，用户已接受此残余风险。
- **AC-13** — WHEN 搜索接口需要除搜索词外的其他受支持参数，THE SYSTEM SHALL 允许管理员为这些参数配置固定值并在测试及实际调用时使用。

- **AC-14** — 管理员无需新增搜索专用环境变量，即可在界面导入、配置、测试和保存自定义搜索；多实例及后台执行读取同一系统密钥，旧凭据升级后仍可用。

## 边界

- 搜索结果应为可映射的 JSON 列表；仅有总结文本而无网页结果的服务不在首版范围。
- 搜索结果缺少有效链接时，不得作为有效网页引用展示。
- 发布版本为 v3.1.0-beta1，F017。
