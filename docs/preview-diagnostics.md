# 企业微信文件预览诊断

909 分支的只读诊断功能，默认关闭，不修正或重置预览状态。

## 客户使用

1. 部署包含本次修改的前端镜像。
2. 在工作台内打开「设置 → 通用」，开启「文件预览诊断」，然后返回知识空间；无需修改企微嵌入地址。
3. 确认右上角出现「文件预览诊断已开启」，先正常打开、关闭一次文件预览，然后等待或切到企微后台，按原操作复现。
4. 出现点击无反应时不要刷新或退出。再点一次文件名、切换空间并点一次文件名，随后点「导出诊断」。
5. 发送 JSON 文件；如果企微无法下载，点击导出后下方文本框，选中复制记录发给支持人员。
6. 点击「关闭诊断」或在通用设置关闭开关，停止采集并清除内存记录和启用标记。

启用标记只存当前窗口的 sessionStorage，跨空间有效，24 小时后不再自动启用。记录保存在页面内存，最多保留最近 300 条，刷新会丢失；没有后台上报，也不采集文件名、正文、预览链接、令牌或错误消息全文。仍含文件/空间 ID 和设备 UA，按内部诊断资料处理。

## 判读

- `capture.pointerdown` / `capture.click`：实际点击目标、该坐标的顶层元素、是否位于文件行。
- `preview.state` / `route.state`：点击后预览参数及抽屉开关是否更新。
- `drawer.dom.*`：状态改变后 300 / 1500ms 的弹层结构、位置、透明度和 pointer-events；`previewDrawer=true` 标识文件抽屉。
- `preview.request.started/succeeded/failed`：是否挂载预览页并开始请求，失败时记录 HTTP 状态及错误类型，不记录响应正文。
- `visibility.changed` / `window.focus` / `page.show`：企微后台恢复、窗口焦点及页面恢复时的快照。
- `runtime.error/rejection`：异常类型，错误全文脱敏。

先比较同一次点击的上述链路在哪一步中断；缺少后续事件不等于已证明某个根因。捕获事件不能证明 React 业务处理器已执行，DOM 快照也不能证明企微原生合成层正常。

本地前端测试、类型检查与构建按项目约定未执行，需由镜像构建/CI 验证，并在客户企微复现采集。
