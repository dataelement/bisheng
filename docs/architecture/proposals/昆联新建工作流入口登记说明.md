# 昆联新建工作流入口登记说明

用户从昆联项目页点击「新建 Workflow」，在毕昇完成授权、新建工作流并进入编辑画布。按钮登记地址、双方配置项和验收步骤如下。正式联调域名、允许登录的昆联 Workspace 和已授权测试账号待填写。

| 登记项 | 毕昇提供的信息 |
| --- | --- |
| 工作流平台浏览器 Origin | 填写用户浏览器可访问的毕昇 HTTPS Origin，格式为 `https://<毕昇联调域名>`。 |
| 新建 Workflow 页面路径 | `/build/apps?kunlian_workflow=new`。有创建权限的用户打开后，毕昇自动弹出新建表单。提交成功后进入 `/flow/<工作流ID>`。 |
| 项目参数名与实际值 | 无。URL 中的 `kunlian_workflow=new` 是新建标记。昆联 Workspace 用于授权校验，工作流所属租户由毕昇会话确定。 |
| 首次登录回跳规则 | 从昆联打开下方 SSO 入口，由毕昇网关发起授权。授权成功后回到 `/build/apps?kunlian_workflow=new`，保留新建标记，租户归属按授权后的会话确定。已有正确租户的毕昇会话时，可直接打开新建页面路径。 |
| 完整实际示例 | 待正式联调后填写实际入口 URL、测试 Workspace、毕昇租户和创建结果。 |

## 接入准备

| 负责人 | 配置项 | 完成条件 |
| --- | --- | --- |
| 毕昇 | 对外联调 Origin | 提供昆联用户浏览器可访问的 HTTPS Origin。该地址同时提供工作流前端和毕昇网关入口。 |
| 毕昇和昆联 | SSO 客户端与回调 | 确认用于毕昇的昆联客户端及允许的 Workspace。昆联登记授权回调 `https://<毕昇联调域名>/api/kunlian/callback`，毕昇网关配置相同的 Origin 和回调地址。 |
| 昆联 | 测试账号和 Workspace | 提供一个可登录的联调账号，确认其授权令牌中的 `workspace_id`。如需验证拒绝行为，再准备一个超出授权范围的测试账号。 |
| 毕昇 | 测试租户与创建权限 | 为联调租户启用创建入口并准备所需存储，确认测试账号登录后进入预期毕昇租户，具备访问应用开发页面和创建工作流的权限。 |
| 昆联 | 项目页按钮 | 将毕昇提供的完整入口 URL 配置到「新建 Workflow」按钮，用浏览器顶层页面打开。 |

## 昆联按钮登记地址

昆联项目页统一使用下方入口即可发起授权并保留新建目标。将域名替换为毕昇提供的联调域名。

```text
https://<毕昇联调域名>/api/oauth2/kunlian?return_to=%2Fbuild%2Fapps%3Fkunlian_workflow%3Dnew
```

`return_to` 的原始值为 `/build/apps?kunlian_workflow=new`，作为查询参数编码一次。该值使用毕昇站内路径，回跳范围需允许 `/build`。页面地址和网关地址使用同一个 Origin。

已有正确租户的有效毕昇会话时，也可直达新建页。

```text
https://<毕昇联调域名>/build/apps?kunlian_workflow=new
```

## 用户操作与回跳流程

1. 用户从昆联项目页点击「新建 Workflow」。浏览器访问毕昇网关的 `/api/oauth2/kunlian`，网关保存新建目标并跳转昆联授权页。
2. 昆联完成授权后，通过浏览器回到毕昇的 `/api/kunlian/callback`。浏览器已有可复用的昆联会话时，是否需要再次输入账号密码由昆联授权策略决定。
3. 毕昇校验本次授权，检查昆联租户和 Workspace 是否在允许范围内，并根据昆联用户及租户绑定建立毕昇会话。
4. 网关回跳 `/build/apps?kunlian_workflow=new#kunlian-login`。毕昇前端处理会话提示后，地址栏保留 `/build/apps?kunlian_workflow=new`。有创建权限的用户会看到「创建工作流」窗口。
5. 用户填写名称并点击「创建」。毕昇在当前会话所属租户创建工作流和初始版本，返回工作流 ID。浏览器进入 `/flow/<工作流ID>` 编辑画布。

## Workspace、租户与入口参数

| 字段 | 来源 | 作用 |
| --- | --- | --- |
| `workspace_id` | 昆联授权令牌 | 毕昇检查它是否在允许名单中，并核对令牌内省结果。昆联提供的是实际授权值。 |
| 毕昇 `tenant_id` | 毕昇根据昆联租户及用户绑定建立的会话 | 决定工作流创建后的租户归属。联调时核对测试账号实际进入的租户。 |
| `kunlian_workflow=new` | 新建页面 URL | 打开新建表单，提交由用户在毕昇页面完成。 |

因此，按钮只配置入口 URL。联调人员分别确认授权允许的昆联 Workspace，以及该测试账号在毕昇的租户归属。

## 联调验收

| 验收场景 | 操作与预期 |
| --- | --- |
| 首次访问 | 在没有毕昇会话的浏览器里点击昆联按钮。完成授权后直接看到新建表单，地址保留 `kunlian_workflow=new`。 |
| 已有毕昇会话 | 使用属于预期租户的有效毕昇会话访问直达地址，打开新建表单。 |
| 创建与归属 | 输入名称并提交。确认进入实际工作流 ID 对应的画布，返回列表可找到该工作流，并核对创建人和租户。 |
| 权限拒绝 | 使用缺少创建权限的测试账号，确认无法通过入口创建。超出允许 Workspace 的账号在授权阶段被拒绝。 |
| 联调记录 | 记录实际入口 URL、测试 Workspace、毕昇租户、创建出的工作流 ID 和页面结果。 |

如果回到应用列表但没有弹出表单，先检查地址栏中的 `kunlian_workflow=new` 和当前账号的创建权限。如果表单可打开但提交提示「登记不可用」，由毕昇检查当前测试租户是否启用了该入口。
