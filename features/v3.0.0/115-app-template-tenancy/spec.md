# F115：工作流与助手模板租户隔离及管理员管理

**所属版本**：v3.0.0
**优先级**：P1
**关联需求**：shanghang 于 2026-11-02 在本会话提出并确认：模板仅当前租户可见；仅全局管理员、当前租户管理员可增删，修改与排序同样限制；普通用户保留查看、使用能力；历史模板不自动复制。
**状态**：需求口径及 spec 已由 shanghang 于 2026-11-02 在本会话确认。
**依赖**：现有租户上下文、全局管理员与当前租户管理员身份能力、应用模板及应用创建能力。

## 1. 用户故事与范围

作为租户用户，我希望只看到自己租户的工作流与助手模板，以免混用其他租户的内容。

作为全局管理员或当前租户管理员，我希望管理当前租户的工作流与助手模板，以便为租户维护可复用的应用。

本次纳入模板列表、详情、使用、从应用新增模板、删除、修改和排序，以及页面与直接请求两种访问方式的权限一致性。

本次不提供跨租户共享、复制、迁移或批量分发模板，不自动给子租户补发根租户的历史或预置模板；不改变工作流、助手本身的授权规则，不涉及任务模式 PPT 模板管理。

## 2. 验收标准

- **AC-01** — WHEN 用户查看工作流或助手模板列表、搜索结果或详情，THE SYSTEM SHALL 仅展示当前租户的模板；子租户不得看到根租户或其他子租户的模板。
- **AC-02** — WHEN 全局管理员切换管理租户后查看或管理模板，THE SYSTEM SHALL 仅操作所选租户的模板；未切换时仅操作当前默认租户的模板，不提供全租户混合列表。
- **AC-03** — WHEN 全局管理员或当前租户管理员新增、删除、修改或排序本租户的工作流或助手模板，THE SYSTEM SHALL 允许操作；仅担任其他租户管理员不构成当前租户的管理资格。
- **AC-04** — WHEN 普通用户查看或使用当前租户模板，THE SYSTEM SHALL 保留其原有查看和使用能力；使用模板创建应用仍须满足原有应用创建权限。
- **AC-05** — IF 用户不是全局管理员或当前租户管理员，THEN THE SYSTEM SHALL 隐藏模板新增、删除、修改、排序和管理入口，并拒绝直接请求的写操作；持有“创建应用”权限也不得获得模板管理能力。
- **AC-06** — IF 请求指向其他租户的模板，THEN THE SYSTEM SHALL 拒绝读取、使用、删除、修改或排序，不暴露模板内容、不改变目标模板；此约束同样适用于全局管理员在当前租户范围内的操作。
- **AC-07** — WHEN 管理员新增模板，THE SYSTEM SHALL 将其归属当前租户；请求者不得通过指定其他租户使模板写入该租户。
- **AC-08** — WHEN 管理员从应用新增模板，THE SYSTEM SHALL 同时支持工作流与助手，且仅允许使用当前租户内有权读取的源应用；跨租户来源或无权读取的来源须拒绝。
- **AC-09** — WHEN 不同租户分别创建同名模板，THE SYSTEM SHALL 允许分别保存；当前租户内保留原有名称去重规则；排序仅影响当前租户的模板。
- **AC-10** — WHEN 上线本改造，THE SYSTEM SHALL 保留历史模板的原租户归属及内容；根租户历史和预置模板仅根租户可见，不自动复制到其他租户。
- **AC-11** — IF 多租户部署中无法确定当前操作租户，THEN THE SYSTEM SHALL 拒绝模板访问与管理，不返回全部租户模板，也不将新增模板静默归入其他租户。
- **AC-12** — WHERE 多租户功能关闭，THE SYSTEM SHALL 以默认租户提供模板功能，仍维持管理员管理、普通用户查看和使用的权限边界。
- **AC-13** — WHEN 用户从本租户模板创建应用且模板包含报告文档等附属内容，THE SYSTEM SHALL 保留既有可用能力；其他租户模板不得成为取得其附属内容的授权依据。

## 3. 边界情况

- 空租户展示空模板列表，不借用根租户模板填充。
- 不存在及不属于当前租户的模板，均不得返回模板内容或产生写入效果。
- 权限或租户范围发生变化后，后续请求按当前身份与范围重新判定，不能依靠旧页面继续操作。
- 删除模板不删除源工作流、源助手或已经由模板创建的应用。
- 新增失败不得留存模板；拒绝修改、删除或排序时原数据保持不变。
