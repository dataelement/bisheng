## 本机联调：真实模型（2026-11-13）

同一套本机环境，改接真实的 OpenAI 兼容模型网关（Callum 提供的网关地址与 Key；Key 只存在本机测试库的模型配置里，未写入任何仓库文件）。每次调用的 token 数是厂商实际返回的；核对脚本不读调用自己的价格快照，而是用后台配置的模型价格、积分单价和汇率独立重算，再与账本逐条比较。积分单价 0.01 元，汇率 7.2。

|---|---|---|
| 网页日常对话两轮 + 标题生成 | deepseek-v4-pro（9 / 0.3 / 27 元，价格表带出） | 4 次调用全部一致；其中一次输入 1,370、缓存命中 1,024、输出 97，扣 0.60402 积分 |
| 美元模型 | gpt-5.6-luna（0.2 / 0.02 / 1.2 美元） | 输入 1,024、输出 26 → 0.0017 元 = 0.16992 积分，一致；快照记录汇率 |
| 免费模型 | kimi-k3（不在价格表，默认 0） | 记 1 条调用，扣 0 |

| 知识库文件解析（生成摘要） | deepseek-v4-pro | 不计费（不在本特性计费范围），账本无记录 |
