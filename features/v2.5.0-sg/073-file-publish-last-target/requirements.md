# 发布文件记住上次目标路径

- Feature ID: `073-file-publish-last-target`
- Status: `implemented-local-verified`
- Created: `2026-10-14`
- 用户已确认：跟随账号跨设备同步；使用现有 `user_link`；不用考虑租户。

## 范围

按账号和源库发布层级保存最近一次成功提交申请的目标库、目录。三个独立分组为个人→团队/科室、团队/科室→部门、部门→公共。同层级源库共享记录，团队与科室共用向部门发布分组。根目录的目录 ID 为空。

复用 `user_link`，不新增表、字段、迁移或租户分组。账号只取服务端登录态。目标恢复与实际提交仍保留既有权限、层级及资源有效性校验；用户取消租户分组不改变业务访问权限。

## 需求与验收

| Requirement | 行为 | Acceptance | 验证 |
|---|---|---|---|
| REQ-1 | 当前账号、三类发布分组独立存储，跨设备读取 | AC-1 三类互不覆盖，不同账号隔离；同账号不因租户不同拆分；其他 user_link 类型不受影响 | 仓储/API 隔离及独立客户端测试 |
| REQ-2 | 成功接受申请后更新最近记录 | AC-2 pending/pass 保存，取消、失败和配置异常不保存；保存失败不把已受理申请改为失败 | 提交集成测试 |
| REQ-3 | 打开弹窗恢复有效目标，展开完整当前目录路径 | AC-3 根目录、多级目录自动选中，提交携带正确目标 ID；不恢复版本和理由 | 弹窗与目录树集成、浏览器验证 |
| REQ-4 | 实时校验旧目标并处理服务故障 | AC-4 无效库回默认库，无效目录回该库根目录并提示；偏好服务不可用仍可手动发布 | 参数化负向测试 |
| REQ-5 | 旧异步结果不覆盖新弹窗，保留共享组件兼容性 | AC-5 关闭/切文件/切账号后不接收旧恢复结果；分享目录树正常 | 延迟响应及分享回归 |

## 风险与回退

只写当前用户三个专用类型，保存时锁用户，在事务中合并同分组重复项；不修改收藏/置顶等类型。偏好不代表审批最终执行成功。回退应用代码即可停用此功能，偏好记录可保留，不影响业务数据。不提交、不推送、不部署，不修改线上数据。
