# 登录参与占比口径修正

Status: Locally verified

## 已确认需求

- REQ-01：全员参与占比 = 期间登录去重用户数 / 截至期末累计登录去重用户数。按日、周、月、年或整个筛选区间均按此计算；分母没有查询开始日期下界。
- REQ-02：分子与分母使用相同人员/组织筛选，只读取 participation 来源且 logged_in=true 的记录；重复登录、跨天登录按 user_id 精确去重。分母为零返回零。
- REQ-03：累积登录人数（原“实际登录人数”，`logged_in_employee_count`）按北京时间自然日和用户 ID 去重后跨天累加；同一用户一天登录 5 次计 1，最近 7 天中登录 5 天计 5。图表与导出均采用此口径，导出每行代表一个用户的一天登录。参与占比的明细仍为期间登录的去重人员；全员总数、实际登录次数及其他数据集不改变。
- REQ-04：不执行生产写入、不重建索引、不恢复此前贮藏内容。历史完整性受现有参与度索引中登录事实覆盖范围约束。

## 验收

| ID | 结果 | 验证 |
|---|---|---|
| AC-01 | 查询起日前已登录用户进入分母，未来首次登录用户不提前进入分母 | 服务层回归 |
| AC-02 | 活跃用户和参与度分子跨天按人去重；累积登录人数同人同日计一次、跨日累加，支持日/周/月/年/整段及非连续日期筛选 | 参数化回归 |
| AC-03 | 未登录名单、新增/活跃来源不混入，业务筛选不丢失 | ES 查询边界回归 |
| AC-04 | 零登录日为零，空分母为零；北京时间月/周边界正确 | 时间边界回归 |
| AC-05 | 图表路由和旧数据集入口一致；累积登录人数导出按用户和登录日期去重，其他人数明细仍按用户去重，其他指标保持原路径 | 模块回归 |

用户已在会话确认日口径和期间口径，本轮按该范围实现。

2026-10-23 用户明确更正累积登录人数为每天去重后跨天累加，本次指令作为该局部修正的口径确认，取代此前 REQ-03 的整段按人去重；参与度仍为活跃用户数 / 全员有效用户数，不使用登录人天数作分子。
