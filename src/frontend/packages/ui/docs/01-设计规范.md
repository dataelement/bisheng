## 1. 圆角 Radius → 已迁出

2026-07-23 起圆角规范独立成文，见 [基础-圆角与阴影规范.mdx](基础-圆角与阴影规范.mdx)：八档阶梯 + 四条使用原则（2026-07-31 收拢命名）——**尺寸定档**（控件档 4/6/8px 随尺寸档走、容器档 12/16/24/32px 随容器大小走、胶囊用 full）、**同级同档**（同一界面相同重要程度的模块圆角一致）、**嵌套同心**（内层 = 外层 − 内边距）、**贴边归零**（全屏/贴底容器贴边侧直角）；**弹窗定 16px**（8 vs 16 之争就此了结，A 套 8px 列为待迁移旧值）；禁任意值，存量归并映射见其附录 A。本节旧内容作废，以新文档为准。

## 3. 阴影 / 投影 Shadow → 已迁出

2026-07-23 起阴影规范独立成文，见 [基础-圆角与阴影规范.mdx](基础-圆角与阴影规范.mdx)：只留两档——浮层投影 `0 2px 16px -2px rgba(0,23,66,0.10)`（下拉/气泡）与模态投影 `0 0 16px 0 rgba(3,7,117,0.05)`（弹窗/抽屉），两档取值即下拉与弹窗基准组件已落地值，一律搭配 1px 边框、静态区块不加投影、禁散写 `shadow-*`。本节旧的「三种现状 + 两档建议」作废，以新文档为准。
