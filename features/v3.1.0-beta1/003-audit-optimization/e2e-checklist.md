## Platform 前端

### AC-01 / AC-03: 五个动作和模块归属
- [ ] 以管理员打开 `/log` 的系统操作
- [ ] 操作行为里能看到：修改沙箱配置、关联文件版本、设置文件主版本、删除历史文件版本、忽略相似文件建议，文案不是英文枚举
- [ ] 选「系统」，操作行为含修改沙箱配置和工具动作，不含知识空间动作
- [ ] 选「知识库」，操作行为含四个文件版本动作，不含知识空间动作

### AC-04 / AC-26: 切换与重置
- [ ] 先选一个模块和一个操作行为，再换模块，操作行为被清空
- [ ] 选好组织后点重置，组织和操作行为清空，列表仍只含当前账号能看的记录

### AC-10 / AC-21 / AC-23: 组织列和组织面板
- [ ] 三个页签都有组织列。历史记录显示「未记录」，无主部门显示「无所属部门」，系统触发显示「不适用」
- [ ] 组织面板可搜索部门名称或编号，多选，默认勾选「包含下级部门」
- [ ] 已归档部门单独列出并标「已归档」
- [ ] 租户管理员看得到「无所属部门」「未记录」；部门管理员和菜单角色看不到这两项
- [ ] 点「确定」后列表不变，点「查询」后才按组织过滤

### AC-14 / AC-15 / AC-16: 非管理员范围
- [ ] 部门管理员只看到所管部门及下级（含路径上已归档部门）的记录，看不到「未记录」「无所属部门」「不适用」
- [ ] 只有审计菜单的用户只看到本人主部门这一级，不含下级
- [ ] 这两个账号改参数请求其他部门，列表为空

### AC-17: 没有审计菜单
- [ ] 用户组管理员（无审计菜单）打开 `/log` 被拒绝

### AC-29 至 AC-36: 应用使用
- [ ] 用户列后是组织列；使用类型有日常对话、助手会话、工作流会话、深度研究四项（需求原文写「任务模式」，审计页已确认改用产品名「深度研究」；接口筛选值仍是 task）
- [ ] 知识空间问答、频道问答出现在列表里，点详情进日常会话详情
- [ ] 导出的 CSV 含组织列和使用类型列

### AC-42: 应用运行记录
- [ ] 模型调用、能力调用、应用访问三个子页都有组织列和组织面板
- [ ] 导出的 CSV 里，空组织写成「未记录」「无所属部门」或「不适用」
