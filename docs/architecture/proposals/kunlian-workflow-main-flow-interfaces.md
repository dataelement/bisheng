# 昆联 × 毕昇 Workflow 接口确认清单

请昆联提供第一节的接口，并确认第三节的对接方式。第二节仅在对应场景启用时需要提供。表中路径供对照，可采用已有的等价接口。

## 一、昆联必须提供的接口

| 接口 | 调用方 | 用途 | 请昆联提供或确认 |
| --- | --- | --- | --- |
| **授权资源列表** `GET /resources` | 毕昇编辑器 API | 在画布展示当前用户有权使用的 Agent，以及选定纳入的模型、知识库、MCP 工具和 Skill。 | 资源类型标识、权限过滤、分页、资源 ID、名称和状态。请确认可选版本 ID 是否随列表返回。 |
| **资源版本详情** `GET /resources/{resource_type}/{resource_id}/versions/{version_id}` | 毕昇编辑器 API／发布服务 | 读取指定版本的参数结构，配置节点并在发布时固定引用。 | 版本状态、输入输出 Schema，以及详情能否判定当前用户对该版本的 `use` 权限。若列表不含可选版本 ID，请说明现有版本获取方式。 |
| **执行 Agent** `POST /agent-runtime/invoke` | 毕昇 Worker | 按固定 Agent 版本执行，将结构化输出交给下游节点。 | 固定版本和输入字段、`agent_run_id`、输出、错误、同步等待上限、幂等及超时处理。支持异步或等待输入时，请说明受理状态和运行 ID 的返回方式。 |

## 二、昆联按场景提供的接口

| 接口 | 调用方 | 使用场景和用途 | 请昆联提供或确认 |
| --- | --- | --- | --- |
| **查询 Agent Run** `GET /agent-runtime/runs/{agent_run_id}` | 毕昇恢复任务 | Agent 异步执行或跨请求等待输入时，查询状态和终态结果。 | 运行中、等待输入、成功、失败及取消的表示，结果、错误、交互 ID 和表单是否随状态返回。 |
| **提交 Agent 人工输入** `POST /agent-runtime/runs/{agent_run_id}/interactions/{interaction_id}/complete` | 毕昇交互服务 | Agent 等待人工输入时，把用户输入交回同一次 Agent Run。 | 输入 Schema、交互权限、修订号和重复提交规则。 |
| **查询 Agent 待处理交互** `GET /agent-runtime/runs/{agent_run_id}/interactions/{interaction_id}` | 毕昇交互服务 | Agent 状态只返回交互 ID 时，另取表单和当前状态。 | 表单 Schema、当前状态和修订号。 |
| **订阅 Agent 实时进度** `GET /agent-runtime/runs/{agent_run_id}/events` | 毕昇运行服务 | 状态轮询无法满足实时进度要求时，读取 Agent 事件。 | 事件格式、顺序和断线续读方式。 |
| **取消 Agent Run** `POST /agent-runtime/runs/{agent_run_id}/cancel` | 毕昇运行服务 | Workflow 取消时，需要停止昆联侧仍在执行的 Agent。 | 能否取消在途任务，如何区分取消受理、已取消和已完成，以及结果未知时的查询方式。 |
| **模型推理** `POST /model-gateway/chat/completions` 或现有接口 | 毕昇模型节点 | 毕昇节点直接调用昆联模型时使用。 | 模型及版本、输入输出、流式支持和错误格式。 |
| **知识库检索** `POST /knowledge/retrieve` | 毕昇检索节点 | 毕昇节点直接检索昆联知识库时使用。 | 知识库 ID、查询参数、数据权限、命中片段和引用。 |
| **MCP 工具／连接器调用** `POST /capabilities/invoke` 或现有协议 | 毕昇工具节点 | 毕昇节点直接执行昆联工具或连接器动作时使用。 | 工具及版本标识、参数、结果状态和写入幂等规则。 |
| **指令型 Skill 内容读取**，可复用资源版本详情 | 毕昇编辑器 API／Worker | 毕昇需要加载指定版本的 Skill 指令时使用。 | 正文及附件清单能否随详情返回，或通过哪个现有接口读取。 |
| **Skill 附件读取**，路径或签名下载方式待确认 | 毕昇 Worker | Skill 运行需要读取昆联侧附件时使用。 | 按版本获取附件的方式、授权、有效期和支持格式。 |
| **可执行 Skill 调用**，可确认是否复用能力调用接口 | 毕昇 Worker | Skill 由昆联执行且需要毕昇直接触发时使用。 | 调用入口、版本、参数、结果和错误格式。 |
| **资源权限预检** `check` 或等价接口 | 毕昇发布服务 | 资源版本详情无法判定使用权限时，补做发布前校验。 | 资源、版本、动作及允许或拒绝的返回方式。 |
| **跨系统环路检查** `POST /dependencies/cycles:check` 或等价能力 | 毕昇发布服务 | Agent 与 Workflow 可以双向嵌套时，发布前检查递归依赖。 | 检查范围、依赖清单和成环响应，或等价的防环机制。 |
| **接收 Workflow 发布与下线**，登记接口或事件通道 | 毕昇发布服务 | 双方选择由毕昇推送时，昆联接收发布或下线变更。 | 接收入口、版本及状态字段、鉴权、回执和失败补偿。发布与下线可共用同一通道。 |

## 三、只需双方确认的对接方式

| 对接事项 | 双方确认内容 |
| --- | --- |
| **毕昇调用昆联的鉴权** | 确认编辑者、实际运行用户和租户的传递方式。优先确认能否复用 SSO Access Token、适用接口和过期行为。若无法复用，请说明现有服务鉴权及用户委托方式。 |
| **Workflow 工具登记及下线同步** | 选定毕昇推送或昆联拉取。确认工具描述、输入输出 Schema、依赖、版本和上下线状态所需字段，以及同步时效和补偿。 |
| **昆联调用毕昇的身份和版本绑定** | 确认昆联使用的凭据、实际用户和租户、授权范围，及如何明确指定或可靠绑定 `workflow_version_id`。约定与昆联 Tool Call、Trace 的关联字段。 |
| **运行与人工交互对接** | 确认昆联界面需要展示的状态、进度、结果与表单类型，及双方如何关联 Workflow `session_id`、Agent Run 和交互 ID。约定人工等待、断线恢复和取消结果的显示方式。 |
| **页面与身份适配** | 确认昆联页面入口、深链接和定位参数，用户、角色、租户与毕昇项目的映射，以及切换租户时可信的租户来源和权限重校验规则。 |
| **节点支持范围** | 确认哪些资源由毕昇节点直接调用，哪些由昆联 Agent 内部使用。明确指令型 Skill 的正文和附件来源，以及可执行 Skill 的执行方。 |

请回复可用接口的正式路径、测试 Base URL、OpenAPI 或消息 Schema、鉴权方式及预计可联调时间。请提供一个固定 Agent 版本和输入输出样例，覆盖 A 发布、B 按自身权限运行及无权拒绝。启用人工交互或远端取消时，请补对应样例。
