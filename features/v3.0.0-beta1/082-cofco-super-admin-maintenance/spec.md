# 超级管理员运维脚本

用户已确认在现有 `set_admin` 脚本内扩展，不新增页面或管理 API。

- 支持按内部用户 ID 查询、授予、取消超级管理员；执行前显示姓名和人员 ID。
- 保留原有只传用户 ID 即授予的调用方式，提供授予预览。
- 取消默认预览，必须显式 `--apply`；禁止取消首位管理员 `user_id=1`，禁止取消最后一位有效超管。
- 未找到用户时拒绝；已停用用户不能授予，但可以取消；其他角色和租户关系保持不变。
- 同步毕昇数据库与 OpenFGA 超管身份，清理跨租户权限缓存及全局超管缓存，并核验结果。
- 每次执行初始化运行连接，成功或失败都关闭连接；不创建 OpenFGA Store，不发布权限模型。
- 查询发现两边不一致、外部依赖不可用或部分写入失败均返回非零；相同操作可重试修复。

## 验证边界

本次是单模块运维入口的小功能，无页面和 HTTP API 变更。使用真实 SQLite 执行角色查询与修改，
隔离 OpenFGA；使用 FakeRedis 验证精确清理；验证命令行与连接关闭。MySQL/DM8 行锁和真实
OpenFGA 联调留到测试环境验收，不对真实账号自动执行授予或取消。验收时先查询，预览，再对
专用测试用户执行授予与取消，核对数据库、OpenFGA 与业务访问结果；首位管理员仅验证拒绝。
