# 知识空间按文档统计

- Feature ID: `066-dashboard-document-statistics`
- Status: `confirmed-scope`
- Created: `2026-09-21`

## 已确认范围

用户要求看板与 `export_portal_category_usage.py` 的文档去重一致，接受重新导入 ES。
保留个人库筛选；对账时排除个人库。增加被系统化调用知识数、调用比例，预览/下载次数仍统计操作次数。
脚本按上传人当前主组织及子组织选库存，入选知识在同租户全部非个人空间中的调用计入。
本阶段交付本地代码、测试和迁移工具；不推送、部署或操作生产数据。

## 需求与验收

| Requirement | Acceptance | 验证方式 |
|---|---|---|
| REQ-001 同文档引用去重 | AC-001 管理、发布、分享入口计 1；独立上传不按名字/MD5 合并；文档 ID 与文件 ID 不碰撞 | 仓储与统计契约测试 |
| REQ-002 全链路精确计数 | AC-002 分类、组织、空间、时间筛选后计数；跨组总计重新去重，导出条数一致；不使用近似计数或截断后计数 | 后端及前端转换回归 |
| REQ-003 时间口径 | AC-003 总数/调用数截至每个桶结束累计去重；新增按当前筛选范围内首次有效入口时间计数，后续引用不新增；当前库存不能还原已删除历史库存 | 跨日/月与空桶回归 |
| REQ-004 调用覆盖率 | AC-004 当前入选文档任一非个人入口历史预览或下载次数大于零即计 1，调用比例分母与总数相同；个人入口调用不计入；操作次数保持原含义 | 跨组织、个人库、重复动作测试 |
| REQ-005 保留筛选与归属 | AC-005 个人库仍可选；同一文档可出现在多个组织分组，但全局合计只计 1；贡献占比以全局去重总数为分母，各重叠组占比之和可能超过 100% | 多维交叉表回归 |
| REQ-006 库存与脚本对账 | AC-006 排除失效引用、历史版本、软删除、退役空间；统一分类解析规则；相同租户/非个人/上传人范围且同步完成时与脚本一致 | 固定数据端到端对账 |
| REQ-007 安全重建 | AC-007 默认只读；保留原索引的完整备份及历史日统计；新索引导入验证后才切换；不丢操作计数，不改变原日统计 ID，不重复回放；部分失败不得切换 | 迁移成功/失败/重跑测试 |
| REQ-008 持续同步 | AC-008 新上传、引用、版本、组织变更后的增量和全量同步均保持相同身份规则；分页超时/分片失败不能返回成功数字 | 同步、分页与失败路径测试 |

## 边界

- 数据量大时允许查询耗时增加，但不允许近似结果冒充精确结果。上线前必须进行实际数据量压测。
- 不修改知识文件业务数据和访问权限，不重构其他数据集。
- 无法关联到现存文件的历史日记录必须保留并报告；不能猜测文档身份。
- 迁移执行须明确源、目标、备份及暂停写入窗口；未经验证不得清理旧索引。
