## 已确认范围

当前 feat/2.5.0-sg 注册十个 MCP 工具，全部移除 external_id，不作为可选参数保留；显式传入按未知参数拒绝。Token 校验后使用 principal.user 和 principal.tenant_id，角色沿用共享 Token 身份构造，不查询用户当前归属租户，不代理其他账号，不改共享 Token 角色/管理员语义。

空间/文件权限、读写操作者、Owner、配额、来源及异步任务的身份均使用绑定用户与 Token 租户。业务阶段保留租户上下文隔离，禁止 bypass。Token 归属、绑定关系有效性、IP、路由空白名单和限流逻辑不变。原 search_knowledge 和九个知识空间工具均覆盖。

| ID | 角色 | 操作 | 预期结果 |
|---|---|---|---|
| AC-01 | MCP 客户端 | tools/list、无账号调用工具、显式传 external_id | 十工具 schema 不含 external_id；无账号参数可调用，传入被拒绝且不执行领域操作 |
| AC-02 | Token 持有者 | 使用不同绑定用户/租户的 Token 读取或写入 | 只使用绑定身份的正常权限，不能借权；跨租户/无权资源拒绝，写入与任务身份一致 |
| AC-03 | Token 持有者 | 凭证无效、IP/路由/限流拒绝、并发调用或超时/取消 | 保留原鉴权拒绝，执行身份/会话/上下文不串用，审计记录绑定身份且不泄漏凭证 |
| AC-04 | 既有接入方 | 调用原 REST、folder_id 数字字符串及内容/写入工具 | REST external_id 代理保持；MCP 其他业务参数、响应、上传大小和预览权限不变 |
| AC-05 | 接入开发者 | 按使用文档和 SDK 示例调用 | 文档不再要求账号，说明 Token 权限及刷新工具清单；旧代理客户端必须移除 external_id |
