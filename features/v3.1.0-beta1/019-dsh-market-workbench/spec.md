# 企业市场与工作台增量（F019）

版本：v3.1.0-beta1。沿用 [F055 基线规格](../../v3.0.0-beta1/055-enterprise-plugin-market/spec.md) 的身份、权限和租户边界；本目录定义本次 PR 的增量，冲突处以本版本为准。

- AC-01：插件及工作台相同内容重复导入幂等；管理员主动导入同版本不同内容时允许覆盖并更新摘要、元数据和 revision。A→B→A 以最后一次主动导入为准；低版本及身份冲突仍拒绝。
- AC-02：工作台 TGZ 单包压缩体积上限 100 MiB（含边界）；每批最多 50 个，按序串行预览和导入，无独立批次总量上限；单包失败不阻断后续通过项。
- AC-03：工作台 patch 仅静态校验、不执行代码；允许受限 config 和完整匹配的 dshHomePath 表达式，具体边界见 [校验规则](workbench-package-validation.md)。
- AC-04：校验失败保留数值业务码 26205，并提供安全的原因 code、规则、字段和具体提示；区分资源超限、压缩包损坏与内容错误。失败不替换当前版本。
- AC-05：租户管理员二次确认并携带当前 revision 删除工作台；拒绝非管理员、跨租户和过期 revision。删除后列表、详情和旧下载链接不可用，保留记录，不卸载客户端内容；主动重导入可恢复。
- AC-06：桌面端按最新详情中的 SHA-256 校验内容，不能只以版本号或版本 ID 缓存制品。下载或静态校验通过不代表已获安装、启用或离线授权。

接口协议见 [Desktop 工作台接口](desktop-workbench-api.md)，上传和校验设计见 [设计](design.md)。运行与安装仍须单独验收。
