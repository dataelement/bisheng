# F001 统一离线下载与部署

依据：用户确认“联网电脑下载 → 整目录拷贝 → 隔离服务器部署”，批准统一 `deploy.sh download/install`；2026-11-27 补充要求 Gateway 使用 Compose 配置中的镜像并随包交付。按用户明确指定的 `feat/3.1.0-offline-bundle` 基线实施。

## 验收标准

- AC-01：联网电脑仅指定平台版本与目标架构，一条 `deploy.sh download` 命令下载；电脑不要求 Docker，不按本机架构选包。
- AC-02：按固定版本清单自动下载完整包或全部连续分卷，无需目录浏览或探测到 404；缺文件不能提示完成。
- AC-03：支持重新执行跳过已校验文件；凭据通过环境变量或交互输入，不写入交付文件或命令参数。
- AC-04：拷贝完整目录后执行同一脚本 `install`，重新校验、自动解包、导入镜像并禁止联网拉取；分卷不另存合并 tar，重跑保留密钥和配置。
- AC-05：`download --gateway` 下载可选 Gateway 组件；`install --gateway` 通过 license 文件与公开地址配置数据库、共享密钥和 Nginx，再禁止拉取地启动 Gateway 与全栈。
- AC-06：构建端解析发行版本 Compose 配置所指 Gateway 镜像并按目标平台拉取、校验架构、保存归档；不猜测 tag，架构不符则失败。
- AC-07：版本不符、路径越界、缺卷、校验损坏、架构不符或 Gateway 未交付时，在启动服务前明确失败。
- AC-08：发行端只上传清单精确列出的文件，所有文件上传校验成功后才发布固定版本下载清单；上传失败不发布新索引。

范围：Linux 全新单机部署；电脑为 macOS/Linux 或带 Bash/curl/Python3 的 WSL/Git Bash。Docker/Compose、Python3、zstd 等宿主机工具及模型/应用额外依赖另行离线准备，不新增系统软件在线安装或数据库升级功能。
