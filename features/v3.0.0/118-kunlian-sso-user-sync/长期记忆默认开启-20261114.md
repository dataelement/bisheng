# 昆联集成分支：新建助手与工作流的记忆默认开启

日期：2026-11-14。用户裁定，只在 `feat/v3.0.0/118-kunlian-integration` 生效。

F132 的默认是关（spec AC-69、AC-70）。昆联分支改为开：

| 对象 | 位置 | 本分支取值 |
| --- | --- | --- |
| 新建助手 | `bisheng/database/models/assistant.py` `ASSISTANT_MEMORY_DEFAULT` | `True` |
| 新建工作流的开始节点 | `platform/src/util/workflowMemory.ts` `MEMORY_SWITCH_DEFAULT` | `true` |

不受影响的对象：

- 升级前已存在的助手：数据库列的 `server_default` 仍为 0，记忆保持关。
- 升级前保存的工作流：打开时补上的开关仍为关（`ensureMemoryStartGroup` 固定传 `false`）；已上线版本没有开关参数，按关处理。
- 作者仍可在助手设置与开始节点里关闭。

需要注意：F132 设计把"开关默认关"作为告知应用作者可取得使用者记忆的手段之一（spec 第 278 行）。默认开启后，这一告知只靠开关旁的说明文字承担。

从发版线合并 F132 时，这两个常量会出现冲突或被覆盖，合并后要确认仍是开。
