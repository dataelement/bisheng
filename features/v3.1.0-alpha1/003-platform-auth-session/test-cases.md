## 依据与范围

- 已确认规格：[spec.md](./spec.md)，S1，用户于2026-11-27确认；设计：[design.md](./design.md)，D1，同日确认。Access默认30天，Session及Refresh默认90天闲置期限。
- 设计复查：本轮逐项对照D1的期限、接口、Cookie隔离、网关绑定、DSH及SSO边界，未改变确认的预期行为。用例依据列在主表之外。
- 目标版本与构建：v3.1.0-alpha1；实现分支为`feat/3.1.0-alpha1`及手机`fix/mobile-session-refresh`；提测构建 **本地开发与单元已完成、待用户部署集成**。不得把文档分支当成可执行构建。
- 代码核对：只读核对毕昇`572d5ecf77`，手机`6990f73`，桌面`a7a982c`，详见[discovery](./discovery.md)。开发及本地单元验证已完成；实际实现/运行结果见后续验证记录，本文结果不因此改为通过。
- 覆盖范围：30条AC的登录、期限、并发、退出、旧网页、旧DSH、第三方SSO、网关、真机、双DB与发布边界；实际第三方/网关/安装包/DM8验收均未执行。
- 本文只供QA准备和记录业务验证；不生成测试脚本，不代替研发测试或E2E验收，不作为tasks拆分输入。全部结果保持“待执行”；用户随后明确真实集成测试由其处理。
