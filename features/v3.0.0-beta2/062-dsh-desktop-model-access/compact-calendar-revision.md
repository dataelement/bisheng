# Compact usage calendar

## Acceptance criteria

- Tiles use a fixed 12 px square with a 3 px gap. Seven rows occupy 102 px; the surrounding card stays full width and uses compact padding.
- Tiles use borderless fills. Observed zero usage uses the secondary neutral fill, future periods use a lighter muted fill, and missing usage has an amber corner dot. Hover and keyboard focus supply transient outlines without changing tile dimensions.
- The initial view is an annual timeline for the selected user, retaining the current-user default. The timeline ends today and includes at least 53 weeks, growing to fit the container up to 104 weeks. Month labels identify year boundaries, and the actual query dates remain visible.
- Extra width adds earlier complete weeks. Each tile uses real usage in its date range. Empty periods remain zero, missing usage remains unknown, and future periods are distinct.
- Today uses one horizontal row of 24 hourly tiles. The last seven days use one horizontal row of seven daily tiles. The last 30 days and annual history use calendar geometry: seven weekday rows and one week per column. Calendar month labels stay above the tiles and no weekday-label column is reserved. Text stays outside the tiles; full values remain available on focus or hover.
- The chart ends after the grid, with details available through tile tooltips. Daily tile tooltips show the Beijing calendar date and recorded total Tokens. Chinese values below 10,000 use grouped integers; larger values use localized compact units with at most two decimals, e.g. `318.79万 Token`. Hourly tiles retain their time interval. Aggregation, missing-data semantics and timezone remain unchanged. Tooltips are portalled beyond the scrolling grid, with viewport collision padding.
- The current local trial uses five equal-width positive usage bands, with neutral gray reserved for zero. Daily usage spans a fixed zero to 1.2 billion Tokens, with 240 million per band; hourly usage spans zero to 120 million, with 24 million per band. Boundary values enter the higher band, and values at or above the domain ceiling remain in band 5. The tile's aggregation unit determines its scale; changing the selected user, range or maximum preserves the color for the same amount and unit. Full values remain available in the tooltip. Five fills retain the palette's lightest color and softened peak, with existing geometry and sample values kept for direct comparison.
- Existing single-request API contracts and tenant authorization remain unchanged. A history adapter composes at most two non-overlapping requests of up to 366 days; totals, member rows and heatmap share the same actual range. Any failed segment fails the whole view.
- Verify fixed square geometry, compact height, range boundaries, aggregation, cancellation and admin's recorded usage in a local browser. Deployment and authenticated runtime acceptance remain separate.
