# 审计 · 异常文件内容预览

F086｜需求 v1｜2026-11-23。适用于 BiSheng 平台管理端。用户已在本次会话确认需求发现结论；本文记录该范围，不代表设计已确认或代码已交付。

导航：问题与目标 → 范围与流程 → 规则与依赖 → 验收与回滚。

## 1. 背景与问题
审计人员可从异常文件表看到文件名和失败原因，但当前文件名单元格仅展示文本。判断下一步是否重试或删除时，用户希望先查看文件本身，而非再次查看错误备注。

## 2. 目标与指标
判断标准是一次具体操作：对已有正文查看权限且可预览的记录，点击文件名后可不离开列表读到相应内容。基线来自源码（尚无点击入口），不假设线上使用率或耗时。研发验证请求与状态规则，测试岗位验收可见结果；不新增运营指标。

## 3. 范围
本次仅覆盖平台「审计 → 异常文件」文件名列；对象为列表已有记录，沿用页签准入和文件预览授权。排除门户、下载入口、重新解析、格式转换、扩权及公共接口变化。仅本期交付，无后续分期承诺。

## 4. 用户流程
点击文件名 → 当前页显示以该文件名为标题的只读弹窗 → 查看内容或获知不可预览 → 关闭并继续原列表操作。文件重名时以所点记录为准。

## 5. 功能需求
REQ-01（本期唯一必做项，建议 P0）：文件名触发对应文件内容预览，不以文件状态、失败原因或上传人替代正文。输入仅使用所选记录已有的空间标识、文件标识（数字）及文件名（文本），均来自列表，无新输入、默认值或长度限制。

| 条件 | 结果 |
|---|---|
| 有预览权限且内容可用 | 展示当前文件正文，不导航、不自动下载 |
| 无正文权限 | 沿用现有拒绝处理，不显示正文、不尝试其他读取途径 |
| 内容缺失、不支持、请求失败或超时 | 展示不可预览反馈；可关闭，并可重新点击 |
| 等待期间关闭或重开其他文件 | 关闭保持有效，旧响应不覆盖新文件 |
| 列表无数据 | 没有预览入口，不新增占位操作 |

## 6. 非功能与依赖
以既有文件预览权限与格式支持为上限；列表展示不预取文件内容。复用已有服务及其正常阅读审计，不修改接口、权限、依赖或配置；无新容量指标。开发期不以静态检查替代实际渲染验收。

## 7. 数据与埋点
预览为临时读操作，不改文件、列表记录和选中状态，不另存正文或签名链接，不新增埋点；不取消现有服务的审计副作用。

## 8. 验收条件
格式验收以[设计 §3 第4项](design.md)的拟定规则为准，随本次设计确认。例如有 PDF 表示时展示 PDF；只有可读 DOCX 原件时展示纯文本；只有无法内嵌的旧版 DOC/PPT 原件时提示不可预览。此处是待确认的验收细化，不代表新增转换服务。

| ID | 角色／前提 | 操作 | 预期结果 |
|---|---|---|---|
| AC-01 | 有正文权限，文件可预览 | 点击异常文件名 | 在当前页看到所点文件的标题和正文 |
| AC-02 | 可看列表，但无正文权限，或文件不可用 | 点击文件名 | 无权限、格式不支持、内容缺失或请求失败时不显示正文或旧文件，有相应反馈且可退出 |
| AC-03 | 审计人员已筛选、翻页、勾选 | 打开并关闭预览 | 不自动下载，不触发重试／删除，筛选、页码和勾选保持；既有单条和批量操作不变 |
| AC-04 | 审计人员先打开 A | 关闭后打开 B，使 A 晚于 B 返回 | 弹窗只能展示 B；关闭后迟到的结果不能重新打开弹窗 |

## 9. 风险与回滚
异常文件可能没有可用预览，能看审计记录也不代表能看正文；失败按 AC-02 处理，不以扩大权限、后台重新转换或自动下载兜底。若出现错显、越权或列表操作回归，撤回本次局部前端入口；无数据迁移或回填。

## 10. 变更记录
