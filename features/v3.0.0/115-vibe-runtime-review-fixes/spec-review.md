## 本轮自审补齐

1. 显式登记 F114 AC-33 的限定审批摘要例外，防止将“审批人可读”误扩展为通用授权目录读取资格。
2. 明确“当前授权范围”与“此刻运行可达”不同：草稿、待审批和下线本身不清空已生效授权，否则首发审批永远无法准确表达范围。
3. 明确负责人已失效且无其它有效普通授权时的空态；完整查询失败或部分结果不能宣称“仅负责人可见”。

以上是对已确认 D3 边界的明晰化，不新增资源移交、授权写入或发布行为。
