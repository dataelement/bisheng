# 从零创建（不用内置模板时）

只在两种情况下走这条路：用户明确要求自由设计；或五套内置模板都明显不贴合主题。
技能目录不可见时也走这条路（见 `environment.md`）。SKILL.md §2 的大纲要求、§6 的自检照常适用。

## 步骤

1. **定结构**：大纲写到 `scratch/outline.md`（格式同 SKILL.md §2）。10–15 页是常见规模。
2. **定视觉**：按 `design-zh.md` 选一套贴题的配色、一个贯穿全篇的视觉母题和版式节奏。
3. **写构建脚本**：用 `write_file` 写到 `scratch/build_deck.py`。python-pptx 的写法读 `pptx-cookbook.md`
   （画布尺寸、文本框、项目符号、表格、原生图表、图片、中文字体，都有可直接抄的片段）。
4. **执行**：`subprocess.run([sys.executable, "scratch/build_deck.py"], ...)`，不要写 `python scratch/...`。
5. **自检并返修**：SKILL.md §6。返修用 `edit_file` 定点改脚本再重跑。

## 排版底线（细则见 design-zh.md）

- 标题 32–44pt 加粗，小标题 20–24pt，正文 14–18pt，注释 10–12pt；正文不要小于 12pt。
- 每页留 ≥0.5 英寸边距；内容块之间 0.3–0.5 英寸，全篇统一。
- 除封面外，每页都该有一个视觉元素（图表 / 图形 / 表格 / 图片），不要通篇「标题 + 三行要点」。
- 正文左对齐，只有标题居中。
- 字体写「微软雅黑」「黑体」「等线」这类用户端一定有的中文字体，并且同时写 `<a:ea>`（用 `pptx_helpers.set_font`）。
- 不要自己加装饰线（标题下划线、页眉色带、侧边色条），用留白和字号层级做分隔。
- 文字绝不允许溢出容器；放不下就精简文案或换版式，不要一味缩字号。
