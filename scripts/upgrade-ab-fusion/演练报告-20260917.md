| `env.sh` 写死 APPLY=0 覆盖 CLI | `APPLY="${APPLY:-0}"` |

| 消息期望含无会话 300 条 | 期望改为 dump 会话内消息 |
| MinIO while-read 被 ssh 吸走 | fd 3 + stdin `/dev/null`；作业可从 dump 重建 |

| ES 401 | 读 `BS_ELASTICSEARCH_SSL_VERIFY` |
