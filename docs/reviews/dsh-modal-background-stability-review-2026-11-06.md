## 根因与处理

- Desktop 扩大全窗口后仍保存原内容区，但网页公共壳继续使用 `100vw/100dvh`；旧尺寸保护只在聊天页按需 CSS 中。实际复现测得原 890×760px 区域扩到 1130×800px 后，背景页头横移约 49.41px，底部按钮下移 40px。
- 尺寸保护上移至 MainLayout 常驻 CSS，背景宽高和滚动壳持续使用原区域；Portal 继续覆盖原生窗口。公共 4% 留白、桌面样式、表单单双栏和紧凑页面改按内容区域判断。
- 宽度 hook 在已准备的桌面内容区域使用有效宿主预留宽度，兼容旧宿主的弹窗标记。普通网页、无尺寸的旧宿主、非宽度能力查询保留浏览器结果；MediaQueryList change 事件语义和清理逻辑保留。
- 后续逐帧排查确认闪烁来自宿主：原生视口先扩展，定位与透明背景后异步切换；弹窗先在内容区绘制再跳到窗口中心。宿主改为常驻内容区域、CSS 同步定位与持续透明背景；preload 在绘制前标记模态状态，扩展未完成时暂缓 Portal 绘制。开关不再异步替换区域样式。
- 没有关闭模态行为或滚动锁，没有修改认证、权限、保存行为或共享 UI 默认外观。
