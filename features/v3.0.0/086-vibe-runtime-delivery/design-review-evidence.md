## 3. 自审中已消除的设计问题

| 问题 | 修正 | 核对依据 |
| --- | --- | --- |
| 错把16123记为容量码 | 更正16123为runtime不支持、16125为容量不足 | common/errcode/app_factory.py的实际Code定义 |
| 全局环境接口放在apps下可能与动态路由冲突 | 使用独立runtime-profiles/runtime-artifacts顶级前缀，增加注册匹配检查 | resource_tier.py现有“静态路由被apps动态路由吞掉”的注释和实际注册顺序 |
| 完整镜像可能误走源码语言模板闸口 | image模式明确按镜像运行契约，不按源码SUPPORTED_RUNTIMES过滤 | 现有manifest_validator/模板门，spec AC-12 |
| 日志/状态消费合同不充分 | 补只读manager接口、backend范围校验和原F054封装 | 现有只读API及原F054消费 |
| npm/sdist安装钩子与源凭据边界 | 下载禁脚本、固定构建依赖、安装编译阶段撤去源凭据与传输票据 | spec AC-25、AC-29、AC-53的输入/离线/身份要求 |
