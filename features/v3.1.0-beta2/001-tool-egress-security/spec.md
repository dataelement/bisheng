## 兼容性与非目标

两个入口固定公网，不提供出站配置或私网例外，不需要配置迁移。正常内部工具执行不接入该策略，无需迁移已保存工具。内容解析不变。

正常执行保留已知同族 SSRF/出站风险，本补丁不覆盖，不宣称工具全局安全。同步安全传输不在本次交付范围；MCP、知识预览、网络隔离、分布式限流及普通用户测试权限恢复另行评估。
