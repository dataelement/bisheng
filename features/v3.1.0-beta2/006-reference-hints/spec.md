# Feature: 引用关系辅助提示

**状态**：2026-11-23 用户已确认原 13 条规格，并在评审修复中明确 AC-14 的旧应用边界；用户已授权开发，当前实现及验证见 verification.md。
**关联 PRD**：[本次用户需求及代码核查记录](../../../docs/reviews/reference-simplification-beta2-discovery-20261123.md)。用户最新澄清优先于该记录中引用的历史背景建议。
**优先级**：P1。
**所属版本**：v3.1.0-beta2。
**依赖**：沿用 F118 既有引用能力及各业务功能，不依赖 F118 升级账本完成或覆盖证书。

## 1. 用户故事与范围

作为资源管理者，我希望删除资源前了解已有引用及影响，并自行决定是否继续删除；引用功能不影响正常业务操作。

作为业务使用者，我希望正常查看、编辑、保存和使用工作流、助手及知识空间等资源，引用同步失败由后台重试处理。

作为升级人员，我希望沿用已有引用数据，不因本次简化额外迁移数据或重新验收历史升级。

本次纳入：

- 保留模型、知识空间及已有资源引用，提供删除影响提示。
- 知识空间元数据不纳入引用关系，解除元数据操作对引用索引的间接依赖。
- 解除引用功能对业务读取、编辑、保存、使用、发布、删除、租户初始化的准入限制。
- 业务修改后的引用异步同步与失败重试；复用原有数据，允许同步滞后。

本次排除：

- 引用强一致、完整性签证、引用变化冻结或基于引用变化的反复确认。
- 为引用增加业务事务待修账本、可靠补投子系统或治理面板。
- 新增引用类型，重建一套引用存储，要求迁移或全量回填后才能使用本功能。
- 修改权限规则，自动清空引用方配置或自动替换缺失模型。

## 2. 验收标准

### 2.1 引用范围与提示

- **AC-01** — WHEN 已有业务配置使用模型或知识空间，THE SYSTEM SHALL 保留这些关系的查询与提示能力，包括知识空间使用的 Embedding 模型，不因引用辅助化取消模型引用。
- **AC-02** — WHEN 用户查看或修改知识空间的元数据字段定义及元数据值，THE SYSTEM SHALL 不将这些元数据作为资源引用来源或目标，且不要求引用索引或覆盖验收就绪。
- **AC-03** — WHEN 用户删除资源且查询到已有引用，THE SYSTEM SHALL 展示引用影响提示，并允许具有删除资格的用户确认后继续删除；已有删除入口不得仅因存在引用而拒绝执行。
- **AC-04** — IF 引用查询失败、引用索引缺失或同步滞后，THEN THE SYSTEM SHALL 不据此阻止删除；查询失败时提示无法获取引用，查询结果不得表述为经过全量一致性证明的无引用。
- **AC-05** — WHEN 用户确认删除后引用关系发生变化，THE SYSTEM SHALL 不仅因引用变化拒绝删除或要求重新确认；资源自身的权限、范围和状态变化仍按该业务规则处理。
- **AC-06** — WHEN 展示引用提示，THE SYSTEM SHALL 遵循原有租户及资源可见范围，不向操作者披露其无权查看的关联业务详情。

### 2.2 主流程独立与异步更新

- **AC-07** — IF 引用记录缺失、过期、不一致或尚未同步，THEN THE SYSTEM SHALL 不据此拒绝正常业务的查看、编辑、保存、读取配置、使用或发布；合法零引用来源同样不需要先登记才能使用。
- **AC-08** — WHEN 业务修改成功，THE SYSTEM SHALL 异步更新其引用关系；引用同步失败时重试，且不回滚已成功修改、不改变业务成功结果、不阻止后续正常业务操作。
- **AC-09** — WHEN 引用同步任务重试，THE SYSTEM SHALL 依据来源当前业务配置更新已有引用记录；来源已删除时移除其失效记录，重复处理不产生重复关系。
- **AC-10** — IF 任意租户存在缺失、残留或未完成的升级账本及引用验收记录，THEN THE SYSTEM SHALL 不因此拒绝其他资源的业务操作、安装或租户初始化；正常业务不要求先修复升级账本。

### 2.3 兼容与业务边界

- **AC-11** — WHEN 已有环境采用本次简化，THE SYSTEM SHALL 继续使用已有引用数据，无须引用数据迁移、全量回填、清空旧表或重做已完成的升级；引用同步是否完成不作为正常业务及开服的额外前提。
- **AC-12** — WHEN 业务自身权限、租户隔离、实际所需目标或处理状态不满足条件，THE SYSTEM SHALL 按原业务规则返回实际原因；引用辅助化不得使无权操作或真实失败被报告为成功。
- **AC-13** — WHEN 被引用的资源删除成功，THE SYSTEM SHALL 保留引用方业务配置原值，不自动切换模型或清空配置；后续实际使用缺失依赖时由对应业务报错，仍允许有权用户查看及修复配置。
- **AC-14** — IF 历史托管应用只有名称声明且原目标身份已经无法确定，THEN THE SYSTEM SHALL 保持查看、编辑及不涉及该能力的功能正常，仅在实际调用该未确定能力时返回目标无法确定的错误；已有原绑定时保留原目标，不按当前名称自动替换。

## 3. 边界情况

- 知识空间本身被其他业务引用、知识空间使用 Embedding 模型，以及知识空间的元数据字段/值是不同对象；前两种引用保留，元数据不纳入引用。
- 元数据处理确实需要访问检索存储或其他业务能力时，仍处理其真实失败；缺少辅助引用记录本身不构成失败理由。
- 引用提示根据当前已有记录展示，允许短暂滞后，不承诺强一致或全量覆盖，也不要求删除流程遍历所有业务原配置。
- 引用异步任务失败与业务自身数据库提交失败分开处理；本功能不为引用同步引入额外事务成功条件。
- 历史账本及真实业务恢复状态保留原有职责，日常引用提示及业务使用不再依赖它们。
- 用户已确认 AC-14：历史应用原身份无法恢复不等于全局引用未就绪；未确定的能力不能被静默替换或省略。一次操作确实需要全部声明时，任一必需目标无法确定可以使这次操作失败，不能因此拒绝无关能力。

## 4. 设计与实现

本规格只定义需求与验收。具体接口、旧表兼容写法、异步任务及重试参数在规格确认后写入设计，不提前引入新表或数据迁移。
