# Feature 昆联 Workflow 编辑与执行直达入口

**Feature ID**: F129
**Status**: Confirmed，用户于 2026-11-11 确认规格及设计；实施进度见 tasks.md
**Created**: 2026-11-11
**优先级**: P1
**所属版本**: v3.0.0
**关联需求**: [本轮需求与已确认版本规则](./discovery.md)
**依赖**: F118 统一身份与会话、F121 工作流管理及发布状态、F048 既有权限体系、毕昇既有工作流编辑与执行能力。

## 1. 目标与范围

昆联用户无需先进入毕昇工作流列表再查找对象，即可通过两类浏览器链接打开指定 Workflow 的编辑页或执行页。用户未登录时，完成昆联 SSO 后仍到达原先指定的工作流和页面；已有符合要求的有效会话时直接进入目标。

**本次纳入**：

- 指定工作流的编辑直达入口及执行直达入口，向昆联交付清楚区分用途的完整链接模板、参数说明和已验证示例。
- 编辑页使用现有画布；执行页使用现有输入、交互和结果展示能力。
- 执行链接使用当前已发布上线版本；发布新版本后链接保持不变，由用户在页面发起运行。
- 登录回跳、目标保留、失败后手动重试及现有权限与租户隔离。

**范围边界**：

- 本次不提供通过浏览器链接指定历史发布版本或草稿执行的能力，也不自动发起业务运行。
- 不新增匿名执行、凭据型分享链接、服务账号代替实际用户、自动授予权限或通过链接切换租户的能力。
- 不新增昆联后端运行接口，不改造已有运行状态机、取消与人工交互协议，不重建编辑器或执行界面。
- 不引入项目／Workspace 映射作为链接可用前提，不新增数据库对象或迁移历史工作流。

具体 URL、参数、数据流及复用代码位置在后续 design 中确定，本规格只约定用户可观察的行为。

## 2. 用户故事

作为昆联中的工作流维护者，我希望直接打开某个已有 Workflow 的画布，以便编辑和管理该工作流，返回时仍能进入毕昇工作流管理入口。

作为昆联中的工作流使用者，我希望直接打开某个 Workflow 的执行页面，以便填写输入、发起运行、处理人工交互并查看结果，无需拥有编辑权限。

作为尚未建立毕昇会话的昆联用户，我希望登录完成后回到刚才选择的工作流和页面；登录失败时能看到原因并重试，而不是反复跳转或被带到其他工作流。

## 3. 业务需求

| ID | 需求 |
| --- | --- |
| REQ-01 | **编辑直达。** 编辑链接唯一指向指定 Workflow 的现有画布。对象可用且用户拥有所需编辑及现有入口资格时允许进入；返回操作进入工作流管理页，并保留既有未保存提醒。 |
| REQ-02 | **执行直达。** 执行链接指向指定 Workflow 的现有使用页，复用输入、运行状态、人工交互和结果展示。是否有编辑权不作为执行资格，仍需满足已有使用权限及入口资格。 |
| REQ-03 | **当前上线版本。** 同一执行链接的新运行使用当时的已发布上线版本；新版本上线后无需修改昆联链接。未发布、已下线或删除的工作流不能由该入口发起新运行，不能回退为草稿或其他版本执行。 |
| REQ-04 | **身份及目标保留。** 两个入口使用实际用户及可信的当前租户。无有效会话时发起昆联 SSO，成功后保持原工作流及编辑／执行目标；已有符合要求的会话直接进入，不重复授权。 |
| REQ-05 | **失败与安全。** 登录、目录就绪、会话准入、权限或目标校验失败时显示相应失败状态。不反复自动发起 SSO；允许用户手动重试原目标。链接不携带令牌、密码或服务凭据，不能授予身份、权限或切换租户。 |
| REQ-06 | **浏览器使用及兼容。** 两种链接能够直接粘贴打开、从昆联点击和刷新；保持现有管理页、编辑器、执行页和非昆联登录行为。打开或刷新链接、SSO 回调本身不创建业务运行或提交答案，不改变已有运行的恢复及版本规则。 |
| REQ-07 | **交付与验收。** 提供双方可使用的链接说明及编辑、执行各一个已验证示例。Mock 证据与真实联验证据分开记录，未执行项标记待执行，不以示例地址代替业务权限或 SSO 验收。 |

## 4. 验收标准

| ID | Requirements | 可观察结果 | Verification |
| --- | --- | --- | --- |
| AC-01 | REQ-01、REQ-04 | **当** 同租户用户具备既有编辑及入口资格并打开编辑链接，**系统应** 直接展示指定 Workflow 的画布；从画布返回时到达工作流管理页，有未保存修改时保留原确认行为。 | V-01、V-03 |
| AC-02 | REQ-02、REQ-04 | **当** 用户具备既有使用及入口资格、没有编辑权限，并打开执行链接，**系统应** 展示该 Workflow 的执行页面，允许按现有方式填写输入并发起运行；不要求授予编辑权。 | V-01、V-03 |
| AC-03 | REQ-03 | **当** V1 已上线并通过该链接发起一次新运行，随后 V2 上线，再通过相同链接发起一次新运行，**系统应** 分别执行 V1 和 V2，不改变已开始的原运行版本。 | V-02、V-03 |
| AC-04 | REQ-03、REQ-05 | **如果** 指定工作流未发布、已下线、已删除、类型不符或不存在，**系统应** 阻止新运行并显示不可用或拒绝状态，不执行草稿、其他工作流或历史版本。检查页面后、发起运行前已下线的情况也必须阻止新运行。 | V-02、V-03 |
| AC-05 | REQ-04、REQ-06 | **当** 用户尚未登录并分别从编辑链接和执行链接进入，且昆联 SSO 与目录准入成功，**系统应** 回到原工作流的原页面目标；页面刷新后目标仍保持。 | V-01、V-03 |
| AC-06 | REQ-04、REQ-05 | **如果** 用户仅有查看或使用权限而打开编辑链接，或没有使用权而打开执行链接，或目标不属于可信当前租户，**系统应** 拒绝相应访问，不通过来源参数、用户或租户参数、旧缓存授予权限，也不泄露未获授权的详情。 | V-02、V-03 |
| AC-07 | REQ-04、REQ-05 | **如果** 登录被取消、目录未就绪、依赖不可用或回调后会话仍失效，**系统应** 显示失败并停止自动重跳；用户手动重试时保留原工作流及编辑／执行目标。目录未就绪继续遵循现有补同步后重新登录规则。 | V-01、V-03 |
| AC-08 | REQ-05 | **如果** 入口包含非法目标、站外回跳或试图通过链接传递凭据，**系统应** 拒绝不安全内容或进入明确安全失败状态，不将其作为登录凭据，不跳转到站外目标。 | V-01、V-02 |
| AC-09 | REQ-02、REQ-03、REQ-06 | **当** 用户打开、刷新执行链接或完成 SSO，**系统应** 仅加载页面、历史及现有运行状态，不自动发起新的业务运行或重新提交人工答案。由用户明确发起的新运行使用当前上线版本；恢复原运行继续遵循既有版本及恢复规则。 | V-01、V-02、V-03 |
| AC-10 | REQ-06、REQ-07 | **当** 两个入口完成首轮验证，**交付文档应** 分别列出用途、参数含义、完整链接及已验证示例，并标明依赖的身份、权限和发布条件。现有管理页进入编辑器及普通执行入口回归通过，真实联调未运行时保持待执行。 | V-01、V-03、V-04 |

## 5. 边界情况

- 用户在租户 A 的会话中打开租户 B 的工作流链接，不能自动改租户或沿用其他主体的权限；页面提示无权或不可用。
- 原目标在登录期间被删除、下线或撤权，登录成功不代表允许访问或运行，目标按登录后的当前事实处理。
- 仅有查看权的用户不因编辑链接降级显示可编辑画布；是否查看摘要继续使用管理页现有入口。
- 同一页面多个初始化请求发现会话失效时，不形成重复授权；回调后仍失败时停止自动授权。
- 切换到其他工作流时不能短暂显示上一个工作流的受保护数据。非法链接或错误页面不能导致新建、发布、下线、执行或答案提交。
- 入口可复用已有会话和历史，打开链接不承诺每次新建会话；用户新发起业务运行时的版本与恢复原运行的版本必须区分。

## 7. 双方联调条件

- 昆联登记两类按钮的完整浏览器链接，传入毕昇实际 Workflow 标识；当前测试入口继续使用 3001 端口。
- F118 的真实登录回调、目录同步及会话准入可用；不能仅凭毕昇本地管理员会话宣布真实 SSO 回跳通过。
- 准备有编辑权、有使用权但无编辑权、无使用权及其他租户的受控账号，以及可安全发布和运行的测试 Workflow。
- 真实联调中的参数或配置若尚待确认，在设计和实施中保留 `TODO`，相关验收保持 `NOT_RUN`。
