# 企业市场直接导入社区插件包

用户于 2026-10-16 确认移除专用 manifest 的导入要求，客户端目标为 BISHENG Work 企业分支。

## 验收条件

管理员上传包含 package.json 与运行代码的 ZIP 或 npm tgz 包，后台从包内读取名称、版本、描述、作者和许可证。平台范围使用 npm os/cpu 声明。依赖由客户端既有安装器准备。旧发布包保持可读。

版本预览保持只读，确认后重新校验；同版本内容冲突和低版本保护按 SemVer 执行，包括预发布版本。租户隔离、审计和制品摘要沿用现有企业市场服务。

## 设计

社区包返回系统派生的 schema_version=2 元数据，数据库与现有 API 信封保持一致。旧 schema_version=1 完整离线包继续按原校验器处理。下载保留原始内容，按 ZIP/gzip 返回类型。

后台执行静态检查。桌面安装、依赖准备与运行激活由配套 bisheng-work 版本执行。依赖安装来源为客户端既有 npm 源；内网通过可达企业源或 npm bundledDependencies 交付。

## 验证任务

- 社区 ZIP/tgz 导入、路径与平台检查。
- 预发布到正式版升级、同版本不可变、低版本和跨租户保护。
- 管理端 ZIP/tgz 文件选择、预览与确认。
- 真实后端路由与桌面安装及加载配套验证。
- 后端测试、Ruff、架构守卫、管理端定向检查与生产构建。
