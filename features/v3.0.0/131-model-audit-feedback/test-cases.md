# 消息审计评价测试用例（测试工程师参考）

## 依据与范围

依据 2026-11-09 [spec.md](./spec.md)、[design.md](./design.md)，目标为修复 PR #2646 的 work-130 构建；本轮原始代码证据为 c6f182a5d7，最终修复提交见 tasks.md。设计复查涉及全部用例。自动化路由/存储回归与下表真实客户端验收分开记录。

## 环境、账号与测试数据

准备测试租户 A 的桌面用户 U1/U2、另一租户 B 的 U3，以及有权查看 A 审计的管理员。通过正常模型调用创建前缀 e2e-feedback- 的会话，启用元数据审计；不修改真实用户会话。Desktop 必须支持 audit_message_feedback.version=1，当前安装包是否支持需现场确认。测试后按前缀仅清理本轮测试数据。
