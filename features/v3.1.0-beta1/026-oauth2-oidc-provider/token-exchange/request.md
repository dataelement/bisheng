# 同一用户跨系统换证需求来源

用户要求毕昇支持 token exchange，以 A 的身份凭证获得供 B 登录使用的凭证；本轮明确选择“1：同一个人在两个系统登录”，用户和租户不变。此前已明确：由毕昇签发、B 信任毕昇；输入是毕昇 OAuth Access Token；首版由可信 confidential 服务端发起；B 可本地验签并接受短期撤销延迟。

用户已于2026-11-26（America/Los_Angeles）明确“规格接受，继续下一步”，接受 spec.md 中300秒上限、显式scope、策略管理API及本地验签撤销语义。技术设计仍待评审确认；尚未实现换证能力。

ApiCredential 的随机密钥/哈希存储/5秒撤销约束继续保留。F026 OAuth 临时登录断言与 ApiCredential 的窄契约边界已随规格确认，仍需同步发布契约，不得用换证结果绕过既有开放API鉴权。
