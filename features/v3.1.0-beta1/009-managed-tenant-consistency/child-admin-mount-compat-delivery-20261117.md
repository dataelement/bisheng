## 历史核对及实现

- v3.0.0登录前的无角色闸没有子租户管理员例外；其平台侧栏、路由和业务鉴权已有独立子租户管理员处理。恢复的是完整既有身份语义：通过permission应用入口校验真实主属的管理员身份，补齐登录、系统管理入口和管理端默认落点。普通角色仍为空，不生成平台AdminRole，不修改超管专属接口和资源权限。
- userrole在v3.0.0已经有tenant_id。Role.tenant_id是定义归属，UserRole.tenant_id是人员普通绑定归属，UserTenant活动记录是当前主属，三者含义不同。本次不改有效角色过滤、不自动将Root绑定搬到子租户。
- 挂载创建事务去掉普通绑定清理。主属同步只在DEPT_CHANGE、DEPT_MOVED、UNMOUNT_REDERIVE显式组织变更时采用原角色终止/默认规则；MOUNT_BACKFILL及LOGIN、CELERY_RECONCILE、MANUAL补同步保持原绑定所有字段、不发默认。后者覆盖首次人员同步失败后经登录/Beat补齐的路径。
- 账号创建、SSO组织/角色写入和显式授予各自原规则不在本次重构；历史修正、类型转换、已删除绑定恢复及私有角色映射未执行。原挂载后的外部身份同步和初始管理员授予仍分步，不能把本次补丁描述为挂载全流程原子化。
