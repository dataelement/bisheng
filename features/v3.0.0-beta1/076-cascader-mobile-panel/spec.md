# Cascader 移动端单面板

日期：2026-11-02。范围：共享 `@bisheng/ui` Cascader 及组件设计规范；保持既有公开参数、路径值与业务回调格式。

用户已明确要求沿用 Select 现有浮层形态：不从底部弹出，手机上始终只展示一个层级面板，二级及以下提供左上角返回。本次按单模块小功能流程实施。

| AC | 验收条件 |
|---|---|
| AC-01 | 手机宽度 < 576px 时，面板跟随触发器展开，不出现底部抽屉或遮罩；下方空间不足时自动翻转，宽高受可用视口限制。 |
| AC-02 | 手机每次只展示当前层级；点父节点进入下一级，二级及以下左上角显示返回按钮与当前父级名称。 |
| AC-03 | 返回时恢复父级选项高亮、该层滚动位置和既有选择；列表定位不滚动背后的页面。 |
| AC-04 | 单选点击叶子后关闭，仍只回显末级名称并提交完整路径；重新打开恢复已选层级，受控及默认展开同样有效。 |
| AC-05 | 手机搜索位于同一浮层内，完整路径结果仍可选择；清空搜索回到原层级，方向键和 ESC 可正常操作，输入框左右键保留编辑光标用途。 |
| AC-06 | 多选保持勾选即时生效、父子联动与任意层级独立选择；不放完成按钮，点外部、再次点触发器或 ESC 收起。 |
| AC-07 | 懒加载、加载失败重试、空数据、搜索无结果、禁用与只读均保持可用；点击导航和选择有清晰的角色与焦点。 |
| AC-08 | 平板与桌面保留多列；手机 320px/390px、短视口、深浅色均不出现横向溢出或被裁切的列表。 |
| AC-09 | Cascader 规范、示例和移动端说明同步更新；Select 规范中尚未落地的底部抽屉说明对齐当前浮层行为。 |
| AC-10 | 手机菜单项与 Select 一致为 32px；返回使用 24px small 图标按钮，32px 导航行不加底部分割线。 |

实现取舍：复用现有 Radix Popover 负责定位、外部点击和 ESC 关闭；手机布局仅作为同一浮层的内容。保留共享 32px 菜单行和既有搜索/多选文案参数；返回按钮使用共享 Button small。滚动限制在菜单列，按路径保留每层位置。

验证结果见同目录 `e2e-checklist.md`。
