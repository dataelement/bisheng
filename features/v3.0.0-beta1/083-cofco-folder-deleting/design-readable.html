后端怎么改

  1. 直接删除前，先记“删除中”文件夹 status 从正常 2 改为 8，独立提交后再做完整检查和删除。需要审批的请求仍走原“待审核”。
  2. 用已有元数据辅助恢复保存本次删除编号和最后更新时间；服务端保护这些信息，防止旧请求或其他编辑覆盖。
  3. 成功删除，失败恢复成功沿用原事务移除目录；确认失败恢复 status=2。成功结果沿用已有删除账本查询。

前端怎么改

  1. 刷新后读取服务端状态目录或祖先正在删除，就恢复“删除中”和操作限制；其他目录仍可用。
  2. 每 3 秒查询处理结果成功移除目录，失败刷新并恢复操作；页面隐藏时暂停查询。
  3. 超过 60 秒未更新，先核对显示“状态待确认”。服务器取得目录锁、阻止旧请求继续提交后才恢复操作；锁仍被占用就继续等待，不自动重发删除。
