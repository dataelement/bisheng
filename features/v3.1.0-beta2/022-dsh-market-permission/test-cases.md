# 企业插件与企业工作台按用户 / 部门 / 用户组授权测试用例（测试工程师参考）

## 依据与范围

- 已确认规格：[spec.md](./spec.md)，2026-11-16 需求方确认版。
- 设计复查：[design.md](./design.md) 2026-11-16 设计评审修订版（需求方确认）。用例中的入口、观察方法按该版本编写。
- 目标版本与构建：v3.1.0-beta2 / 分支 `feat/3.1.0-beta2-022-dsh-market-permission`（待实现）；桌面端对应分支待实现。
- 其他依据：F055 企业插件市场、F019 企业工作台市场规格（被本特性收窄的条目见 spec 范围边界）。
- 代码核对：已核对 `feat/3.1.0-beta2` 4315308da 的 `dsh_market` 接口与仓储、F048 runtime，以及桌面端 `V1.3.1` 的 `packages/dsh-desktop-enterprise/market.js`。新增接口、原因码与界面文案均为拟实现，待实现后复核。
- 覆盖范围：管理员授权、员工侧可见与拒绝、收回与恢复、删除与恢复、升级与回滚、不受影响的部分。性能只在单租户几百项的规模下观察，不做压测。
