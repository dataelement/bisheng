## 1. 什么时候用

分段控制器让**同一份内容换个看法**——列表还是卡片、按日还是按周、地图还是卫星图。它本质是个**即时生效的单选控件**：选项少、文案短、点完立刻切换。

判别口径（规则只写在这里，标签页那边引用）：

| 你在切什么 | 用什么 |
|---|---|
| 切完后「你在哪」变了——换了一块内容区 | 标签页 Tabs，见 [组件-Tabs标签页.md](组件-Tabs标签页.md) |
| 还在原地，同一份内容换展现方式 / 模式 / 粒度 | 分段控制器 Segmented |
| 选完要随表单一起提交才生效 | 单选框 Radio |
| 选项超过 5 个 | 换标签页或选择器，别硬塞 |

- 段数 **2～5 段**（Apple HIG / Material 的一致推荐区间），超出就不是「几个看法」而是「一堆选项」了。
- 分段控制器**总有一段被选中**，不存在「都不选」的状态；允许空选的场景用单选框。

## 2. 长相与结构

半透明底槽里一块选中浮块，点哪段滑到哪段；深浅色跟随整站。

- **底槽**：浅色模式用深灰主文字色的 4% 不透明度，深色模式用柔白主文字色的 8% 不透明度（`bg-text-1/[0.04] dark:bg-text-1/[0.08]`），无描边。
- **浮块**：浅色模式用页面色底、主题色文字和图标；深色模式用主题色的 20% 不透明度底、主文字色（柔白 `#F6F6F6`）文字和图标。盖在选中段上，切换时滑动过去；**不加投影**。
- **槽内边距 3px**，浮块圆角 = 外圆角 − 3px（嵌套同心，见《圆角与阴影规范》使用原则）。
- **默认各段按内容宽度显示**：每段宽度由自身内容加对应尺寸的水平内边距决定，不因其他段内容更长而被拉宽；**仅 `block` 模式**撑满父容器、各段平分。
- 浮块跟随选中段的实际位置和宽度，切换时同时过渡位移与宽度；内容、尺寸或容器宽度变化后仍与选中段贴合。

## 3. 尺寸 Size

三档，medium 是默认。高度保留 28 / 32 / 36px，字号统一为 14px、行高 22px。large 通过更大的上下留白和 20px 水平内边距区分尺寸，不再放大文字；medium 32px 继续与同排控件等高对齐。

| size | 高度 | 字号 / 行高 | 外圆角 | 浮块圆角 | 段水平内边距 | 什么时候用 |
|---|---|---|---|---|---|---|
| `small` | 28px | 14 / 22 | 6px | 3px | 8px | 表格工具条、卡片角落 |
| `medium`（**默认**） | 32px | 14 / 22 | 8px | 5px | 12px | 绝大多数场景 |
| `large` | 36px | 14 / 22 | 8px | 5px | 20px | 页头、大表单 |

- 字号统一取《字体规范》的 14 / 22 档；small / medium 外圆角保持增大一档后的 md / lg（6 / 8px），large 恢复原来的 lg（8px）。浮块圆角按外圆角减 3px 计算，保持嵌套同心。
- 和旁边的按钮、输入框同档搭配：32px 的搜索框旁边配 medium（等高对齐）；small / large 与相邻控件差 4px 以内，同行混排时垂直居中即可，不追求像素等高。

## 4. 内容形态

段内容三种形态，**同一个控件里只用一种**——文本段和纯 icon 段混在一起，读的人要在两套语言间来回翻译（Apple HIG 同款禁令）。

| 形态 | 什么时候用 | 细则 |
|---|---|---|
| **纯文本** | 绝大多数场景 | 文案 2～4 个字、含义清楚，不要求各段等长；跟《文案规范》 |
| **icon + 文本** | 文案短且 icon 能加速识别（如「列表 / 卡片」） | icon 随档 14 / 16 / 18px、与文字间距 8px（small 档 4px），同《图标规范》 |
| **纯 icon** | 空间极窄且 icon 语义业内公认（视图切换的列表 / 网格） | **每段必须配 Tooltip** 说明含义，见 [组件-Tooltip文字提示.md](组件-Tooltip文字提示.md) |

- 文案装不下**不加省略号**——改短文案，或者承认它不是分段控制器该干的活，换标签页。

| ✅ 推荐 | ❌ 不推荐 | 原因 |
|---|---|---|
| 「全部 / 进行中 / 最近更新」等简短文案 | 「所有任务 / 当前正在进行中的任务 / 最近更新过的任务」 | 文案应简短易扫读；默认各段随内容宽度显示，不必刻意凑成等长 |
| 纯 icon 段配 Tooltip | 纯 icon 段裸奔 | icon 语义再公认也有第一次见的人，没提示等于猜谜 |

## 5. 状态 State

| 状态 | 样式 |
|---|---|
| 选中 active | 浅色：页面色浮块 + 主题色文字和图标，字重 400；深色：20% 不透明度主题色浮块 + 主文字色（柔白）文字和图标，字重提高一档至 500 |
| 未选中 default | 无底色 + 辅助文字色（text-3）——比常规控件的次要文字浅一档，让位给选中段 |
| 悬停 hover | 未选中段文字与图标使用主题色（blue-500，随蓝 / 绿主题切换），底色与字重不变；已选中段保持 active 样式 |
| 单段禁用 disabled | 灰字（同按钮 disabled 文字色，见 [组件-Button按钮.md](组件-Button按钮.md) §6）+「禁止」光标，其余段照常可点 |
| 整体禁用 | 全部段灰字 + 浮块保持在当前段，深色浮块使用禁用背景色，整体「禁止」光标 |
| 键盘焦点 focus-visible | 控件外圈灰色聚焦环（同输入框的 2px gray-2 环口径，见 [组件-Input输入框.md](组件-Input输入框.md) §5） |

- **选中使用主题色**：浅色模式的文字与图标使用 `blue-500`，深色模式改为 `bg-blue-500/20` 填充浮块、文字和图标使用 `text-text-1`（当前为 `#F6F6F6`）；主题色对应 `--brand-500`，随蓝 / 绿主题切换。悬停选中项保持当前选中样式。禁用项使用禁用文字色，深色浮块使用禁用背景色。
- **深色选中文字的对比度**：按页面底色 `#121212`、柔白 8% 底槽、主题色 20% 浮块依次叠加计算，柔白文字在蓝 / 绿主题下分别约为 **11.16:1 / 10.36:1**；在常用较亮容器底色 `#2E2E30` 上仍约为 **8.11:1 / 7.52:1**，均超过 [WCAG 普通文字 AAA 的 7:1 标准](https://www.w3.org/WAI/WCAG22/Understanding/contrast-enhanced.html)。因此深色选中文字使用主文字色，不沿用主题色文字。透明背景的对比度随承载底色变化，业务在其他底色上使用时按最终叠加色校验。
- 浮块位移与宽度过渡均为 200ms；切换即生效，段对应的内容区即时替换、不加转场。
- **字重按明暗区分**：未选中默认 400；浅色选中保持 400，深色下启用且选中的段提高一档至 500。禁用项保持 400。深色切换引起段宽变化时，浮块重新测量并保持贴合。

## 6. 移动端适配

跨组件通则见 [基础-多端适配原则.md](基础-多端适配原则.md)，这里只写分段控制器自己的细则。

| 项 | 触屏 / 窄屏规则 |
|---|---|
| 悬停 hover | 触屏没有悬停，关掉 hover 态 |
| 热区 | 高度不足 44px 的档位用透明热区扩到 ≥44px（同按钮口径，WCAG / Apple HIG 推荐值），视觉高度不变 |
| 宽度 | 窄屏下优先用 `block` 撑满容器，各段平分——悬空的小控件在手机上难点中 |
| 段数 | 手机上更要守住 ≤5 段；文案放不下就减段或换组件，不缩字号 |

## 给实现窗口

1. 组件位置建议 `packages/ui/src/components/Segmented/`，尺寸映射 `size`（高 28 / 32 / 36，字号统一 14 / 22，外圆角 6 / 8 / 8，槽 padding 3px，浮块圆角 3 / 5 / 5，段水平 padding 8 / 12 / 20）。默认按各段内容排布，仅 `block` 等分。浮块单独一个绝对定位元素，测量选中段实际位置和宽度并同时过渡（200ms）；监听各段与容器尺寸变化，不能再用段索引乘固定段宽定位。
2. 无障碍走 `role="radiogroup"` + 每段 `role="radio"` / `aria-checked`（它语义上是单选，不是 tabs）；方向键在段间移动并即时选中。
3. 颜色全走 token：槽底 `bg-text-1/[0.04] dark:bg-text-1/[0.08]`；浅色浮块 `bg-bg-page`、启用且选中项文字与图标 `text-blue-500`；深色浮块 `bg-blue-500/20`、启用且选中项文字与图标 `text-text-1`，并使用 `font-medium`。未选中 `text-text-3`，hover 使用 `text-blue-500`；disabled 复用按钮 disabled 文字 token，深色禁用浮块使用 `bg-btn-disabled-bg`；选中项悬停保持原样，无裸 hex。选中样式依据 `aria-checked`，避免纯图标段的 Tooltip 开关状态覆盖 `data-state`。
4. 触屏热区复用 `btn-touch-hit` 口径；`block` 模式宽度 100%，以等分网格实现各段平分。
5. 站点接线（元规范 §5）：`rspress.config.ts` 侧栏注册本文 + `components/segmented.mdx` demo 页（ASCII 文件名）；00-总纲 §四 与 01-设计规范 §0 索引行本次已随建档更新。
6. 现状扫描未做：client 内现存分段样式（手拼 toggle 组、按钮组充当切换器等）的用量与迁移映射，待迁移窗口扫描后补附录。
