## 环境、账号与数据

| 代号 | 角色或数据 | 准备方法 | 确认方式或待确认项 |
| --- | --- | --- | --- |
| U | 仅目标文件夹 upload_file 用户 | 隔离测试租户授权，不授根 edit/visible | 权限 API 与允许/拒绝配对检查 |
| A/B | 当前目标及另一身份/租户/目录 | 仅使用测试数据与测试账号 | 服务端验证 canonical parent；真实环境待配置 |
| S/N | 有空间默认/无空间默认 | 测试空间保存不同于系统的规则及零值，另建无配置空间 | upload-settings 返回值核对 |
| F | 文档、表格、音视频、嵌套目录 | 使用隔离样本，保留测试前非测试数据 | 依部署支持格式和大小限制检查 |
