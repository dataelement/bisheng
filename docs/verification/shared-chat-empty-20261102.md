# 只读分享页空状态

## 问题与根因

用户在 macOS Chrome、BS 1.2.0 测试环境打开 `/workspace/share/<token>` 的空会话分享，点击“开始一个新的对话吧”后仍停留在原页。

应用会话的空状态向所有页面提供新建回调，分享页也拿到了这个入口。该回调从普通应用路由读取 `fid` 和 `type`，分享路由仅包含 `token`，因此点击后提前返回。分享页的产品边界是只读历史；复用可交互空状态遗漏了这一边界。同时原空状态条件依赖个人会话列表及应用开场内容，造成同一份空分享在不同上下文下展示不同。

## 修复

- 只读分享根据共享消息数量显示空状态，文案为“该分享暂无对话记录”，复用现有 StateView 视觉样式。
- 空状态按当前页面是否提供新建能力显示操作。只读分享传入静态展示；普通应用会话、应用入口和独立应用页继续传入新建回调。
- 共享历史已有消息时继续按只读会话展示。中英日翻译同步。
