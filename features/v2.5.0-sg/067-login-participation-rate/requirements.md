# 登录参与占比口径修正

Status: Locally verified

## 已确认需求

- REQ-01：全员参与占比 = 期间登录去重用户数 / 截至期末累计登录去重用户数。按日、周、月、年或整个筛选区间均按此计算；分母没有查询开始日期下界。
- REQ-02：分子与分母使用相同人员/组织筛选，只读取 participation 来源且 logged_in=true 的记录；重复登录、跨天登录按 user_id 精确去重。分母为零返回零。
- REQ-03：实际登录人数同步按期间去重，导出参与占比的明细为期间登录的去重人员；全员总数、实际登录次数及其他数据集不改变。
- REQ-04：不执行生产写入、不重建索引、不恢复此前贮藏内容。历史完整性受现有参与度索引中登录事实覆盖范围约束。

## 验收

| ID | 结果 | 验证 |
|---|---|---|
| AC-01 | 查询起日前已登录用户进入分母，未来首次登录用户不提前进入分母 | 服务层回归 |
| AC-02 | 同人跨天多次登录在周/月/整段区间仅计一次；按天分别累计 | 参数化回归 |
| AC-03 | 未登录名单、新增/活跃来源不混入，业务筛选不丢失 | ES 查询边界回归 |
| AC-04 | 零登录日为零，空分母为零；北京时间月/周边界正确 | 时间边界回归 |
| AC-05 | 图表路由、旧数据集入口和去重明细一致，其他指标保持原路径 | 模块回归 |

用户已在会话确认日口径和期间口径，本轮按该范围实现。
