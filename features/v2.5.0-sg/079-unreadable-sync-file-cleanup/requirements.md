# 需求

## 确认范围

仅处理 Filelib 文件同步及其共用链路进入的文件。接口既有入队响应不变；解析阶段明确确认原文件加密或结构损坏时，删除无其他业务关联的失败记录，保留审计，后台清理附属存储。历史失败记录不扫描。

| Requirement | Acceptance | 验证 |
|---|---|---|
| REQ-001 只清理明确不可读的接口原文件 | AC-01 加密 PDF、Office 加密容器、损坏 PDF/Office 容器生成明确失败原因；有效文件不触发 | 真实临时文件测试 |
| REQ-002 保留其他失败和普通上传 | AC-02 超时、服务异常、转换失败、原因不明、手动上传均保留；不凭错误文本判断 | 参数化解析/事务测试 |
| REQ-003 保护关联业务及并发状态 | AC-03 历史版本、分发入口、引用、审批/纠错关联及状态/对象已变时不删除，不级联 | 真实 ORM 拒绝和快照测试 |
| REQ-004 清理持久化闭环 | AC-04 删除单文件及初始 V1/空文档、标签/候选/产物关联，同事务登记全文删除和后台清理；回滚无半成品 | 事务回滚、重复投递测试 |
| REQ-005 保留诊断与可重试补偿 | AC-05 原审计不删；清理任务保留原文件快照和原因；权限失败可重试，对象仍被引用则保留 | 后台失败/恢复测试 |

## 不包含

不修改线上数据，不执行迁移，不清理历史失败、不恢复此前同步替换的旧文件，不增加外部接口、不改变页面上传。无法可靠识别的特殊加密或损坏继续保留，禁止猜测删除。
