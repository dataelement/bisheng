# F075：中粮机器人问答调试客户端

状态：需求、设计和计划已确认；本地实施中，尚未部署。更新：2026-10-10。

## 目标

测试人员在 105 使用简易聊天页面复现机器人知识问答问题，无需客户 E+ App、WebSocket 或 Bot Secret。可区分未调用知识工具、未检索目标空间、来源丢失、文件过滤和模型错误归属。

## 范围与假设

- 是单独启动的测试工具，不加入正式产品菜单，不自动随生产服务启动。
- 入口位于助手编辑页的「E+ 机器人」配置区，打开独立调试页面并带入当前助手；仅启用调试工具的环境、授权管理员可见，不替换原助手测试入口。
- 仅对授权管理员开放；不得因可选择测试用户而形成公开身份模拟入口。选定助手、机器人配置和测试用户必须满足租户及状态校验。
- 读取实际机器人绑定空间、助手提示词、模型及执行模式，不允许在聊天请求里任意扩展知识空间或绕过正式检索边界。
- 第一版仅文字问答，工具聚焦机器人知识检索；其他有业务副作用的工具不执行。页面明确显示实际测试工具清单与正式助手清单的差异。
- 不使用新知识问答 `/filelib/answer` 代替机器人助手执行流程；真实复用助手的模型、ReAct/函数调用和机器人空间检索能力。
- 不伪造模型或检索结果，不改提示词以使诊断测试“通过”。

## 验收条件

AC-01：WHEN 授权管理员从已启用调试的助手配置进入，THE SYSTEM SHALL 带入当前助手，并允许选择对应机器人配置及合法测试用户，显示本次模型、执行模式、绑定空间和测试工具清单。未配置机器人绑定时明确报错，不默认开放全部空间。

AC-02：WHEN 用户发送文字问题或清空测试历史，THE SYSTEM SHALL 展示回答、仅维护独立测试历史，不能加载、删除或覆盖正式机器人历史。

AC-03：WHILE 执行测试问答，THE SYSTEM SHALL 不建立客户长连接、不发送 E+ 消息、不申请机器人单活租约、不消费正式队列、不写正式 E+ 消息/会话/轮次表。

AC-04：WHEN 执行知识检索，THE SYSTEM SHALL 使用真实模型及检索资源，保留正式机器人知识空间边界，包括绑定部门空间的实际行为，不自动新增绑定或修改权限。

AC-05：WHEN 一轮执行完成或失败，THE SYSTEM SHALL 展示是否调用工具、调用问题、实际工具类型、工具结果、最终答案及异常，两种执行模式都能关联执行结果；无工具调用时明确显示。

AC-06：WHEN 展示知识工具结果，THE SYSTEM SHALL 区分实际交给模型的空间名称、空间 ID、文件名与原始检索元数据中的文件 ID 等，不把未传入字段说成已传入，缺失字段不猜测填充。

AC-07：WHEN 一轮包含多次调用或同名文件，THE SYSTEM SHALL 按执行顺序展示全部调用、区分用户原问题和模型检索问题，按真实文件标识和空间区分来源。

AC-08：WHEN 请求超时、断开或取消，THE SYSTEM SHALL 停止本地执行，并限制并发；模型供应商已经开始的计算及计费不承诺可撤销。

AC-09：WHEN 返回调试数据，THE SYSTEM SHALL 仅向授权测试人员提供脱敏结果，不返回 Bot Secret、模型 APIKey、配置全文或认证头；测试历史与详细追踪临时保存，不新增共享文件状态或业务数据库表。

AC-10：WHEN 进行第一轮现场验收，THE SYSTEM SHALL 支持观察正常检索、无结果、同名文件分属不同绑定空间、绑定部门空间、模型未调用工具五类场景的真实执行情况。

## 不做

本轮不修空间归属幻觉或部门空间检索问题，不修改正式链路；不做图片输入、客户 E+ 协议测试、工具权限扩展、正式机器人历史导入或自动构造测试资料。

## 隔离与影响边界

独立进程和测试会话使代码、长连接及消息状态隔离；模型、数据库、检索服务仍共用，因此会产生正常模型费用、配额及既有调用审计/遥测，并可能影响资源繁忙时的性能。限制并发，默认一次一轮，不宣称完全零影响。

部署到 105 前核对认证、访问范围和端口；不通过替换生产镜像或重启正式机器人来启用调试工具。测试结束可以单独停止工具。

## 验证约定

后端覆盖准入、租户/绑定范围、历史隔离、工具执行追踪、取消超时及不触发 E+ 传输/持久化。现场以真实模型、索引和部门空间完成诊断样例。按用户约定，不在本地重复执行前端测试或构建，未执行部分不得宣称通过。
