# F116 可编辑知识空间列表性能修复

目标：`feat/3.0.0`。日期：2026-11-02。

用户已明确授权把本会话中已评审的 managed 修复同步到主线，并要求考虑分支差异。来源：中粮 `a8602ada9`；本文件记录同一已确认方案，不重开产品决策。

| AC | 验收标准 |
|---|---|
| AC-01 | `/knowledge/space/managed` 普通用户返回可见且有 edit 的空间；edit-only 入选，manage-only/viewer 不入选，成员角色不直接授予权限。 |
| AC-02 | 先完整获取可见 ID；空集直接返回；流失败、非法 ID、不完整或超过 5,000 上限时明确失败，不退回全租户逐页扫描或部分成功。 |
| AC-03 | 业务行按 ID 有界读取；权限目标每批最多 100 个，快照、Catalog、动作门禁、围栏及一致性标记按批准备，减少逐资源数据库/Redis 往返。 |
| AC-04 | 保留主线租户/状态/版本/投影和数据范围约束；仅全范围超管走当前租户全量路径，租户管理员及收窄 token 保持可见范围约束。 |
| AC-05 | 保留字段、数据库排序、置顶、角色、根文件计数及部门装饰；主线退出重入、详情/广场状态、公开应用访问、文件权限与创建回滚行为不被覆盖。 |
| AC-06 | 新增服务阶段计时、候选/批次/返回数及失败阶段；异常传播，日志不记录凭据、原始 SQL 或文件内容。 |
| AC-07 | 仅同步本修复；不合并中粮分支其它定制代码，不改 schema、索引、权限模型、前端或环境，不自动推送或部署。 |
