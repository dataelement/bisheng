# 知识空间返回列表保留标签 — 2026-10-31

## 问题与根因

在“我加入的”或“我创建的”打开空间详情，点击顶部返回后，列表选中“部门知识空间”。列表标签原本保存在组件本地状态中，进入详情会卸载列表，再次挂载时恢复默认值。页面外层 KeepAlive 还会冻结路由上下文，离开知识模块后重新进入指定标签可能继续显示旧标签。

## 修复

- 把列表标签作为 URL 查询参数 `tab`，支持 `department`、`created`、`joined`。缺省和未知值使用部门知识空间。
- 切换标签替换当前历史记录并保留其他查询参数；进入空间、文件夹及返回列表时携带标签。
- 知识页面使用实时路由上下文，与现有频道页采用相同渲染方式；数据继续使用 React Query 缓存。
- 保留原有页面组件与视觉样式。
