# Chat / Work 样式核对与交互边界

核对日期：2026-10-16。桌面使用 bisheng-work/V1.2.0，工作目录 `.worktrees/bisheng-work-chat-work`，本地及远端基线 `5b14db873105d2b3d937e7512619e20e4914507f`，安装的 Harness 为 0.2.0-rc.2。Chat 使用 `.worktrees/bisheng-dsh-chat-3006`，后端保持 feat/3.0.0-beta4。本次修改为前端展示与空过程区域收敛。

## 样式对照

| Before | After | 原因 |
| --- | --- | --- |
| 输入框工具按钮 32px、14px 字号，操作区有不同间距 | 工具按钮 28px、13px 字号；发送按钮 34px，工具间距 12px、窄屏 8px | 按安装的 Harness 样式定义统一控件基线 |
| 用户气泡圆角 16px，时间与复制行高度 24px | 气泡圆角 20px、内距 10×16px；操作行 28px，间距 6px | 统一用户消息轮廓 |
| 回复叠加旧行内距、正文内距、空过程容器间距 | 正文 14px/24px，消息间隔 12px；仅有过程内容时显示过程区域 | 修复留白的结构来源 |
| 回复操作按钮 24px，间距 12px，上方留白 20px | 按钮 28px，间距 8px，上方 16px | 与 Work 的操作行对齐 |
| 深色 Chat 的知识/工具弹层使用浅色主题 | 弹层直接取得 Chat 的主题变量，选中颜色继续表示业务状态 | 修复 Portal 脱离主题作用域的问题 |
| 新建页空的副标题仍占空间 | 有实际副标题内容时渲染 | 保持标题与输入框位置稳定 |
| 附件历史卡片和文字密度不同 | 240px 宽、64px 最小高度、20px 圆角 | 与 Work 附件卡片轮廓统一 |

头部保留上一轮已验证的 76px 标题/对话区，第一条气泡距分隔线 16px。消息区和输入框继续共用以当前聊天列宽计算的 680–920px 内容宽度；打开右侧预览时重新计算。

## 交互边界

- Chat 的“+”继续负责毕昇文件上传及已有入口；知识空间支持多选，显示已选卡片，并可移除；工具按组独立开关；深度研究保留现有模式切换及企业配置权限。
- Work 继续使用本地文件、工作区、访问模式、模型与本地执行能力。
- 共用外观尺寸、字体、色彩语义、焦点反馈和菜单轮廓。业务能力差异由各自组件呈现。
- 本次没有修改登录、历史 API、消息持久化、上传请求和工具调度协议。

## 能力入口位置（2026-10-16 更新）

| Before | After | 原因 |

## 桌面首次发送状态

ChatView 的消息与流式状态为欢迎页的权威状态。桌面专用可选 `dshChatPresentation.reportLanding(boolean)` 只上报展示状态；企业凭据、文件和本地执行接口继续由宿主负责。KeepAlive 页面按当前路由过滤上报。网页先显示用户消息，桌面同步收起模式选择，服务端分配会话 ID 后继续沿用现有会话同步流程。独立网页无需此接口。
