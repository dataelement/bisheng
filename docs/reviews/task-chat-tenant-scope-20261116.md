# 工作台任务提交缺少租户信息

日期：2026-11-16。基线：`origin/feat/3.1.0-beta1` 的 `015a7127d8`。分支：`codex/fix-task-tenant-scope-20261116`。

## 原因与修复

116 的任务提交在 `/api/v1/workstation/chat/completions` 请求准入阶段返回 HTTP 400 / 19703，尚未进入任务执行或模型调用。现场 admin 的租户选择记录已不存在。

最新代码已有 `prepareBrowserHeaders`：先按统一范围初始化租户，再向 SSE 对象补上请求头并显式启动。但 sse.js 2.8.0 默认在构造时立即调用 `stream()`，导致首次请求早于异步初始化且没有租户头。后续显式启动不能补救已发送的请求。

工作台问答（含任务模式）和频道/知识问答的 SSE 构造均增加 `start: false`，沿用现有异步初始化后的显式启动。等待期间取消或初始化失败时不发送问题。独立 Linsight 提交入口已在构造前等待租户头，本次不改动。后端租户准入、失效后的暂停规则、权限判定与任务重试策略保持不变。
