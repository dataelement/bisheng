# Feature: 任务模式角标溯源 · 报告与来源对照查看

> **本文档定位 — 纯 What（需求口径，不随代码漂移）**
> spec 只回答 **做什么 / 验收标准 / 不做什么**。How（组件拆分、状态字段、文件清单）写在 design.md。

**关联 PRD**: 无独立 PRD；问题来源为 3.0-beta2 任务模式验收反馈（2026-09-29，截图见 §7）
**优先级**: P0（现状下「对照核对引用」这一主场景不可用）
**所属版本**: v3.0.0-beta2
**依赖**: F047（任务模式角标溯源）、F069（短句柄引用）、F054（统一引用入口）
**交互原型**: https://claude.ai/artifact/LFZw3hwuLoMuWewKNnmw5M （可点击，含三档宽度与定位失败态）

> **范围边界**
> - **本次纳入**：
>   - 任务模式工作区里，点报告角标后「报告 + 来源」左右并排查看，不再互相遮挡
>   - 来源文件自动定位到被引段落：PDF 保持现有能力，docx / md / txt 新增定位
>   - 当前引用在两栏同时标出；同一来源的多处引用可逐处切换，两栏同步
>   - 桌面宽屏、桌面窄屏、平板 / 手机三档的对照形态
> - **本次明确排除**：
>   - xlsx 来源的单元格定位：表格没有「段落」可对，本期只展示被引片段原文
>   - 日常对话的引用面板：已经是停靠在对话旁的形态，不存在遮挡问题
>   - 旧 `/linsight` 独立页的文件预览（Sheet 形态）：需先确认该入口是否还在用，若无入口按死代码删除，不接入新交互
>   - 网页来源：仍在新标签页打开原网页，不进入对照栏（网页不是可定位的文件）
>   - 来源文件内容的编辑、批注

## 1. 用户故事

作为 **用任务模式生成对比报告、评估报告的业务人员**，
我希望 **点开报告里的引用时，报告和原文能左右并排显示，原文直接停在被引用的那一段**，
以便 **逐条核对报告的结论有没有依据、有没有引错，而不用在两个互相遮挡的窗口之间来回开关**。

作为 **审阅别人生成报告的负责人**，
我希望 **在同一份来源文件的多处引用之间逐处跳转，报告同步滚到对应位置**，
以便 **按来源文件一份份核对，而不是在长报告里人工找下一个角标**。

## 2. 交互方案

### 2.1 现状问题（为什么要改）

| # | 现象 | 后果 |
|---|---|---|
| 1 | 来源文件以 520px 浮层盖在工作区上，报告被挡住大半 | 无法同时看报告和原文，「对照」这一核心动作做不了 |
| 2 | 浮层没有稳定的关闭规则：设计上点外部即关闭，实际外部点击的处理代码引用了未定义的变量、每次点击都抛异常 | 用户无法预期浮层何时消失，只能靠右上角关闭 |
| 3 | docx / md / txt 来源打开后停在第一页，不定位 | 用户要自己在几十页文档里找被引段落，溯源形同虚设 |
| 4 | 点了哪个角标、原文里哪段是出处，都没有持续标记 | 视线离开后找不回当前正在核对的那一条 |

问题 1 同时违反组件规范《Drawer 抽屉》§1「抽屉里不能再开抽屉」与 §2「非模态抽屉推开主内容，不盖在上面」：工作区本身就是一块停靠面板，来源浮层是叠在它上面的第二层。

### 2.2 核心思路

把来源文件从「浮层」改成工作区的**第二栏**。工作区有三种状态：

```
 文件列表 ──点文件──▶ 单文件预览 ──点角标──▶ 对照查看
    ▲                   ▲    │                  │
    ▲─────── 返回 ───────┘    └◀── 收起来源 ─────┤
    ▲                               (或按 Esc)    │
    └──────────────── 返回 ─────────────────────────┘

 任一状态点「关闭工作区」→ 工作区整体关闭，对话列恢复（见 §2.5）
 对照查看中再点其它文档角标 → 只替换右栏内容，不新增层
```

进入对照查看时，中间的对话列自动收起，把宽度让给两栏；关闭来源栏后对话列恢复原宽。对话列收起不影响任务：任务仍在后台进行，完成后结果照常出现。

### 2.3 三档布局

**桌面宽屏（窗口 ≥ 1280px）**

```
┌侧栏┐┌─ report.md ─────────── ⤢ ✕ ┬─ OKR绩效管理运营规则 2025.docx ⤓ ◨ ┐
│    ││ 一、基本信息对比             ║        ‹  第 2 处，共 5 处  ›        │
│    ││ …2025 版与 2026 版均包含     ║ ─────────────────────────────────  │
│    ││ 相同的八章结构 (1) 2         ║  第二条 适用范围                   │
│    ││               ▲当前角标加深  ║ ▌本规则适用于公司全体正式员工…     │
│    ││                             ║   ▲被引段落高亮                    │
└────┘└──────────────────────────────┴────────────────────────────────────┘
                              ║ = 可拖拽分隔线，默认各占一半，每栏最小 400px
```

**桌面窄屏（1024–1279px）**：布局同上，左栏默认 55%，每栏最小 360px。

**平板 / 手机（< 1024px）**：宽度不够并排（两栏都会低于 360px），改为同一面板内用分段控制器在「报告 / 来源」之间切换：

```
┌──────────────────────────────┐
│ ‹ 返回   [ 报告 | 来源 ]   ✕ │   点角标自动切到「来源」
│──────────────────────────────│   切回「报告」时，报告停在刚才那个角标的位置
│ OKR绩效管理运营规则 2025.docx │
│ ‹ 第 2 处，共 5 处 ›          │
│ ▌本规则适用于…               │
└──────────────────────────────┘
```

全屏按钮在单文件预览和对照查看两种状态下都可用；对照查看 + 全屏时两栏覆盖整个主区域（含侧栏位置）。

### 2.4 两栏之间的关联

- **当前引用**：左栏被点的角标保持加深（即 Badge 规范 §5 的「展开态」底色），右栏被引段落以浅品牌色底高亮。两处标记一直保留，直到切换到别的引用或关闭来源栏。
- **逐处切换**：右栏顶部显示当前这条是本文件在报告里的第几处引用，带「上一处 / 下一处」。切换时左栏滚动到对应角标并加深，右栏定位到对应段落。计数只统计**指向同一份来源文件**的角标，顺序按角标在报告里出现的顺序。
- **一句话挂多个角标**（如 `(1)(2)` 分别出自两份文件）：点哪个打开哪份文件；悬停预览卡保持现状。
- **关闭**：只有右栏的「收起来源」按钮和 Esc 键会关闭来源栏。点左栏正文、滚动左栏都不会关闭它。

### 2.5 两级关闭

对照查看时顶栏上有两个关闭入口，作用范围不同，图标也必须不同，否则两个 ✕ 隔着分隔线挨在一起，用户分不清点哪个会关掉什么：

| 入口 | 位置 | 图标 | 作用 |
|---|---|---|---|
| 收起来源 | 来源栏顶栏最右 | 「收起右侧面板」图标，Tooltip「收起来源（Esc）」 | 只关来源栏，回到单文件预览；对话列恢复 |
| 关闭工作区 | 报告栏顶栏最右 | ✕，Tooltip「关闭工作区」 | 报告和来源一起关闭，对话列恢复原宽；若在全屏中同时退出全屏 |
| 返回文件列表 | 报告栏顶栏最左 | ← | 回到工作区文件列表，来源栏一并关闭（来源是依附于这份报告的） |

Esc 只关最内层：对照查看时先关来源栏，不会一次把整个工作区关掉。关闭工作区后，再从对话里「已整理输出文件」点报告，回到单文件预览，不恢复上次的来源栏。

### 2.6 定位不到被引段落时

原文匹配失败（例如来源文件在引用之后被替换、或解析文本与渲染文本差异过大）时，右栏不能静默停在第一页。右栏顶部下方展开一条提示条：写明「没能自动找到被引段落」，并给出被引片段原文，用户可据此自行查找。xlsx 来源始终走这一形态。docx / md / txt 的预览没有分页，不显示页码。

### 2.7 文案

| 位置 | 中文 | 说明 |
|---|---|---|
| 右栏计数 | 第 {k} 处，共 {n} 处 | n = 1 时隐藏上一处 / 下一处 |
| 切换按钮（Tooltip） | 上一处 / 下一处 | 图标按钮 |
| 右栏操作 | 下载文件 / 收起来源（Esc） | 图标按钮，文案在 Tooltip 与 aria-label |
| 报告栏关闭 | 关闭工作区 | ✕ 图标按钮的 Tooltip |
| 分段控制器 | 报告 / 来源 | < 1024px 时出现 |
| 定位失败提示 | 没能自动找到被引段落，下面是引用的原文 | 下方显示片段原文 |
| 来源已失效 | 这份文件已被删除或移动，无法打开 | 沿用 F054 的失效态 |
| 无权查看 | 你没有这份文件的查看权限 | 沿用 F054 的无权限态，不进入对照查看 |

三语（zh-Hans / en / ja）同批交付。

## 3. 验收标准

### 3.1 对照布局

- **AC-01** — WHEN 用户在任务模式工作区预览报告时点击知识库或临时文件来源的角标, THE SYSTEM SHALL 进入对照查看：报告在左、来源文件在右并排显示，两者互不遮挡。
- **AC-02** — WHEN 进入对照查看且窗口宽度 ≥ 1024px, THE SYSTEM SHALL 收起对话列，由两栏占用其宽度；WHEN 关闭来源栏, THE SYSTEM SHALL 恢复对话列原宽度。
- **AC-03** — WHILE 处于对照查看且窗口宽度 ≥ 1024px, THE SYSTEM SHALL 允许拖动两栏分隔线调整比例，且任一栏宽度不小于其最小宽度（≥ 1280px 为 400px，1024–1279px 为 360px）；调整后的比例在刷新页面后保持。
- **AC-04** — WHILE 处于对照查看, WHEN 用户点击报告中另一个文档来源角标, THE SYSTEM SHALL 在右栏替换为新来源并定位，不新增任何浮层或面板。
- **AC-05** — WHILE 处于对照查看, THE SYSTEM SHALL 仅在用户点击来源栏关闭按钮或按 Esc 时关闭来源栏；点击或滚动报告栏 SHALL NOT 关闭来源栏。
- **AC-06** — WHERE 窗口宽度 < 1024px, WHEN 用户点击文档来源角标, THE SYSTEM SHALL 在同一面板内切换到「来源」视图，并提供「报告 / 来源」分段控制器；切回「报告」时 SHALL 保持报告停在被点角标所在位置。
- **AC-07** — WHILE 处于对照查看, THE SYSTEM SHALL 允许切换全屏，全屏下保持两栏及当前定位不变。
- **AC-19** — WHILE 处于对照查看, WHEN 用户点击报告栏的「关闭工作区」, THE SYSTEM SHALL 同时关闭报告与来源、恢复对话列原宽度，并在全屏时一并退出全屏。
- **AC-20** — WHILE 处于对照查看, WHEN 用户点击报告栏的「返回文件列表」, THE SYSTEM SHALL 关闭来源栏并显示工作区文件列表。
- **AC-21** — THE SYSTEM SHALL 让「收起来源」与「关闭工作区」使用不同图标，并在 Tooltip 中写明作用范围。

### 3.2 定位与关联

- **AC-08** — WHEN 来源栏打开 PDF 来源, THE SYSTEM SHALL 高亮被引片段并滚动到可视区（保持 F047 AC-10 现有能力）。
- **AC-09** — WHEN 来源栏打开 docx、md 或 txt 来源, THE SYSTEM SHALL 在原文中找到被引片段，高亮并滚动到可视区。
- **AC-10** — IF 被引片段在原文中无法定位, THEN THE SYSTEM SHALL 在来源栏顶部显示定位失败提示，并展示被引片段原文；SHALL NOT 在无任何提示的情况下停留在文件开头。
- **AC-11** — WHERE 来源为 xlsx, THE SYSTEM SHALL 按 AC-10 的形态展示被引片段原文，不尝试单元格定位。
- **AC-12** — WHILE 某条引用处于当前核对状态, THE SYSTEM SHALL 在报告栏保持该角标为加深态，在来源栏保持被引段落高亮，直到切换引用或关闭来源栏。
- **AC-13** — WHERE 同一来源文件在报告中被引用 n 处且 n > 1, THE SYSTEM SHALL 在来源栏显示「第 k 处，共 n 处」及上一处 / 下一处；WHEN 用户切换, THE SYSTEM SHALL 同步滚动报告栏到对应角标并定位来源栏到对应段落。
- **AC-14** — WHERE 同一来源文件在报告中只被引用 1 处, THE SYSTEM SHALL 隐藏上一处 / 下一处。

### 3.3 不变量

- **AC-15** — WHEN 用户点击网页来源角标, THE SYSTEM SHALL 仍在新标签页打开原网页，不进入对照查看。
- **AC-16** — WHERE 查看者无权查看某来源或该来源已失效, THE SYSTEM SHALL 保持 F054 的无权限 / 失效呈现，不进入对照查看。
- **AC-17** — THE SYSTEM SHALL 保持日常对话的引用面板行为不变。
- **AC-18** — THE SYSTEM SHALL NOT 在来源栏或分隔线上使用毛玻璃（backdrop-filter）效果。

## 4. 边界情况

- **任务仍在执行时打开对照**：对话列收起期间任务继续；任务产出新版本时工作区按现有逻辑重置（关闭来源栏、回到文件列表），对话列随之恢复。
- **报告是 HTML 产物**：HTML 产物现有逻辑是在新标签页打开，不在工作区内预览，因此不涉及对照查看。
- **一个角标关联同一文件的多个片段**：定位到第一个片段，其余片段同样高亮。
- **窗口在对照查看中跨越 1024px**：从并排切到分段控制器（或反向）时保留当前引用与定位，不关闭来源栏。
- **来源文件很大，预览加载中**：右栏显示加载态，左栏角标已进入加深态；加载完成后再定位。

## 5. 设计规范依据

- 《组件-Drawer抽屉》§1「一次只开一个抽屉，抽屉里不能再开抽屉」、§2「非模态抽屉推开主内容，不盖在上面」、§2「窗口窄于 1024px 时空间不够并排」、§3「需要并排两栏的场景本身应该是独立页面」→ 对照查看做成工作区内的两栏，而不是抽屉叠抽屉。
- 《组件-Badge徽标》§5 溯源角标「展开态底色保持加深」→ 当前引用的加深态直接用该状态，不另造样式。
- 《组件-Segmented分段控制器》→ 窄屏「报告 / 来源」切换。
- 《基础-多端适配原则》→ 窄屏交互按触屏判断（无悬停预览，点击即打开）。
- 根目录 AGENTS.md「No frosted glass by default」→ AC-18。

以上布局属于对现有面板的视觉 / 布局变更，**实现前需设计师确认**。

## 6. 不做什么（汇总）

xlsx 单元格定位；日常对话引用面板改版；旧 `/linsight` 页 Sheet 预览（先核实入口，无入口即删）；网页来源进入对照；来源文件编辑与批注。
