# E2E 检查清单

目标：v3.1.0-beta1包含本变更的构建。测试环境地址与独立账号尚未提供，以下均待真实环境执行。

- [ ] 全新Compose与Helm部署默认出现Vibe、沙箱、BS Client，backend/worker配置一致。
- [ ] 管理员准备可用模型与样例工具/技能，普通用户有use权限；另准备无权限用户做拒绝配对。
- [ ] 不填写platform_public_url：Desktop服务发现、浏览器登录、换票、Chat、Work工具和技能/MCP、续期、退出均通过。
- [ ] 不填写地址：个人资料与会话列表正确，撤销指定设备后该设备被拒绝，其他设备继续可用。
- [ ] HTTP非默认端口与TLS反代均通过；可信边缘代理清理转发头、保留Host与端口；错误Origin及不可信转发头不扩权。
- [ ] 显式固定地址时链接及来源校验以配置为准；同时存在bs_client与dsh时新块整块优先，显式关闭保留。
- [ ] 分别部署依赖基础镜像外Python包和npm包的应用：真实下载、安装、调用可用；安装/编译/正式运行保持既有网络边界。
- [ ] 企业内部包源与离线模式不自动切公网，缺包明确失败。
- [ ] 重复准备/升级不轮换既有密钥，不覆盖镜像/开关/离线/来源选择；失败不删除数据。
- [ ] MySQL与DM8对应受影响业务回归、真实Gateway链路和浏览器权限检查完成。

数据使用e2e-defaults-前缀，只清理本次创建的数据；不使用生产账号或无条件清库。
