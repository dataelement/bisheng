# 注册表单实时校验

本文件记录注册页基础改造；后续正式规则及前后端实现以 [账号与昵称规格](../011-account-nickname/spec.md) 为准。

范围：本地 platform 注册页；沿用当前注册接口和登录流程。

| AC | 验收标准 |
| --- | --- |
| AC-01 | 账号占位文案为「账号用于登录，创建后不可修改」；昵称为「昵称用于系统内展示」；两个字段无常驻说明小字。注册输入框使用组件 medium 档，输入框和按钮宽度与登录页一致。 |
| AC-02 | 账号、昵称输入框后缀各有可聚焦的问号，悬停或键盘聚焦展示既定填写规则。 |
| AC-03 | 账号 1–64 个字符，以英文字母或数字开头，仅允许英文字母、数字及 . _ - @，保留大小写；昵称 1–32 个可见 Unicode 字符。 |
| AC-04 | 键盘、粘贴、输入法提交和其他输入事件均过滤空格及空白字符；粘贴替换选区后保留其余内容。 |
| AC-05 | 非法格式与超长内容保留供修改，实时显示红色边框和具体原因；修正后恢复。空值在失焦或提交时提示必填。 |
| AC-06 | 「密码强度」下仅显示两项圆点检查：「至少8个字符」「必须同时包含大小写字母、数字和字符」。长度独立判断；第二项同时满足大写、小写、数字和符号才通过。无输入或尚未满足时使用中性色，通过项使用当前主题色。密码与确认密码均支持显示和隐藏。 |
| AC-07 | 空白或汉字不计作密码符号；密码字符原样保留，实际校验与两项提示使用同一组条件。 |
| AC-08 | 确认密码无常驻说明或检查项；输入不一致时立即显示红框及错误原因，任一密码变化都立即重算，修正后移除错误。 |
| AC-09 | 无效表单不能发起注册请求；重复点击不得并发注册；请求失败保留输入并沿用现有错误处理。 |
| AC-10 | 保持既有登录占位、登录行为和品牌页面；注册区域容纳完整新文案及校验信息；中文、英文、日文资源同步。 |

验证：纯函数边界测试、注册组件交互测试、浏览器输入与真实粘贴检查；有效注册提交在组件测试中使用接口替身，浏览器不创建测试环境账号。
