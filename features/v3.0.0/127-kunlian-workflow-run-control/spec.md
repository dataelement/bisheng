## 1. 目标与范围

昆联 Agent 调用固定版本的毕昇 Workflow 后，能够在原运行会话上取消、查询权威终态，并在断线后续读运行事件。首轮依次交付取消与终态、事件续读与访问权限、隔离链路验收。

首轮样例为固定版本的纯文本 Workflow 和单次原生文本表单。运行中取消使用无外部写入的可控节点验证。跨平台嵌套与远端 Agent 取消接线、推送式事件及回调、完整追踪明细、管理员代管和跨平台授权治理另行确定范围。

## 2. 用户故事

- 作为昆联调用方，我希望在超时或用户停止后取消原运行，并区分取消受理、最终取消和已完成。
- 作为实际执行用户，我希望断线重连后继续查看同一次运行的状态和结果，并从最后确认的事件继续读取。
- 作为工作流维护者，我希望只有授权主体能取消或读取结果与追踪信息，迟到的任务也无法覆盖已经确定的终态。

## 3. 业务需求

| ID | 需求 |
| --- | --- |
| REQ-01 | **原运行绑定。** 取消、查询及事件续读均针对原会话和受理时固定的 Workflow 版本。重连、重试、编辑草稿、替换版本及下线沿用已有运行约定。原会话的版本和截止时间不因本次查询或重复取消而改变。 |
| REQ-02 | **取消受理与终态。** 有权调用方可取消排队、执行中、等待文本输入、待恢复或恢复中的运行。取消已受理后阻止新的执行、恢复和答案推进。已有节点在可安全停止的边界收敛，执行者退出后已受理的取消仍可收敛。受理与最终取消可分别识别，断线后可在原会话查询。 |
| REQ-03 | **竞争与重复。** 同一会话的重复取消收敛为一次有效操作，已受理响应丢失后可查回。取消先裁决时，迟到的派发、答复及输出均不能推进或改写终态。有效成功先提交时，保留原成功及结果。既有失败和超时终态保持稳定，已发生的外部动作不计为回滚。 |
| REQ-04 | **事件续读。** 原会话的已受理、开始、等待输入、恢复、取消受理和终态等适用事件有稳定递增序号。读取后可从上次确认的序号继续，可重读并按同一序号去重。过期起点须明确标识，允许调用方查当前授权状态后重新建立读取位置。 |
| REQ-05 | **权限及可见范围。** 取消、状态、结果、事件和追踪均按对应访问范围核验。Mock 仅允许原租户和原接入方下的原实际用户，并复核当前 Workflow 使用权。权限不可确认时拒绝操作或读取受保护内容。状态摘要、事件和错误不携带业务正文、表单答案、凭据或内部堆栈。授权后的表单与结果沿用原会话查询约定。追踪只在授权范围内返回关联标识。 |
| REQ-06 | **兼容与隔离。** 固定版本受理、重复启动查回、文本提交、按会话查询和授权后的结果读取保持既有行为。隔离 Mock 用来验证业务语义，正式契约和真实环境独立验收。 |

## 4. 验收标准

| ID | Requirements | 可观察结果 | Verification |
| --- | --- | --- | --- |
| AC-01 | REQ-01、REQ-02 | **当** 有权调用方取消排队、等待输入或待恢复的固定版本运行，**系统应** 在原会话收敛到取消终态。随后送达的任务或答案不能开始或恢复执行，下游输出次数为零。 | V-01、V-02 |
| AC-02 | REQ-02、REQ-03 | **当** 有权调用方取消已开始的执行或恢复，**系统应** 在运行尚未收敛时显示已受理，并允许独立查询终态。验证取消先裁决后，即使原 Worker 退出，原会话也能收敛且不会再开始下一节点或提交下游结果。 | V-01、V-02 |
| AC-03 | REQ-01、REQ-03 | **当** 两次取消并发或受理响应丢失后重试，**系统应** 返回同一运行的处理结果。核对有效取消只有一次，运行截止时间不续期。若成功先提交，取消后仍返回同一成功结果。若失败或超时先确定，查询仍返回原终态。 | V-01 |
| AC-04 | REQ-01、REQ-04 | **当** 调用方在等待或取消期间断开连接，再按最后确认的序号分页续读，**系统应** 返回原会话后续事件，重复读取同一事件时序号一致。核对跨页无缺漏，终态事件与最终查询一致。 | V-02 |
| AC-05 | REQ-04、REQ-05 | **如果** 事件起点超过保留窗口，**系统应** 明确提示需要重新定位。已授权调用方在状态仍可读时能查询当前快照及可用续读位置。不可访问的会话不返回续读位置或数据。 | V-02 |
| AC-06 | REQ-05 | **如果** 调用来自其他用户、租户或接入方，或者原用户已撤权、停用或当前权限无法确认，**系统应** 拒绝对应的取消、状态、结果、事件或追踪访问，不返回受保护内容，也不改变原运行。 | V-01、V-02 |
| AC-07 | REQ-05、REQ-06 | **当** 调用方仅获准读取状态或事件，**系统应** 只返回对应授权内容。仅获准读取追踪关联时只返回关联标识。有结果读取权限时，仍可独立读取符合原版本约定的结果。 | V-02 |
| AC-08 | REQ-01、REQ-06 | **当** 原反向执行或单文本交互流程未请求取消，**系统应** 继续按已绑定版本执行，重复启动可拿回原会话，等待点可由另一 Worker 续跑，最终结果可独立查询。 | V-02 |

| ID | 验证方式 | 当前状态 |
| --- | --- | --- |
| V-01 | 隔离 Mock 的状态、权限和竞争验证。用可控执行边界及时间覆盖取消重试、超时、成功先提交、答案竞争与迟到任务。 | `PASS`，隔离 Mock |
| V-02 | 隔离调用与独立 Worker 验收。串联固定版本、文本等待、取消、断线续读及终态查询，复用现有反向调用和原生交互回归。 | `PASS`，隔离 Mock |
| V-03 | 受控基础设施验收，核对实际权限、事务竞争和跨进程补偿。 | `NOT_RUN`，待环境 |
| V-04 | 使用昆联测试租户、授权与拒绝样例验证正式会话控制、事件续读和授权边界。 | `NOT_RUN`，待双方契约和联调环境 |
