# Release Contract — v3.0.0

> 本文件登记 v3.0.0 新增特性的领域归属与跨特性约束。已在
> [v3.0.0-beta1](../v3.0.0-beta1/release-contract.md) 和
> [v3.0.0-beta2](../v3.0.0-beta2/release-contract.md) 登记的能力继续有效；
> 架构规则以 [constitution.md](../../docs/constitution.md) 为准。

## 表 1：领域对象归属

| 领域对象 | Owner Feature | 说明 |
|---|---|---|
| 无新增领域对象 | F077-subject-id-search | 现有授权及选人入口按业务 ID 完整值和前缀检索，保留主线范围和稳定身份；仅增加查询索引，不改变授权模型或写入合同 |
| 助手工作区（workflow 助手节点与助手应用的会话级文件空间）及交付文件 | F078-agent-skills | 负责工作区的分配、隔离、跨节点可读和随会话清理；技能本身仍归 F035 技能库，F078 只读取已启用技能，不取得技能的领域所有权 |
| 子工作流引用关系（父工作流当前版本中【子工作流】节点指向的工作流） | F086-nested-workflow | 负责引用关系的登记、同步、删除拦截与保存提醒；工作流本身仍归既有 flow 模块，F086 不改工作流的存储与版本合同 |
| 网页读取内置工具及其配置、网页读取引用来源 | F085-web-fetch | 新增独立内置工具，配置与联网搜索分开保存；网页读取来源复用既有网页角标链路展示，不取得角标领域对象的所有权 |
| MinerU 4.0 解析提供方及其配置 | F076-mineru-v4 | 负责新增提供方的选择、输入输出适配和配置；复用既有知识文件及预览对象，不取得这些对象的领域所有权 |

## 表 2：跨 Feature 不变量

| ID | 不变量 | 涉及对象 | 来源 |
|---|---|---|---|
| V3-INV-1 | 选择旧 MinerU 提供方时，旧请求协议和解析行为保持可用；新提供方必须显式启用，不通过失败自动切换 | 解析提供方 | F076 AC-01、AC-02、AC-10 |
| V3-INV-3 | ID 检索不改变主线授权、成员和审批写入合同，不引入客户定制；用户/部门按 external_id，组按数字 ID，保存仍用原内部 ID | 授权及管理选择器 | F077 AC-01、AC-02、AC-07 |
| V3-INV-4 | 网页读取与联网搜索的设置互不影响；修改或切换其中一个工具的引擎和秘钥，不改变另一个工具的行为 | 内置工具设置 | F085 AC-04 |
| V3-INV-5 | 未配置技能的助手节点和助手应用与改动前行为一致；技能可用集合只由租户技能库的启用开关决定，与任务模式共用同一开关 | 助手节点、助手应用、技能库 | F078 AC-06、AC-25、AC-27 |
| V3-INV-6 | 【结束】节点「返回结果」开关关闭（含旧数据无该参数）时，工作流的运行行为与改动前一致 | 【结束】节点、工作流引擎 | F086 spec §3 |
| V3-INV-2 | 文件预览结果若被用户接受并复用于入库，入库正文须与用户看到的预览结果一致；提供方切换本身不强制重算已接受的预览结果 | 预览、知识文件 | F076 AC-08 |

## 表 3：Feature 依赖图

| Feature | 依赖 | 说明 |
|---|---|---|
| F076-mineru-v4 | 既有知识文件解析、预览、分块和引用链路 | 扩展现有解析提供方，不新建知识文件领域对象 |
| F078-agent-skills | F035 技能库；平台已配置的代码执行器 | 读取技能包和启用状态，复用代码执行器；不改技能库的管理与存储合同 |
| F086-nested-workflow | 既有工作流引擎、版本与权限链路 | 子工作流在父工作流的 worker 线程内运行；不改工作流存储与授权模型 |
| F085-web-fetch | 联网搜索 DeepSeek 引擎（e5f616b10、eb03de547）、网页角标链路（F069、F072） | 复用网页来源的注册、卡片和历史回放 |
| F085-web-fetch | DeepSeek Fetch 接口 | 第一期唯一读取引擎，抓取由 DeepSeek 服务端完成 |
| F076-mineru-v4 | 独立部署的 MinerU 4.0 解析服务 | 服务版本和能力由部署环境确认 |

## 已分配模块编码（MMMEE）

本特性优先复用知识模块现有错误码。若实施中确需新增错误码，先按
`docs/constitution.md` C5 扫描实际占用并更新本表；当前不预留新模块编码。

| 编码 | 模块段 | Feature | 说明 |
|---|---|---|---|
| 11075 | 110 灵思（技能管理段已由技能中心用到 11074，顺延） | F078-agent-skills | 配置的技能已被管理员停用 |
| 11076 | 同上 | F078-agent-skills | 配置的技能已被管理员删除 |
| 11077 | 同上 | F078-agent-skills | 当前模型的执行方式不支持技能 |
| 10560 | 105 flow | F086-nested-workflow | 子工作流内部节点失败或构造失败 |
| 10561 | 同上 | F086-nested-workflow | 子工作流不存在（运行时，或上线时草稿指向的工作流已被删除） |
| 10562 | 同上 | F086-nested-workflow | 引用的返回结果不存在 |
| 10563 | 同上 | F086-nested-workflow | 子工作流运行中到达禁止节点 |
| 10564 | 同上 | F086-nested-workflow | 上线时子工作流不满足条件 |
| 10565 | 同上 | F086-nested-workflow | 删除被引用的工作流 |
| 10566 | 同上 | F086-nested-workflow | 新增引用的工作流没有编辑权限 |

11060 不使用：前端 locale 仍保留已下线 SOP 错误码的旧键。
