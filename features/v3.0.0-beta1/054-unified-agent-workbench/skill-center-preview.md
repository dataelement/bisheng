## 页面与操作

| 位置 | 用户操作 | 页面结果 |
| --- | --- | --- |
| 工作台侧栏 | 点击“技能中心” | 打开统一技能列表，保留对话缓存 |
| 输入框加号菜单 | 展开“技能” | 同一面板内展示可用技能列表、上传入口和“管理技能” |
| 技能菜单 | 点击某个技能 | 打开该技能详情 |
| 技能菜单 | 点击“上传技能” | 弹窗选择文件，原对话保留 |
| 技能菜单 | 点击“管理技能” | 打开管理页 |
| 技能中心 | 搜索名称或说明 | 列表即时过滤，可清空搜索 |
| 上传弹窗 | 选择或拖入已有 Skill 文件 | 校验后显示名称、说明、大小和文件清单，确认后添加 |
| 技能详情 | 查看任意技能 | 展示名称、说明和来源 |
| 个人技能详情 | 更新、启停、删除 | 更新保留原 ID 和启停设置；删除前确认 |

默认不按企业/个人分栏；管理动作按技能的归属展示。企业技能由已有的 `/api/v1/linsight/skill/selectable` 读取，列表包含当前账号实际可用的技能。企业维护详情说明跟随现有能力口径。

2026-09-10 根据用户补充的 Kimi 截图，输入框加号菜单统一使用一个“技能”一级入口。桌面端展开右侧面板；移动端在当前菜单内进入技能面板，并提供返回入口。面板上方合并展示可用技能的名称和说明，列表可以滚动；底部固定展示上传已有技能和管理技能。个人停用的技能仍保留在完整管理页中。点击技能进入详情，任务按现有逻辑自动选用技能。

按用户后续反馈，技能列表沿用原选择器的紧凑行布局。名称或说明被截断时，鼠标悬停或键盘聚焦该行，在右侧展示完整名称和说明；空间不足时由现有 Tooltip 组件避让。截断检测与原 `SkillSelector` 共用 `useIsClipped`，面板宽度变化后重新检测。桌面技能面板宽 280px，高度随内容变化，最高 440px；底部分隔线下仅保留“上传技能”“管理技能”两个普通菜单项。文件格式说明和前端预览提示保留在上传弹窗及完整管理页面。

技能中心保留两列，采用四行共 8 张卡片的首屏密度目标。页面内容最大宽度 960px，卡片最小高度 128px、间距 12px，页面超出视口时继续滚动。卡片展示名称、标识和两行说明；启停操作保留在个人技能详情中。整张卡片可点击进入详情；“查看详情”位于右上角，在鼠标悬停或键盘聚焦时显示，触屏设备保持可见。技能数量按实际数据展示。

## 前端预览的数据边界

个人 Skill 文件和元数据存入当前浏览器 IndexedDB，按当前账号及 `/api/v1/user/current-tenant` 返回的租户隔离。页面、上传弹窗和个人详情显示预览提示。个人技能的启用状态用于预览管理交互；正式上传接口、跨设备同步和任务调用接入留待后端阶段完成。

文件支持 `.md`、`.zip`、`.skill`，预览上限为上传 10 MiB、解压声明体积 100 MiB、1000 个文件或目录、SKILL.md 正文文件 1 MiB。压缩包包含一个 SKILL.md，元数据要求 name 和 description，正文包含技能说明。仅解析文本并保存原始文件。

同一账号个人技能标识重复时，引导到已有技能的更新操作。与企业技能同名时保留两个记录，并提示在详情查看来源。更新失败保留原版本；读取与写入失败显示具体恢复提示；并发操作依据记录 revision 校验，提示刷新后重试。
