> 调研来源（不进展示层）：antd 5 Select（面板属于 Select：`popupRender` / `classNames.popup` / `listHeight` 256 / `popupMatchSelectWidth` / `maxTagCount`；尺寸 24/32/40；多选默认开搜索）、Arco Select（`dropdownRender` / `triggerProps`）、TDesign Select（面板插槽）、Radix Select（Root / Trigger / Value / Content / Viewport / Item / Group / Label / Separator 一个命名空间，listbox 语义；`position` 分 item-aligned 与 popper）、Adobe Spectrum Picker（移动端面板自动换底部 tray；明文禁止子菜单）、Apple HIG Pop-up buttons（「显示互斥选项的菜单」、给有用的默认值、空间有限时用）与 Menus（分组、分隔、勾选标记）、Primer Select。业内共识：**下拉面板是 Select 的一部分，不单独成组件**；拆出去的是「执行动作」的 Dropdown 下拉菜单（menu 语义），两者共用浮层外壳。
> 触发器形态调研（2026-10-21 补）：antd `variant` 四档 outlined / filled / borderless / underlined、Atlassian Select `appearance="subtle"`（「交互或报错前保持透明」）与 PopupSelect（自定义按钮触发）、Radix Themes `variant="ghost"`（无容器、负外边距与同排元素对齐）、Carbon 的 inline 修饰（嵌在仪表盘等内容中、无筛选）、Spectrum `isQuiet`、Apple 的无边框 pop-up button（iOS 日历「重复：永不 ›」）。**没有一家提供「只有箭头」的 Select**：只有箭头的入口都贴在主按钮 / 标题旁，归 Dropdown，或由旁边元素回显值。client 现状：`AiModelSelect`、`Linsight/ModelSelector` 为无边框款（`border-none bg-transparent px-2 text-text-2`，悬停 `fill-1` / `black/5` 两套），`ChatFormTools` 两处为图标 + 文字胶囊款（`h-7 rounded-full`，展开描边 `blue-500`）。
> 设计师拍板（2026-10-21）：面板与 Select 同篇、Dropdown 另起一篇并引用本文 §5；选中标记为右侧 ✓ + 文字加深；多选项用左侧 Checkbox；选项超过 10 个才开搜索、在触发器内直接打字；面板最高 8 行，多选已选项折叠为「+N」。触发器沿用输入框三档与灰环聚焦、面板圆角 12px、已选标签用 Tag small，均为既有规范的直接引用，未单独拍板。

## 1. 什么时候用

选择器让用户**从一组给定的选项里挑出一个或几个值**，挑完把结果显示在框里。

- 选项 ≤ 5 个、且版面放得下，用单选框 / 分段控制器把选项全摆出来——用户不用点开就能比较。
- 选项多、或版面紧，用选择器。
- 答案要用户自由输入，用输入框（见 [组件-Input输入框.md](组件-Input输入框.md)）。
- 点了是**执行一个动作**（重命名、删除、导出），用下拉菜单 Dropdown，不用选择器。判别方法：点完之后框里要不要显示「选了什么」？要显示就是选择器。
- 选项有层级（省 / 市、部门树），不在本文范围，用级联 / 树选择。

| ✅ 推荐 | ❌ 不推荐 | 原因 |
|---|---|---|
| 「排序：最新 ▾」用选择器 | 「排序 ▾」用下拉菜单、点完框里不变 | 当前排序方式是状态，用户要一眼看到它 |
| 卡片「⋯」里放重命名、删除 | 用选择器装重命名、删除 | 动作没有「当前值」，放进选择器会把「删除」显示在框里 |
| 「公开 / 私有」两项用单选框 | 两个选项也做成选择器 | 两个选项点开才看得见，多一步还藏起了另一个选项 |

## 2. 结构 Anatomy

选择器由**触发器**和**面板**两部分组成，两者是一个组件。

| 部分 | 是什么 |
|---|---|
| 触发器 | 收起时看到的框：显示当前值或占位文字，右侧下箭头 |
| 面板 | 点开后出现的浮层，装着选项列表 |
| 选项 | 面板里的一行，可带前缀图标、一行说明 |
| 分组标题 / 分隔线 | 选项多时给选项归类 |

## 3. 类型 Type

| 类型 | 什么时候用 | 触发器里显示 | 面板选项长相 |
|---|---|---|---|
| **单选**（默认） | 挑一个值 | 选中项文字 | 选中项右侧 ✓ |
| **多选** | 挑若干个值 | 已选项用标签排开，放不下折成「+N」 | 每行左侧一个复选框 |

- **搜索不是一个类型，是开关**：选项超过 10 个就打开（§6.3），单选、多选都适用。
- **单选选完立即关闭面板；多选选完不关**，点外部或按 ESC 才关——用户通常要连着挑几个。

### 3.1 触发器形态

先按所在位置挑形态；**表单里一律用描边形态**。

| 形态 | 什么时候用 | 长相 |
|---|---|---|
| **描边**（默认） | 表单、筛选栏 | 同输入框：底色 + 灰描边 + 下箭头 |
| **无边框** | 嵌在工具栏、对话输入区、标题行里的切换（如模型切换），不该像一个待填字段 | 只有当前值文字 + 下箭头；画法同文字按钮——无底无边、悬停出浅灰底（见 [组件-Button按钮.md](组件-Button按钮.md) §2.2） |
| **图标** | 空间极紧，且每个选项都有一眼能认出的图标（如视图切换） | 当前选项的图标 + 下箭头，画法同无边框；**悬停出文字提示写明当前值** |

- **不做「只有下拉箭头」的选择器**。选择器的本分是让人看见当前值，光一个箭头什么都看不见。例外：值已经显示在紧挨着的元素上（页面标题、组合按钮的主按钮），箭头只是打开入口——这时箭头必须贴着那个元素，读屏标签写「切换 XX，当前：YY」。只是放一组动作的箭头，是下拉菜单（见 [组件-Dropdown下拉菜单.md](组件-Dropdown下拉菜单.md) §3）。
- 无边框与图标形态**不承载校验**：不显示错误 / 警告态，需要校验的字段换回描边形态。
- 无边框与图标形态**展开时只铺浅灰底，不出描边**，品牌色描边更不行——展开不是语义时刻，颜色留给真正需要说话的状态（同输入框 §5.1）。
- 无边框与图标形态宽度随内容，长文字截断；面板宽度按 §5.1 触发器窄于 160px 的规则撑宽。
- 三种形态高度都走 §4 的三档，同排对齐。

| ✅ 推荐 | ❌ 不推荐 | 原因 |
|---|---|---|
| 对话输入区的模型切换用无边框形态 | 对话输入区里塞一个带框的表单选择器 | 输入区不是表单，带框的字段会抢走输入框的焦点感 |
| 图标形态悬停提示「列表视图」 | 只放一个图标，没有任何文字说明 | 图标认不出来时用户不知道现在是哪一项 |
| 「我的知识库 ▾」标题整体可点切换 | 标题旁只有一个孤零零的箭头、标题本身不可点 | 用户会去点标题，点不动以为坏了 |

## 4. 尺寸 Size

**描边形态与输入框完全同壳**：三档 24 / 32 / 40，medium 默认，字号、圆角、内边距照 [组件-Input输入框.md](组件-Input输入框.md) §3，本文不另列。同一行的输入框和选择器用同一档，天然对齐。

- 下箭头随档 14 / 16 / 18px，与图标规范、输入框后缀一套。
- **面板不随触发器分档**：选项行固定 32px，small 触发器点开也是 32px 一行——24px 的行太难点准。
- 宽度跟随布局，同一表单里与输入框等宽；不手写高度。
- 圆角默认随档 4 / 6 / 8px，需要时可换档，见 §5.4。

## 5. 面板 Panel

本节同时是下拉菜单 Dropdown 的面板取值来源，Dropdown 规范引用本节、只写差异。

### 5.1 外壳

| 项 | 值 | 说明 |
|---|---|---|
| 底色 | 页面底色 `bg-page` | 与页面同底，靠投影分层 |
| 投影 | 浮层投影 `shadow-popup` | 见 [基础-圆角与阴影规范.mdx](基础-圆角与阴影规范.mdx) §2 |
| 圆角 | 12px | 下拉面板取容器档 xl |
| 内边距 | 6px | 选项文字左缘 = 6 + 6 = 12px，与 medium 触发器的文字对齐 |
| 行间距 | 4px | 选项行之间、行与分组标题 / 分隔线之间同值 |
| 宽度 | 默认与触发器等宽 | 触发器窄于 160px（筛选栏常见）时按内容撑宽，上限 320px |
| 最大高度 | 8 行，296px（8 × 32 + 7 × 4 行间距 + 上下 6） | 超出在面板内滚动 |
| 与触发器间距 | 4px | |
| 层级 | 1100 | 与气泡卡片同档，见 [组件-Modal弹窗.md](组件-Modal弹窗.md) §5 |

### 5.2 选项行

| 项 | 值 |
|---|---|
| 高度 | 32px；带一行说明时随内容长高，上下内边距 5px |
| 文字 | 14 / 22，主文字色 `text-1`；说明 12 / 20 `text-3`，与标题间距 2px |
| 左右内边距 | 6px |
| 圆角 | 6px（外壳 12 − 内边距 6，内外同心） |
| 前缀图标 | 16px，与文字间距 8px；同一组要么都有、要么都没有 |
| 长文字 | 单行截断加省略号，悬停出完整文字；触发器里同样截断 |

### 5.3 分组与分隔

- **分组标题**：12 / 20 `text-3`，上下内边距 4px，不可选中、键盘跳过。前面已有选项时，标题上方再多留 8px（与上一行共 12px），让每组从视觉上另起一段——只靠字号和颜色，标题会被看成一个灰掉的选项。
- **分隔线**：1px `border-base`，上下各留 4px，**与选项行同宽**——留在面板 6px 内边距里，不顶到面板两侧边缘。有分组标题时不再加分隔线，二选一。
- 选项超过 8 个且能自然归类时再分组；少于 8 个的列表分组只会添乱。

### 5.4 圆角可配置

默认圆角就是上面的值，绝大多数场景不用动。**业务场景要求换圆角时，用组件的圆角配置项换档，不要写样式去覆盖**。

| 部位 | 默认 | 可选档 |
|---|---|---|
| 触发器 | 随尺寸取 `sm` / `md` / `lg` | 阶梯全部八档：`sm` `md` `lg` `xl` `2xl` `3xl` `4xl` `full` |
| 面板 | `xl` | `sm` `md` `lg` `xl` `2xl` `3xl` `4xl`（不含 `full`：面板是一块表面，做不成胶囊） |

- **取值就是圆角 token**（`sm` 4px · `md` 6px · `lg` 8px · `xl` 12px · `2xl` 16px · `3xl` 24px · `4xl` 32px · `full` 胶囊），数值以「设计变量 Design Token」页的圆角表为准，组件不写裸 px，也不接受阶梯以外的值（阶梯规则见 [基础-圆角与阴影规范.mdx](基础-圆角与阴影规范.mdx) §1.1）。
- **选项行圆角跟着面板自动走**，保持内外同心（面板 − 6px 内边距，向下归到最近的档，最小 `sm`），不单独配置：

| 面板 | 选项行 |
|---|---|
| `sm` / `md` / `lg` | `sm` |
| `xl`（默认） | `md` |
| `2xl` | `lg` |
| `3xl` | `2xl` |
| `4xl` | `3xl` |

- **触发器和面板各配各的**：触发器换成胶囊，面板不跟着变圆。
- **换档的理由只有一个：和所在区域的同级元素对齐**（同级同档，见《圆角与阴影规范》§1.2.2）。比如对话输入区的工具条整排都是胶囊，里面的选择器就用胶囊。

| ✅ 推荐 | ❌ 不推荐 | 原因 |
|---|---|---|
| 工具条里的选择器配成胶囊，和同排按钮一致 | 用 `className="rounded-full"` 覆盖触发器样式 | 覆盖样式绕开了档位，组件升级时会被冲掉或打架 |
| 面板换 `2xl` 时选项行自动变 `lg` | 面板改 `2xl`、选项行还是 `md` | 内外圆弧不同心，角上的空隙一头宽一头窄 |

## 6. 内容形态

### 6.1 占位文字与默认值

- **能给默认值就给**，挑大多数人会选的那一项（如「默认模型」）——空框等于让用户多做一次决定。
- 没有合理默认值时写占位文字「请选择 + 对象」，如「请选择知识库」；用提示文字色，与输入框 §4.1 同一档。

### 6.2 多选的已选项

- 已选项用 [组件-Tag标签.md](组件-Tag标签.md) 的 **small 档（20px）可关闭标签**，标签间距 4px，点 × 直接取消该项。
- **触发器高度固定不长高**：一行放不下时，放得下的照常显示，其余折成一个「+N」标签（默认色 small 档），悬停「+N」列出被折叠的项。
- 一个都没选时显示占位文字。

### 6.3 搜索

- **选项超过 10 个打开搜索**；10 个以内靠眼睛扫更快。
- 搜索在**触发器里直接打字**：点开即进入输入，原值变成浅色提示文字留在框里，敲第一个字时消失。多选时光标跟在已选标签后面。
- 按选项文字匹配，不区分大小写；没有匹配时面板显示「无匹配结果」（§6.5）。
- 选项来自服务端时边打字边查，结果回来前面板显示加载中（§6.5）。

### 6.4 一键清除

规则同输入框 §4.3：搜索、筛选类默认开，正式表单默认不开。有值且悬停时，**清除图标替换下箭头的位置**，不并排出现。

### 6.5 空、加载、加载更多

面板里只放一行文字，不放插画——面板是临时浮层，插画会把它撑成一张卡片。

| 情况 | 面板里显示 |
|---|---|
| 没有任何选项 | 「暂无数据」，14 / 22 `text-3`，居中，上下内边距 16px |
| 搜索无结果 | 「无匹配结果」，同上 |
| 加载中 | 16px 圆环 + 「正在加载…」，内联级，见 [组件-Loading加载.md](组件-Loading加载.md) §3 |
| 滚到底加载更多 | 列表尾部加载，见 [组件-Loading加载.md](组件-Loading加载.md) §2.2 |

| ✅ 推荐 | ❌ 不推荐 | 原因 |
|---|---|---|
| 8 个模型选项不开搜索 | 只有 4 个选项也挂搜索框 | 几个选项一眼扫完，搜索只是多一个要理解的东西 |
| 多选折成「标签 A、标签 B、+3」 | 选了 5 个就把触发器撑成三行 | 触发器长高会把下面的表单推下去，同排控件也对不齐 |
| 面板为空写「暂无数据」 | 面板为空就弹出一块空白 | 空白面板看起来像加载失败，用户会反复点 |

## 7. 状态 State

### 7.1 触发器

触发器的常态 / 悬停 / 聚焦 / 只读 / 禁用 / 错误 / 警告七态**全部照搬输入框 §5.2**，包括聚焦用灰描边 + 灰阴影环、不用主题色。选择器只多两条：

- **展开 open**：画法同聚焦，下箭头旋转 180°；面板开着时触发器一直保持这个样子。
- **只读**：不显示下箭头、点击不展开，值可以选中复制。
- **无边框 / 图标形态**：常态、悬停、禁用、键盘聚焦环照文字按钮；展开时保持悬停底色、不出描边、下箭头旋转 180°；没有错误 / 警告态（§3.1）。

### 7.2 选项

| 状态 | 样式 |
|---|---|
| 常态 | 透明底，`text-1` 字重 400 |
| 悬停 / 键盘高亮 | 浅灰底 `fill-2`；键盘上下键移动的就是这一块高亮，与悬停同一个样子 |
| 选中（单选） | 文字加深为字重 500，右侧 16px 品牌色 ✓；**不加底色**，底色只留给悬停 |
| 选中（多选） | 左侧复选框勾上（16px，与文字间距 8px），文字不变 |
| 禁用 | 文字 `text-4`，无悬停，「禁止」光标；多选的复选框同步禁用 |

| ✅ 推荐 | ❌ 不推荐 | 原因 |
|---|---|---|
| 选中项打 ✓、悬停才铺灰底 | 选中项铺浅色底、悬停也铺浅色底 | 两种底色叠在一起，用户分不清哪个是「选中」哪个是「指着」 |
| 多选用左侧复选框 | 多选也只在右侧打 ✓ | 复选框一眼看出能挑多个；只有 ✓ 时用户以为点一下就关 |

## 8. 位置与交互

- **默认在触发器下方、左边对齐**；下方空间不够时翻到上方。**面板不盖住触发器**——用户要看着当前值做选择。
- 点开时面板**滚到当前选中项**，让它出现在可视区里。**没有选中值时，用鼠标点开不预先高亮任何一项**——灰底一铺上，用户会以为第一项已经选好了；用键盘（方向键、回车、空格、字母）打开时仍从第一项开始高亮，键盘用户需要一个起点。高亮为空时按 ↓ 从第一项开始，按 ↑ 从最后一项开始。
- 点外部、按 ESC 关闭面板，焦点回到触发器。
- 键盘：上下键移动高亮，回车选中；未开搜索时敲字母跳到首字匹配的选项；Tab 关闭面板并移到下一个控件。
- **面板里不放子菜单**——选择器选的是一个值，一层选项就够；要层级用级联选择。
- 动效：淡入 150ms 并从触发器方向滑入 4px，淡出 100ms，与文字提示、气泡卡片同一组时长。

## 落地（给实现窗口）

1. **组件位置**：`packages/ui/src/components/Select/`，基座 `@radix-ui/react-select`（单选）。对外一个 `Select`，`multiple` / `showSearch` / `allowClear` / `size` / `status` / `loading` / `options`（含 `group`、`icon`、`description`、`disabled`）。**Content 用 `position="popper"`，不用默认的 `item-aligned`**——后者会把面板对齐到选中项、盖住触发器，违反 §8。多选与可搜索 Radix Select 不支持，建议用 Radix Popover + listbox（或 cmdk / ariakit Combobox）自组，读屏语义保持 `role="combobox"` + `role="listbox"` + `aria-multiselectable`；选型由实现窗口定，记入改动记录。
2. **触发器**：直接复用 `Input/shared.ts` 的外壳 cva（三档、七态、`shadow-focus` 灰环、`borderless`），不另写一套。`data-state=open` 套聚焦样式；下箭头 `Outlined.Down` 随档 14/16/18，`group-data-[state=open]:rotate-180`。清除用 `Filled.CloseCircle` 14px（同输入框 §4.3 的固定尺寸与 `text-4` / 悬停 `text-3`）。
3. **面板 token**：`bg-page shadow-popup rounded-xl p-1.5 dark:border dark:border-border-base`，`max-h-[296px] overflow-y-auto flex flex-col gap-1`（行间 4px），`z-popover`，`sideOffset=4`，宽 `min-w-[var(--radix-select-trigger-width)]`、触发器 < 160px 时 `max-w-[320px]` 按内容。选项 `h-8 rounded-md px-1.5 text-body text-text-1`，高亮 `data-[highlighted]:bg-fill-2`，选中 `font-medium` + `Outlined.Check` 16px `text-primary`（品牌色 token 以 `design-token.cjs` BRAND 为准）；禁用 `text-text-4`。分组标题 `text-caption text-text-3 px-1.5 py-1`，分隔 `h-px bg-border-base`（上下 4px 由行间距提供，自身不带外边距）。组件内无裸 hex、无 Tailwind 预设投影。
4. **多选**：选项左侧复用 `@bisheng/ui` 的 `Checkbox`（medium 16px）；已选项 `<Tag size="small" closable>`，`gap-1`；折叠按触发器实测宽度计算（ResizeObserver），「+N」为 `<Tag size="small">` 外包 `Tooltip`。
5. **搜索**：`options.length > 10` 时默认开启，`showSearch` 可显式覆盖。服务端搜索给 `onSearch`（防抖 300ms）+ `loading`。
6. **移动端**：`< 576px` 面板改走底部面板形态（复用 Drawer 的底部滑入），选项 `h-11`；触发器挂 `.input-no-zoom` 与 `.input-touch-hit`（输入框落地区第 5 条）。
7a. **圆角配置**（§5.4，2026-10-21 设计师要求）：类型直接取 `design-token.cjs` 的 RADIUS 名（`type RadiusToken = typeof RADIUS[number]["name"]`，不手抄联合类型）：Select 暴露 `radius?: RadiusToken`（缺省 = 随 `size` 取 sm / md / lg）与 `panelRadius?: Exclude<RadiusToken, "full">`（缺省 `xl`），映射到 `rounded-*` token 类，不接受任意字符串。选项行圆角由面板派生：`menuSurface.ts` 里写一张 `panelRadius → 选项行 rounded-* 类` 的映射（sm / md / lg → `rounded-sm`，xl → `rounded-md`，2xl → `rounded-lg`，3xl → `rounded-2xl`，4xl → `rounded-3xl`），经 context 下发给选项行——现有圆角 token 只有 Tailwind 类（sm / md / lg 由 `--radius` 派生、其余为 Tailwind 原生档），没有逐档 CSS 变量，所以走类名映射，不新造变量。业务侧对触发器 / 面板 `className` 里出现 `rounded-*` 视为违规，评审拦截（可加 eslint 规则，非必须）。Dropdown 共用 `panelRadius` 与同一派生变量（`menuSurface.ts`）。
7. **触发器形态**：`variant: "outlined" | "ghost" | "icon"`，默认 `outlined`。`ghost` / `icon` 直接复用 `Button` 的 `default × text` 样式（hover / active / disabled / `focus-visible` 环），水平内边距随档 4 / 8 / 8，`status` 在这两档上忽略并在 dev 下 warn。`icon` 档触发器内只渲染选中项的 `icon`，外包 `Tooltip`（内容为选中项 label），`aria-label` 由调用方传。不提供 `chevron` 档；值在外部展示的「箭头入口」由调用方用 `Select` 的受控 `open` + 自定义 `trigger`（`asChild`）实现，且必须传 `aria-label`。现状归并：`AiModelSelect` / `Linsight/ModelSelector` → `ghost`（两套悬停底 `fill-1` / `black/5` 统一为文字按钮悬停 token、13px 字号回 14px 档）；`ChatFormTools` 两处图标 + 文字胶囊 → `ghost` + `radius="full"`（2026-10-21 设计师拍板）：删 `data-[state=open]:border-blue-500`，展开只保留悬停底色；`h-7`（28px，档外）收到 small / medium 档由迁移时目检定；联网搜索开启时的 `bg-blue-100` 是业务开关态，不属于 Select 状态，迁移时原样保留并请设计师过目。
8. **动效**：复用 Tooltip 的 150ms 淡入 / 100ms 淡出 token，叠加 `data-[side=bottom]:slide-in-from-top-1` 系 4px 位移。
