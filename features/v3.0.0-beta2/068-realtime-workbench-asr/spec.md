# 流式 ASR 模型接入与连续语音输入

确认依据：2026-09-20 用户在本任务明确要求按精简交互开发并部署 119:3007，覆盖此前飞书草案的状态设计。已确认 PRD： https://dataelem.feishu.cn/wiki/Vx80wZZgzibNuQkHKCOcBxNJnsp#doxcnIZhVIG7iS7CIkNdcQooc1e （2026-09-20，revision 183，多厂商扩展 v0.3）。

- AC-01：模型管理允许配置阿里 Paraformer、Qwen，以及火山引擎、百度智能云语音、腾讯云实时 ASR；检测发送样音并获得最终识别文本。
- AC-02：沿用系统模型配置中的 ASR 选择，按适配能力决定调用方式。
- AC-03：工作台及知识空间保留一个语音入口，输入框有文字和附件时仍可开始录音。
- AC-04：点击开始后录音；点击暂停立即关麦、恢复普通按钮，后台收尾接收最后文字。
- AC-05：非流式暂停后提交整段音频，流式在说话期间持续更新文字。每次录音在已有文字上继续输入。
- AC-06：输入框保持已有内容。用户修改识别范围时以用户输入为准，结束该次录音；最终文字和中间文字按段替换，重复事件保持幂等。
- AC-07：保持当前代码的 10 分钟上限。界面只表达开始/暂停；空识别结果保留原输入。
- AC-08：卸载或取消及时释放资源，迟到回调保持隔离。基本调用错误沿用提示，自动重连、无语音专门判断和连接/收尾状态展示属于后续范围。
- AC-09：在当前 3007 版本上部署，保留技能中心及其他功能；各厂商真实模型效果由用户配置后验证。

2026-09-20 追加确认：用户要求继续支持火山、百度千帆及其他主流厂商接口。沿用现有 ASR 选择和工作台交互，新增火山豆包语音、百度智能云语音、腾讯云语音三种原生协议。

- AC-10：每家厂商分别配置其语音服务凭据。仅配置 ASR 时只校验语音凭据；同时配置 LLM 时分别校验两组凭据，编辑保留已有配置。
- AC-11：新增型号通过精确能力登记切换为实时输入；文件识别和模型检测使用同一适配器完成最终文本收集。
- AC-12：语音密钥在配置响应中脱敏；保留脱敏值再次保存时恢复原密钥。
