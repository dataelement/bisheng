# F119 API 验收

沿用功能场景的真实账号和数据。目标库测试夹具的候选维护人员不超过 100 人。

| 编号 | 前置条件及操作 | 预期 |
|---|---|---|
| API-119-01 | 反馈待分派，负责人和无权限用户分别读取知识库选项，负责人查询关联库和无关库的维护人员 | 库选项包含关联库，排除无关库。候选包含目标维护人员。无权限和无关库查询被拒绝 |
| API-119-02 | 负责人重复分派，再在结果提交后重复回复 | 各动作首次成功，重复请求被拒绝，第一次回复保留 |
| API-119-03 | 原提交人读取已回复反馈 | 显示已发回复，响应省略内部处理结果、受派人及分派知识库 |
