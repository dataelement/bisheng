# Feature: 桌面消息评价的模型审计记录

**版本**：v3.0.0 work-130。按用户 2026-11-09 授权修复并集成 PR #2646，补记现有功能，不追认历史 SDD 审批。关联 [design.md](./design.md) · [tasks.md](./tasks.md)。

## 用户故事与验收标准

桌面用户对消息的赞踩在对应审计会话中独立保存，管理员查看数量和详情，不要求网页聊天记录拥有桌面消息编号。

| ID | 角色 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| AC-01 | 已认证桌面用户 | 评价本人已有审计会话的消息 | 保存评价并在授权审计页显示数量和内容，不触发模型调用或计费 |
| AC-02 | 桌面用户 | 更新、重试或乱序发送评价 | 同序号同内容幂等、不同内容冲突，旧序号拒绝，新序号可更新 |
| AC-03 | 桌面用户 | 撤销后重放旧评价，或撤销先于写入到达 | 保持撤销状态，列表数量为零，详情不返回已撤销内容；新序号可再次评价 |
| AC-04 | 其他用户或租户 | 访问不属于本人的会话反馈写入 | 不允许跨身份或跨租户写入；审计查询沿用既有管理范围 |
| AC-05 | 桌面用户 | 提交不合法反馈或遇到存储错误 | 拒绝不合法输入，存储故障只暴露通用错误；不调用模型 |

## 边界

本功能不改变模型上下文、原文审计开关、审批或计费。桌面消息 ID 作为会话下的独立反馈键，不伪造它与网页消息或单次模型请求的对应关系。
