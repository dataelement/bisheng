# 文字提示 Tooltip

悬停 / 聚焦触发的一句纯文字说明。组件库 `@bisheng/ui` 导出 **`Tooltip`**（外加可选的 `TooltipProvider`），基座 Radix Tooltip。规范全文见「文档 → 组件规范 → 文字提示 Tooltip」。

**内容里有链接、按钮、输入框的任何一个，它就不是 Tooltip，用 Popover**——键盘焦点永远进不去 tooltip，里面的可点元素对键盘用户等于不存在。所以也没有「带标题和按钮的加强版 tooltip」。

**触屏上什么都不显示**，也不做长按替代。由此反推出桌面端的铁律：tooltip 只装「没看到也不误事」的信息。

## 长相

半透明深灰底 + 浅色字，14/22 正文档，上下 6px / 左右 12px 内边距（单行总高 34px），圆角 6px，最大宽度 250px 超出自动换行，浮层投影档、不描边；箭头恒定带（没有无箭头档），是 8×8 旋转方块，与气泡同底色同透明度。悬停下面两个按钮看气泡。

```tsx
import { Button, Tooltip } from '@bisheng/ui';

export default () => (
  <div style={{ display: 'flex', alignItems: 'center', gap: 16, padding: '48px 0 8px' }}>
    <Tooltip content="恢复默认设置">
      <Button color="default" variant="outlined">恢复默认</Button>
    </Tooltip>
    <Tooltip content="模型输出结果仅供参考，重要结论请结合知识库原文进行二次核对">
      <Button color="default" variant="outlined">长文案</Button>
    </Tooltip>
  </div>
);
```

底色与文字取的是灰阶**两端**（最深档 90% 不透明度 + 最浅档），不是写死的白字——两端在深色模式下一起翻转，气泡自动变成浅底深字，不会白字压在近白底上。两种品牌主题（蓝 ⇄ 绿）下长相相同，不换肤。

## 悬停 / 聚焦触发

指针进入 **100ms** 后出现；同组控件间快速移动（300ms 内）时下一个提示立即出现，不再各等一次。键盘 Tab 聚焦**立即**出现。ESC 关闭；指针可移进浮层（读长内容、复制文字），移入期间不消失；不自动超时消失。

「300ms 内不再等一次」需要一个**共享的** `TooltipProvider`——所以应用根上挂一个。不挂也能用（每个 `Tooltip` 自带兜底 provider），只是各自计时。试试在下面一排图标按钮上滑动，或用 Tab 逐个聚焦：

```tsx
import { Outlined } from 'bisheng-icons';
import { Button, Tooltip, TooltipProvider } from '@bisheng/ui';

// 单 icon 按钮的 aria-label 与 tooltip 文案同源，不写两份——读屏用户不悬停
const Item = ({ label, icon }: { label: string; icon: React.ReactNode }) => (
  <Tooltip content={label}>
    <Button color="default" variant="text" iconOnly aria-label={label}>
      {icon}
    </Button>
  </Tooltip>
);

export default () => (
  <TooltipProvider>
    <div style={{ display: 'flex', alignItems: 'center', gap: 4, padding: '48px 0 8px' }}>
      <Item label="重命名" icon={<Outlined.Edit />} />
      <Item label="固定到侧栏" icon={<Outlined.Pin />} />
      <Item label="下载副本" icon={<Outlined.Download />} />
      <Item label="删除会话" icon={<Outlined.Delete />} />
    </div>
  </TooltipProvider>
);
```

## 十二方位

`side` × `align`：上 / 下 / 左 / 右 × 居中 / 首端 / 尾端，**默认上方居中**；空间不够时自动翻到对面，任何情况下不被视口裁掉。同一排控件统一用同一个方位——提示位置跳来跳去会打断视线。

```tsx
import { Button, Tooltip, TooltipProvider } from '@bisheng/ui';

const Cell = ({ side, align, label, row, col }: {
  side: 'top' | 'bottom' | 'left' | 'right';
  align: 'start' | 'center' | 'end';
  label: string;
  row: number;
  col: number;
}) => (
  <div style={{ gridRow: row, gridColumn: col }}>
    <Tooltip content="提示文案" side={side} align={align}>
      <Button color="default" variant="outlined" size="small" style={{ width: 72 }}>
        {label}
      </Button>
    </Tooltip>
  </div>
);

export default () => (
  <TooltipProvider>
    <div
      style={{
        display: 'inline-grid',
        gridTemplateColumns: 'repeat(5, 72px)',
        gridTemplateRows: 'repeat(5, 24px)',
        gap: 12,
        padding: '48px 100px',
      }}
    >
      <Cell side="top" align="start" label="上左" row={1} col={2} />
      <Cell side="top" align="center" label="上" row={1} col={3} />
      <Cell side="top" align="end" label="上右" row={1} col={4} />
      <Cell side="left" align="start" label="左上" row={2} col={1} />
      <Cell side="left" align="center" label="左" row={3} col={1} />
      <Cell side="left" align="end" label="左下" row={4} col={1} />
      <Cell side="right" align="start" label="右上" row={2} col={5} />
      <Cell side="right" align="center" label="右" row={3} col={5} />
      <Cell side="right" align="end" label="右下" row={4} col={5} />
      <Cell side="bottom" align="start" label="下左" row={5} col={2} />
      <Cell side="bottom" align="center" label="下" row={5} col={3} />
      <Cell side="bottom" align="end" label="下右" row={5} col={4} />
    </div>
  </TooltipProvider>
);
```

## 禁用控件的提示

禁用控件也要能出提示，说明满足什么条件才能用。禁用元素不派发鼠标事件，**组件内部**会给它包一层可聚焦热区（`span` + `tabIndex=0`）——业务页照常写 `<Tooltip><Button disabled>`，不用自己包，也不许自己包。

```tsx
import { Button, Tooltip } from '@bisheng/ui';

export default () => (
  <div style={{ padding: '48px 0 8px' }}>
    <Tooltip content="勾选至少一项后可删除">
      <Button color="danger" variant="outlined" disabled>批量删除</Button>
    </Tooltip>
  </div>
);
```

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `content` | `ReactNode` | — | 一句纯文字。放链接 / 按钮 / 输入框请改用 Popover |
| `children` | `ReactElement` | — | 触发元素，应当是可聚焦的（按钮、链接、输入框）；`disabled` 的会被自动包热区 |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'top'` | 方位，空间不足自动翻面 |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | 交叉轴对齐 |
| `disabled` | `boolean` | `false` | 只保留触发元素、整个浮层不挂载——用于「只在真的截断时才提示」这类场合 |
| `open` / `defaultOpen` / `onOpenChange` | — | — | 受控 / 非受控开合，转交 Radix |
| `contentClassName` | `string` | — | 气泡的附加类名。底色、字号这些不是页面级决定 |

`TooltipProvider`：`delayDuration`（默认 100）、`skipDelayDuration`（默认 300）。**默认值就是规范**，改它要有理由。

以下三件事组件已经替业务页决定了，不开 prop：`disableHoverableContent` 恒为 `false`（关掉即违反 WCAG 1.4.13 悬停内容必须保持可见）、`z-index` 恒为最高浮层档 1300（弹窗里的图标钮也要有提示）、触屏不响应（不做长按替代）。
