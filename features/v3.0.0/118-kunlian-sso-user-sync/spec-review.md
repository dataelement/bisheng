## 4. 本轮收口与自审修正

1. 明确人工授权记录保留是用户对补充说明“撤销本地授权”的限定，停用拒绝仍成立，不能将其记作原文已明确的默认策略。
2. 将“系统接受可信停用后拒绝新访问”与“上游变化多久传播到本地”区分；后者没有上游时效协议，不拿五分钟建议同步周期冒充撤权保证。
3. 区分全部接口返回目录与尚不可获取的空租户／组织树／组成员，不让全租户字样变成不可实现的完整目录承诺。
4. 退出后旧会话不能复活；用户重新发起并完整通过的新授权仍可创建新会话，避免把正常 SSO 重登误判成违规恢复。
5. 补齐 REQ-03 对 AC-15 的反向追溯，保持需求覆盖表与 AC 定义一致。
