# 模型列表获取与批量配置

用户于 2026-10-12 确认直接开发并部署 119:3006，2026-10-13 恢复内网连接后继续部署。

管理员填写供应商连接信息，完成输入后获取当前凭据可见的模型。用户搜索、勾选多个模型，统一填入配置，检查后保存。系统优先读取类型元数据，再匹配已知模型系列；未知模型由用户选择类型。已有模型继续保留，重复名称按稳定模型 ID 去重。

获取与填入阶段只修改编辑中的配置。原有模型 ID、默认模型引用、租户隔离、密钥脱敏、模型状态验证、限流和分享合同继续沿用现有保存流程。修改连接信息后清空查询结果与选择，并丢弃旧请求的返回结果。

支持 OpenAI 兼容列表、Anthropic 分页列表、Ollama 本地列表和 Xinference 类型元数据。供应商缺少列表接口时采用手动配置。API 返回的 ASR/TTS 等类型按当前运行适配器的可用范围展示；需要新增运行适配的类型显示待适配。图片与视频模型保留展示并显示待适配。

鉴权失败、连接失败、超时、空列表、返回格式异常分别反馈，并支持重新获取或手动添加。凭据仅用于当前请求，接口返回模型 ID、展示名和类型信息。

## 2026-10-16 确认的交互更新

- API 连接信息填写完成后，以弹窗展示获取中的状态和模型列表；也可通过【选择模型】再次打开。
- 弹窗提供名称搜索、类型筛选、当前结果全选、多选计数与确认添加。已识别类型展示标签，未知类型确认后可选，已有模型显示已添加状态。
- 确认添加后弹窗收起，页面展示已添加模型。关闭后重新打开保留本次待确认的选择；确认添加前只维护选择草稿。
- 已添加模型采用紧凑列表，集中展示模型名称、类型、配置摘要与操作。点击【配置】展开模型名称、类型和参数；点击【收起】后保留编辑值。手动新建的空模型默认展开，缺少必填配置的模型显示待完善状态。
- 服务设置位于模型列表之后；模型添加、参数调整及服务设置通过页底【保存】统一持久化。

## 展开区与高级参数统一

展开区集中排列模型名称、模型类型、供应商可用的网络搜索开关和高级参数入口；宽度充足时同排，空间收窄时自动换行。类型统一展示为 LLM、Embedding、Rerank、ASR、TTS，选择弹窗、已添加列表与类型下拉保持一致。输出长度统一通过高级 JSON 参数配置，Ollama 沿用 num_ctx 的上下文长度语义。打开高级配置时展示既有独立字段对应的生效值，确认修改后以高级参数保存；原独立字段在该模型配置中移除。取消保持既有配置，显式清空则恢复该模型高级参数默认值。原有配置在用户编辑前继续按既有逻辑生效。


## 存量升级与既有功能

版本升级时统一将语言模型旧 `config.max_tokens` 的有效值迁入高级 `config.user_kwargs`，沿用旧值高于同名高级参数的优先级；Ollama 对应 `num_ctx`，其余供应商对应 `max_tokens`。迁移完成后移除该模型旧字段，并保留其他高级参数。缺少旧字段的模型按原配置使用；旧值为 0、空或 null 时保留高级参数中的既有值，清理旧字段。非法高级 JSON、异常旧值及失效关联要求人工处理，整批预检通过后统一写入。

升级操作提供全租户与指定租户范围、默认只读预检、写入前私有备份、幂等重跑与配置一致性保护的恢复。模型 ID、服务关联、类型、所有权、授权、状态及默认模型引用保持原值。恢复时保护升级后编辑与新增模型。结构和索引沿用目标版本，业务数据转换通过独立升级脚本执行；API、Worker 与 Linsight 在迁移后重启以刷新模型进程缓存。

每日调用限制沿用服务商级的 limit_flag 与 limit，开关关闭时保存原次数，开启后按服务商和服务日期共享计数。新服务默认关闭、次数为 1。获取模型及高级参数迁移继续保留配额字段，升级保留已有 Redis 调用计数。
