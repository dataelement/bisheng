# F026｜隔离租户双后端验收清单（T056）

**当前结论：未取得真实服务或浏览器证据，不能放行。** 下列复选框均非执行结果。自动入口只验两个指定空间的 Work 检索和两个既有知识引用；不代替 [55 条 QA 用例](./test-cases.md)、双库并发/恢复或 [37 项 AC](./spec.md)。

## 先准备夹具，再启用测试

- 验收负责人明确授权本次使用团队自有的**隔离、非生产**环境，核对 API、Platform 和 Client `/workspace` 的准确 URL、TLS 证书、数据保留与测试边界。不得以线上环境、默认管理员、共享演示账号或本机默认地址替代。不要把新版代码部署到环境来运行本清单。
- 记录实际 BiSheng 构建、前端构建、DB 类型/版本、WeKnora 核心提交与扩展提交、能力修订、OpenFGA 模型和夹具版号。Native 有真实向量与文本索引；W 绑定就绪、路由/解析/检索/文本节选有已验证能力；两人均开启 Work 的 `bisheng_knowledge_search` 工具。不接入替身来证明真实 provider 可用。WeKnora 服务密钥只配置在受控服务端，不提供给测试进程。
- 对照 QA 的 N/W/LIN/ZHOU，在专用非根租户为**自动入口另备两个单文件空间**（不是手工三文件 Wiki/目录样例）。租户显示名、两个用户登录名均以 `e2e-f026-` 起头。A/B 为两个不同普通用户，均可见两个空间；仅 A 可读目标文件，B 对目标文件无可见/预览/下载权。用身份/资源台账确认实际租户、用户、空间、文件和引用 ID，不猜 ID、不遍历资源。
- N 唯一当前文档含 `N026`；W 唯一当前文档含 `S026`，前三个文本块中可预览该标记。两边均用非敏感合成文本且不含另一标记。W 原文只在远端；N 不在远端。分别用 A 正常问答，保留两个已登记、当前仍有效的 **per_user** RAG 引用；登记 W 的物理版本 ID、generation、operation epoch。所有写入在预制夹具阶段完成；自动入口不上传、不创建/清理资源，不切换租户、不变更授权。

| 自动观察（四例分别报结果） | 判定，不以 HTTP 200 或 capabilities 替代内容证据 |
|---|---|
| N/W 各一次 Work 检索正负配对（AC-01/26/32） | 两身份先核对 `/user/info`、目标空间 `provider_key`，W 核对代次。仅传一个指定空间到 `POST /knowledge/space/retrieve`。A 的非空命中仅属于该文件、含对应标记且无另一标记；同租户 B 在同一个单文件空间命中为空。 |
| N/W 各一次真实引用正负配对（AC-13/28） | 同一已登记引用 A 得对应空间/物理文件，B 得业务 404 + `forbidden`（不是 expired/未登录）。N 只验证引用解析及合法用户获原有定位信息，**不抓取对象存储签名 URL**。W 核对三元锚与本地受控路径，再以 A 读出 `no-store` 纯文本合成节选；B 打开同一受控路径须业务码 19000、无文件字节。不跟重定向、不按响应中的任意 URL 发请求。 |

这些探针不覆盖自动生成新引用、浏览器渲染、原件下载、匿名请求、W 故障时 N 的写路径或实时撤权。标记/已知文件核验是客户端证据；由平台负责人另以**已有的脱敏只读观测**核对一次请求实际调用的后端、库/代次和操作次数，排除缓存/回落/重复投递。没有观测视图或前置不满足时填“未验”，不得启用其他地址/身份/夹具凑数。

## 故障与恢复（独立验收，不在上面的 HTTP 套件注入）

**以下均未验。** 只允许夹具负责人启用既有的应用级可控适配器，作用域固定到自己测试租户、合成资源、单次 operation/generation，并有复位与对照数据。缺少夹具、权限、预期基线、两侧只读取证或复位能力：停在“未验”。不停止服务、不干预网络/系统/消息基础设施，不写库或账本，不试其他人资源。

| 场景 | 操作与判据 |
|---|---|
| [ ] 丢 ACK（003、011、023、046） | 在目标测试操作的适配器中选择“已受理、回执暂不可见”。UI 不得报已完成或终态失败；恢复该夹具回读，只重试原操作。原租户、空间、库、幂等键及唯一收据一致，成功部门不重建、容量只记一次，N 对照无 W 写入。 |
| [ ] 半登记（005、014、047、052） | 用预置状态“远端有收据、本地登记未完成”；绑定/授权未获证明时不返回检索、预览或 Wiki 内容。释放该步骤后只补登记一次，无新增远端库/文档；部门明细各阶段不混淆。 |
| [ ] 撤权（004、018、025、040–041） | 在独占夹具内用正常应用授权界面/适配器撤去 A 的一条路径，保留部门权时仍可读；撤去最后有效权后，用正常 UI 重开**原先获准**的引用和预览。旧句柄不再返回原文，合法其他文件仍可读。仅在已支持且获准的下载夹具验证后续分段；W 文本节选不声称支持 Range。恢复基线授权并二次核对。 |
| [ ] 迁移切代（047、055） | 只用成套 G1/G2 测试夹具释放已挂起的应用事件；旧作业不投新库、未验权限不开放旧结果。复位代次和应用开关；无夹具不尝试系统恢复。 |

**收口记法：** 逐行填 `通过 / 失败 / 未验（缺项）`，注明 CI 作业或人工复核编号。故障适配器证据注明“应用层演练”，不等价于物理故障或双数据库验证。外部内容驻留、历史容量、网页快照/开放写入、跨租户及所有未执行的 QA 条目仍以 [完整用例表](./test-cases.md) 单独取证。任一必验场景无目标构建证据即保留发布阻断，不以本清单或默认跳过作为通过。
