# F055 企业插件市场

更新：2026-09-10。用户确认首版收敛为【构建 → DSH】中的导入、查看、删除。当前规格替代此前的审核、管理视图和上下架交互。

## 用户与页面

- 登录租户的管理员管理本租户插件；员工在 Desktop 安装本租户可用插件。全局管理员进入本页时同样使用登录租户。
- 页面展示标题、说明、导入按钮和插件列表。列表列为插件名称、版本、适用系统、更新时间、操作；每行提供详情和删除。
- 详情只读展示版本、发布者、许可证、权限声明、服务地址及更新说明。
- 页面按登录身份取租户，搜索、状态筛选、状态列、上下架按钮、租户管理视图均已移除。其他管理页面选过的租户范围对本市场保持独立。
- 超过一页时显示分页；删除最后一行后回到有效页。导入显示上传进度和校验结果，失败任务保留重试入口。

## 导入与删除

1. 管理员导入一个完整离线包（manifest ZIP，或含 package.json 的 ZIP / npm tgz）。校验通过后自动供已登录员工安装；上传有效新版本切换当前版本，失败保留原版本。
2. 当前可用插件相同内容重复上传安全幂等；同一插件同一版本的不同内容按管理员明确重导入覆盖，更新摘要/元数据并推进 revision。A→B→A 以最后一次主动导入为准；已删除或旧版下架的插件可再次导入恢复，低版本仍拒绝。
3. 删除前确认影响，并携带当前 revision。删除后从管理列表、详情、员工目录和下载入口移除；其他租户的记录保持独立。并发版本变更导致旧 revision 删除失败，刷新后重试。
4. 删除采用持久化标记，保留版本及后台操作记录。已安装插件在会话有效且保持连接时继续使用；会话撤销、到期或断开连接后停用，恢复后按用户开关启用。新安装、更新需当前可用版本。历史制品自动回收留待容量治理。
5. 旧 publish/unpublish/disable 接口和设备报告保留协议兼容，首版页面提供导入、查看、删除。旧禁用状态仍按原策略生效；明确再次导入可恢复可用。
6. 管理员负责选择导入内容。系统校验包结构、依赖、平台和摘要；权限/来源声明由管理员查看，真实内网服务可用性另行验证。

## Desktop 与范围

企业模式内置市场，通过部署指定地址读取目录和授权下载。市场契约版本为 2，不使用独立签名策略。manifest ZIP 须包含完整依赖；npm 包按 package.json 声明元数据，实际依赖安装由客户端处理。安装执行解压、校验和真实 Cordis Loader 加载。更新失败恢复旧运行版本；退出、身份变化或策略禁用停止运行实例。短暂断网保留安装记录，不把断网当成退出。同步周期 60 秒。

ZIP / npm tgz 上限 512 MiB、展开上限 1 GiB、50,000 项；manifest 8 MiB；配置 JSON 64 KiB。当前支持单插件完整包；批量集合包导入、配额/清理和结构化配置向导留待后续。插件作为管理员选择的可信宿主代码运行，逐操作权限和进程隔离由宿主环境提供。

企业 HTTPS/网关绑定按用户决定后续处理。本次沿用 Desktop 安装包。确定性测试、部署健康、登录用户完整流程及原生 Desktop UI 的证据分别记录于 tasks.md 和 deployment.md。

## 工作台压缩包扩展（2026-10-15）

以下验收标准只针对工作台 `.tgz`，不改变上文插件包的发布协议：

- **AC-WB-01**：租户管理员可在企业插件市场的「工作台」区域预览并上传一个 `.tgz`；服务端按[工作台压缩包校验规则](workbench-package-validation.md)验证内容，不执行包内代码。失败时显示规则或冲突原因，且不替换当前版本。
- **AC-WB-02**：相同包重复上传复用记录；同身份的新 SemVer 版本成为当前版本；同版本不同内容可按用户确认覆盖，较低版本、身份冲突仍不得覆盖。失败或中断任务可在原包仍可用时恢复。
- **AC-WB-03**：管理员可查看本租户工作台、详情和导入任务；其他租户不能查询、上传或下载这些数据。两个附带样包应分别识别为仓库身份和旧格式身份。
- **AC-WB-04**：已登录 Desktop 可查询本租户当前工作台列表、详情，并下载当前版本原始 `.tgz`；服务端和客户端以 SHA-256 核对，旧版本及其他租户文件不可下载。
- **AC-WB-05**：工作台结果明确标为静态校验；查询或下载不表示已经获得安装、启用或离线授权。现有第三方安装开关默认关闭语义不变。
- **AC-WB-06**：工作台单包压缩 TGZ 上限 100 MiB（含边界），前端/API/domain 一致；超限明确拒绝。每批最多 50 个、串行处理、无独立 64 MiB 批次门槛，展开与元数据安全限制不变。
- **AC-WB-07**：租户管理员可二次确认并使用 revision 删除工作台；非管理员、其他租户和过期 revision 不可删除。删除后市场列表、详情和旧下载链接不可见，已安装客户端内容不自动卸载；主动重导入可恢复。

客户端接入契约见[Desktop 工作台接口说明](desktop-workbench-api.md)；安装与运行验收不在上述 AC 内。

## 工作台多选扩展（2026-11-07）

用户确认仅 TGZ 多选，不支持 ZIP；一次选择多个工作台包，校验和导入独立执行，有效升级正常导入，失败文件展示具体原因且不阻断其他项。轻量验收标准与实现边界见[工作台多选规格](workbench-multiselect-spec.md)。
