## Platform（正式测试租户）

- [ ] AC-18、AC-19、AC-29：真实登录超管/本租户管理员/普通用户/受限 Child 管理员；客户端管理→模型审计，对照允许/拒绝配对，包含越租户与 PUT 模式。

- [ ] AC-19、AC-33：Network 默认没有 body-access；仅显式展开一条，先查看日志再正文；日志失败时无正文、收起取消、翻页清理、部分状态不冒充完整。
- [ ] AC-24、AC-31、AC-37、AC-38：模式读取失败=降级 OFF；独立进入证据在窗口内等待/活动保护；超窗缺失、迟到恢复与缺尾片，不把未知改为失败。
- [ ] AC-33：窄屏与信创环境、超长原文分段、1000+片段、键盘和状态提示；不执行 HTML，不加载模型原文中的外部目标。
