# Gitee 知识空间权限与数据集一致性修复

日期：2026-11-19。分支：`codex/3.1.0-beta1/workspace-bugfixes-20261118`。
审查基线：`df0caf2ac246aaf7ef2b6341cd0521601dcc85c3`。沿用独立 worktree；本轮未部署、未修改 116 数据或 Gitee 状态。

## 缺陷与代码核对

### [IKWBRT：知识空间无操作权限时入口未隐藏](https://e.gitee.com/Data-Elem_1/projects/560870/sprints/421319/issues/table?issue=IKWBRT)

截图为普通用户仅获 `manage_permission`，但批量菜单和文件预览仍显示无权操作的入口。基线已有逐动作菜单控制，仍遗漏权限摘要和预览授权的生命周期：文件摘要成功一次后不再重查；容器摘要未随身份/列表刷新失效；预览只按文件 ID 请求，切换文件期间可能沿用上一次下载许可。

- Client 改用现有 React Query，菜单重新打开及窗口返回时刷新摘要，查询中/失败时隐藏旧动作；身份、空间、目录、列表版本及文件集合变更隔离旧查询，A→B→A 也不能接收最早 A 的响应。
- 下载权限继续来自下载批量 inspect，摘要不能覆盖 inspect 拒绝。只获授权管理时保留授权管理，隐藏无权的下载、标签、移动、删除。
- 预览下载许可绑定身份与目标；切换或重新获得焦点先隐藏，再查询；离开后迟到的下载签名不启动下载，旧预览响应不覆盖新文件。
- Platform 原有操作闸门无需扩大权限或另写一套。新增工作区/普通管理表格两个展示模式的回归：仅授权管理时仍可管理权限，批量与单项无权操作均隐藏。

### [IKWDSL：系统管理员和租户管理员数据集展示不一致](https://e.gitee.com/Data-Elem_1/projects/560870/sprints/421319/issues/table?issue=IKWDSL)

截图中子租户管理员看到较多历史 Root 数据。正确口径是同一具体租户、同一搜索和分页条件下，系统管理员和租户管理员的列表与总数一致；用户迁入子租户不会使其历史 Root 数据变成子租户资源。

实际页面走 `getPresetFileApi → GET /api/v1/finetune/job/file/preset → FinetuneFileService → PresetTrainDao`，并非旧 `dataset.py`。当前基线请求准入已经收窄到具体租户，因此初始 API 对比原本通过；可复现遗漏在数据集 DAO 仍接受共享资源的宽可见租户集合，以及页面不响应管理租户切换。

- `PresetTrainDao.search_name` 的列表和 count 同用 `strict_tenant_filter`；`find_all/find_one` 同步收紧。复用 ORM 自动租户过滤，不手写租户 SQL 或按创建者归属猜测租户。
- 同时间记录追加主键排序，分页有稳定的次序。
- 页面监听既有管理范围变更事件及登录身份变化，重新创建列表、搜索、分页和创建弹窗；旧请求结果不能更新新视图，旧删除确认和签名下载也失效。
- 没有迁移历史资源、复制 Root 数据或放宽超管的跨租户读取。
