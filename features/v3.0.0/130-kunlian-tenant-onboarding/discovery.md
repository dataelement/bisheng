# 昆联租户与用户自动开通：需求发现

- **Feature ID**：`F130`
- **Created**：2026-11-11
- **Status**：需求、工作流专属创建调整、修订设计及任务规划均已确认；首批 T001–T012 已本地实施并经后续授权部署，其他任务待实施，完整联合验收待执行。
- **目标**：将已验证的单租户试点扩展为可信目录驱动的多租户和新用户自动开通。跨租户 Workflow 资产消费为后续独立工作包。

## 1. 确认记录

| ID | 用户明确选择 | 本批范围 |
| --- | --- | --- |
| C-01 | 自动开通：为可信目录中的有效租户创建独立毕昇租户。 | 自动建立独立本地租户与稳定映射，不自动认领同名历史租户。 |
| C-02 | 自动配置最小基础角色。 | 工作流管理入口和新建能力；不授予管理员身份，不自动取得其他人的 Workflow 权限。明确调整 F118 C-03 的人工提前配置规则。 |
| C-03 | 用户在说明通用创建能力会扩大到助手等类型后，回复“好的 请继续”。 | 收窄为工作流专属创建；自动角色不授予通用创建权，既有独立人工通用权限保持。 |
| C-04 | 用户审阅修订设计及 42 项任务后回复“确认 继续”。 | 授权按既有范围实施；本轮先交付基础声明与专属创建最小闭环，不部署。 |
| C-05 | 用户随后要求“更新到服务器上，并提交暂存区”。 | 授权部署已完成首批；保留原 fixed 范围和人工资格，不启用待开发自动开通，提交仅使用原暂存区。 |

需求依据为用户 2026-11-11 提供的沟通截图、当前改造请求及上述两项回复。截图中的模型入口修复说明与跨租户模型资产附件只显示文件名，未取得正文，不能作为已经实现或已确认接口的依据。

## 3. 契约与范围限制

- 已读取 F118、F128、F129 规格及版本契约、架构约束。F118 C-03／REQ-08 的自动基础入口限制需由 F130 的已确认增量替代，其他身份、资源权限及人工授权保留规则继续有效。
- 已读取昆联 `发给毕昇-Workflow联调配置-20261111.txt` 中非敏感范围说明：当前客户端固定 Workflow 试点租户，其他租户尚未开放；目录则要求全租户。不开通上游客户端范围，不能通过本地改造完成真实多租户登录。
- 用户目录不必包含无成员租户，首批只自动开通可信目录实际提供且状态明确有效的租户。空租户发现若需要新增契约，另行确认。
- “同步及时可用”首批定义为有效完整目录被接受、开通处理完成后可用；保留缺目录时补同步后重新登录。秒级推送与具体时效承诺不从现有 300 秒轮询推导。
- 不把外部角色名转换成管理员权，不改 Workflow 对象权限，不处理跨租户资产调用、模型平台或账号迁移。
