# 文件所属组织需求

- Feature ID: `082-file-belonging-organization`
- Status: `confirmed-implemented-local-verified`
- Created: `2026-10-23`

## 已确认口径

- 首次上传取上传人的所属组织。
- 个人库发布到科室库时，使用科室库绑定组织替换。
- 个人库发布到团队库时，使用团队创建人的所属组织替换。
- 人员组织统一取唯一主组织；缺失或异常时留空，不任意取附属组织。
- 整份逻辑文档统一归属，各版本及发布、分享入口保持一致。
- 主业务不自动批量补历史数据，仅覆盖新上传和后续发布；用户随后要求提供独立手动脚本，规则见 REQ-007。
- 先添加字段及上述赋值行为，展示、筛选、统计用途后续说明。

## 范围说明

- 新文档上传覆盖现有文件登记入口；已有文档新增版本属于继承，不重新按本次上传者组织覆盖整份文档。
- 组织取值是在上传或指定发布成功时写入的事实，人员后续调组织不触发历史文件同步。
- 历史文档参与指定发布时可按该次发布规则更新；主业务不主动扫描未发生业务操作的历史文档。独立脚本只在运维明确运行时扫描。
- 现有权限检查、发布审批及任务状态机保持不变。
