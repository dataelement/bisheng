## 0. 结论

任务模式的报告接入平台既有的溯源机制：报告正文出现可点击角标，点击回看知识库原文件（定位到页）或原网页。

日常对话模式已有完整溯源链路，任务模式的报告预览已复用同一渲染器。本期前端不改动，后端改动集中在检索工具与任务完成时的持久化。

分两期：一期应用内预览角标；二期下载的 Word/PDF 内带可见编号引用与参考资料。

## 1. 目标与范围

| 本期做 | 说明 |
|---|---|
| 报告预览内联角标 | 覆盖知识库检索与网页检索两类来源 |
| 角标悬浮预览卡 | 标题、摘要、来源名 |
| 点击回看 | 知识库角标预览原文件并定位；网页角标打开原网页 |
| 权限 | 角标遵守知识库文件的查看权限 |
| 持久化 | 任务完成时保存报告实际引用的来源 |

| 本期不做 | 去向 | 原因 |
|---|---|---|
| 下载的 Word/PDF 内的引用 | 二期 | 需独立的导出处理；下载件内知识库文件只能显示名称与页码 |
| 用户上传附件的溯源 | 候选 1.5 | 附件经按需翻阅，不走检索工具，需另一套机制 |
| 「参考资料」汇总列表面板 | 后续 | 先只做行内角标 |
| 漏标记的补救重跑 | 不做 | 优雅降级 |
| 检索本身的文件级可见性 | F029 / F035 | 本期只在角标呈现面复用其过滤 |
| 日常对话模式 | 不改 | 本期只接入任务模式 |

## 2. 用户场景

| 角色 | 目标 | 价值 |
|---|---|---|
| 业务用户 | 在报告里看到引用旁的角标，一键回看原文件对应页或原网页 | 核实结论出处，不必人工翻找 |
| 管理员 / 合规 | 无权查看某文件的用户，看不到该文件来源信息，也无法借角标预览它 | 溯源不成为越权入口 |

## 3. 需求规则

### 3.1 来源捕获

| # | 规则 | 依据 |
|---|---|---|
| R1 | 知识库检索命中的每个片段登记一条来源，含文档名、知识库名、页码、页内定位 | 角标要能回看到原文件对应位置 |
| R2 | 网页检索的每条结果登记一条来源，含 URL、标题、摘要、站点 | 网页角标要能打开原网页并展示预览 |
| R3 | 模型只对实际使用的来源打标记，标记紧跟使用处；不使用则无标记 | 角标位置即出处 |
| R4 | 子任务检索到的来源标记能传递到主流程撰写的报告里 | 检索常由子任务完成，报告由主流程撰写 |

### 3.2 报告呈现

| # | 规则 | 依据 |
|---|---|---|
| R5 | 报告预览时标记渲染为顺序编号上标角标 [1][2]… | 与日常模式一致 |
| R6 | 知识库角标蓝色，网页角标紫色 | 与日常模式一致，一眼分辨来源类型 |
| R7 | 悬浮角标显示标题、摘要、来源名；知识库附页码，网页附日期 | 不打开文件即可判断出处 |
| R8 | 点击知识库角标打开原文件预览；PDF 高亮并定位到被引片段 | 核实出处需看上下文 |
| R9 | 点击网页角标在新标签打开原网页 | — |
| R10 | 同一句多来源时相邻显示多个角标 | — |

### 3.3 权限

| # | 规则 | 依据 |
|---|---|---|
| R11 | 用户对某知识库文件无查看权限时，角标解析不返回该文件任何来源信息 | INV-7 |
| R12 | 无权限的角标显示为灰色「无权限查看」，不可点击 | 不报错、不泄露 |

### 3.4 持久化与健壮性

| # | 规则 | 依据 |
|---|---|---|
| R13 | 任务完成时只保存报告实际引用到的来源，绑定该任务轮结果 | 老报告预览时仍可解析 |
| R14 | 重复完成（续轮、恢复）不产生重复来源记录 | — |
| R15 | 来源登记的任何异常不影响检索与任务，回退为无溯源的结果 | 溯源是增强，不能拖垮任务 |
| R16 | 模型漏打部分标记时对应来源无角标，其余正常，不出现坏角标 | 优雅降级 |
| R17 | 不改任务执行流的事件协议与执行记录结构 | 非侵入 |

## 4. 交互说明

交互 demo：见本 PRD 随附的可点击页面。demo 展示对话内嵌任务模式：左侧对话列（提问、任务卡、结果），右侧工作区面板预览报告。

| 状态 | 触发 | 表现 |
|---|---|---|
| 角标 | 报告预览 | 顺序编号上标胶囊；知识库蓝、网页紫 |
| 悬浮卡 | 鼠标悬浮角标 | 标题、摘要、来源图标 + 来源名 + 页码或日期 |
| 回看知识库 | 点击蓝色角标 | 工作区切到原文件预览；PDF 黄色高亮并滚动到被引片段 |
| 打开网页 | 点击紫色角标 | 新标签打开原网页 |
| 无权限 | 悬浮灰色角标 | 「无权限查看」；点击无反应 |
| 多来源 | 同一句引多个来源 | 相邻多个角标 |

一期不在结果区增加「参考资料」汇总面板。

## 5. 验收标准

| ID | 验收标准 |
|---|---|
| AC-01 | WHERE 任务开启了知识库检索, WHEN 知识库检索返回结果, THE SYSTEM SHALL 为每个命中片段登记一条带稳定来源标识的来源，含文档名、知识库名、页码、页内定位，并使模型读到该结果时能获得对应来源标识 |
| AC-02 | WHERE 任务开启了网页检索, WHEN 网页检索返回结果, THE SYSTEM SHALL 为每条网页结果登记一条带稳定来源标识的来源，含 URL、标题、摘要、站点 |
| AC-03 | WHEN 模型撰写报告并使用了某条已登记来源的内容, THE SYSTEM SHALL 使报告正文在对应句或段位置内联携带该来源的溯源标记；未使用任何已登记来源时不产生标记 |
| AC-04 | WHEN 检索发生在子任务而报告由主流程撰写, THE SYSTEM SHALL 使来源标记可越过子任务边界传递到最终报告正文 |
| AC-05 | WHEN 任务完成, THE SYSTEM SHALL 解析报告中实际引用到的来源，仅将被引用的来源持久化并绑定到该任务轮的结果消息 |
| AC-06 | WHEN 同一份报告被重复完成处理, THE SYSTEM SHALL 保持幂等，不产生重复的来源记录 |
| AC-07 | WHERE 查看者对某知识库文件无查看权限, WHEN 解析该报告角标, THE SYSTEM SHALL NOT 在角标解析接口响应的任何结构化字段中返回该文件的来源信息 |
| AC-08 | WHEN 用户在应用内预览任务报告, THE SYSTEM SHALL 把正文溯源标记渲染为顺序编号的上标角标；同一句多来源时相邻显示多个角标 |
| AC-09 | WHEN 用户悬浮某角标, THE SYSTEM SHALL 展示该来源的标题、摘要、来源名；知识库来源附页码，网页来源附日期 |
| AC-10 | WHEN 用户点击知识库角标, THE SYSTEM SHALL 打开该原文件预览；WHERE 文件为 PDF, THE SYSTEM SHALL 高亮并滚动定位到被引片段 |
| AC-11 | WHEN 用户点击网页角标, THE SYSTEM SHALL 在新标签打开原网页 URL |
| AC-12 | WHERE 查看者对某知识库角标对应文件无权限, THE SYSTEM SHALL 将该角标呈现为「无权限查看」态且不可点击，不报错 |
| AC-13 | IF 来源登记过程发生任何异常, THEN THE SYSTEM SHALL 回退到不带溯源的检索结果并继续任务 |
| AC-14 | IF 模型在报告中漏发部分标记, THEN THE SYSTEM SHALL 对应来源不出现角标，其余角标正常，不产生坏角标或解析报错 |
| AC-15 | THE SYSTEM SHALL 保持既有任务执行流的事件协议与执行记录结构不变 |

## 7. 决策记录

| # | 决策 | 选定 | 被否方案 | 理由 | 何时重估 |
|---|---|---|---|---|---|
| D1 | 整体路线 | 复用平台既有溯源机制 | 自研任务模式专属机制；用 Skill 或提示词让模型自己写参考资料 | 检索工具今天不把来源信息给模型，让模型写参考资料只能编造文件名；Skill 按会话勾选，溯源会时有时无；复用后前端零改动、权限过滤现成 | 溯源机制大改，或报告不再以 Markdown 预览 |
| D2 | 来源信息的捕获点 | 在任务模式检索工具边界保留并登记 | 换用日常模式的检索工具 | 两者白名单语义与错误契约不同，整体替换比在现有工具补信息改动更大 | 两条检索路径合并时 |
| D3 | 来源的收集方式 | 写运行时缓存 | 内存收集器跨子任务传递 | 子任务独立执行，内存对象要穿透子任务；缓存天然全局 | 出现缓存不可用的部署形态 |
| D4 | 引用来源的保存位置 | 既有消息引用记录，绑定任务轮结果 | 存进任务结果字段 | 既有记录自带权限过滤、定位、链接刷新；另存要重造且绕开权限红线 | 报告需脱离对话独立分享时 |
| D5 | 漏标记的处理 | 优雅降级 | 补救重跑 | 少角标不影响报告可用；重跑成本高且不保证补全；Deep Research 类产品同样接受降级 | 漏标率明显影响使用 |
| D6 | 分期 | 预览先行，下载随后；先不做汇总面板 | 一次做全 | 预览面零前端改动、价值最高；下载件需独立导出处理 | — |

## 附录 A 实现约束与取证

一期改动点（后端）

| 位置 | 现状 | 改动 |
|---|---|---|
| `src/backend/bisheng/tool/domain/langchain/linsight_knowledge.py` `base_search` | 只返回片段文本，丢弃来源元数据（第 92 行） | 保留元数据、补知识库标识、登记来源并写缓存；异常回退为原结果 |
| `src/backend/bisheng/linsight/domain/services/agent_factory.py` | 系统与子代理提示词无引用规则 | 追加引用规则（复用 `core/prompts/yaml/citation.yaml`）；包装网页检索工具登记来源 |
| `src/backend/bisheng/linsight/domain/task_exec.py` 三个完成处理器 | `persist_task_turn_message` 返回值被丢弃 | 捕获返回，解析报告引用并保存来源 |

复用不改：`bisheng/citation/` 的 `annotate_*`、`collect_*`、`cache_citation_registry_items`、`extract_citation_ids_from_text`、`save_message_citations`、`/api/v1/citations/resolve` 及其权限过滤。

一期前端：无改动。报告预览 `PreviewBody.tsx` 已走 `Chat/Messages/Content/Markdown`，具备角标渲染、悬浮卡、点击预览、PDF 高亮、无权限灰化。

约束

| 约束 | 内容 |
|---|---|
| INV-7 | 角标解析响应不得含无权文件的来源字段；复用 `CitationResolveService` 的 view_file 过滤 |
