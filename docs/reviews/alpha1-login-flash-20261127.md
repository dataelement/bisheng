# alpha1 登录成功后登录页闪现修复

2026-11-27，基线 `9aaac91b2501d16d9d0ac31afcf49e8056c3191e`。本次为认证展示时序 hotfix，无 API 或会话协议变更。

## 问题与修复

登录成功事件清空旧用户并进入 loading。原 UserProvider 在会话 metadata 返回后即标记 ready，但用户信息仍待加载；此时 App 因 user 为 null 重新挂载登录路由，用户信息返回后再进入平台。已有本地诊断和新增回归测试均可复现。

将 ready 与启动完成的发布推迟到身份加载和落地路由判定结束；会话检查完成后继续保持静默 loading，直到用户身份就绪才挂载页面。失败时保留服务不可用/重试状态，宿主接管时保留重连状态；epoch 校验阻止退出或切换账号后旧请求重新开放页面。原登录表单的工作台默认入口与合法回跳处理保持原有行为。

## 验证

- 新增延迟身份请求的启动、登录成功场景，修复前均失败：业务组件提前挂载、匿名登录路由再次出现；修复后通过。
- 覆盖身份请求网络/服务端失败，以及身份请求未完成时跨标签退出，确认不会提前开放页面或恢复旧身份。
- 启动/认证请求、登录表单、OAuth 授权和 SSO 回跳相关测试共 40 项通过；管理端 1451 个严格类型文件通过，变更文件 ESLint、arch-guard 与 diff 检查通过。
- 本次只提交 alpha1，未部署或操作 109 服务。运行环境中的浏览器验收待后续部署后执行。
