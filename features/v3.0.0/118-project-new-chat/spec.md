# 项目内新建对话

流程：Small feature（现有客户端项目模块的小幅补全，无 API 或领域契约变更）。

来源：原实现为 3.1 分支上的 `573a62d10d`（codex/project-new-chat）。2026-11-03 用户将本需求定为高优，要求在 3.0 提前交付，因此在 feat/3.0.0 上按 3.0 代码结构重新提交；3.1 通过常规 3.0→3.1 合并获得本功能，codex/project-new-chat 不再单独合并。

## 验收标准

| AC | 行为 |
| --- | --- |
| AC-01 | 自建项目行“更多”按钮右侧提供“新建对话”图标，两个按钮间距为 4px；两个按钮采用相同实现、尺寸和悬停／焦点／触屏显隐规则；鼠标悬停、键盘聚焦及触屏均可操作。 |
| AC-02 | 点击后展开目标项目并进入空白普通对话；窄屏导航关闭。 |
| AC-03 | 发送首条消息后，正式会话自动归入所选项目，出现在项目内，不重复出现在平铺对话列表；刷新保留归属。 |
| AC-04 | 全局新建对话及打开已有会话不继承项目新建意图；连续选择项目以后一次选择为准。 |
| AC-05 | 流式创建事件延迟到达时仍归入发起项目；项目已删除或创建失败时不留下无效归属；任务模式创建亦保留归属。 |
| AC-06 | 对话列表行“更多”图标按钮复用项目操作按钮的实现：相同尺寸、图标、圆角、悬停底色与 Tooltip；桌面端仅在行悬停、键盘聚焦或菜单打开时显示，选中会话本身不使按钮常驻；触屏保持可操作。 |
| AC-07 | “移入项目”子面板顶部提供“新建项目”；与已有项目列表以分割线区分，“移出项目”与项目列表也以分割线区分。无项目时不显示多余分割线。 |
| AC-08 | 在“移入项目”中新建项目时复用项目命名弹窗；创建成功后当前对话自动移入新项目，取消不改变原归属。 |
| AC-09 | 从菜单切换到新建项目弹窗时，菜单在原位置淡出，退出期间不跳向屏幕左侧；淡出结束后打开弹窗并聚焦名称输入框。 |

## 实现边界

- 项目与归属延续现有当前浏览器 localStorage 实现；不增加后端项目模型。
- 开发演示项目延续只读呈现；新建入口面向用户创建的项目。
- 3.0 的项目区只存在于桌面工作台侧边栏，窄屏仍使用 3.0 原有导航。因此 3.0 窄屏继续隐藏「移入项目」；AC-02 中“窄屏导航关闭”一项在 3.0 不适用，随 3.1 移动端导航改造生效。
