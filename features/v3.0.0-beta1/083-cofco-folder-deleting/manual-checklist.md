# 人工验收清单

以下均待在客户大数据量环境或有延迟/故障注入的环境执行；未在本地浏览器验证。

- [ ] 单删含大量文件的目录：确认框立即关闭；桌面列表、卡片、手机列表显示图标与「删除中」，行保持可见。
- [ ] 等待期间刷新、切换筛选和搜索：处理中行保留；原空间切走再回来仍显示处理中；其他目录可正常进入和操作。
- [ ] 等待期间点击目录行、名称、侧栏目录和已展开的后代：同一提示，页面不变。
- [ ] 全空间搜索出现深层后代且中间父目录从未加载：打开、开始重命名、版本管理、版本历史、移动、删除均阻止。
- [ ] 已打开的操作菜单、移动框及移动撤回 Toast 在目录开始删除后再执行：重新校验，目标或来源在删除范围内不提交。
- [ ] 上传和目录上传的提交、重名覆盖、新建目录均拒绝删除范围内的目标；导航后旧上传仍按原始空间和父目录校验。
- [ ] 独立目录并发删除：分别显示状态；重复点击不重复提交；混合文件/目录批删仅移除已完成项。
- [ ] 审批 pending：移除本地「删除中」，保留行和既有审批提示；单删与批删审批行为一致。
- [ ] 明确失败：恢复操作、刷新列表、仅提示「删除失败，请刷新后重试。」。
- [ ] 超时/断网/服务端异常：提示请求异常；新后端启用状态能力时，从状态接口查询/有权核对结果恢复；仅目录存在不能解除锁。旧后端仅保留第一阶段降级行为。
- [ ] 分页、筛选不含目标：不以未出现推断删除完成，不增加父目录全量扫描请求。
- [ ] 请求等待中切换空间/目录、快速点击多个树目标：旧响应和旧守卫不覆盖新位置。
- [ ] 中英日三种语言下删除状态及提示均正确显示。

## 第二阶段跨刷新（待升级测试后端后人工执行）

- [ ] 删除子树授权尚在处理时整页刷新：目标仍显示“删除中”，列表/卡片/侧树一致。
- [ ] 两标签页：另一页删除后，本页已加载第一页/追加页的目录均能恢复标记；未加载中间祖先的搜索后代也显示删除状态。
- [ ] 直接刷新空目录/后代 URL：列表为空仍恢复祖先范围状态；状态未读取时不能上传或打开相关项。
- [ ] 普通观察者能看未知但不能代替发起人核对；资源消失停止观察且不弹“删除成功”。
- [ ] 模拟进程中断：60秒无续报转“状态待确认”；有权核对先使旧请求失效，再恢复目录；恢复后旧请求不得提交删除。
- [ ] 删除长事务锁住根目录且续报暂时受阻：核对保持未知，不中止正常事务、不提前解锁；提交成功后目标移除。
- [ ] 编辑元数据/旧页面快照不能清除删除标记；删除成功后旧快照不能重新插入目录。
- [ ] Web链接导入窗口先打开、另一页再删除：确认及覆盖提交都被拦截；普通文件移动撤回仍可操作，不能把文件 ID 当文件夹查询。
- [ ] 审批请求只显示原待审核；审批执行完成后的状态及后台物理清理沿用既有规则。
- [ ] 切账号/租户/空间、延迟旧列表响应和旧查询响应：不得带入旧标记或覆盖新操作编号。
- [ ] 隐藏标签页停止轮询；可见时立即补查；不自动重发 DELETE。
- [ ] 后端未升级：不请求新接口；保留第一阶段体验。loading超时/列表刷新策略本期无变化。
