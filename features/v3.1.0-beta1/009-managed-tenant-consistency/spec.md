## 1. 目标与范围

作为平台管理员，我希望管理视角中的资源在选定租户内正确保存，身份、子对象、菜单和后续权限状态一致，以免请求报错后实际留下错误租户或不可用资源。

作为租户或部门管理员，我希望只能影响自己有权管理的人员策略，兼属部门和主属迁移不会悄悄改变其他租户的菜单、预算或审批政策。

作为普通用户，我希望菜单、创建限制和实际资源归属一致，统计失败会明确拒绝新增，复制失败能够恢复且重试不会重复产生目标。

### 1.1 本次纳入

- 六项已核查问题：全局角色及菜单保存、角色配额读取、API/MCP工具创建、工作流及版本创建、文档/QA库复制、部门角色候选及最终绑定。
- 单一主属租户内的有效策略角色，以及绑定创建、默认授予、SSO、撤销、作用域变更、主属迁移后的统一生效行为。
- 登录菜单、菜单申请模式、创建门禁、配额、审批动态角色标签、DSH统一角色策略对同一有效政策的消费一致性。
- 个人/租户用量边界、上限与剩余额度、预算责任交接前止增、统计失败拒绝增量；必要的创建/复制不可用状态与恢复。
- 现有数据影响盘点、正确行为回归及真实环境验收要求。

### 1.2 明确排除

- 普通用户的多租户执行身份和租户切换产品能力。
- 按每个部门授权来源独立授予/撤回的体系；当前角色保持按人绑定，不能假装历史数据能还原部门来源。
- 普通配额严格并发预留或全资源通用额度/恢复引擎；保留已有提交前检查的并发容忍。
- 跨租户知识库复制能力、自动搬迁业务资源、按同名角色自动迁移人员政策。
- 部署、合并、发布及自动修复、删除或批量改写真实存量数据；现有共享/凭据/资源权限产品能力的重构。

## 2. 业务术语

- **主属租户**：用户当前唯一生效的身份归属；兼属关系不改变它。
- **管理目标**：已授权管理员本次选择的具体管理租户；不改变本人身份。
- **部门业务租户**：由有效组织挂载关系决定的部门所属业务范围，不以部门存储位置判断。
- **有效策略角色**：用户主属租户内的合法绑定，引用合法全局定义或本租户定义，并满足当前有效的部门作用域。
- **预算责任人**：相应指标承担个人用量的人，可以和操作者不同；责任失效不等于资源可被无权者访问或删除。
- **终止绑定**：该份授予不再生效，之后扩大定义或恢复成员关系不能隐式复活；新的合法默认/显式授予是另一次可审计行为。

以下 WHEN/IF/WHILE/THE SYSTEM SHALL 表达业务结果；具体接口、字段、事务、错误码归属和实现文件在后续 design.md 中定义。

| ID | 优先级 | 验收标准 |
| --- | --- | --- |
| AC-28 | P0 | WHEN 在具体管理租户创建API或MCP工具，THE SYSTEM SHALL 将父类别、非空子工具及其权限归属保持一致，随后列表和详情可用；IF 子工具创建失败，THEN THE SYSTEM SHALL 不留下可误用的父类别半成品。 |

| AC-30 | P0 | WHILE 工具、工作流或知识复制处于未完成创建或恢复状态，THE SYSTEM SHALL 禁止普通列表详情后的使用、执行、发布或派生写入将其误当可用资源；超级管理员也不应让半成品进入正常执行。 |
| AC-31 | P0 | WHEN 复制文档库或QA库，THE SYSTEM SHALL 在源的合法业务租户内产生同租户目标并保留真实操作者；IF 目标范围不符或源不可复制，THEN THE SYSTEM SHALL 在改源状态或建目标前拒绝。 |

| AC-33 | P0 | WHEN 同一次复制重试、重复投递或进程重启恢复，THE SYSTEM SHALL 继续同一操作和目标，不重复创建目标、文件、QA数据或授权；同标识而关键参数不一致应拒绝。 |

| AC-35 | P0 | WHEN 复制出现部分文件、批次或任务失败，THE SYSTEM SHALL 可观察地报告未完成或失败并支持受控恢复，不因任务函数返回就把全部目标标成复制成功。 |

## 4. 边界情况

- 同一角色的全局定义可复用，但用户绑定仍需合法；正常无角色、失效绑定和读取失败不可混为一种状态。
- 真正新加入成员或新主属激活可重新合法授予默认角色；SSO重放同一成员快照、扩大角色定义或恢复旧行不属于新的授予。
- 有部门作用域角色仅在没有任何剩余合法同主属成员关系支持时终止；全局/无作用域直接策略不假装按部门来源自动撤回。
- 主属迁移后资源留在原地、创建者与操作者不同、授权所有者与计量责任不同分别判定，不将移交授权视作移交预算。
- 真实零用量可用于检查；统计失败应拒绝增量，但不扩大成拒绝所有合法减量和删除。
- 普通配额并发预检查和严格结算属于不同保证；本次不改变现有DSH结算或应用容量预留合同。
- 权限结果不确定、消息可能已发出、复制源占用变更和恢复重入必须各有可观察结果，禁止异常后返回完整成功或无条件删除目标。
- 单租户模式保持默认租户的合法行为；真实数据库、中间件和浏览器环境的未验收项须如实记录。

## 5. 设计与实现指针

需求覆盖与核查依据见 [spec-review.md](spec-review.md)。本规格已确认，接下来进入设计确认及仓库要求的QA参考用例、任务、实现、E2E和特性级审查。开发交付不包含合并或部署授权。
