# Release Contract — v3.1.0-beta1

> 本版本在 v3.0.0 发版线基础上演进。既有领域归属、全局不变量和错误码占用继续以 [v3.0.0 release contract](../v3.0.0/release-contract.md) 及其继承的版本契约为准；本文只登记本版本增量。

## 表 1：领域对象归属

F004 扩展既有工作流的删除语义；F005/F006 扩展幻灯片检查与技能包；F007 新增账号私有项目与对话归属，保留对话正文和企业身份的既有写入权。

| 增量界面范围 | Owner Feature | 边界 |
| --- | --- | --- |
| 工作台浏览器窄屏全局导航呈现 | F001-client-mobile-navigation（本版本） | 负责小于 768px 时的全局菜单及工具与技能首页排版；消费现有菜单、项目和会话能力，不取得这些业务对象的写入权 |
| 审计记录的组织归属快照，以及审计页的部门数据范围 | F003-audit-optimization（本版本） | 负责审计来源表上记录发生时的操作者主部门与路径，以及审计列表、候选、详情、导出的部门范围；只读部门、主部门和用户组，不取得它们的写入权；不改变 17 类结构化动作的业务写入点 |
| 工作流逻辑删除 | F004-workflow-soft-delete（本版本） | 保留主记录和版本，封闭普通查询与新操作；沿用既有授权、审计及历史数据归属，不新增在途协调 |

## 表 2：跨 Feature 不变量

除下文登记的 F008 窄增量外，沿用 v3.0.0 及其引用版本的既有不变量；其他特性的验收约束归各自 spec。

F008 的用户需求已于 2026-11-06 确认，正式规格已于 2026-11-10 确认：

- **仅 Kubernetes 环境诊断门槛**：取消 F059 对环境实测报告及 24 小时有效期的强制运行前提，手动诊断与业务状态解耦。限定替代 F059 AC-13/AC-23/AC-30/AC-31 及 F086 AC-58 中“必须先完成 Kubernetes 环境实测方可运行”的部分；不删除权限清单、实际应用检查、安全控制或运行错误处理。Docker/legacy 宿主隔离合同及其有效性要求不变。
- **官方环境首次种子**：在 F086 AC-14/AC-15/§2.11 及 INV-42 的全局环境管理资格上增加受控系统初始化窄例外：仅从受信发行物校验并补齐官方记录和缺失默认项，记录系统来源，不伪造管理员。人工登记/替换/默认切换仍仅平台超管；不向 Manager、普通用户、租户管理员或服务账号授予该管理权，不覆盖用户默认项或改变被冻结版本。原领域 Owner 与其他主体矩阵不变。

F059 的实际准入、UID 停止证明及保护历史、单写、未知状态数据保护和 F048/F114 权限要求继续保留；发布必审、档位/版本冻结、运行期出站、物料身份隔离与未来正式发行矩阵均不变。F114 已替代早期 owner-only 限制，恢复按 edit、涉及正式启动另需 publish，不能借继承旧数据保护条款恢复旧资格；应用清单 v1 兼容不恢复已退役的运行控制协议 v1。历史版本文档不改写为新版本行为，具体新验收口径及继承表见 [F008 spec](./008-standard-helm-delivery/spec.md)。
