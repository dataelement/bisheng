# F085 检索步骤显示知识空间名称

状态：需求与设计草案，待确认；未开发。日期：2026-11-05。

来源：用户在本会话提供的截图。截图中的要求为“优化成显示具体的知识空间名称，如果不行至少换成中文”。

## 目标

任务执行过程中的知识检索步骤，让用户看清本次检索了哪个知识空间或知识库。拿不到可靠名称时显示中文，不再把内部工具名作为面向用户的步骤标题。

## 验收标准

| 编号 | 条件与结果 |
|---|---|
| AC-01 | 当实际检索对象是知识空间且名称可见时，步骤显示“检索知识空间：名称”；知识库显示“检索知识库：名称”，个人知识库保留通用称呼。 |
| AC-02 | 当有多次调用时，每行对应本次实际对象；同一空间重复检索仍保留每次记录，现有调用次数、执行顺序和折叠行为不变。 |
| AC-03 | 当名称缺失、旧记录没有可靠名称、对象不在当前可用范围或记录不完整时，显示“检索知识空间”或“检索知识库”；类型也不明确时统一显示“检索知识库”，不回显英文工具标识或原始ID。 |
| AC-04 | 当参数分段到达时，允许先显示通用中文，再更新为已确认的名称；实时、重连和历史显示同一调用对应的名称快照。 |
| AC-05 | 名称过长时，行内最多两行；展开后能完整查看。桌面可补充悬停提示，移动端不依赖悬停。 |
| AC-06 | 检索失败时仍可识别目标；失败原因按F084显示在对应步骤，保留其他检索结果，不把步骤结束直接当成检索成功。 |
| AC-07 | 名称仅来自既有授权上下文或可信历史快照，不能采信模型编造的名称；分享和他人只读记录按现有可见范围过滤，无法证明可见时使用通用中文。 |
| AC-08 | 内部调用、检索参数、权限与实际检索范围保持不变；旧记录仍能打开，三种语言同步交付。 |

## 范围

本期完成截图对应的任务模式检索步骤，包括主任务、子任务、恢复与历史读取。日常问答相似工具行不自动扩大为一次展示改版；双方只对齐显示名称与失败来源的传递约定。
