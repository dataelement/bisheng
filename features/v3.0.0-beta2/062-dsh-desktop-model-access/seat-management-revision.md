## 产品与验收

- AC-S1：授权席位表展示用户、部门、席位状态和操作，保留用户检索、席位状态筛选、分页、撤销及重新分配。
- AC-S2：登录状态、会话数量、设备信息、最近登录和最近活动退出企业管理界面。使用统计聚焦模型调用、消息数、Token 与额度。
- AC-S3：毕昇浏览器接口退出管理员会话查询、本人会话查询与逐会话吊销；席位列表响应投影身份和席位字段。
- AC-S4：客户端认证、退出、凭据刷新及席位撤销失效继续使用现有 Gateway 协议，单账号按席位计数。

Gateway 内部席位返回结构沿用现有契约，`SeatItem` 继续严格校验上游；浏览器输出排除登录状态、会话数、登录与活动时间。Gateway 的内部认证对象及数据表由认证模块管理，本次交付为毕昇单仓 PR。
