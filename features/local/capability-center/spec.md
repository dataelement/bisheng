# 企业工具与技能中心

用户授权先在 3007 网页实现统一目录与管理；桌面复用同一企业 MCP。

- AC-01：前台“工具与技能”提供全部、技能、内置工具、API、MCP 分类与搜索。
- AC-02：后台“构建 → 工具”提供内置工具、API、MCP、技能管理；工作台设置专注模型、提示词、知识库与外观。
- AC-03：目录按资源 use 权限和租户隔离计算。技能遵循单项启用状态，取消工作台展示名单、总入口开关、管理员默认勾选与单独 Work 发布。
- AC-04：用户首次工具、技能选择为空，按任务选择并可全部关闭；保留用户自行选择的工具偏好。任务模式支持多选技能和行内引用。
- AC-05：时间、订单 API、库存 MCP 可试用，复用既有权限、参数校验、执行器和审计。订单与库存为明确标识的合成数据，通过真实 HTTP/MCP 演示且无需外部 API Key。
- AC-06：Work 读取同一资源与单项状态；缺少连接配置的工具初始化失败时，其他工具保持可发现。调用与技能下载重新验证当前权限、启用状态、内容版本及工具依赖。
- AC-07：保留 3007 现有用户数据、积分与模型配置；3006 保持。新增 Skill 的模型驱动报告生成作为独立桌面验收项。
