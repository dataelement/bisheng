# F026 知识空间多后端与 WeKnora 测试用例（测试工程师参考）

## 依据与范围

- 已确认[规格](./spec.md)：2026-11-24，AC-01～AC-37；预期结果以该版为准。
- 设计复查：[技术设计](./design.md) 2026-11-24 修订，本轮用户已确认。文内“待确认”是初稿状态，不表示功能已经实施。下表逐例列出所用设计边界。
- 目标：v3.1.0-beta1 / CNNC，构建待实现。设计记载接手基线 `150dbe62b9`；本次未核对实现代码，未运行产品用例。实际端点、状态文案、取证权限以提测构建为准，不以拟定符号或某个 HTTP 状态码代替业务判定。
- 范围：新建个人/部门空间、Native 回归、跨入口身份和恢复；不迁移存量原生库、FAQ 或临时附件。必做能力缺证据即阻断放行；可选能力须同时验证可用、未验证和暂不可用的分支。
