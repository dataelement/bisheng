# 模型审计页面与正式环境验收清单

日期：2026-10-14。基于仓库 e2e-test 流程整理；执行记录及每条 AC 的来源见 [audit-acceptance.md](./audit-acceptance.md)。不得拿合成身份的 HTTP 通过代替正式 JWT/FGA 验收。

## Platform（正式测试租户）

- [ ] AC-18、AC-19、AC-29：真实登录超管/本租户管理员/普通用户/受限 Child 管理员；客户端管理→模型审计，对照允许/拒绝配对，包含越租户与 PUT 模式。
- [ ] AC-21、AC-32：两轮请求重复历史，默认两卡；用户名、模型、时间、四轴过滤组合、精确编号、稳定翻页。
- [ ] AC-19、AC-33：Network 默认没有 body-access；仅显式展开一条，先查看日志再正文；日志失败时无正文、收起取消、翻页清理、部分状态不冒充完整。
- [ ] AC-24、AC-31、AC-37、AC-38：模式读取失败=降级 OFF；独立进入证据在窗口内等待/活动保护；超窗缺失、迟到恢复与缺尾片，不把未知改为失败。
- [ ] AC-33：窄屏与信创环境、超长原文分段、1000+片段、键盘和状态提示；不执行 HTML，不加载模型原文中的外部目标。

## Desktop 与共享存储

- [ ] AC-01、AC-02、AC-05、AC-07、AC-08、AC-28、AC-34：正式 Electron 的续接/Fork/编辑/标题/压缩/并行调用，能力缺失/子集及旧服务端兼容，不增加重放。
- [ ] AC-04、AC-10、AC-14、AC-19：MySQL/DM8 同编号比对输入工具/图片/输出原件、管理员范围、密钥恢复与逐次日志。
- [ ] AC-17、AC-27、AC-30：相同上游并发长流，OFF/METADATA/CONTENT 的首字/总耗时、内存、可见时效和独立分母；分别正常/失败/取消/模式读取降级，不拿已写行作分母。

## 回归与启用门禁

- [ ] 同步当前发布线后 lint/typecheck/i18n、DSH 登录/额度/席位/用量/原操作任务回归；处置基线既有 7 个测试失败及 93 个 lint error。
- [ ] 私有存储策略、密钥版本/轮换/备份恢复、持续容量和告警责任方确认；按 [audit-rollout.md](./audit-rollout.md) 默认 OFF 逐租户开启。
- [ ] 所有样本使用明确隔离环境和 `e2e-dsh-audit-` 合成前缀，不使用业务提示词或生产 token，不清空业务表/bucket。
