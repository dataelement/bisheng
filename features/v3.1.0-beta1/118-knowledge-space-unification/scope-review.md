## 已修正的范围表述

- **T135/T136**：删除可见即可发布、发布资格统一改 visible 的表述。区分来源的原 use 判断与应用自身的发布动作；发布/分享/管理和 lifecycle 不放宽。
- **T193**：只将原使用按钮及能力语义按 visible 解释；其他动作继续消费各自服务端结果，不能依据 visible 显示发布或分享。
- **T093/T094**：QA 保持既有入口和模型变更/重建逻辑，仅按本轮维护引用；不引入统一空间高级处理/UI 或合并 QA。
- **T133/T134**：限定旧 type/ID/use 字段和错误/身份兼容；不引入新的 SDK/MCP 协议或通用兼容平台。
- **T063/T064**：任务框架限知识处理和恢复，复用 Celery/Beat；不新增全平台任务平台。
- **T163/T164**：旧 type=2 只保持退休、不复活；不以迁移为由删除/清理其历史数据，type=1 保持独立。
- **T173/T174**：明确运维 CLI 属性，纠正“后端 API”类型标签；不新增在线迁移 HTTP API 或停服控制。

默认 Embedding 全空间联动已在上轮删除，本轮不恢复；显式改单空间模型仍按 AC-48 重建。其他既有缺陷若与上述限定无关，独立记录，不能自动成为 F118 的前置或借通用 AC 扩大工作。
