## 环境、账号与测试数据

| 代号 | 角色或数据 | 准备方法 | 确认方式或待确认项 |
| --- | --- | --- | --- |
| ENV-A | 已部署的站点入口、后端和对象存储 | 使用当前公共桶与临时桶。入口配置保持设计确认时的桶名无关写法 | 浏览器打开对象时，响应不是站点首页 HTML |
| USER-A | 能预览知识库文件、查看会话附件和自己的头像 | 使用现有业务权限，不新增授权 | 该用户在改路径前就能打开这些对象 |
| PUB | 当前公共桶中的一个原文件、一张切片图、一个头像 | 沿用现有上传或知识库解析产生的对象 | 对象键已知，且切片图在匿名可读范围内 |
| TMP | 当前临时桶中的一个附件 | 沿用工作台上传产生的对象 | 地址带签名且未过期 |
| OTHER | 不是当前公共桶或临时桶的桶，其中有一个对象 | 使用应用附件桶或测试桶，并准备一张有效签名 | 直接访问对象存储能取到该对象，经站点入口则不应取到 |
| OLD | 正文里保存着旧路径的消息或切片 | 旧路径第一段是当前公共桶或临时桶，库中的原文先记录下来 | 读接口之后再查库，原文仍是旧路径 |
| STALE | 正文里的路径第一段已经不是当前桶名 | 构造或选用换桶前留下的路径，对象仍在旧桶 | 读出结果仍指向旧桶名，新桶中没有该对象 |
