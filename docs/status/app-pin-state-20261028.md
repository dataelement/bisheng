# 应用置顶状态修复 — 2026-10-28

## 根因与修复

应用中心通过统一目录读取助手与工作流。置顶接口原先仅查询 Flow 表，实际保存在 Assistant 表的助手被判定为不存在，保存流程提前结束。Client 将 HTTP 成功响应中的业务错误继续作为成功处理，随后刷新出原状态。

置顶接口改用与列表相同的 `FlowDao.aget_all_apps`，统一解析应用类型、租户范围与助手删除状态，再校验上线状态与 `use` 权限，保存当前用户的置顶记录。Client 以业务状态码 200 确认保存成功，成功后读取服务端状态，失败时保留列表并显示对应操作提示。
