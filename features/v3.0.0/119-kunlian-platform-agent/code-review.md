## 前次实施修正（保留背景）

1. 发布图、版本指针、绑定及状态改为同一事务；离线草稿和移除最后节点不覆盖旧发布图。
2. 开放与浏览器入口保存实际用户和冻结图后投递引用；正式浏览器图取服务端发布内容，拒绝平台节点 override。
3. START／RESUME 分开领取；旧消息不重建许可。不同执行的 Redis 状态和事件隔离，停止先写 SQL。
4. 输出写入纳入受控作用域；SQL 提交失败恢复原变量，停止或超时后不输出迟到结果。
5. Mock V2 有意更换 query／answer 字段，版本更换后检查输入与下游引用；只保留正常结果为 result。
6. 超时、非终态、权限拒绝和错误输出有稳定原因；保留已有 Agent Run，失败日志不夹带成功业务输出。
