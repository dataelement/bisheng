## 问题与目标

`GET /file/detail` 的 MinIO 文本读取未命中后调用旧 ES 适配器，SPACE 被主动拒绝。
同文件中的 `/chunks_string` 直接调用旧向量写入，`/file/list` 的摘要读取也调用旧 ES。
资源创建默认 NORMAL，资源删除/清空继续使用通用清理流程；不能只替换索引名就认为完成共享适配。

目标是将 Filelib 文件业务统一收口到 SPACE 文档模型和租户共享 ES/Milvus，复用现有文档身份、
版本、投影、归属和生命周期服务。QA 保持当前模型与行为。

## Scope

- Includes: `filelib.py` 中 14 个知识资源/文件/切片/检索接口及其必要服务、仓储、测试和 API 文档。
- Excludes: 6 个 QA 接口和 `/download_statistic`；仓库其他入口的 NORMAL/PRIVATE/QA 行为；
  `filelib_sync.py` 业务规则重构；MCP 外部身份开发；生产部署、真实数据迁移、删除旧物理存储、Schema、依赖和运行配置变更。
- 保留现有 URL、成功响应包装及分页字段；默认类型和非 SPACE 请求拒绝属于本次明确的兼容性变化。

## 验收标准 Acceptance Criteria

| ID | 角色 | 操作 | 预期结果 |
|---|---|---|---|
| AC-01 | Filelib 调用方 | 不传 type 创建或列举资源 | 默认 SPACE；创建绑定租户共享目标和模型，具备正常空间归属；不创建独立索引 |
| AC-02 | Filelib 调用方 | 在文件接口传入非 SPACE、类型别名冲突或混合类型检索 | 参数/类型错误在读取正文、签名或写入前拒绝；不修改资源 type、不访问旧存储 |
| AC-03 | 有文件读取权限的用户 | 对已成功处理的 SPACE 文件查询详情，文本对象分别存在与不存在 | 两条路径均返回正确正文；无文本对象时读取共享分块，按切片顺序完整拼接 |
| AC-04 | 有读取权限的用户 | 对发布/分享入口或已切换主版本的文档查询详情和列表摘要 | 返回对应有效内容版本；不把入口 ID 当物理内容 ID；不读旧代次或其他空间内容；历史非主版本拒绝正文读取，不配上当前正文 |
| AC-05 | 有上传权限的用户 | 经 `/file/{knowledge_id}`、`/chunks`、`/chunks_string` 写入并重试 | 只写共享 ES/Milvus，元数据身份和归属正确；失败不能标记成功；重试不产生重复有效内容 |
| AC-06 | 有删除权限的用户 | 删除单文件或同空间批量文件，包含发布/分享入口 | 沿用现有管理入口/发布/分享生命周期语义；保留仍被有效入口使用的物理内容；跨空间批量输入在副作用前拒绝 |
| AC-07 | 有对应操作权限的用户 | 清空或删除一个空间 | 不 drop 租户共享目标、不按空间直接批量删 MinIO 对象；清空保留空间，删库走既有退役规则；其他仍有效入口可用 |
| AC-08 | 已授权用户 | 检索文件或获取原文件地址 | 仅返回请求范围内授权结果；签名指向解析后的实际原对象；无权结果不进入签名器 |
| AC-09 | Filelib 调用方 | 路由缺失/字段不完整、后端失败、成功文件的投影未就绪或共享正文缺失、读取期间版本变化 | 有可识别错误；不回退旧库；不将这些失败包装为空正文成功；未处理成功文件保留既有空详情响应 |
| AC-10 | 不同权限用户 | 访问无权文件、跨租户资源、冻结空间，或通过 external_id 查询 | 保留 Token/业务用户上下文规则；领域权限与冻结保护有效；冻结禁止写入但保留合法读取；拒绝后无正文、签名或写入泄露 |
| AC-11 | 既有调用方 | 使用列表、详情、上传、检索和原地址接口 | URL、既有成功字段、文件列表 total/page_num 和资源列表 cursor 结构保持；切片数量与正文路径语义有文档说明 |
| AC-12 | QA/统计下载调用方 | 调用本次排除的 7 个接口 | 路由、请求/响应、调用目标与原行为保持；通用旧适配器仍可供这些明确排除的业务使用 |

## 风险与边界

- 兼容性：过去不传类型默认 NORMAL，现在默认 SPACE；显式非 SPACE 的文件请求不再支持。
- 创建：默认为操作者拥有的团队库，避免创建没有 scope 的 SPACE；公共/部门库复用现有资格校验，不能绕过个人库创建禁令。
- 数据：删除与清空影响当前空间入口及现有分发规则允许的范围；共享目标和有效引用的原对象必须保留。
- 可逆性：本轮只修改本地代码和规格。未来回退代码不能撤销已发生的共享写入或删除，恢复数据须走已有回收/恢复流程。
- 环境：真实共享目标必须已初始化，历史内容须已迁移；本功能不自动 bootstrap 或迁移。
- F069 的全局业务用户作用域仍只适用于未启用租户功能的部署，本次不将其推广到多租户环境。
