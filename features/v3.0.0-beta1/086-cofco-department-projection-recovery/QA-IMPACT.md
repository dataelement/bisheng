# F086 QA影响范围与重点回归

交付目标：`feat/cofco-1118-3.0.0-beta1`。原开发基线：`00720a9c697f55f19086fc7c7ad111986a95f4ac`；测试时以包含本文的提交及实际镜像SHA为准。按用户要求，cofco-1111通过revert撤销本次修复，cofco-1118从撤销后的基线单独迁入；修复范围及24项回归不变。此次修正组织同步后的部门路径与权限投影失效，增加受限自动恢复、默认dry-run的运维校对及结构化告警。

这次涉及在线业务路径和共用权限基础设施，不能只验收历史异常部门能否修好。优先验证健康用户正常使用、正常组织变更及资源授权，再注入故障验收恢复。不需要为本次新增表、列、索引或发布新授权模型；前端、Gateway及IAM代码未改。

## 影响范围

| 范围 | 行为变化及关联风险 | QA重点 |

正常新业务投影使用已验证的运行时模型pin与SQL Catalog锁，不逐操作发现FGA模型、不套恢复专用写限速。恢复操作仍保留模型刷新、全目标证明及限速。需在真实环境比较正常流程耗时，不能由本地测试推断没有性能回归。

## 放行与发布提醒

- 上述P0全部通过，尤其健康普通用户允许/拒绝、正常组织和成员变更、非部门资源投影、跨租户及失败时关闭。P1调度、告警和DM实际性能结论应随测试报告提供；未执行项不能记为通过。
- SQL/FGA/operation及审计必须一致；不允许仅凭HTTP 200、状态CURRENT或成功日志判断修复完成。按普通用户实际业务访问复核允许与拒绝。
- 自动恢复默认开启。回退为停用自动任务只能停止周期/提示恢复，不能撤销同步执行器、子树path和上下文等代码变更。发现正常流程回归须停止新写入并按已验证的版本回退流程处理；回退前核对本次维护operation兼容性，不能无条件混跑新旧写入者。
- 人工修复须按[OPERATIONS.md](OPERATIONS.md)确认备份与写入窗口。仅提供正向修复/续跑，没有在线inverse或自动整库恢复；DBA整库恢复涉及停写和业务/FGA一致性，不能当作随时可用的单部门撤销。
- 日志规则参考[ALERTING.md](ALERTING.md)，交付代码没有替客户安装告警规则。`PROJECTED`仅证明正常原投影完成，不证明整个归档关联清理完成。
- 本地验证与实际部署分开记录，详见[validation.md](validation.md)。本地HTTP注入/SQLite和task注册不能替代真实API/Worker/Beat、双库、FGA/Redis、多节点及普通用户E2E；生产性能和十分钟目标未证明。
