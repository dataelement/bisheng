# 组织与成员页面链路验证

2026-11-10 本地执行。浏览器没有可用的 Browser plugin，使用已安装的 Playwright/Chrome。实际部门页面源码与共享控件，专用 API 模拟数据；后端另以真实 SQLite 查询与 HTTP ASGI 链路验证。此记录不代表真实部署联合验收。

| AC | 本地证据与结果 | 目标环境复验 |
| --- | --- | --- |
| AC-01 | SQL 名称包含/通配符/编号不匹配；组件 IME 与旧响应竞态通过 | 真实大组织数据下的响应时间 |
| AC-02 | SQL 去重、停用、跨租户和既有 scope parity 回归通过 | 实际普通管理员的权限来源 |
| AC-03 | SQL 主属优先、当前兼职优先、树序回退；浏览器仅显示“产品部（兼职部门）” | 真实主属不可见、兼职可见账号 |
| AC-04 | SQL 可见祖先路径排除自身；浏览器路径与分组正确 | 超长组织路径与大量分页结果 |
| AC-05 | 组件失败保留结果、清空恢复树；浏览器清空通过 | 目标网络延迟下的体验 |
| AC-06 | 浏览器选择深层部门展开、选中和退出搜索通过 | 真实组织迁移后的树缓存 |
| AC-07 | 服务端页码/筛选 SQL，StrictMode、迟到响应、旧 total 分页回归；浏览器第二页成员高亮通过 | 真实数据并发增删后的再次定位 |
| AC-08 | 浏览器默认成员页与三按钮，无原设置/流量页签；1024px 无页面溢出 | 实际菜单入口与角色组合 |
| AC-09 | 5 项弹窗测试：跨页签、失败重试、关闭确认、移动部分成功、保存锁定；浏览器统一保存通过 | 真实流量接口与并发限制生效 |
| AC-10 | 既有归档/删除 3 项组件回归通过；复用原写入接口 | 真实归档、恢复、彻底删除、挂载/卸载 |
| AC-11 | HTTP 允许/拒绝，SQL 过期目标权限复验通过；成员迟到响应丢弃 | 完整登录/网关/OpenFGA 与管理视图切换 |
