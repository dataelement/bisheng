# 运输当前运行合同（2026-11-26）

业务范围见 README.md 与 SKILL.md；API 为同目录 openapi.json，模型参数为 tool-schema.json。旧 fixture 的完整原字段只为历史回执/状态兼容保留，不用于当前业务计算。

公开工具 transport_history 接收 {"request":{...}}。可信执行端提供 workspace/base_url/token；不接受模型提供路径、凭据、receipts 或代码。原生 API 入口接受 request_json 与 context_id，详情可由服务绑定当前 query_id；本地工具 detail 必须提供同次查询 query_id。

history 只取所给范围的全部分页并返回历史费用和覆盖；inquiry 先澄清必要条件，不完整不取数。同一完整候选池可重用；更改显式方式/服务商/币种/日期保护时重新取数。show/filter/reset/detail 不联网。排序只接受 source。日期仅支持 etd/eta；按主分单组合精确确认，不把同主单其他分单当作命中。

每次动作一次有界分页取数，不循环重试。每页最多 100 条、最多 100 页/10000 条，总原始字节及状态最多 16 MiB。完整空结果与参数、鉴权、超时、取数、状态错误区分。工具结果 terminal=true、next_action=none，直接展示 answer。

共享账单一单一笔原币总额；覆盖保留该费用单全部实际关联明细，关联补充不计命中，不自动分摊或计算每公斤价格，不生成当前正式报价。推荐金额按币种分别展示范围，无 CNY 排序依赖。

原始 HTTP 字节以 0600 独占创建并校验哈希。状态 uploads/transport-runtime/session.json 原子写入，独立非阻塞锁覆盖取数到提交；坏状态、缺页、混快照、覆盖丢失、金额错配、旧引用均结束。路径拒绝符号链接和逃逸。目录绑定/能力引用与静态密钥不证明跨用户权限隔离。

底层 contract.query 与旧字段校验保留，以验证历史回执/状态；当前 HTTP 和公开业务输入由 active_query 拒绝净重、包装数量及开票日条件。旧日期排序不再读取开票日，按来源顺序展示；旧查询若依赖撤回筛选则要求新查询。旧净重询价要求补毛重重查。旧状态附带 advice 可以读取但不展示和执行。

本轮仅本地与 3.0.2 候选，不包含发布、推送、D 变更、真实模型自然语言提取或客户正式数据验收。历史 D 证据仍只适用于当时版本。
