## 失败定位、回退与回执

421 按“入口代理 → 中间代理 → API 实例 → MCP 校验”逐跳定位；401 优先核对登录会话，403 结合响应来源区分 Origin 校验与业务权限。目录为空时核对账号权限、工具启停和发布配置，并用预先指定工具确认结果。界面仍显示通用登录错误时保留该提示，同时记录真实上游状态供客户端错误展示问题继续处理。

若候选发布影响原有登录/Chat，按发布流程恢复上一个后端版本及配套 Nginx/地址配置，重新检查健康、登录和 Chat。用户会话与业务数据沿用原存储。记录回退原因、版本、时间和复测结果。

测试回执包含：候选 SHA/镜像 digest、API 实例一致性、公开地址、代理链与实际 Host、客户端版本、账号类型/租户、上述各项 PASS/FAIL、MCP initialize/tools/list 状态、一次工具业务结果和失败时的请求 ID。全部现场项目通过后再将 13001 标记为恢复。
