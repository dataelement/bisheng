## 行为

- 用户页保留用户名与 ID、授权状态、每月用户额度、用户授权开关与保存。状态文字完整单行显示。
- 开关与额度独立保存。开关关闭时保留额度；开关开启且额度为零时，该条直接授权的有效权限为关闭。
- 最终权限继续采用有效用户、部门、角色来源的最大额度；关闭直接用户授权保留部门或角色来源。
- 开关切换即提交当前额度，过程中锁定控件；确定失败时恢复保存前开关，修改额度后也可单独保存。
- 沿用平台现有 bs-ui 组件和页面风格，保留系统开关规范的即时保存、处理中锁定与失败反馈。
