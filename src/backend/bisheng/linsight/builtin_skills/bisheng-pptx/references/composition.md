# 页面组合建议


- 开场：说明要解决的问题和核心判断。封面只保留一条主信息。
- 展开：依据比较、流程、时间、层级或因果关系选择结构；不要所有页面都使用三列卡片。
- 证据：图表标出单位与来源，正文解释证据为何支持结论。
- 收尾：给出负责人、动作、验证标准或仍待回答的问题。

模板是布局工具。不要继承示例里的公司、数字或结论。沿用模板的边距、字阶和颜色关系，按实际内容调整元素数量。所有区域应在页面内；文本容量不足时拆页。保持文字、图表和结构可编辑，只将必要照片或插画作为图片。

## 精细排版

- 分析页按“结论—主图—辅助证据—解读”组织。辅助证据可以是贡献对账、对照表或待验证的问题，不要再次复述大标题。观点页仍应保持简洁，避免所有页面同样密集。
- 分清章节标、主标题、图示标题、正文、图注五个层级；优先用字号和间距区分。数字按列对齐，图注共用基线。检查末行孤字、孤立标点和机械换行；中英文分别重排。
- 重要拐点和异常直接标在图上，必要时加短引线；避免引线穿过文字。同页两幅图如果分母不同，分别注明样本、单位和期间。桥图及贡献分析要对账，所有比例和差值要重新计算。
- 结论栏只放一条解读、行动或待解问题。路线图补负责人和决策门槛；计分表重点标出异常行，不把每个格子都涂满颜色。
- 沿用当前模板的字阶、色彩和页面节奏。细化不等于把海报、报告和工程图都改成一张咨询报告。保持正文可读，空间不足时改写或拆页。
- 渲染后查看实际页面，检查阅读顺序、文字断行、图表标签、色彩对比和页脚间距。包围框检查通过不等于版式已经合格。
