## 2. 本轮修订与复核

自审识别并在同一设计稿中修正两点，未修改已确认 AC：

1. **时序准确性**：排队发生在 accept 返回之前，图已改为先 enqueue、后响应 CLI；审批创建仍先于正式版本 INSERT，不误写为相反顺序。
2. **错误合同**：明确 v2 HTTP 400 + 业务码 16233，来源为当前 open_api_http_status 映射；不采用缺少读取方的自定义错误状态属性。参数类型错误沿用框架原校验响应。

复核了能力元数据的整数类型（排除 bool/string）、结构变更确认重传只读一次文件、两处版本组件和 CLI 安装件输出目录，以及不支持混合 API/worker 版本发布的升级前提。

## 3. 验证证据边界

本轮只有源码核对、设计自审和文档一致性检查，没有业务代码变更、依赖安装、运行单元测试、数据库迁移、镜像构建或远端部署。所有 design 中的新参数、字段、版本号及测试均为待实施，不构成交付证据。

正式设计按 AGENTS.md §6、SDD-Guide §3、sdd-review 需用户确认；确认后进入 tasks 并实施，仅做本功能必要的定向验证。
