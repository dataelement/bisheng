# PRD 24 项对照

依据已确认 PRD 第 4 节缓存；不是所有场景均已在真实环境复现。完整浏览器/中间件验收见 e2e-checklist.md。

| 场景 | PRD 归并 | 本次处理及证据 |
|---|---|---|
| E01 设备离线 | 网络 | 浏览器离线、明确请求传输错误 → 本次页面的网络对象；前端测试已写，待运行。 |
| E02 页面连接中断 | 网络 | 未正常终结的 SSE 关闭 → 网络；明确服务/HTTP 错误优先；主动停止排除。前端测试待运行。 |
| E03 响应数据异常 | 按返回异常的服务归并 | 供应方边界标记 + SDK 类型来源；平台协议错误不强归。后端定向回归通过。 |
| E04 模型连接失败 | 模型服务 | 真实 LLM/Embedding/Rerank/ASR/TTS 调用边界，不包裹外层额度守卫。后端回归通过。 |
| E05 模型响应超时 | 模型服务 | 同 E04；保持原异常及重试。后端回归通过。 |
| E06 模型服务异常 | 模型服务 | 同 E04；供应方内部数据错误不改判数据库。后端回归通过。 |
| E07 模型限流 | 模型服务 | 五类元数据与旧限流身份分别传递；后台恢复保留原反馈。后端重试回归通过，实时身份前端测试待运行。 |
| E08 模型认证失败 | 模型服务 | OpenAI SDK/实际模型边界归模型，不按普通 HTTP401 猜 SSO。后端回归通过。 |
| E09 模型调用权限不足 | 模型服务或原授权提示 | 供应方边界归模型；平台拒绝保留原业务错误码。后端反例回归通过。 |
| E10 模型已停用或不存在 | 模型服务 | 实际停用/缺配置等已知模型错误类识别；不改配置和权限。后端回归通过。 |
| E11 模型服务余额不足 | 模型服务 | 模型边界 + 内部 reason=balance_exhausted；旧失败/重试策略不变。真实供应方待场内验证。 |
| E12 平台使用额度耗尽 | 业务额度提示 | 不打模型类别；响应保留已登记业务码，前端按本地三语翻译。定向反例通过，UI 待验证。 |
| E13 模型调用额度受限 | 模型服务或业务额度提示 | 供应方与平台分别处理，来源继承优先，保留恢复字段；后端回归通过。 |
| E14 上下文超限 | 模型服务或输入校验提示 | 模型边界可归模型；平台长度校验仍为业务码。真实超长上下文待场内验证。 |
| E15 模型能力不匹配 | 模型服务 | 已知模型配置/类型错误与真实调用边界；不改模型工具绑定与能力控制。真实多模态待场内验证。 |
| E16 内容安全限制 | 模型服务 | 模型边界 + 内容拒绝 reason；原重试/子任务降级行为回归通过。 |
| E17 知识检索失败 | 数据库 / 模型服务 / 对象存储 / 网络 | 日常按库隔离失败，任务软失败明确标记；保留成功结果。来源/快照/命名空间回归通过，UI 待验证。 |
| E18 文件解析服务繁忙 | 按实际失败依赖归并 | 解析包装保留原因链，实际模型/数据来源继承；独立 ETL 无可靠来源仍保留原解析提示。场内 OCR 待验证。 |
| E19 文件解析失败 | 业务提示或按实际失败依赖归并 | 附件软失败不终止其他附件；依赖元数据在准备步骤展示；损坏/格式按原业务状态。场内真实解析待验证。 |
| E20 登录失效 | 单点登录 | 提供 sso 枚举和固定文案，仅消费可靠来源；未改全局认证、401/403 和外部网关。仓库内本次无可直接验证的独立 SSO 故障，需场内证据。 |
| E21 资料访问权限不足 | 业务权限提示 | 不将权限拒绝强归五类；仅已知依赖 SDK 故障继承来源。既有权限规则未改。 |
| E22 引用资料失效 | 业务资源提示 | NoSuchKey/正常缺失不判存储故障，其他明确存储依赖失败保留来源。后端回归通过。 |
| E23 工具执行失败 | 按工具实际失败依赖归并 | 日常 ToolNode、任务 ToolExecutor/SearchKnowledgeBase、模型降级步骤带结构化元数据；不终止既有软失败流程。后端回归通过。 |
| E24 原因未知 | 内部待定位 | 通用失败，不从 Connection error 或任意文本猜类别；旧记录读取脱敏，无数据回填。后端回归通过，前端测试待运行。 |
