## Evidence and limits

- 使用统一环境模块已存在的桌面身份标记，覆盖入口 `embed=dsh` 以及后续会话识别，不将 CSS 展示标记用于权限或接口判断。
- CSS 同时限定桌面身份、≥768px 宽度和公共首页框架；浏览器默认规则、窄屏布局和框架外的广场不采用该变体。
- 960px 上限、两侧流动留白和顶部 56px 均来自本机插件页面及宿主最终覆盖；没有把插件原始 macOS 避让与宿主覆盖重复相加。
- 保留原来的数据、创建、筛选、排序和开关行为。公共正文样式替换页内多余留白，使四个页面的正文间隔统一为 32px。
- 实际组件预览验证了 890px 四个首页、768 / 1280px 边界和浏览器端回归；测量详见 [布局说明](../module-home-layout.md)。
- 标题后续修正同步了 DSH 默认字体回退栈、抗锯齿和原生 20px 标题 token，覆盖知识空间局部字体继承；DSH 原始字体声明与实际公共页头的四个中文标题及英文数字样本字形尺寸一致。用户自选字体尚未由宿主桥传递，不将默认字体对齐表述为自选字体同步。
- 全仓 lint、类型检查以及 56 项相关既有测试通过。差异空白检查、架构守卫通过。
- 预览使用演示数据，不代表安装包中已实际加载本轮前端。BishengWork 仅作只读参考，没有修改或打包宿主。

## 知识空间内部页补充审查

- 仍为无契约变化的视觉修正，按同一七维度清单复核，无新增 HIGH / MEDIUM 问题。
- 内部页复用公共桌面框架的顶部、左右 Padding 和内容宽度，仅用局部变量取消首页底部留白；没有复制一套新的尺寸值。
- 局部覆盖同时限定桌面身份、≥768px 视口和知识空间内部页祖先。文件行等共享内容只在该祖先内调整；未扩散至预览抽屉、普通浏览器或窄屏。
- 页头、工具栏、列表复选框共用同一内容边缘。取消返回按钮组负外边距，避免在取消内层 Padding 后裁切按钮；文件列表仍自行滚动并保留提问框占位。
- 890 / 768 / 1280px 测量、767px 与浏览器回归、深色列表/卡片视图和长列表底部手动验证通过；数据、业务 hook、输入框内部与弹层为夹具，验证边界见布局说明。
- 全仓 lint、类型检查、36 项相关既有测试通过；架构守卫、差异空白检查通过。
