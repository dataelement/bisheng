## 验收中发现并已修复

1. 启动补权限全部报 `NoTenantContextError`（553719f7c）。
2. 平台工具列表显示 `categories.网页读取.name`（a1dee645d）。
3. 日常模式角标渲染成原文：itemId `page` 被 remark-directive 当成指令，改为 `0`（25ce30dd4）。

## 未覆盖与既有问题（非本功能引入）

- **工作流**：工具节点「单节点运行」在 release 上对所有工具都报 `run_async_safe cannot be called from a running event loop`（联网搜索同样失败），本次未搭完整工作流图验证 AC-15、AC-16；这两条由单测 `test/citation/test_web_fetch_scenarios_agent.py` 覆盖。
- **助手运行日志重复**：同一次工具调用记两条「已使用 …」（引用包装层和内层工具各一条），联网搜索同样如此。
- **助手角标**：助手场景不注入引用规则（design 决策 9），模型是否写角标取决于搭建者提示词；本次模型写了 Markdown 链接「[来源]」。
