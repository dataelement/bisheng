# 文件预览与引用溯源共享

状态：2026-10-23 用户确认规格；设计已确认，尚未实施。

关联需求：[调研及用户确认记录](discovery.md)。所属版本：v3.0.0。依赖：既有文件预览、F078 共享 UI、F086 共享会话、F088 请求错误处理。

## 1. 目标与边界

作为前后台用户，我希望查看同一文件及回答引用时，预览和定位行为一致；作为维护者，我希望修复公共预览或引用问题后，两端同时受益。

纳入：现有 Excel/CSV、DOCX、Markdown、TXT、HTML、图片、PDF、音视频预览的公共能力；引用标记、来源列表、原文预览/定位/下载；两端 ECharts/Mermaid 资源同源维护和独立部署。展示以 client 为基准，保留后台已有业务编辑能力。

排除：新增 DOC/PPT 等尚不支持格式的直接渲染、替换解析引擎、后端/数据库/权限合同变更、前端状态库迁移、视觉重设计、图表库版本升级、新增 CDN 或独立资源服务。不顺手修改无关表单或错误处理。

## 2. 验收标准

### 文件预览

- **AC-01** — WHEN 用户从前台知识空间或后台知识库打开已支持的文件，THE SYSTEM SHALL 使用共享的对应预览能力，并保留各入口已有的可见内容与操作。
- **AC-02** — WHEN 打开 Excel/CSV，THE SYSTEM SHALL 保留现有表格、工作表切换及可用图片展示；不引入另一套 Excel 实现。
- **AC-03** — WHEN 打开 DOCX、Markdown 或 TXT，THE SYSTEM SHALL 保留正文、已有格式/图片及滚动；在入口已有缩放或引用文字定位时保留相应能力。
- **AC-04** — WHEN 打开 HTML，THE SYSTEM SHALL 在隔离预览环境中展示，预览内容不得取得宿主登录态或访问宿主 DOM，保留已允许的内容运行能力。
- **AC-05** — WHEN 打开图片，THE SYSTEM SHALL 保留该入口已有的适应容器、缩放、旋转及下载操作；不把已无此操作的入口强制改成新交互。
- **AC-06** — WHEN 打开 PDF，THE SYSTEM SHALL 保留分页、缩放、滚动、引用定位和高亮；后台框选/切片编辑及相关保存仍仅在可编辑业务入口可用。
- **AC-07** — WHEN 打开音频/视频及其引用，THE SYSTEM SHALL 保留播放和已有的转写内容展示，不把媒体原文件地址与转写预览地址混用。
- **AC-08** — IF 文件读取或渲染失败，THEN THE SYSTEM SHALL 结束加载并给出本地化失败提示；旧文件在切换或关闭后完成/失败不得覆盖当前预览或触发过期提示。

### 引用溯源

- **AC-09** — WHEN 查看现有或历史会话中的引用标记，THE SYSTEM SHALL 保留既有支持的引用格式与编号，对应同一来源和原文片段；未知引用不得伪造成可用来源。
- **AC-10** — WHEN 在前台或后台打开来源列表，THE SYSTEM SHALL 保留文档、网页及媒体等已有来源的信息和操作，同一来源的多个引用片段可正确访问。
- **AC-11** — WHEN 点击文档引用，THE SYSTEM SHALL 打开对应文件，并在入口已有定位能力时定位到正确引用片段；PDF 支持已有多个片段高亮，非 PDF 保留已有文字定位。
- **AC-12** — IF 引用详情缺失、资源失效或无权访问，THEN THE SYSTEM SHALL 显示对应不可用状态，不显示空白成功预览，不通过其他权限路径获取受限内容。
- **AC-13** — WHEN 用户切换引用、会话或关闭抽屉，THE SYSTEM SHALL 保持当前来源、标题、文件及定位属于同一次选择，不混入旧请求结果。
- **AC-14** — WHILE 处于分享、日志、审计等只读入口，THE SYSTEM SHALL 保留获准的复制/预览/下载，且不因预览挂载触发发送、执行、标注或 QA 写入。

### 图表资源及整体回归

- **AC-15** — WHEN 更新 ECharts 或 Mermaid 的公共资源，THE SYSTEM SHALL 使前后台输出使用相同内容；现有压缩脚本不重新编译或转译。
- **AC-16** — WHEN 分别开发启动、生产构建或独立部署任一前端，THE SYSTEM SHALL 能从本应用访问对应图表资源，不依赖另一前端运行或产物目录存在。
- **AC-17** — WHEN 同页多个图表请求同一脚本，THE SYSTEM SHALL 避免重复加载；IF 加载失败，THEN THE SYSTEM SHALL 结束等待并允许后续重试。
- **AC-18** — WHEN 在会话或后台看板使用现有图表能力，THE SYSTEM SHALL 保留该入口已有的渲染、切换源码、缩放及导出操作，不改变图表库版本。
- **AC-19** — WHEN 使用中文、英文、日文及浅色/深色、桌面/窄屏布局，THE SYSTEM SHALL 保留可读文案、可用操作和原有布局适配，不显示翻译键或未替换参数。
- **AC-20** — THE SYSTEM SHALL 为本次已纳入且可共享的预览、引用及图表加载能力保留一个公共维护来源；两端仅保留必要业务适配，失去调用方的旧副本应删除，第三方完整分发包中的内嵌依赖另行核查。

## 3. 测试及业务边界

- 覆盖知识库文件预览、会话引用、独立/分享页、后台工作流/助手调试、标注及日志入口；日常/任务模式仅覆盖其现有预览/引用消费入口，不修改会话业务流程。
- 覆盖正常、空内容、失效、拒绝访问、读取/渲染失败、快速切换、关闭后回调和重复加载；不能用下载失败代替 PDF 页面渲染失败。
- 旧格式引用、缺失字段和不同文件扩展名/地址形态需回归；不重新定义后端返回合同。
- 已接受并用于入库的预览正文与入库正文一致的既有约束保持；抽离不触发文件重新解析或写入。
