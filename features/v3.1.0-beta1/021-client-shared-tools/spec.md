# 客户端共用工具配置

流程：Small feature（SDD-Guide §1）。仅为已有工具配置增加入口，不新增领域对象、接口或配置副本。

用户已确认：修改客户端入口中的配置后，平台也生效。

| AC | 验收条件 |
|---|---|
| AC-01 | 客户端 → 模型权限 → 其他模型配置内提供“搜索工具”和“绘图工具”配置入口。 |
| AC-02 | 搜索复用平台网页搜索配置表单，绘图复用通用图片生成表单（兼容旧 image_generation 工具）；入口使用通用名称“绘图工具”。 |
| AC-03 | 两个入口读写平台现有的同一份工具配置，独立保存；提示修改同时影响平台，无需保存模型配置。 |
| AC-04 | 沿用平台超管配置权限；其他用户不能通过新增入口读取或修改配置。 |
| AC-05 | 每次打开读取最新配置；工具缺失、重复、配置无效或请求失败时明确报错，不误报成功；保存失败保留输入，保存期间防止重复提交。 |
| AC-06 | 新增文案覆盖中、英、日三种语言，沿用工具配置接口的密钥掩码机制，不输出密钥日志。 |

边界：不改变工具执行方式、模型授权或额度，不实现新的绘图供应商。
