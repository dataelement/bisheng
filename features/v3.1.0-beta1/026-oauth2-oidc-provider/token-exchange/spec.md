# 同一用户跨系统 Token Exchange

状态：规格草案，待评审及用户确认。需求来源：[request.md](./request.md)。所属能力：F026 OAuth Provider；目标发版线：feat/3.1.0-alpha1。检查基线：572d5ecf77。

## 目标与用户故事

用户已通过毕昇身份服务登录 A。受信任的 A 服务端代该用户向毕昇申请 B 的登录凭证，B 接受后识别同一个人、同一个租户，不再要求重复输入毕昇密码。

平台全局管理员能明确批准、限制和撤销 A→B 的换证关系。用户、租户与原有业务权限的归属不改变。

## 验收标准

- **AC-01**：WHEN 同一用户持有归属 A 的有效毕昇 OAuth Access Token、可信 A 服务端申请预先批准的 B 目标且全部校验通过，THE SYSTEM SHALL 返回可供 B 使用的短期登录凭证，保持用户及其当前租户不变。
- **AC-02**：WHEN 请求方无法证明其为 A 的可信服务端、请求方与原凭证所属应用不一致、或者由公开客户端直接申请，THE SYSTEM SHALL 拒绝换证；首版不支持第三方代其他应用发起交换。
- **AC-03**：WHEN A、B 不存在、禁用、相同，或者 A→B 未批准/已禁用，THE SYSTEM SHALL 拒绝换证；不得自动批准任何组合。
- **AC-04**：WHEN 原凭证伪造、签发方/所属应用不匹配、缺少必要身份信息、过期、其会话撤销/到期、自然人账号失效、当前租户禁用或当前成员关系不存在，THE SYSTEM SHALL 拒绝换证。
- **AC-05**：WHEN 请求指定其他用户、其他租户、第三方签发凭证、毕昇网页/旧DSH凭证、ID Token、Refresh Token，或以换出的凭证继续连锁换证，THE SYSTEM SHALL 拒绝，不提供身份切换或代登录通道。
- **AC-06**：WHEN 请求权限并非同时包含在原用户授权、A→B 授权策略及 B 的允许权限中，THE SYSTEM SHALL 整体拒绝；不得静默扩大或静默裁剪。首版仅交换已有身份资料范围 openid/profile/email，不支持 dsh、offline_access 或业务权限。
- **AC-07**：WHEN 请求未明确指定至少一个身份资料权限，THE SYSTEM SHALL 拒绝；成功响应必须准确说明实际授予的范围。
- **AC-08**：WHEN 换证成功，THE SYSTEM SHALL 使新凭证有效截止不晚于原 A 凭证到期、原会话到期、本次开始换证校验时刻加 B 配置访问有效期、本次开始换证校验时刻加300秒四者最早值；在途处理耗时计入此上限，不得因延迟签发延长有效截止。签发时已无正数剩余寿命则拒绝；不签发独立刷新凭证或额外身份令牌。
- **AC-09**：WHEN A 会话、账号或当前成员资格已失效，THE SYSTEM SHALL 拒绝失效状态已提交后发起的新换证；B 仅本地验证的既有凭证可继续有效至到期，残余有效期最多300秒。不会承诺本地验证下的5秒撤销。
- **AC-10**：WHEN 全局管理员批准、编辑或禁用 A→B 关系，THE SYSTEM SHALL 保存该变更；变更提交后开始校验的交换采用新状态。与变更并发且已开始校验的交换可按其已读取的有效状态执行，但有效截止不得晚于该次变更提交后300秒。
- **AC-11**：WHEN 普通用户、租户管理员或未认证调用者尝试管理 A→B 关系，THE SYSTEM SHALL 拒绝；策略是平台级的应用信任关系，不是跨租户或跨用户身份映射。
- **AC-12**：WHEN 无法确定策略、会话、用户或租户状态，THE SYSTEM SHALL 返回错误并拒绝签发，不得降级放行。
- **AC-13**：WHEN 换证成功或被拒绝，THE SYSTEM SHALL 提供可追溯的非敏感事件，包含可确定的应用、目标、用户/租户标识、结果和时间；不得记录原始令牌、密钥、密码或完整敏感请求。
- **AC-14**：WHEN 参考 B 接收端接收有效的 B 凭证，THE SYSTEM SHALL 能验证来源并识别同一稳定用户/租户，完成免重复密码的身份接入；错误目标、签发方、签名或过期的凭证必须被拒绝。实际 B 产品自己的账号映射和本地会话建立由其集成方完成，验收使用明确的参考接收端证明协议。
- **AC-15**：WHEN 使用交换所得凭证访问毕昇在线身份查询或撤销接口，THE SYSTEM SHALL 仅授予该次 B 会话对应的能力；撤销 B 会话不得撤销用户原有 A 登录，A 撤销后在线身份查询不得继续把该派生会话视为有效。
- **AC-16**：WHEN 申请协议能力未支持、输入缺失或类型不匹配，THE SYSTEM SHALL 返回明确的客户端/授权/目标/权限/请求错误，且不暴露无法确定的账号或租户详情；响应不得被缓存。
- **AC-17**：WHILE 新换证能力开启，THE SYSTEM SHALL 保持现有授权码、PKCE、刷新、撤销、OIDC发现及旧DSH登录兼容，未配置交换授权的客户端原有登录行为不变。

## 范围与不做

- 本次只处理“同一用户、同一租户、不同接入应用”。不支持从用户A变成用户B，也不支持跨租户/角色切换。
- A 必须是可保密的服务端。插件和桌面端不得内置客户端密钥；若自身是公开客户端，应走正常授权码登录，或另行设计经授权的后端代理，而非本轮跨客户端代换。
- B 明确信任毕昇并自行维护本地登录会话、业务授权。不会凭空生成由其他独立签发方签名的令牌；不自动修改未提供的 B 系统代码。
- 新凭证不是 /api/v2 的 ApiCredential、个人访问令牌或 DSH 模型凭证，不能因为获得交换凭证就直接访问这些业务接口。
- 首版提供管理员策略管理接口与接入说明；新增策略管理UI不属于本轮范围。

## 契约确认项

沿用已确认的B本地验证方向，拟在发布契约中明确：F026短期OAuth身份断言与F049/F053的ApiCredential分属不同对象；现有随机凭据哈希存储及5秒撤销规则保持原样。本轮OAuth断言的最长300秒本地验证残余有效期需要随本规格明确确认，不将其冒充为现有ApiCredential的豁免或已经生效的实现。若该边界不能确认，则改为在线校验方案，重新评审，不静默变更撤销承诺。
