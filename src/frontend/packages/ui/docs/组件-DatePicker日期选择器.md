# 日期选择器 DatePicker

> 设计系统 · 日期选择器 v1 · 2026-11-10
> 适用 BISHENG 的表单与筛选场景。首版范围已确认，交互与视觉取值见正文及文末「调研附录」。
> 配套 [组件-Input输入框.md](组件-Input输入框.md)、[组件-Select选择器.md](组件-Select选择器.md)、[基础-多端适配原则.md](基础-多端适配原则.md)。

日期选择器让用户直接输入日期，也可以打开日历点选。收起时，字段里显示已经选好的日期或范围。

查看[日期选择器演示](/components/date-picker)。

## 1. 什么时候用

| ✅ 推荐 | ❌ 不推荐 | 原因 |
|---|---|---|
| 给生效日期用单日选择 | 用普通输入框要求用户自己核对日期 | 日历能显示星期和可选日期，也能避免填出不存在的日期 |
| 给日志查询用日期范围 | 把同一范围拆成互不关联的两个单日字段 | 共用日历能看到起止日期和中间覆盖了哪些天 |
| 给密钥到期时间用日期时间 | 业务只精确到天，却要求用户填写时分秒 | 只收业务真正使用的精度，避免用户猜该填几点 |

只提供「最近 7 天」「最近 30 天」等固定选项时，用 [组件-Select选择器.md](组件-Select选择器.md)。当用户还需要选自定义范围，再使用日期范围和可选的快捷区间。

## 2. 结构 Anatomy

| 部分 | 用途 |
|---|---|
| 日期字段 | 显示日期格式或已选值。点击输入框任意位置即可展开面板，右侧日历图标提示字段用途 |
| 日历头部 | 显示年和月，提供上一月、下一月，以及跳到指定年或月的入口 |
| 日期网格 | 按七列显示星期和日期。范围模式在这里标出开始日、结束日和中间日期 |
| 快捷区 | 由业务提供快捷区间时显示，放在日期网格下方 |
| 时间与操作区 | 日期时间模式显示时、分及可选的秒，底部提供「取消」「确定」 |

## 3. 类型 Type

| 类型 | 选择内容 | 面板内何时生效 |
|---|---|---|
| 单日 | 一个日历日 | 点中可选日期即生效并收起 |
| 日期范围 | 一对起止日期，包含首尾两天，可选同一天 | 选完两个端点即生效并收起。第一个端点只暂存 |
| 单边日期范围（按需启用） | 开始和结束日期可以分别选填，包含选中的当天 | 点选一端即更新范围并收起，空着的一端显示「不限」 |
| 日期时间 | 一个具体日期和时刻，默认到分钟，按业务需要显示秒 | 日期和时间均有效时，点「确定」后一起生效并收起 |

- 单日和日期时间各用一个输入区。日期范围用同一个外框包住两个输入区，中间用短横线「–」隔开，并分别标识「开始日期」和「结束日期」。
- 日历头部的年、月使用组件库的下拉选择器定位日期。列表打开时滚动到当前项。选择年或月后收起列表，日历保持打开，字段保留原值，直到用户完成日期选择。

### 3.1 单边日期范围

- 在需要持续生效或按日期前后筛选的场景启用单边范围。点击要填写的那一端，打开日历选日期。
- 只选开始日期时，回显「2026-11-11 — 不限」，覆盖当天及之后。只选结束日期时，回显「不限 — 2026-11-11」，覆盖当天及之前。
- 点击「不限」可以补选日期。编辑任意一端时保留另一端的值，日历会禁用导致起止顺序颠倒的日期。
- 删掉一端的日期，按 Enter 或离开字段后，该端显示「不限」。两端均为空时，清除日期筛选，并恢复 §5.1 的占位文案。
- 业务设置了最大跨度时，要求填写起止日期，并说明跨度限制。

## 4. 尺寸 Size

- 触发器沿用 [组件-Input输入框.md](组件-Input输入框.md) §3 的 24 / 32 / 40px 三档，默认 32px。同排筛选控件用同一档，字段宽度应容纳完整日期、时间和常驻图标。
- 日历图标按输入框后缀尺寸取 14 / 16 / 18px。保留图标位置，清除图标出现时使用相邻的后缀位，避免日期文字或日历图标跳动。图标与清除样式见输入框 §4。
- 面板不随触发器分档。每月七列，日期格均为正方形，桌面每格 36 × 36px，触屏每格 44 × 44px。桌面面板内边距 12px，单月主体宽 276px。日期范围默认并排显示连续两个月，两月间距 12px。容不下双月时切到单月，用翻页跨月选择。
- 面板沿用选择器的页面底色、12px 圆角和浮层投影，与触发器间隔 4px。面板优先在字段下方对齐左缘，空间不足时向上翻转并在视口内平移。外壳规则见 [组件-Select选择器.md](组件-Select选择器.md) §5.1 和 §8。

## 5. 内容形态 Content

### 5.1 日期与时间格式

- 日期统一显示为「2026-11-10」，日期时间显示为「2026-11-10 14:30」，启用秒时显示为「2026-11-10 14:30:05」。时间用 24 小时制。星期、月份名称和操作文案随界面语言显示。
- 单日和日期时间的空字段用格式占位，例如「YYYY-MM-DD」。日期范围的两端分别用「开始日期」和「结束日期」占位。在字段外保留「生效日期」等业务标签，填完后仍能看出字段含义。
- 日期范围显示完整的具体日期，不限的一端显示「不限」，跨月或跨年时也能独立读懂每一端。「不限」表示没有这一端的边界。
- 纯日期表示日历中的一天，跨时区显示时保持原来的日历日。日期时间使用场景指定的时区，缺省时使用用户本地时区。场景指定时区时，在字段旁标明，便于核对实际时刻。

### 5.2 默认值与快捷区间

- 空字段打开时，日历定位到今天所在的月份。今天不可选时，定位到离今天最近的可选日期所在月份。今天的标记用于定位，字段继续保持空值。
- 有值时定位到已选日期。普通范围从开始日期所在月份显示。启用单边范围后，优先定位到打开日历的那一端，该端为空时定位到另一端的日期。窄屏可翻页查看其他月份。
- 日期时间首次编辑时，时间保持空白，由用户填写。编辑已有值时保留已选时间。换日后如果原时间超出当天可选范围，提示用户重新选择时间。
- 快捷区间按业务选配。用「最近 7 天」「本月」这类能看懂的短语，按使用频率排序。没有可用快捷项时，收起整块区域。
- 点快捷项按同一套可选规则更新完整区间，并回显起止日期。说明容易有歧义的统计口径。例如，若「最近 7 天」含今天，范围是今天和向前 6 个日历日。查询页面原有的「应用」仍负责执行查询。

## 6. 状态 State

触发器的常态、悬停、聚焦、只读、禁用、错误、警告沿用 [组件-Input输入框.md](组件-Input输入框.md) §5。面板打开时保留聚焦外观。只读可以复制值，日历与清除动作隐藏。禁用时整组停止交互。

| 日历状态 | 画法 |
|---|---|
| 默认 | 当月日期用正文色。相邻月份的补位日期降一级文字色，可选时仍能点选 |
| 悬停 | 普通可选日期用浅灰底。触屏按下时给反馈，松手后恢复 |
| 键盘焦点 | 用 2px 描边标出当前焦点。聚焦在已选日期上时，两种标记同时可辨认 |
| 今天 | 日期数字下方加 4px 品牌色圆点。今天处于已选范围时保留圆点 |
| 单日已选 / 范围端点 | 品牌浅底、1px 品牌色描边。起始日右侧、结束日左侧的圆角为 0，与区间色带贴齐。其余圆角为 6px。单日和起止同一天时，四角均为 6px |
| 范围内 | 在日期所属的月份面板内绘制端点和连续的浅品牌色带，色带在周行和月末断开。等待第二次点选时，预览也遵循这条规则。预览色带在哪一侧，已点日期那一侧的圆角就设为 0 |
| 单边范围 | 具体日期画端点，朝不限方向铺浅品牌色带，覆盖各月份面板内属于当月的相应日期。两端均可打开日历点选或直接输入 |
| 不可选日期 | 用禁用文字色，点击和回车均不选中。可选范围有明确限制时，在字段旁说明原因 |

## 7. 交互 Interaction

### 7.1 点选与关闭

- 从日历重选普通范围时，第一次点选标记新端点，并提示「选择另一个日期」。两端选完后按日期先后回显。只改某一端时，可直接编辑对应的输入区。
- 日历里限制无法组成有效范围的第二个端点，并给出限制说明。第一个端点仍保留，用户可继续选择。
- 普通范围只选了一端，或日期时间还没点「确定」时，点外部或按 Esc 收起面板，保留上次已选值。日期时间也可以点「取消」。再次打开时从已选值开始。
- 清除沿用输入框的默认规则，筛选字段默认提供，正式表单按需启用。范围清除一次清空两端。清除后焦点留在字段内，方便重新选择。

### 7.2 输入与校验

- 允许键入或粘贴日期。按 Enter 或离开整个字段时检查输入，合法值按 §5.1 的格式回显。范围在两个输入区之间切换时继续编辑。普通范围需填好两端，单边范围允许留空一端。
- 从手输切换到日历时先校验。输入有效时用该日期定位日历，输入有误时保留原文并从上次选好的日期打开。
- 保留输入错误的原文，并在字段下说明怎么改，例如「请输入有效日期，例如 2026-11-10」或「结束日期不能早于开始日期」。手输范围按输入区的顺序校验，用户可以直接改对应的一端。
- 日历、手输和快捷区间使用同一组边界和可选规则。业务可限制最早、最晚日期，以及允许的跨度。规则针对整个区间时，检查中间日期是否满足限制。

### 7.3 键盘操作

- 聚焦输入框后，按向下键进入日历。日历从已选日期、今天或最近可选日期开始聚焦，翻页和移动焦点时保留已选值。
- 方向键在网格内按天或周移动，Page Up / Page Down 切换月份，Enter / 空格选择焦点所在的日期。Tab 在月份导航、日期网格和面板操作之间移动，日期网格只占一个 Tab 停靠点。
- 完成点选、按 Esc 或点「取消」关闭面板后，焦点回到打开面板的控件。Tab 或点击移到面板外时，让焦点留在用户去往的位置。

## 8. 移动端适配

- 手机档用单月面板，范围跨月通过翻页完成。保持浮层贴近字段，按可用空间翻转。面板超过可用高度时，内容区可滚动，日期时间的底部操作保持可达。
- 触屏日期格的热区至少 44 × 44px，七列热区彼此不重叠。窄屏先减小面板内边距，优先保证七列共 308px 的可点宽度。内容区仍不足 308px 时，只在网格内横向滚动，避免挤小热区。
- 轻点输入框打开日历。需要手输时，在日历中点「输入日期」，再调出键盘。普通范围选完两端后回显，单边范围点选一端后即可回显。
- 其他热区与断点规则见 [基础-多端适配原则.md](基础-多端适配原则.md)。

## 9. 深浅色

- 字段、浮层、范围色带和品牌标记用现有设计变量，随深浅色和品牌主题切换。深色下面板加 1px 基础描边，见 [基础-圆角与阴影规范.mdx](基础-圆角与阴影规范.mdx) §2。
- 在两种模式下同时检查今天的圆点、端点描边、范围预览和键盘焦点。几种状态重合时，仍能分清今天、已选日期和当前焦点。

## 给实现窗口

- `@bisheng/ui` 从 `src/frontend/packages/ui/src/index.ts` 导出 `DatePicker`。组件位于 `src/frontend/packages/ui/src/components/DatePicker/`，使用已有的 `react-day-picker` 日历、输入框外壳和 Select 浮层。示例位于 `src/frontend/packages/ui/docs/components/date-picker.mdx`。
- 面板色取 `bg-bg-page`、`shadow-popup`，深色描边取 `border-border-base`。范围填充取 `bg-blue-50`，端点取 `bg-blue-100`、`border-blue-500`、`text-text-1`，普通文字取 `text-text-1`，跨月文字取 `text-text-2`，禁用文字取 `text-text-4`。焦点描边用 2px 的当前文字色，和端点描边留 1px 间隔。
- 将已提交值、手输原文、面板暂选和当前浏览月份分开。普通范围只有一个端点时继续暂存。面板翻页、悬停预览、键盘移焦均不发送值变更。取消面板时丢弃面板暂选。手输非法时保留原文并向表单暴露错误，防止表单把旧有效值当成本次输入提交。
- 组件值使用 `YYYY-MM-DD` 日期、起止日期元组，或 `YYYY-MM-DD HH:mm[:ss]` 的当地日期时间。时区指定「今天」的计算及界面提示，业务侧处理到实际时刻的转换和业务时区校验。按日筛选时包含结束日，业务可用业务时区下的次日零点作不包含的结束边界。
- 单边范围使用 `mode="range" allowOpenRange`，值类型为 `DatePickerOpenRange`。形如 `[date, null]` 表示无结束日期，`[null, date]` 表示无开始日期。整值 `null` 表示清空。日历点选更新打开日历的那一端，另一端沿用当前值。用 `DatePickerOpenRangeLocale.unlimited` 为有效单边范围的空端提供占位文案，字段值仍为空。
- `minDate`、`maxDate` 和 `isDateDisabled` 校验具体端点，`isRangeDisabled` 接收含 `null` 的完整范围并校验业务约束。`maxRangeDays` 为有限跨度限制，设置后单边范围不可选。旧的有限范围仍使用 `DatePickerRange`。
- 两个范围输入区分别提供无障碍名称。为输入格式与错误建立可读关联，输入区声明可展开的日历面板，月份切换时播报新年月。禁用日期需读出状态，键盘焦点与实际选中分开。
