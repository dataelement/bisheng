## 本轮用户补充的专项核对

未配置地址的正常使用覆盖：发现、授权链接与批准、换票/续期、Chat、个人资料与会话、Work 工具/技能、MCP。地址解析仅服务于需要 origin 的环节，其余路径继续使用原有运行时与业务准入；不能新增「必须填写部署地址」的替代门槛。可信代理列表由默认部署接线提供，并非另一个必须手填的对外地址。
