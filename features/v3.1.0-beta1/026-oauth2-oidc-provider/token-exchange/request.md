# 同一用户跨系统换证需求来源

用户要求毕昇支持 token exchange，以 A 的身份凭证获得供 B 登录使用的凭证；本轮明确选择“1：同一个人在两个系统登录”，用户和租户不变。此前已明确：由毕昇签发、B 信任毕昇；输入是毕昇 OAuth Access Token；首版由可信 confidential 服务端发起；B 可本地验签并接受短期撤销延迟。

尚未确认实现规格或技术设计。本轮把原草案中没有可测上界、调用方绑定与权限边界等问题补齐后提交评审。300秒最大寿命、必须显式指定scope、策略管理入口及本地验签撤销语义是本轮待确认的具体化方案，并非已经实现的能力。

ApiCredential 的随机密钥/哈希存储/5秒撤销约束继续保留。F026 OAuth 临时登录断言与 ApiCredential 的契约边界需在本次规格确认中明确，不得用换证结果绕过既有开放API鉴权。
