# 组织与成员搜索及设置调整

关联需求：本聊天中的三张 UI 截图、用户确认的方案及后续修订。用户明确不需要另出 PRD，并授权按方案实现。

## 验收标准

| ID | 行为 |
| --- | --- |
| AC-01 | 左侧统一搜索框按部门名、成员列表展示名称进行包含匹配，不匹配人员或部门 ID。输入约 300ms 后查询，中文选字期间不发查询，旧响应不得覆盖新结果。 |
| AC-02 | 搜索覆盖当前管理视图与组织树相同的可见范围；成员任一所属部门可见即参与搜索，每人只出现一次，停用成员可被搜到。 |
| AC-03 | 成员优先定位可见主部门，否则优先当前选中兼职部门，再按组织树顺序选择一个可见兼职部门。结果右侧仅显示“部门名称（兼职部门）”，不返回不可见主部门名称或路径。 |
| AC-04 | 结果分成员、部门两组，独立分页加载；部门显示从可见根到直属上级的完整路径，不含自身，长路径换行。 |
| AC-05 | 清空、删空文字恢复原树及选中项；搜索期间右侧保持原部门。选择成功后清空搜索；失败保留结果。 |
| AC-06 | 点击部门展开沿途上级及目标部门，选中并滚动到可见位置，右侧显示第一页。 |
| AC-07 | 点击成员选择结果中显示的部门，自动翻到目标成员所在页、滚动并高亮约 5 秒；只调整遮挡成员的所属关系筛选并提示。 |
| AC-08 | 组织页移除设置与流量控制页签，展示成员列表与部门设置、创建部门、添加成员按钮；保留所属关系筛选。 |
| AC-09 | 部门设置在弹窗内展示基本设置与有权限时的流量控制，切页保留修改；统一保存、取消、关闭时保护未保存修改，部分成功不得提示全部成功。 |
| AC-10 | 保留归档、恢复、彻底删除和子租户操作及既有权限；归档后选中可见上级或根。显示已归档开关同时作用于树与搜索。 |
| AC-11 | 选中目标已调走、删除或权限变化时由服务端重新验证，失败时展示错误；切换管理视图时沿用请求层的清空/重载机制。 |

## 范围

只修改管理端组织与成员入口及配套部门只读搜索/定位接口；原人员选择器、授权、流量计算、归档和彻底删除的业务规则保持原有归属。不新增“包含下级成员”的管理能力；直属成员范围按原接口展示。
