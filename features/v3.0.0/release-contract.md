## DSH 本地接入发布约束（main / work-110）

- Python DSH 模块持有授权请求、会话与凭证真相，运行时无 Gateway 依赖。
- 无商业 License、人数或分配席位准入；平台身份、租户和模型权限继续有效。
- 个人模型额度优先，无个人配置继承部门；部门每位成员独立计量。
- 用量、UNKNOWN、模型审计及历史证据不因认证迁移清零或删除。
- 旧桌面路径由 Python 本地兼容；旧 Gateway 会话重新登录，不远程兜底。
