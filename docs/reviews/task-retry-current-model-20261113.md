# 聊天内任务模式重试使用当前模型

日期：2026-11-13。目标分支：`feat/3.1.0-beta1`。

原行为：失败卡片重试只发送任务 ID 和原问题，Worker 继续读取原任务模型，忽略用户在聊天输入区的新选择。

修复：点击重试时读取现有模型选择状态，向 `/api/v1/linsight/workbench/continue` 添加可选的非空字符串 `model`。后端保留任务所有者与终态检查，将模型与运行状态一起保存，然后入队；入队失败恢复原模型和原终态。Worker 沿原模型解析、租户隔离和调用权限链路执行，不更换任务 ID 或上下文。普通追问及不携带模型的旧客户端沿用原选择；当前没有选中模型时也保留原选择。

代码审查：本次新增参数兼容原请求；无数据库结构、新状态库或权限绕过。历史恢复映射行为保持，管理 hook 中的废弃注释代码已移除以满足单文件 600 行限制。

验证覆盖：切换模型后的真实请求载荷、普通追问、不选模型、重复点击、分享页只读、状态恢复、HTTP 参数校验、入队前保存模型、入队失败回滚以及其他用户/运行中任务拒绝修改。未部署到 116。

验证结果：前端 31 项、后端 19 项相关回归通过；前端工作区 lint、typecheck、后端 Ruff 与 diff 空白检查通过。

本机 Jest 的可选 `canvas` 包缺少原生二进制，使用仅作用于测试进程的临时加载器让 jsdom 按未安装 canvas 处理；未修改依赖。相关旧测试补齐 SSE/界面 barrel 的 mock，避免被无关 ESM 模块阻断。
