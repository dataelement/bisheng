# 日常/任务模式验收清单

状态：待测试环境更新前后端后执行。本次未部署、未操作共享环境数据。

- [ ] 日常与任务分别触发模型连接、超时、认证、限流：显示 PRD 固定主提示，组件/模型、时间、定位编号相邻；现有恢复按钮可用。
- [ ] 检索两个知识库，其中一个依赖失败：保留另一知识库结果、引用与答案；刷新后失败编号及来源一致。
- [ ] 数据库/Redis/ES/Milvus、MinIO、Embedding/Rerank 的失败按真实依赖分类；供应方内部数据库报错仍属模型服务。
- [ ] 文件解析失败保留正常附件和已有业务提示；实际存储/模型故障显示对应类别；普通无命中、格式/权限/资源错误不强归五类。
- [ ] 部门并发、平台额度、文件夹上传限制仍显示原业务提示；获得任务版本前失败也能在当前页面看见。
- [ ] 浏览器断网/流中断只报一次网络错误；明确 HTTP/服务错误不改判网络或单点登录；主动停止不报网络错。
- [ ] 任务启动响应丢失、WS 断开后按已有版本恢复，不重新提交；切换到其他会话时，原任务失败仍被记录。
- [ ] 同一失败实时/历史使用相同编号、时间、分类；保留部分答案、附件、引用及恢复身份。
- [ ] 知识检索运行/结束/刷新均有中文前缀及已授权名称；空参数补齐一次、并行子任务不串名，同名/重复调用不去重计数。
- [ ] 长名称两行，展开可读全名；手机可见知识检索和失败步骤；个人库、旧记录及不可信元数据使用通用名称。
- [ ] 分享/他人只读的 API 响应无原始凭据、地址、错误堆栈；未授权名称被裁剪，个人库不出现真实标题。
- [ ] 中文、英文、日文一致；正常问答、原重试/降级、限流恢复、历史/分享无回归。
