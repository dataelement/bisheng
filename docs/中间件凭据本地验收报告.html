4. 发现与修复

问题复现及影响修复与复检
P0 · MySQL 特殊字符初始化失败CR MySQL 8.0.43 vendor 脚本直接将含单引号密码插入 SQL，报 1064 后留下部分数据；TCP 不可用，未设密码的 root socket 仍可连接。应用启动被阻止。新增安全 bootstrap/CNF 序列化 wrapper，保留 vendor 生命周期及 mysql 用户降权；Compose 显式 mysqld。相同密码新装成功、正确 TCP 通过、无密码 socket 拒绝。5 项单测及真实组合复检。
P1 · 缓存清理关闭全局 DB 上下文真实迁移已提交 DB，清理缓存时关闭全局上下文，导致后续读取抛 ContextStateError；恢复 Redis 后仍不能完成迁移。使用独立 RedisClient，只关闭自身；成功/失败两项红到绿。保留同一迁移现场，更新配套镜像后原命令续跑，主 key 与数据幂等性复检通过。
P1 · 维护工具重复挂载输入清单和输出包共用父目录时，Docker 报 Duplicate mount point；账号尚未改密。同目标合并一个挂载，显式输出父目录保留写权限，其余只读；两种参数顺序回归，真实五组件准备和回退包生成成功。

测试侧同时修正 SDK 实际抛出的 gRPC 认证异常断言，以及登录标识、验证码和“移除 URL 密码”的夹具用法；没有降低认证断言、关闭认证或扩大产品改动来制造通过。
