## 保存链路根因修复（本轮）

- 运行版 `d939732d6` 中，用户 4、5 对模型 5 的操作已提交 SQL，恢复任务持续返回 `policy_sync_pending`。用户直接授权版本与部门/角色合成版本共用 Redis 字段，触发 `version_conflict`。
- 同步协议分开直接授权修订号和有效权限指纹。操作所有权、租约与幂等校验使用直接修订号；运行时模型可见性和额度使用全部有效授权来源的计算结果。恢复缓存时保留 SQL 和现存 Redis 用量证据，通过协议标记迁移旧缓存。
- 原操作沿用原 ID 和提交记录恢复。保存后的额度继续采用有效来源的最大值，开关、零额度、部门/角色继承及席位规则保持原样。
- 前端写入和结果读取有 10 秒等待上限；操作查询有 10 秒前台等待窗口。超时显示待确认，解除弹窗导航保护，保留原操作查询入口；确认结果后恢复编辑。
