## 六、遇到问题时如何区分

| 现象 | 优先核对 |
| --- | --- |
| 管理页打不开或一直加载 | 公网地址及端口是否可达，页面脚本、样式请求是否成功。 |
| 进入登录页但没有自动跳昆联 | 当前 SSO 尚未调通，先用本文测试账号在账号密码登录页登录；后续再核对 SSO 配置及回调。 |
| 登录后提示目录未就绪 | 当前用户的目录和租户绑定是否已就绪；补同步完成后重新登录。 |
| 列表为空或没有新建入口 | 当前租户、对象查看权及创建权限是否符合测试范围。 |
| 能查看但不能编辑、发布或运行 | 分别核对编辑、发布／下线和使用权限，以及工作流上线状态。 |
| 地址变成内网 IP 或本机地址 | 对外站点、前端使用端地址及网关回跳配置是否仍引用旧地址。 |
| 页面可打开但运行没有响应 | 工作流是否上线、账号是否有使用权、WebSocket 是否连接成功及是否返回业务错误。 |

本说明中的“页面可访问”为公网 HTTP 检查结果；账号操作、真实 SSO、权限矩阵和实际运行仍需按上述场景联合验证。
