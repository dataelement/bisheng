# 表格 Table

> 设计系统 · 表格 v0.2 草稿 · 2026-11-10
> 适用：BISHENG 管理端与使用端的结构化数据表格。不含电子表格编辑器、文档里的表格预览。
> 配套：[基础-字体规范.mdx](基础-字体规范.mdx)、[基础-色彩规范.mdx](基础-色彩规范.mdx)、[组件-Pagination分页.md](组件-Pagination分页.md)。调研和待决策项见文末内部区。
> 设计师指定以 client 知识空间的桌面文件列表为外观基准。参考实现与规范取舍见「给实现窗口」。

**草稿**。表格和文件列表共用浅斑马纹、行高和选中样式。需要逐列比较时用分栏表格，主要按名称找记录时用文件列表的排法。

## 1. 什么时候用

每行放一条记录。用户要按同一字段比较多条记录时，把字段排成列。主要按名称查找、预览或处理记录时，把相关信息排在名称下面。

| ✅ 推荐 | ❌ 不推荐 | 原因 |
|---|---|---|
| 按成员对比部门、角色和状态，用表格 | 把每个成员做成一张大卡片 | 同类字段对齐后，可以顺着一列比较 |
| 在知识空间按文件名找文件，把日期和标签排在名称下方 | 把日期和每种标签都拆成独立的列 | 主要任务是认出文件，辅助信息放一起更好扫读 |
| 浏览应用封面和简介，用卡片 | 把不同长度的应用简介塞进表格 | 用户主要在浏览内容，长短不一的简介会打断逐行扫读 |
| 查看一个应用的配置详情，用字段列表 | 把一个应用的每个字段拆成表格的一行 | 只有一个对象时，重点是读懂它，而不是对比多条记录 |

## 2. 类型与结构

| 排法 | 什么时候用 | 从上到下 |
|---|---|---|
| **分栏表格** | 逐列比较或管理记录，如成员管理、运行日志 | 按需加工具栏 → 列标题 → 数据行 → 按需加分页 |
| **文件列表** | 按名称定位后查看、预览或处理，如知识空间文件 | 浅灰工具栏 → 数据行 → 按需加列表尾部加载 |

- **用浅灰顶栏和浅斑马纹。** 数据行从容器底色开始，与浅灰底逐行交替，底色铺满行宽。用底色区分相邻行，行面平铺，省去横竖网格线、行间留缝和行圆角。
- **按任务放置顶栏。** 分栏表格用浅灰列标题说明每列含义，查询和筛选放在列标题上方。文件列表用一条浅灰工具栏作为顶部区域，左侧放全选，右侧按需放搜索、筛选、排序和视图切换。
- **让名称靠前、操作靠右。** 分栏表格依次放勾选列、主要识别列、其他数据列、操作列。文件列表从左到右放勾选框、图标、名称和辅助信息、状态、操作。按任务决定是否提供勾选和行内操作。
- **让列标题跟随数据行横向滚动。** 当分栏表格有独立的纵向滚动区，且用户需要持续对照列名时，固定列标题。横向溢出时按需固定左侧识别列，勾选列与它一起固定。

分栏表格需要分页时，使用 [组件-Pagination分页.md](组件-Pagination分页.md)。文件列表需要滚动续载时，使用 [组件-Loading加载.md](组件-Loading加载.md) 的列表尾部加载。

## 3. 尺寸 Size

桌面以 **56px 数据行**为基准。名称可带一行辅助信息，用户放大文字时，允许数据行和顶栏随内容增高。

| 部位 | 基准值 |
|---|---|
| 浅灰顶栏 | 最小高度 44px。文件列表的工具栏与数据行左右对齐 |
| 数据行 | 最小高度 56px。行首和行尾默认各留 16px，嵌入式面板可收至 8px，同一容器内保持一致 |
| 文件列表的行内间距 | 勾选框、图标、文本区、状态和操作相邻间距 8px。图标 32 × 32px，勾选框 16 × 16px |
| 名称与辅助信息 | 名称 14 / 22px，辅助信息 12 / 20px，上下间隔 2px |
| 行末图标按钮 | 32 × 32px，使用中档文字按钮。保留操作区宽度，让各行状态与操作位置对齐 |

分栏表格的列标题用 500 字重，数据用 400 字重，默认字号 14px、行高 22px。启用分页时默认配中档。按钮的其他规则见 [组件-Button按钮.md](组件-Button按钮.md)。

## 4. 内容形态

### 4.1 表头与对齐

- **用短名词写列名。** 写「文件名」「更新时间」「大小」，不加句号。单位全列一致时放在表头，如「耗时（ms）」。
- **列名跟本列内容对齐。** 文本、日期、编号和状态左对齐，可比较的数值右对齐并使用等宽数字。勾选列居中，操作列右对齐。编号即使由数字组成，也按识别文本处理。
- **给主要识别列留弹性宽度。** 先给勾选、日期、状态和操作分配足以容纳内容的列宽，剩余空间给名称等识别字段。在列宽不足时滚动表格区域，不撑宽整页。

### 4.2 单元格

| 内容 | 怎么放 |
|---|---|
| 名称、路径和长文字 | 默认单行，超长显示省略号。需要辨认文件后缀时保留结尾。完整值可从详情或可聚焦、可点开的入口查看 |
| 文件列表的辅助信息 | 放在名称下一行，先日期、再标签。两组都存在时用短竖线隔开。参与比较的字段在分栏表格中单独成列 |
| 日期、时间、状态、行内操作 | 保持单行。同一时间列统一格式；跨时区会影响判断时，在列名或说明中标明时区 |
| 数值 | 同列统一单位和小数位；保留有意义的 `0`，不要用占位符替代它 |
| 空值 | 用「—」表示没有值；「未设置」「不适用」会影响判断时直接写出含义 |
| 状态 | 用文字说清楚「可用」「停用」等含义；需要快速识别时用 [组件-Tag标签.md](组件-Tag标签.md)，颜色只做辅助 |
| 操作 | 每行最多露出 2 个入口，含「⋯」。常用动作常驻，其余放 [组件-Dropdown下拉菜单.md](组件-Dropdown下拉菜单.md)；危险操作依照 [组件-Confirm二次确认.md](组件-Confirm二次确认.md) |

| ✅ 推荐 | ❌ 不推荐 | 原因 |
|---|---|---|
| 「失败次数」列把 `0` 显示为 `0`，缺值显示「—」 | `0` 和缺值都显示「—」 | 没发生和没有记录是两件事 |
| 文件名截断后，可以点开详情看全名 | 只能悬停才知道两个相似文件名的区别 | 键盘和触屏用户也要能认出文件 |
| 名称打开详情，勾选框负责选择 | 点行有时打开详情，有时选中 | 不会因为想查看记录而误选 |

## 5. 状态与交互

### 5.1 排序与筛选

- **分栏表格在列标题上排序，文件列表在工具栏上排序。** 可排序的列标题依次切换首选方向、反方向和默认顺序。文件列表把名称、更新时间等字段集中在「排序」菜单，再次选择同一字段时切换方向。两种排法都一次只按一个字段排序，用箭头标明当前方向。
- **把查询和筛选放在数据上方，已生效条件持续可见。** 多个条件同时生效时提供「清空筛选」。查询、筛选和排序作用于符合当前范围的全部记录。已分页时，条件变化后回到第 1 页。分页规则见 [组件-Pagination分页.md](组件-Pagination分页.md)。

### 5.2 勾选与批量操作

- **明确区分选择与打开。** 分栏表格用复选框选择。桌面文件列表也可点击行内空白切换选择，点名称打开或预览，行内按钮和菜单执行各自的动作。不可选的记录保留禁用复选框，让各行对齐。
- **让全选范围和当前界面一致。** 分页时只选当前页可选记录，滚动续载时只选当前已加载且显示的可选记录。部分选中用半选，范围内没有可选记录时禁用。样式与键盘操作见 [组件-Checkbox复选框.md](组件-Checkbox复选框.md)。
- **用勾选标记和浅主题底同时反馈。** 有勾选时在顶部操作区显示「已选 N 项」、批量动作和「取消选择」。切页、排序或更改查询条件后，在新的结果展示时清空勾选。等待期间暂停对旧结果的行内和批量操作。

### 5.3 行和表体状态

| 状态 | 怎么显示 |
|---|---|
| 常态 | 第一行用容器底色，第二行用浅灰底，依次交替 |
| 悬停 | 有行级交互的行用中性浅灰底覆盖斑马纹。整行可以点击时，整行使用手形光标。只有控件可以点击时，光标只在控件上变化 |
| 已勾选 | 浅主题底覆盖斑马纹，勾选标记常驻。悬停时保留选中底色 |
| 键盘聚焦 | 在当前控件上显示焦点；鼠标移开不影响键盘焦点 |
| 加载 | 采用 [组件-Loading加载.md](组件-Loading加载.md) 的区域加载。换页、筛选或排序时保留上一批结果作为过渡，成功后再替换 |
| 无数据 | 在表体跨列显示「还没有文件」等与对象有关的说明；保留表头、工具栏和已启用的分页 |
| 无匹配结果 | 在表体说明「没有找到匹配的文件」；保留查询条件，在工具栏提供改条件或清空的入口 |
| 加载失败 | 在表体或所属内容区显示服务异常，给出重试入口。狭窄表体只放提示时，把「重试」放到工具栏 |

无数据、无匹配结果与加载失败的样式和文案见 [组件-State状态页.md](组件-State状态页.md)。

### 5.4 键盘与读屏

- **让读屏能读出表名、列名和排序方向。** 分栏表格的列名要和数据对应。文件列表要能读出记录名称、复选框状态以及排序菜单的当前字段和方向。
- **让 Tab 只经过实际可操作的控件。** 用户能用键盘排序、勾选、打开详情、使用更多菜单和横向滚动。操作按钮的读屏名称要带对象，如「更多操作：项目交接文档」。
- **更新结果后保留用户的操作位置。** 筛选后焦点留在筛选入口，排序后留在当前列的排序按钮。删除后原按钮消失时，焦点移到下一条记录的对应入口；没有下一条时回到表格工具栏或表标题。

## 6. 移动端适配

屏宽和触屏分别按 [基础-多端适配原则.md](基础-多端适配原则.md) 判断。

| 场景 | 做法 |
|---|---|
| 手机档，主要任务是查找后查看详情 | 用平铺列表保留名称和必要的辅助信息，把次要字段放进详情。知识空间文件列表在左侧放图标、右侧放勾选框 |
| 手机档，任务需要逐列比较 | 保留比较所需的列，只在表格区域横向滚动。首屏留出可见的数据列；如果固定列挡住全部数据列，就解除固定 |
| 手机档，表格含行内操作 | 操作列最多保留 1 个入口。多项动作收进常驻的「⋯」，不要靠悬停显示 |
| 触屏（含平板） | 操作热区沿用多端通则，彼此不重叠。热区需要更多空间时增加行高，全文入口通过点按打开 |

滚动条随系统设置，见 [基础-滚动条规范.md](基础-滚动条规范.md)。分页按 [组件-Pagination分页.md](组件-Pagination分页.md) 在手机档切为简洁型。

## 7. 深浅色

顶栏、斑马纹、文字和选中态沿用 [基础-色彩规范.mdx](基础-色彩规范.mdx) 的设计变量。深色下用相邻的两档深色铺出斑马纹，选中底色跟随品牌。固定列用与所在行一致的不透明底色盖住滚动内容，固定列标题也使用不透明底色。

### 样式映射提案

| 部位或状态 | 实现取值 |
|---|---|
| 顶栏和奇数行 | 顶栏用 `fill-1`，奇数行用容器底色。页面默认容器底色为 `bg-page` |
| 偶数行 | 用 60% 不透明度的 `fill-1` 覆盖同一容器底色。默认浅色约为 `#fbfbfb`，深色沿用同一比例 |
| 悬停和选中 | 悬停用 `fill-2`，选中用 7% 不透明度的 `brand-500` 覆盖容器底色。选中优先于悬停和斑马纹，整行只应用一次底色 |
| 固定列和固定列标题 | 采用所在行的最终不透明底色，滚动内容不透出 |
| 字体和颜色 | 主文字用 `text-body`、`text-1`，辅助信息用 `text-caption`、`text-2`。采用 12 / 20px 作为通用辅助字阶，并提高小字在斑马纹和选中底上的对比度。数值列用 `tabular-nums` |
| 键盘焦点 | 沿用共享控件的焦点样式。文件列表的名称入口支持键盘聚焦与激活 |

语义变量见 `src/frontend/packages/ui/src/styles/tokens.css` 和 `src/frontend/packages/ui/tailwind-preset.cjs`。以知识空间做文件列表示例，以组织成员页验证分栏表格。文件列表中的业务专属拖拽、行内重命名和右键菜单单独评估。

### 实现边界

分栏表格保留原生 `<table>`、`<th scope="col">` 与可读名称。排序列用按钮，当前排序列头才设 `aria-sort`。文件列表使用列表语义。行以稳定记录 ID 标识。组件接收记录、列定义、显示状态、界面文案和事件回调。业务负责请求、权限、排序与筛选的数据范围以及批量结果。迁移时保留各页面已有的调节列宽、滚动取数等行为。参见 [W3C 可排序表格示例](https://www.w3.org/WAI/ARIA/apg/patterns/table/examples/sortable-table/)。
