# Feature: 通用图像生成工具

**关联需求**：本会话中用户提出“将 image_generation 绘图重构成为通用 image_generation 工具，支持替换 provider 和模型”，并于 2026-11-09 确认 [需求发现范围](./discovery.md)。无单独 PRD。
**所属版本**：本地草稿，正式版本与编号待分配；未改动发布契约。
**依赖**：现有预置工具配置、工具调用、聊天图片展示和文件存储能力。
**状态**：规格自查完成，用户已于 2026-11-09 确认，并明确去掉 Azure、参考 DSH 简化；设计及实现状态见 [tasks.md](./tasks.md)。

## 1. 用户故事

作为工具管理员，我希望选择图像生成服务和模型，以便替换服务商或升级模型时，不必修改应用。

作为应用使用者，我希望沿用原有提示词生成并查看图片，以便现有应用在工具重构后继续使用。

## 2. 范围

本次纳入：

- 通用图像生成工具名称与设置；只支持 OpenAI Images 兼容服务。
- 管理员通过配置服务地址、凭据和模型切换 provider，无须区分接口协议。
- 文字生成图片，兼容服务返回图片 URL 或 Base64 图片。
- 历史工具引用、配置与提示词输入的兼容。

本次排除：

- 图片编辑、局部重绘、多轮图片对话及视频生成。
- Azure、Responses 图片工具、Gemini 原生接口、厂商异步任务及 ComfyUI 工作流。
- 自动选择模型、自动切换备用 provider、负载均衡及模型能力目录。
- 新建模型管理、凭据管理、文件存储或权限体系；本次不扩大既有授权范围。

## 3. 验收标准

- **AC-01 通用入口** — WHEN 用户查看或配置本工具，THE SYSTEM SHALL 使用“图像生成”这一通用显示名称；新增能力标识为 `image_generation`，不以 DALL·E 3 限定功能说明。
- **AC-02 OpenAI 兼容服务** — WHEN 管理员选择 OpenAI Images 兼容接口并保存服务地址、凭据和非空模型标识，THE SYSTEM SHALL 在后续新发起的生成任务中调用所选服务及模型；同一接口可通过修改服务地址连接其他兼容 provider。
- **AC-04 配置切换与保存** — WHEN 管理员修改服务或模型并成功保存后重新打开设置，THE SYSTEM SHALL 显示已保存的选择；切换服务后不得被遗留配置改变实际调用目标。IF 保存失败，THEN THE SYSTEM SHALL 保留当前编辑内容并显示失败，不显示保存成功。
- **AC-05 必填校验** — IF 所需配置缺失、使用已不支持的接口或服务地址格式无效，THEN THE SYSTEM SHALL 拒绝保存并指出无效配置；不得自动调用其他服务或模型。保留的有效历史配置适用 AC-07 的默认兼容行为。
- **AC-06 旧应用引用兼容** — WHEN 现有应用仍引用 `dalle_image_generator` 并提交原有 `query` 提示词，THE SYSTEM SHALL 继续执行图像生成；管理员和应用作者无需删除或重新添加工具。新能力也接受相同的提示词输入。
- **AC-07 旧配置兼容** — WHEN 加载未显式指定接口类型或模型的历史配置，THE SYSTEM SHALL 保留原调用语义：历史 OpenAI 配置未指定模型时继续使用 `dall-e-3`。历史 Azure 配置须明确提示已不支持、需要重新配置，不得静默把原凭据发给其他服务。升级与打开设置本身不得改写旧配置或清空凭据。
- **AC-08 URL 图片结果** — WHEN 服务成功返回有效的 HTTP(S) 图片 URL，THE SYSTEM SHALL 将对应图片交付给当前调用并能在现有聊天中展示，不只返回成功文案。
- **AC-09 Base64 图片结果** — WHEN 服务成功返回有效的 Base64 图片，THE SYSTEM SHALL 将其转为当前调用可展示的图片结果；不得将整段 Base64 作为工具文本或模型上下文输出。IF 图片解析或保存失败，THEN THE SYSTEM SHALL 将本次生成标记为失败。
- **AC-10 不绑定 DALL·E 参数** — WHEN 使用非 DALL·E 图片模型，THE SYSTEM SHALL 不强制附带该接口或模型未要求的 DALL·E 专属参数；只需基本生成参数即可工作的兼容模型应可执行。
- **AC-11 失败可见** — IF 认证被拒、模型不可用、请求超时、服务报错或响应没有有效图片，THEN THE SYSTEM SHALL 返回明确的生成失败；不得用空图片或成功提示替代失败，也不得静默换服务、模型或返回格式再次生成。
- **AC-12 授权与凭据** — THE SYSTEM SHALL 延续既有工具设置和执行的授权范围。WHEN 无权用户尝试修改配置或调用工具，THE SYSTEM SHALL 拒绝操作；设置读取、日志、工具输出和可见错误不得暴露服务凭据。WHEN 仅修改模型或其他非凭据设置，THE SYSTEM SHALL 支持保留既有有效凭据，不要求重复录入。

AC-03（Azure 服务）已按用户 2026-11-09 的明确要求移除；保留其余 AC 编号以便追溯。

## 4. 边界情况

- 已发起任务继续按发起时选择的配置执行；配置修改影响后续新发起任务。
- 服务支持哪些模型及参数以该服务实际能力为准；本工具不承诺任意同名模型在不同服务之间等价，也不自动发现模型列表。
- 服务返回多张有效图片时，应保留这些图片结果，不静默只取第一张；本期不新增图片数量设置。
- 返回空图片列表、非图片内容、无效 URL 或无效 Base64 都属于生成失败；不得向用户展示损坏的图片链接作为成功结果。
- URL 图片的有效期受上游服务影响；本期不承诺上游链接永久有效。Base64 结果必须在当前调用中完成可展示图片的交付。
- provider/model 的修改仅作用于图像生成工具，不改变网页搜索或其他预置工具配置。
