# Feature: 知识模型配置收敛与旧溯源只读兼容

**关联 PRD**：[需求发现与用户确认范围](./discovery.md#用户已确认的业务范围)，来源为本次会话；2026-11-27 用户确认其他改动，并明确要求保留历史旧溯源功能。
**优先级**：P1
**所属版本**：v3.1.0 / F002
**状态**：规格审查通过，用户已确认（2026-11-27）。
**依赖**：既有系统模型配置、知识空间创建、统一引用展示及历史关键词溯源能力；不新增领域对象。

本次纳入：删除工作台向量模型与溯源生成模型设置；统一新建知识空间的默认 embedding；调整知识模型栏目及三语提示；停止新消息的旧式关键词溯源生成，保留历史旧溯源读取。

本次排除：已有知识空间模型批量切换或索引重建；历史会话引用转换；历史数据清理；新的权限、租户继承、QA 或计费机制。

## 1. 用户故事

作为管理员，我希望只在知识模型栏目设置新建知识空间的默认 embedding，以便默认模型来源一致，修改默认值不影响已有空间。

作为知识空间创建者，我希望系统采用管理员配置的默认 embedding，并允许我在创建时另选可用模型，以便按业务需要创建空间。

作为问答用户和有权查看会话的管理员，我希望新消息使用引用标记查看来源，同时历史消息中已有的旧溯源按钮仍能读取原数据，以便升级后继续查看历史依据。

## 2. 验收标准

### 2.1 模型配置与知识空间默认值

- **AC-01** — WHEN 管理员打开系统模型配置，THE SYSTEM SHALL 不再提供工作台向量模型和知识库溯源模型设置，保存其他配置不要求填写这两个已移除的设置。
- **AC-02** — WHEN 用户新建知识空间且未另选 embedding 模型，THE SYSTEM SHALL 在新建界面显示并在实际创建时采用知识模型栏目中对当前租户生效的默认 embedding。
- **AC-03** — WHEN 用户在新建知识空间时明确选择可用的 embedding 模型，THE SYSTEM SHALL 使用用户选择的模型；该选择不依赖已移除的工作台向量模型设置。
- **AC-04** — IF 新建空间时既未选择模型又无有效的默认 embedding，THEN THE SYSTEM SHALL 拒绝以缺失或不可用的模型完成创建，并返回可识别的配置缺失或模型不可用错误，不改用旧工作台配置或其他模型。
- **AC-05** — WHEN 管理员保存或修改知识模型默认 embedding 或其他系统模型配置，THE SYSTEM SHALL 保留已有知识空间的模型、索引与处理状态，不因保存默认配置发起已有空间的重建。
- **AC-06** — WHEN 已有空间的有权管理者主动更换空间模型或发起重建，THE SYSTEM SHALL 保持现有单空间功能及其准入约束。
- **AC-07** — WHERE 当前租户继承系统默认模型或使用被共享的模型，THE SYSTEM SHALL 沿用既有继承、共享、模型可用性及权限规则；模型配置和空间创建不得获取其他租户未授权的数据。

### 2.2 名称与提示

- **AC-08** — WHEN 用户以中文查看系统模型配置，THE SYSTEM SHALL 将“知识库模型”栏目显示为“知识模型”，本栏目原“文档知识库”的表述使用“知识空间”，并保留 QA 知识库的名称及业务含义。
- **AC-09** — WHEN 用户查看默认 embedding、摘要/标签、提示词或语音解析的相关提示，THE SYSTEM SHALL 按当前功能说明适用场景；默认 embedding 提示须说明其用于新建空间、创建时可另选模型，以及修改默认值不会重建已有空间。中文、英文和日文表达须一致。
- **AC-10** — WHEN 用户使用 QA 知识库或修改其相似问配置，THE SYSTEM SHALL 保持原有功能，不因本次配置收敛取消 QA 能力。

### 2.3 新消息与历史溯源兼容

- **AC-11** — WHEN 新版本生成问答消息，THE SYSTEM SHALL 停止生成旧格式关键词溯源数据，也不再为该生成过程调用溯源模型或执行分词回退。
- **AC-12** — WHEN 新版本展示新生成的消息，THE SYSTEM SHALL 不显示依赖旧关键词数据的文件溯源按钮；新引用标记、来源列表、文件预览和引用定位保持可用。
- **AC-13** — WHEN 有权用户打开历史消息中原有的旧溯源按钮或旧溯源页面，THE SYSTEM SHALL 继续使用原有数据提供关键词展示与调整、来源文件排序和文件定位，无需重新配置或调用溯源生成模型。
- **AC-14** — WHEN 系统升级并移除溯源生成模型配置，THE SYSTEM SHALL 保留历史消息和已有旧溯源数据，不删除旧读取功能、不补生成旧数据、不将历史会话批量转换为新引用格式。
- **AC-15** — IF 用户无权查看历史会话或其来源文件，THEN THE SYSTEM SHALL 沿用当前会话与来源文件访问约束，不因保留旧溯源读取而暴露关键词、文件或正文等未授权内容。
- **AC-16** — WHEN 系统读取或保存含有已移除模型设置的历史配置，THE SYSTEM SHALL 不将这些设置作为新建空间或关键词生成的有效模型选择，也不再将其视为实际模型使用的来源；已有空间等其他真实模型使用关系仍须保留。

## 3. 边界情况

- 知识默认 embedding 与历史工作台 embedding 不同：新建空间采用知识默认值，已有空间继续采用各自保存的模型。
- 新建界面显示默认值后，用户明确提交的模型按其选择处理；保存默认值不批量改写已经创建的空间。
- 默认模型缺失、删除、下线或共享失效：按实际模型和当前权限拒绝无效创建；用户仍可显式选择满足现有准入要求的模型。
- 历史消息同时具有新引用和旧溯源信息：保留两种既有查看能力；新生成消息只使用新引用来源查看。
- 历史旧溯源数据本身缺失或源文件已删除：沿用既有不可用处理，不临时调用模型或分词补造历史数据。
- 已有 QA 来源与链接来源的展示保持原语义；退出的是新数据的关键词文件溯源生成。
- 本次只调整相关系统模型配置文案，不扩大为全站术语替换。
