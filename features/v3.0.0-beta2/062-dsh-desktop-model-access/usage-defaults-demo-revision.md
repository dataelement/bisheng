## 验收口径

- 按部门默认显示整个租户的真实汇总，包含无部门用户；可选择具体部门及下级成员，清除选择后回到整个租户。
- 按用户优先选当前可见列表中的 admin，其次当前用户，最后第一名可见用户。切换日期和维度保留已有选择。
- 3006 专用构建开启历史演示数据，按 admin 实际成员关系汇入对应部门和整个租户；正式默认构建保持真实数据。
- 演示时间固定为 2024-09-16 至 2026-09-15 00:00（右开区间）。固定日期后新增真实数据保持原样；切换日期不会把新真实日期变为演示日期。
- 模拟事件按小时产生，任意时间范围、小时、日、部门汇总、用户明细的加总一致。
- 仅 API 已授权返回的租户与成员能显示演示用量。页面和悬停信息标记演示成分。
- 演示层只参与展示，通过构建参数 `VITE_DSH_USAGE_DEMO` 显式启用并绑定 origin、tenantId、userId、userName 和固定日期区间。保留真实数据库、Gateway、额度和席位。
- 所有新增文字同步中英日；保持 12px 无边框方格与 3px 间隔。
