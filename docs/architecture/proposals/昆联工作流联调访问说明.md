### 操作步骤

1. 打开工作流管理页，或从昆联已配置的「工作流管理」按钮进入；没有有效毕昇会话时自动跳转昆联。
2. 使用昆联交付的测试账号完成登录／授权，回到原管理页。已有正确租户的有效毕昇会话时直接进入列表。原本地管理员仍可通过上述账号密码登录页进入。
3. 页面仅展示当前租户下、当前账号有权查看的工作流，不展示所有租户或其他账号未授权的工作流。
4. 有创建权限的账号点击「新建工作流」，填写名称、描述并创建，随后进入编辑画布。
5. 点击已有工作流，具备编辑权限时进入画布；只有查看权限时进入只读详情。保存、发布和下线分别按实际授权处理。
6. 工作流上线后，具备使用权限的账号可进入毕昇使用端，在应用入口找到相应工作流并运行。

本轮已验证专属测试租户和指定账号。其他用户的授权、上游停用和运行场景需分别联调，不自动沿用测试账号权限。

## 六、遇到问题时如何区分

| 现象 | 优先核对 |
| --- | --- |
| 管理页打不开或一直加载 | 公网地址及端口是否可达，页面脚本、样式请求是否成功。 |
| 进入登录页但没有自动跳昆联 | 是否使用上述公网管理入口，是否存在前次授权失败或手动重试提示；再核对配置及回调错误。 |
| 登录后提示目录未就绪 | 当前用户的目录和租户绑定是否已就绪；补同步完成后重新登录。 |
| 列表为空或没有新建入口 | 当前租户、对象查看权及创建权限是否符合测试范围。 |
| 能查看但不能编辑、发布或运行 | 分别核对编辑、发布／下线和使用权限，以及工作流上线状态。 |
| 地址变成内网 IP 或本机地址 | 对外站点、前端使用端地址及网关回跳配置是否仍引用旧地址。 |
| 页面可打开但运行没有响应 | 工作流是否上线、账号是否有使用权、WebSocket 是否连接成功及是否返回业务错误。 |
