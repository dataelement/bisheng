## 3.1 对照布局

### AC-01: 点文档角标进入对照
- [ ] 打开会话 → 「已整理输出文件」点 report.md
- [ ] 点报告里任一蓝色角标
- [ ] 预期: 报告在左、来源 docx 在右并排，互不遮挡

### AC-02: 对话列收起与恢复（≥1024px）
- [ ] 进入对照后中间对话列不可见，两栏占满
- [ ] 点来源栏「收起来源」→ 对话列恢复原宽

### AC-03: 分隔线拖动与最小宽度
- [ ] 拖动分隔线向左 → 比例变化；拖到极限时左栏不小于 400px（≥1280）/ 360px（1024–1279）
- [ ] 刷新页面重新进入对照 → 比例保持

### AC-04: 对照中点另一个角标只替换右栏
- [ ] 对照中点另一份文件的角标 → 右栏换成那份文件，页面上没有新增浮层

### AC-05: 仅收起按钮 / Esc 关闭来源栏
- [ ] 点报告正文、滚动报告 → 来源栏不关闭
- [ ] 按 Esc → 只关来源栏，报告仍在

### AC-06: <1024px 分段切换
- [ ] 窗口缩到 1024 以下，点角标 → 出现「报告 / 来源」分段控制器，自动在「来源」
- [ ] 点「回到报告」→ 报告停在刚才那个角标附近

### AC-07: 对照 + 全屏
- [ ] 对照中点全屏 → 两栏铺满，当前引用与定位不变

### AC-19 / AC-20 / AC-21: 两级关闭
- [ ] AC-19: 点报告栏 ✕「关闭工作区」→ 报告与来源都关闭、对话列恢复；全屏中则同时退出全屏
- [ ] AC-20: 点报告栏 ←「返回文件列表」→ 来源栏关闭，显示文件列表
- [ ] AC-21: 「收起来源」与「关闭工作区」图标不同，悬停提示分别为「收起来源（Esc）」「关闭工作区」

## 3.2 定位与关联

### AC-08: PDF bbox 定位（需有 PDF 来源的会话）
- [ ] 点 PDF 来源角标 → 被引片段高亮并滚到可视区

### AC-09: docx 文本定位
- [ ] 点 docx 来源角标 → 右栏自动滚到被引段落，段落有浅蓝底 + 左侧竖线

### AC-10 / AC-11: 定位失败 / xlsx
- [ ] 来源定位不到或为 xlsx 时，右栏顶部出现「没能自动找到被引段落，下面是引用的原文」及原文
- 说明: 真实数据难以构造，匹配失败路径由 `citationLocate.test.ts` 覆盖

### AC-12: 当前引用标记
- [ ] 被点角标保持加深底色；来源段落保持高亮，直到切换或关闭

### AC-13 / AC-14: 同一文件的逐处切换
- [ ] 右栏显示「第 k 处，共 n 处」；点下一处 → 报告滚到下一个同文件角标并加深，右栏跳到对应段落
- [ ] 同一段被引两次时，点第二次出现的角标，加深的是第二个而不是第一个
- [ ] AC-14: 只被引用 1 次的文件不显示上一处 / 下一处

## 3.3 不变量

- [ ] AC-15: 点网页（紫色）角标 → 新标签页打开原网页，不进入对照
- [ ] AC-16: 无权限 / 已失效的角标 → 仍显示原有状态，不进入对照
- [ ] AC-17: 日常对话里的角标仍打开对话旁的引用面板，行为不变
- [ ] AC-18: 来源栏、分隔线没有 backdrop-filter
