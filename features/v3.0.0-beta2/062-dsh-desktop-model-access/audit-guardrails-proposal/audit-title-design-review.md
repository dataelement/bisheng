## 自审修正

1. 只随模型请求带标题会漏掉最后一次调用后的生成和改名，改为独立事件通道。
2. 标题唯一副本放可重建目录会随重建丢失，改为独立小表，已授权页批量读取；不查审计大表GROUP BY或LIKE，不因改名重建树。
3. 同一BASE/用户重新登录后的connectionKey可能相同，增加主进程epoch并在派发前后复核，不用旧任务携带新凭据。
4. 复核确认DshRoutes不是路由白名单；新路径不命中两个旧模型过滤规则，通用转发已支持，不新增Gateway代码。认证及既有席位检查仍由毕昇DSH入口执行。
5. 标题先于异步审计到达不创建伪会话，用NOT_READY有界重试；超时后可能已提交，用事件序号幂等，而不是报告确定未写入。
6. title.get可用但其内部可能折叠当前日志，不能在模型await链同步反复调用，不能宣称完全没有CPU开销；禁止新增直接使用弃用事件读取方法。
