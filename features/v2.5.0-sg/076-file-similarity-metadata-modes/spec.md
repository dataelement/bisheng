# 文件相似度按分类与业务域分组配置

- Status: `implemented-local-verified`

用户需要将文件相似度规则拆成两组：一级分类、二级分类、业务域三项完整且相同，使用一致组；任一不同或缺失，使用不一致组。库内相似推荐和发布推荐都覆盖，两组初始参数相同。

用户于2026-10-15确认“按这个方案开始实施”。T001至T004已完成本地实现与定向验证；未提交、推送、部署或更新线上数据。

需求见 [requirements.md](requirements.md)，设计见 [design.md](design.md)，任务见 [tasks.md](tasks.md)，证据状态见 [verification.md](verification.md)。

## 评审摘要

- 复用现有配置、相似候选表和版本管理服务，不新增数据库表或接口。
- 两套规则只决定相似度筛选，不能授予文件或目标库访问权限。
- 旧配置兼容是参数兼容；升级后跨分类候选进入比较是本功能有意引入的行为变化。
- 发布候选增加正文复核，必须正确读取源库和目标库，不能因只查询源库而静默退化成纯 SimHash。
- 配置变化不自动刷新存量候选，不修改已处理状态，不执行线上补算。
- 最终定向回归85项通过，2项已证实修改前同样失败的旧断言排除；本地实际组件展示验收通过。证据及真实基础设施限制见verification.md。
