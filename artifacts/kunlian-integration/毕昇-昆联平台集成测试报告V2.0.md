## 一、方案编制说明

### 1.1 编写概要

系统记录毕昇平台后端、前端双应用与统一安全网关涉及昆联集成全部业务功能的部署适配、全量自动化复测及联合环境实测结果。

### 1.2 编写依据

- 毕昇-昆联平台集成需求说明与对外契约

- 《昆联工作流开放接口使用文档》《删除工作流接口文档》《毕昇工作流授权模型列表对外 API 文档》

- 统一安全网关协议规范与容器部署模板

### 1.3 编写范围

1. 部署适配测试：构建与依赖检查、静态前端加速、安全日志保护与数据表适配。

2. 调试测试：单点登录与目录同步、多租户开通、工作流管理与深链、开放接口与权限、平台大模型与工具节点、快照同步回调及安全网关。

3. 口径界定：仅聚焦本次集成交付功能，不含其他并行独立模块。

## 二、概述

### 2.1 术语与缩略语

| 术语 / 缩略语 | 定义与工程口径说明 |

## 四、调试测试结论摘要

- 可执行自动化用例合计 **1244** 项（另含 5 项外部条件关闭未启用用例），通过 **1236** 项、未通过 **1** 项、跳过 **12** 项，可执行通过率 **99.92%**。

- 遗留待处理：1 项工作流状态变更快照桥接兼容性异常、平台大模型新增错误码 10580–10586 缺失三语前端文案与部分中文提示国际化、用户端局部依赖阻塞，以及真机大模型/快照回调/国产数据库联合验收。
