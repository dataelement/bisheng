## 冲突与接入处理

1. 删除旧 Dalle3 表单，客户端改用通用 `ImageGeneration`，兼容 `image_generation` 与 `dalle_image_generator`。
2. ESLint 生成记录冲突：核实目标分支独有变更只有删除 Dalle3 的 no-console 豁免，源分支也删除了此项；保留源分支生成结果并运行 lint:prune，不丢失独有记录。
3. 搜索表单不再接收旧 formData/onSubmit；客户端改用 toolId/onSaved，沿用源分支带 revision 的设置接口和独立密钥动作。可选 onSavingChange 将独立保存状态传给客户端关闭锁。
4. 三语言错误码自动合并后通过 key parity 和生成产物一致性检查。
