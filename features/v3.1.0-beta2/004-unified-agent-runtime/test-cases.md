# 日常对话与深度研究统一测试用例（测试工程师参考）

本文件在设计确认后、任务拆解前生成，只供测试工程师参考。它不是开发门禁，不进入 tasks.md 和 `/e2e-test`。

## 依据与范围

- 已确认规格：[spec.md](./spec.md)，2026-11-18 确认，共 51 条 AC（AC-01 至 AC-51）。
- 设计复查：已对照 [design.md](./design.md) 2026-11-18 修订版（含决策 1 至决策 12）。入口、观察方法按设计 §4.3 填写；设计尚未实现，凡依赖新接口的观察方法都标了“待研发确认”。
- 目标版本与构建：v3.1.0-beta2 / 待实现。
- 其他依据：交互原型 [prototype/index.html](./prototype/index.html)。
- 代码核对：`origin/feat/3.1.0-beta2` 49ecbd659f。只核对了现有入口与权限点（工作台会话页、「深度研究」开关、`linsight_task_mode` 权限）；新行为均为规格推导。
- 覆盖范围：选取漏测后果明确的场景，包括主链路、插话的顺序与不丢失、权限与数据隔离、停止与恢复、多节点、旧数据兼容。没有为每条 AC 各写一条用例；引用角标、读图、长期记忆的细节沿用各自特性已有的用例。
