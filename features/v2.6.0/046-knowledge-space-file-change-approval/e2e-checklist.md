# E2E 验证清单：知识空间文件与文件夹变更审核

**Feature**: F046
**Platform**: `http://localhost:3001/filelib`
**Client**: `http://localhost:4001/workspace/knowledge/space/{spaceId}`
**审批中心入口**: Client 顶部审批中心
**数据前缀**: `e2e-f046-`（所有人工测试空间、目录和文件都必须使用此前缀）

> 本清单不保存账号密码。账号由测试环境管理员临时创建或分配，密码只通过安全渠道传递。测试完成后，仅清理本轮 `e2e-f046-<run-id>-` 前缀资源。

## 1. 环境与账号矩阵

### 1.1 依赖检查

- [ ] Backend、Platform、Client 可访问，浏览器 console 无启动错误。
- [ ] MySQL/DM8 对应测试环境、Redis、MinIO、OpenFGA、Elasticsearch、Milvus 可用。
- [ ] 默认 `celery` 队列、`knowledge_celery` 队列和 Celery Beat 均在运行。
- [ ] F046 migration 已执行，固定审批场景 `knowledge_space_file_change_request` 已初始化。
- [ ] 租户 A、租户 B 均准备一个非私密普通知识空间；租户 A 另准备一个私密空间和一个部门知识空间。
- [ ] 每个空间与文件、文件夹均使用唯一的 `e2e-f046-<run-id>-` 前缀。
- [ ] 准备一个可正常解析的 UTF-8 文本文件、一个可稳定触发解析失败的测试文件、一个内容变化后的同名文件。

### 1.2 账号矩阵

| 租户 | 账号代号 | 空间角色 | 用途 |
|---|---|---|---|
| A | `A-admin` | 租户管理员 | Platform 策略配置、跨租户隔离验证 |
| A | `A-owner` | 空间所有者 | 直通操作、审批、动态 owner 验证 |

| B | `B-editor` | 编辑者 | 关闭审核后的直通对照 |
