# 内置 Skill 语言切换修复 — 2026-10-30

## 问题与根因

PR #2524 为工具目录复用工具词典；「工具与技能」中的技能区域实际由 `SkillCenterPane`、`useSkillCenter` 和 `/api/v1/dsh/skills` 提供数据。技能接口把 `builtin` 与其他企业技能统一归为 `platform`，前端据此展示服务端原始中文。三个随版本发布的技能为 `bisheng-docx`、`bisheng-pptx`、`bisheng-xlsx`。

## 实现

- 接口增加可选展示字段 `builtin_key`：由已授权技能记录的 `source == "builtin"` 派生，值为稳定的技能 `name`；其他来源返回 `null`。原来的 `source`、资源 ID、执行名称、内容版本、账号开关保持原合同。
- 客户端保留 `builtin_key`，在共享 `useSkillCenter` 渲染阶段解析中、英、日名称及面向用户的功能说明。查询缓存继续保存服务端原始数据，语言切换即时刷新列表和打开的详情。
- 技能列表和广场搜索共用解析逻辑，可匹配当前语言、原始名称/说明和稳定标识。
- 企业自定义、个人上传及管理员编辑后转为 `manual` 的技能使用配置文案；旧接口和新版本未知技能使用原始文案。执行用的 SKILL.md、包内容和权限判定沿用原实现。
