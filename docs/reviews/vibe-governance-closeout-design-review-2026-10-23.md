## 2. 新旧方案对比

| 事项 | 当前正式设计 |
|---|---|
| 数据 | 一张AppSecretConfig，执行/幂等/路由复用RuntimeOperation等既有资产 |
| 保存 | 配置+审计短事务，无manager调用，无自动重启 |
| 生效 | 用户明确确认后重建当前运行版本，保留原镜像/档位/数据 |
| 差异 | 实际运行值与最新保存值比较；未引用/A→B→A不误报，缺上下文unknown |
| 执行衔接 | 既有auto_commit、精确maintenance转换、局部锁图、session-aware凭据producer |
| 保护 | owner会话写、加密存储、预检/预览空值、保留变量与日志保护；部署key轮换仅运维 |
