# F120 Mock 验收清单

正常环境需要 Platform、API、Broker、Worker、Redis、数据库、MinIO 和普通测试账号。用独立测试租户，作者有编辑和发布权限，运行者有 Workflow 使用权限。默认配置提供合成目录。专项身份样例可映射 A、B、C，按设计用实际测试用户与租户。

| 操作 | 预期 | 状态 |
| --- | --- | --- |
| 导入同目录示例图，打开检索节点，保存后重新打开 | 显示模拟数据。选择设备维护示例。问题指向输入节点，四个输出可由下游选取 | NOT_RUN |
| 切换常量／变量，使用节点试运行 | 常量无需试填。变量只接收所选字段。输出变量名固定 | NOT_RUN |
| 执行「轴承温度异常如何处理？」 | 输出润滑和负载建议。节点日志含合成文档与片段来源 | NOT_RUN |
| 运行无匹配问题或有效空变量，再试错误和超时样例 | 空结果成功。错误和超时分别报错，旧结果不会重现 | NOT_RUN |
| 发布后保存另一份草稿并改变选库 | 原发布版继续使用固定配置。混合图的两类节点校验共同决定发布结果 | NOT_RUN |
| A 发布私有库工作流，B 获 Workflow 使用权后执行 | B 的库权限拒绝仍生效；共享库只返回 B 可见片段 | NOT_RUN |
| 在超时样例返回前停止并开始新一轮 | 已停止运行没有迟到结果。旧停止消息不影响新运行 | NOT_RUN |
| 在检索与 Agent 间传递文本变量，复验本地检索 | 混合图的输出引用有效，原本地节点配置含义保持 | NOT_RUN |
| 断开问题来源的连线后试运行和发布 | 预检拒绝。恢复上游连线后允许按正常规则运行 | NOT_RUN |
| 已发布入口等待用户输入时提交错误消息 ID，再提交有效输入 | 首次返回输入错误。同一会话仍可用有效输入继续 | NOT_RUN |

API 端到端脚本为 `src/backend/test/workflow/test_platform_knowledge_e2e.py`。具备测试环境后显式设置 `F120_MOCK_E2E=1`，提供脚本所列账号和租户参数，再用项目 Python 环境运行 pytest。脚本使用唯一测试工作流并核对身份后清理该工作流。Redis 原子性脚本使用独立的 `F120_TEST_REDIS_URL`。账号密码只通过测试进程环境传入。

正式昆联契约与环境验收均为 NOT_RUN。
