## 2. 已确认的实现边界

- 助手应用与机器人在租户内一对一；机器人可绑定多个知识空间。
- 配置空间是管理员对机器人的业务授权，不校验管理员、提问人或助手创建者的空间个人权限。
- 历史会话跨 `scope_version` 完整保留；执行中改绑不撤销本轮，下一轮才读取新配置。
- 本期只向 E+ 返回文字；模型生成图片、媒体上传、卡片、主动推送延期。
- 群聊与单聊走同一处理主线；客户协议仅保证群聊投递文字和图文混排，不保证纯图片。
- 同一机器人由一个 Worker 实例持有长连接；不是每用户、每会话启动一个 Worker。
- 新增的整表由项目启动时的表模型初始化机制创建；本 Feature 不新增 Alembic 整表迁移。环境必须实际核验双数据库表与唯一键。
