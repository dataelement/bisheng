## 业务规则

首次上传取上传人的唯一主组织；个人库发布到科室库成功时，改为目标科室库绑定组织；个人库发布到团队库成功时，改为目标团队创建人的唯一主组织。人员没有主组织或主组织数据异常时留空。

一次发布更新整份逻辑文档，各版本和发布、分享入口归属一致。主业务覆盖新上传及后续业务操作，不自动补历史数据，不改页面、筛选、统计和权限规则。另按用户后续要求提供独立存量脚本，只按当前主版本上传人的当前唯一主组织补空；本次未执行环境回填。

新增可空整数列 `knowledgefile.belonging_organization_id`，保存 `department.id`。组织实体包括部门、科室、班组等层级，字段不限定为部门层级。组织名不重复存储。
