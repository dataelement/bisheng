# 租户上下文第二、三阶段实现设计

2026-11-14。延续用户已批准的统一方案，第一阶段基线为740900516d。用户补充确认组织页跟随所选租户、仅管理其挂载子树；网关仍负责敏感词和限流执行，已退役的旧用户组资源归属不恢复。本批不含合并、推送、部署或历史修数。架构规则引用docs/constitution.md；术语见[术语表](terminology.md)。

## 范围与决策

1. 复用根路由组合，声明租户业务、个人业务、身份、平台、独立凭据、公共六类范围。混合分组按端点函数声明例外。新增租户子端点继承分组；新增未声明组及冲突拒绝。登记附着endpoint，最终include完成后验证并包装，避免路由复制导致登记失效。登记资料从实际声明生成，仅作检查/盘点；前端不导入该资料决定请求是否带目标。持续集成仍检查Python登记与资料一致。独立Java增强分支的控制器须声明并启动验证；旧Java不要求新增声明。仅核对该增强分支时用可选生成参数检查Java源声明，无法解析的新映射形状明确失败。
2. 最终选路后、正文解析和业务依赖之前核验真实身份及目标。范围保持到服务器发送事件流、普通流和WebSocket连接结束；异常退出恢复上下文。旧AdminScopeMiddleware退出生产栈，保留类供旧直接集成调用过渡。原业务动作权限及半成品门禁仍生效，超管动作快捷判断之前另做负向资源归属证明，不重写授权次序。
3. 2026-11-16修订：两个旧聊天回写端点按[可选Gateway兼容修订](optional-gateway-compat.md)的身份与持久归属校验；其余普通人员固定权威主属；异租户头拒绝。超管租户/个人HTTP读写都要求有效选择及匹配的X-Management-Tenant。过期、无选择、查询参数冲突或未知状态均拒绝，不回落Root。只允许显式首次自举建立真实主属默认选择；保留整数Redis格式及滑动过期。切换的审计失败可能发生在选择已写入之后，前端暂停业务并重新确认结果；重读失败保持未就绪。
4. 两套前端共享浏览器通道边界和内存确认会话，不按业务接口清单匹配；并发自举只发一次，旧自举应答不能覆盖新确认结果。Axios及原生流均携带目标；存储仅用来通知跨标签刷新，不作权威来源。WebSocket使用已验证选择和资源事实，连接中不追随后续选择。独立设备、公开执行、服务凭据仍由原领域凭据恢复范围。DSH设备Web会话明确不使用浏览器管理选择。

## 组织、人员与角色

组织页业务目标与物理存储分开。DirectoryRepository根据当前有效Tenant.root_dept_id及规范部门路径证明挂载根；通过已有部门所有者算法验证边界。只在组织API组的依赖生命周期内临时进入已证明的存储租户；LoginUser.tenant_id及请求冻结的业务目标不变，响应仍回传业务目标。没有新增全局SQL钩子或全局bypass。

树、子层、搜索、路径、成员和计数在业务子树内裁剪；Root视图排除子租户挂载子树。写前重新验证部门当前业务归属；移动同时证明目标上级，禁止移动包含其他租户挂载点的祖先而间接改动外租户。归档节点可用于组织读取/恢复，但不会因此成为可编辑角色政策的活跃节点。角色定义、普通绑定、组和审计等业务数据临时返回业务租户上下文，避免存储Root污染它们。

/user/list按主属账号或本租户可证明成员事实限定结果，兼顾无部门的历史Root账号；组织挂载提示只包含当前范围。旧创建用户表单在子租户下复用已有组织成员投影与主属同步，将新账号初始化到该挂载根；Root无部门账号沿旧语义。角色/组资格在建账号前校验。账号启禁及重置密码不允许通过兼属关系操作外国主属账号。本人资料仍为身份接口；网关使用的本人主部门查询只允许查询本人，按真实主属恢复，不依赖管理选择。

跨租户兼属只展示成员事实；外国主属不获得上下文普通角色绑定。授权名册已知人员编号可显示跨主属创建人/授权对象姓名；部门名称及权限解释的部门userset使用业务归属并止于挂载边界，不因Root存储丢失名称或扩张到Root祖先。没有复制账号或为超管制造兼属关系。旧角色读写失败后的旧路径回退删除；旧变量接口验证父工作流/版本和动作权限，写入从父对象恢复租户，批量删除有明确范围。

## 浏览器默认传输与暂停恢复（2026-11-17）

本节替代之前前端依据生成范围资料选路的实现，用户已明确要求本轮开发。原因是116新增积分价格接口未进入生成资料，前端漏头触发19703，再使公共内存确认暂停且无法重试。仅重新生成清单无法消除运行时耦合。

- **传输规则**：同源API业务请求默认自举/确认后附加目标；平台Axios、原生requestStream、客户端Axios及现有SSE准备入口复用同一通道规则。不导入requestScopeRoutes.json或gatewayRequestScopeRoutes.json，也不维护租户业务的逐URL接入表。保留少量会话/发现端点、平台控制面及既有公开/设备协议命名空间边界。相对地址按实际baseURL核对来源，管理头不发往外部Origin。
- **独立协议**：share-token明确标记分享凭据；少量混合入口可在其API包装中显式managementContext=independent，例如审批个人预览，URL、正文及服务端purpose=approval门禁保持。这是客户端传输选项，不发送新头/请求字段，也不能跳过后端认证、范围或资源授权。DSH设备协议保持独立，DSH/admin浏览器业务仍默认接入。
- **状态恢复**：首次仍沿原POST bootstrap；暂停后的下一次确认/重试只调用已存在的GET request-scope，不能建立默认选择。BrowserScopeSession.reconfirm合并并发读取；合法同目标恢复，读取失败/非法证明保持暂停。原失败请求不自动重放；只有调用方后续发起的新尝试才继续。
- **切换与迟到响应**：beginSwitch屏障阻止切换在途的恢复，切换结束或失败在finally释放；旧确认以其Promise身份判旧。内部lastTenant只记最后服务端确认，用于发现目标变化，不作回退授权来源。暂停后证明变成另一目标时，拒绝旧动作并通过现有事件整页刷新。旧目标请求的成功/失败不污染或暂停新确认；同目标A→B→A旧表单仍沿既有整页刷新和资源版本规则，本轮不新增服务端视图编号。
- **失败处理**：19703/19704/19705只使当前业务快照失效，独立控制请求失败及旧快照失败不冲掉新目标；silent只抑制展示，不抑制暂停。后端安全拒绝保持，不靠取消租户校验恢复页面。
- **资料及持续集成**：生成资料继续用于真实路由检查，当前更新为976项；构建依赖检查确认公共客户端仅包含TypeScript输入。共享测试模拟清单模块不可导入，确保不会重新出现运行依赖。现有前端质量工作流增加共享/平台请求恢复回归，并覆盖发布线直接推送；没有新增流水线或依赖。

不修改Python/Java业务代码、Redis格式、数据库表列或历史行；旧Gateway依旧可选且无需升级。验证结果与现场限制见[browser-scope-default-delivery-20261117.md](browser-scope-default-delivery-20261117.md)。重新考虑条件：增加新的独立认证协议或改变浏览器API挂载方式时，审查传输通道边界；新增普通业务接口不应修改该规则。
