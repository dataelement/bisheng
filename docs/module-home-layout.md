# 模块首页布局

2026-11-03，用户确认内容区采用「最大 1000px，居中，更紧凑」。本次为既有首页的视觉规整，不增加业务能力或更改 API 契约。

## 范围与参数

以下默认规则适用于浏览器端（宽度 ≥768px）的知识空间、订阅、应用、工具与技能首页，包括订阅无频道时的发现首页。`embed=dsh` 的桌面客户端规则见下方独立章节；窄屏继续使用各模块原有导航与布局。

| 项目 | 统一规则 |
| --- | --- |
| 内容宽度 | `min(1000px, 右侧可用宽度 − 64px)`，在右侧主体内居中 |
| 页面留白 | 上下 32px，两侧至少 32px |
| 页头高度 | 32px |
| 页面标题 | `text-h2`，20px / 28px，Medium 500；语义标签仍为 h1 |
| 标题位置 | 左对齐，与工具栏和正文内容列共用左边缘 |
| 页头操作 | 同行靠右，保留各页现有搜索或创建入口 |
| 页头至工具栏 | 16px；无工具栏的订阅保留原分组间距 |
| 滚动 | 页头保留在顶部，正文在各自内容区滚动 |

统一框架由 `src/frontend/client/src/components/ModuleHome/ModuleHome.tsx` 的 `MODULE_HOME_FRAME`、`MODULE_HOME_COLUMN`、`ModuleHomeHeader` 提供。应用首页也复用内容列常量，避免单独维护宽度。知识空间的尺寸与动画使用页面局部规则；桌面内部尺寸固定、卡片宽度随内容区伸缩，具体见 [知识空间规范 v1.40](knowledge-space-design-spec.md#v140--桌面窗口变化保持组件尺寸2026-11-03)。网格容器位于受限的内容列内，容器单位以实际内容列宽度计算。

本约定覆盖知识空间旧规范中的页面宽度、页边距、页头高度、页面标题和创建按钮局部几何覆盖；创建按钮使用共享 Button 的原生 medium 尺寸。卡片内容及业务行为不在本次调整范围。

## DSH 桌面客户端（2026-11-05）

用户要求嵌入桌面客户端的四个首页参考 BishengWork 的插件页布局。通过现有 `html[data-bisheng-surface="desktop"]` 标记，在宽度 ≥768px 时启用以下规则；身份标记继续由统一客户端环境模块维护，兼容入口参数、宿主桥和 SPA 导航后的会话识别，不新增页面自己的 `embed` 检测。

| 项目 | 桌面客户端规则 |
| --- | --- |
| 内容宽度 | 最大 960px，居中 |
| 两侧留白 | `clamp(24px, 4vw, 48px)` |
| 页面顶部 / 底部留白 | 56px / 48px |
| 页面标题 | 20px / 28px，Medium 500；页头至少 32px，操作可换行 |
| 页头至分类工具栏 | 16px |
| 应用页简介至页头 | 4px |
| 正文至工具栏或简介 | 32px；订阅没有工具栏时从页头开始计算 |
| 订阅和技能分组间距 | 32px |
| 分组标题 | 14px / 22px、Medium 500，与内容列左边缘对齐 |

参考来源为本机 BishengWork 中 `node_modules/@deepseek-ai/dsh-client-ui-plugin-manager/lib/client.js` 的插件页面样式，以及 `packages/dsh-desktop-client-ui/client.js` 的宿主页头覆盖。插件原始样式包含 28px 顶部留白及 macOS 避让规则，但宿主最终通过 `[data-plugin-panel] > header[data-window-drag]` 将顶部留白统一覆盖为 56px；因此嵌入首页采用最终值，不再额外叠加一层 48px。

实现位于公共 `ModuleHome.module.css`。最大宽度覆盖限定在模块首页框架内部；仅复用内容列常量的广场不采用此变体。各模块继续使用原来的列表、卡片和正文滚动容器。

- 768px 内容窗口：订阅页两侧各约 30.72px，内容宽约 706.56px，无横向溢出。
- 1280px 内容窗口：桌面客户端内容列为 960px、两侧基础 Padding 48px；浏览器端四个首页仍为 1000px 内容列和 32px Padding。
- 全仓 lint、类型检查通过；知识空间、能力中心、订阅、技能列表及客户端环境的 56 项既有测试通过。Jest 沿用临时 preload 跳过本机不可用的可选 canvas。

### DSH 标题字体对齐（2026-11-05）

用户指出同为 20px / 500 的首页标题仍比原生页面显得大。本轮进一步核对了 DSH 的主题字体、应用全局样式和插件页标题，确认此前只对齐字号与字重，没有对齐完整字体环境：公共首页默认使用 BiSheng 字体回退栈及 `auto` 抗锯齿，知识空间另有局部字体覆盖；DSH 的全局 body 使用自己的系统字体栈、`-webkit-font-smoothing: antialiased` 和 `-moz-osx-font-smoothing: grayscale`。

桌面首页框架现统一使用 DSH 默认系统字体栈和上述渲染方式，标题显式引用原生 `--dsw-font-l-20`（未提供时使用 500、20px / 28px 和原生字体栈），避免继承模块局部字体及网页 rem 字阶。已提供的 `--dsw-font-family`、`--dsh-font-family-text` 或默认字体变量优先使用。现有宿主桥只传主题颜色，尚未同步用户自选字体；本次对齐的是 DSH 默认字体，不新增跨项目协议。本机正式与开发配置中保存的窗口 `zoomLevel` 均为 0，未据此将问题归因为缩放。

来源：`BishengWork/node_modules/@deepseek-ai/dsh-client-ui-theme/lib/client.js` 的默认字体与 20px 标题 token、`node_modules/@deepseek-ai/dsh-web-frontend/dist/assets/index-*.css` 的 body 规则，以及插件管理页面的标题样式。

- 890px 实际首页组件预览中，知识空间、订阅、应用和工具与技能的标题均为相同字体栈、20px / 28px / 500、`antialiased`，没有横向溢出。
- 将 DSH 原始字体声明与修改后的实际公共页头并排渲染，四个中文标题及 `Workspace 123` 的字形边界尺寸分别一致；这是同浏览器中的样式对照，不代表安装包联调。
- 浏览器端仍使用原有字体栈、默认抗锯齿与 20px / 28px / 500 字阶。全仓 lint、类型检查、架构守卫和差异空白检查通过。

### 知识空间内部页间距（2026-11-05）

用户要求进入知识空间后，顶部与左右间距参考外层首页。桌面身份且内容视口 ≥768px 时，内部页复用首页的桌面框架与内容列样式：顶部 56px、左右 `clamp(24px, 4vw, 48px)`、最大 960px 居中。该公式中的 `vw` 仍指嵌入内容视口，与同一视口内的首页一致；不视为已经修复与宿主完整窗口之间的视口基准差异。

页头取消重复的上方与左右 Padding，保留至文件工具栏的 16px 间距；文件工具栏、列表行和卡片网格去除重复的左右留白。返回按钮组取消负外边距，确保按钮点击范围不会被居中列裁切。底部提问框保留原有 800px 最大宽度与 16px 底部安全区，在同一内容列中居中；内部页无需叠加首页底部的 48px，继续使用列表自身的 112px 底部占位。

样式位于 `SpaceDetail/KnowledgeSpaceLayout.module.css`，条件与首页一致；浏览器及 <768px 窄屏不启用，数据、权限与文件操作不变。

本轮实际组件预览与手动验证：

- 890px：顶部 56px，两侧各约 35.6px，内容列约 818.81px；工具栏和文件复选框均从 x≈35.59px 开始。
- 768px：两侧各约 30.72px，内容列约 706.56px；1280px：960px 内容列居中，左右实际留白各 160px。均无页面横向溢出。

### 订阅频道内部页间距（2026-11-05）

用户要求频道文章列表采用相同的桌面间距。频道浏览态（未选中文章）复用公共桌面框架：顶部 56px、左右 `clamp(24px, 4vw, 48px)`、页头和文章列表最大 960px 居中，底部 48px。局部样式位于 `Subscription/ArticleList/ArticleListLayout.module.css`，取消原页头及列表内容重复的 24px 左右 Padding；页头至文章滚动区保留 16px。频道标题继续由既有 ChannelSwitcher 提供。

文章阅读仍由 ChannelLayout 管理原有分栏及容器容量判断，不把两个至少 480px 的阅读区域强行限制到 960px。桌面默认左栏宽度根据浏览态的实际公式计算一个卡片宽度，再加回阅读栏自身的 24px 左右 Padding，继续受最小栏宽约束。修改公共框架的 960px 上限或 `clamp` 参数时，需要同时核对 ChannelLayout 的默认宽度计算。浏览器的原有计算保持独立。

验证：

- 890px：两侧约 35.6px，页头和文章列表宽约 818.81px，卡片宽约 392.91px；768px：两侧约 30.72px，内容约 706.56px。
- 1280px：960px 内容列居中，左边缘 x=160px，卡片宽 463.5px；打开阅读分栏后左栏为 512px，扣除两侧 Padding 后卡片宽 464px，差异来自整数像素取整。
