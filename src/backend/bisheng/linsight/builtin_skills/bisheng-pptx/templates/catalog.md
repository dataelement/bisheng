# 模板目录

每套模板目录下有 `design.md`（设计说明：配色、字阶、组件、页面节奏）和 `source-zh/`（中文参考工程：`deck.pptd` + 12 个 `.page`）。
模板是参考，不是底板：读设计说明和参考页，学它的网格、配色和组件，再用自己的内容重建。字号按 SKILL.md 的下限放大。

| 模板 ID | 风格 | 适合 |
|---|---|---|

| blue-professional | 蓝色商务，稳重 | 企业汇报、董事会材料、年度总结（非红色场景） |
| signal | 深蓝决策 | 管理层决策、经营复盘 |
