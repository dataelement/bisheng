# 网页用户头像统一测试用例（测试工程师参考）

## 依据与范围

- 已确认规格为 2026-11-19 的 [spec.md](./spec.md)，覆盖首批 AC-01 至 AC-12 和两端全局补查的 AC-13、AC-14。
- 已复查 [design.md](./design.md) 的头像渲染、本人资料刷新、通知读取和资源授权数据契约。下列用例按该版设计准备，预期取自已确认规格。
- 目标版本为 v3.1.0-alpha1。目标测试构建待研发指定，当前表内记录均待执行。
- 代码核对基线为 `alpha1-ui` 的 `ed1687aee8`。已追踪 Platform `MainLayout`、`useCurrentIdentityRefresh`、`PermissionDialog`，Client `UserPopMenu`、`AccountSection`、`NotificationPane`、`PermissionDraftPanel`，及后端 `get_info`、`get_message_list`、`list_resource_grants`、`list_grant_subject_users` 等入口。
- 覆盖网页本人资料、消息通知、通用资源权限及补查纳入的其他自然人头像位置。

## 环境、账号与测试数据

| 代号 | 角色或数据 | 准备方法 | 确认方式或待确认项 |

| H | 升级与失败样本 | 使用升级前已上传的头像和已存在的授权、通知记录。以浏览器拦截或测试服务独立模拟头像取图失败、上传失败及超时。 | 记录原始可打开头像。失败时保留后端业务及其他图片请求，并确认故障只作用于目标请求。 |
