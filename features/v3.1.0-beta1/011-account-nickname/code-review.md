## 已纠正的实现问题

- 旧 DAO 只薄适配 repository 与纯候选决策，消除模型反向导入 service。
- 旧 SSO 原先按显示名称查用户，人工改名后保留原识别快照；新昵称不成为登录账号。
- 人员编辑异步返回按请求版本和目标 user_id 核对，防止旧成员响应填入另一个成员的表单。
- 后台不再提前写昵称；先校验，其他人员操作成功后再提交昵称及审计。未改昵称的前端表单不发送旧 user_name，避免覆盖其他人的并发改名。
- Client 改名只更新同 user_id 的用户缓存，接口失败保留草稿；缓存刷新不误报已提交改名失败。
- 明确缺失账号不使用昵称或内部 ID 填充，原值复制不截断；账号中的符号按文字搜索。
