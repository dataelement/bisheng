## 资格变更入口核对

- 权威来源保持现有 `system:global#super_admin` 及有效旧管理员绑定；普通共享角色不因此成为平台身份。
- `LegacyRBACSyncService.sync_user_role_change` 及账号初始化会同步平台身份；既有 `_invalidate_user_caches` 清 `user:{id}:is_super`。普通绑定仓储拒绝操作AdminRole，用户角色/删除入口保护平台管理员；没有据此新增公开撤权API。
- 既有 `clear_on_role_revoke` 注明尚未接线。运维直改权威关系、独立身份来源和投影重试不保证都调用它。此次未把所有读取的缓存/选择生命周期改为新合同；对已触及敏感入口执行当前权威核验及第二次LoginUser资格初始化，避免旧缓存再注入平台权限。
- 第一阶段不是“所有外部撤权生产者都完整清理并收敛”的证明；未来新增撤权业务必须接通已有清理与结果核验。不能将仍合法的独立管理员来源误判为已撤销。
