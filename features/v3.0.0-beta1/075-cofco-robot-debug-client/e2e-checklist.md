## AC-01 / AC-09：入口、身份与脱敏

- [ ] 构建时显式设置 `VITE_EPLUS_DEBUG_ENABLED=false`：配置区没有调试按钮，直接访问不执行问答。
- [ ] 未配置前端开关 + 已启用独立进程 + 登录用户：保存并上线助手后，按钮打开新页并带入正确助手；独立服务不可用时隐藏入口。
- [ ] 普通登录用户即使没有助手编辑权限，也可直接打开调试 URL，用自己身份读取上下文和问答；不显示切换测试用户控件。
- [ ] 匿名、普通用户冒用其他身份、其他租户助手、已停用/删除用户、无绑定/无效空间：接口拒绝，模型不执行。
- [ ] 管理员切换到同租户有效测试用户：页面显示该身份；切换清空旧历史；无外部身份明确提示不测 IAM。
- [ ] 浏览器请求/响应、地址栏、运行日志均没有 Bot Secret、模型 APIKey、认证头或配置全文。
- [ ] 调试日志按同一 run_id 关联新会话/追问的原始问题、历史轮数和全文、完整工具检索参数（含文件限制）、实际模型工具结果及最终回复；零次工具调用可见，取消/失败后的部分回复不标为完整；不逐字打印增量、不从配置对象提取凭证，用户写入正文的敏感文本不自动打码。

## AC-02 / AC-03 / AC-08：隔离、停止与限流

- [ ] 连问两轮可使用当前页面历史；清空或刷新后不再带旧历史；正式聊天历史没有新测试记录。
- [ ] 检查正式 E+ 表、队列、单活租约和连接：没有本次调试产生的状态或客户消息。
- [ ] 运行时停止/关闭/清空：执行取消，下次能继续测试；说明供应商费用不可撤销。
- [ ] 两个浏览器同时调试：只一轮执行，另一轮明确失败；两个独立进程也相同，不能只靠同进程替身证明。
- [ ] 超时及请求/答案/追踪越界：明确失败，没有自动重新提问；不是静默截断。

## AC-04 / AC-05 / AC-06 / AC-07 / AC-10：五类真实问答

- [ ] 正常文档问答：真正调用模型及机器人知识工具；所用模型、执行模式、绑定空间与保存配置一致。
- [ ] 无命中问题：看到空工具结果，确认模型没有凭空声称“已找到”。
- [ ] 两个绑定空间的同名文件：分别对照空间 ID、文件 ID；原始元数据与模型工具结果分栏，缺字段不猜。
- [ ] 绑定部门空间内的已入库文件：用明确片段问答，观察实际工具输出，定位召回/过滤/模型归属问题。
- [ ] 检索优化：问「看下深圳市医学研究相关的文件有哪些」，检查工具传 `file_name_query` 的主题关键词，来源显示真实PDF文件及「007部门」真实ID，不编造正文或宣称完整列表。
- [ ] 检索优化：问「深圳市医学研究 大概是什么内容」及该PDF具体申请要求；即使模型传 `file_name_query`，同一次调用也应获取相关正文，不因文件名命中提前只返回来源。
- [ ] 同主题、标题不含关键词但正文相关的已入库文件仍参加全空间召回；已有正文的文件不重复补查，同片段不重复展示。明确指定完整文件名时不能混入其他文件。
- [ ] 边界：不存在的主题、完整文件名、同名/同正文文件，均不混淆真实来源；未绑定/其他租户/未解析成功文件不可返回。更换绑定后下一轮使用新范围。
- [ ] 比较正式机器人与调试页工具输入/结果；两者共用优化，普通助手入口保持原检索路径。部署后使用真实模型验收，本地确定性测试不代表模型效果通过。
- [ ] 闲聊不调用工具：显示调用0次，答案不伪装检索完成。
- [ ] 一轮多次调用：每次原问题、模型检索问题、工具类、结果都按序可见；工具报错但模型仍回答时错误独立标记。
- [ ] ReAct / 函数调用两类真实配置分别验证；ReAct 原行为是整段返回，不能以非流式判失败。
- [ ] 与客户正式机器人同问题对照，只评知识问答；不声称测试了 E+ 通信、图片、其他工具或正式历史。
