# Feature: 支持展示对话中上传的图片

> **本文档定位 — 纯 What（需求口径，不随代码漂移）**
> spec 只回答 **做什么 / 验收标准 / 不做什么**；所有 How 一律在 [design.md](./design.md) 与 [tasks.md](./tasks.md)。

**关联 PRD**: [3.0.0-beta1 需求文档 §支持展示对话中上传的图片](https://dataelem.feishu.cn/wiki/Ifj6wOgSmiyClfkMQySc7ZmvnNb)
**优先级**: P1
**所属版本**: v3.0.0-beta1
**依赖**: 无

> **范围边界**
> - **本次纳入**：
>   - 场景范围（同 PRD）：**日常模式、任务模式、工作流会话**（client 端）
>   - 用户上传图片发送后，消息中显示图片缩略图；点击放大至全屏查看，右上角关闭退出
>   - 图片文件失效（被清理、或访问链接过期）时，保留原消息位置并显示占位：**图片已失效，无法查看**
>   - 存量历史消息中的图片附件同样生效
> - **本次明确排除**：
>   - **失效链接的自动刷新/重新获取**（按 file_id 重取新鲜签名 URL）——用户已拍板本期不做；签名过期与文件被清理统一走"已失效"占位
>   - AI 回复内容中的图片渲染——PRD 范围仅"用户上传的图片"
>   - 输入框内（发送前）的缩略图与预览——已有能力，不动
>   - 非图片附件的展示方式——维持现状（文件卡片/下载）

---

## 1. 用户故事

作为 **对话用户**，
我希望 **上传的图片在会话里直接以缩略图呈现、点开能全屏查看**，
以便 **确认上传内容是否正确，并在对照图片提问时不必反复切换窗口**。

---

## 2. 验收标准

> AC-ID 在本特性内唯一。

| ID | 角色 | 操作 | 预期结果 |
|----|------|------|---------|
| AC-01 | 用户 | 在日常模式/任务模式/工作流会话上传图片并发送 | 该条用户消息中显示图片缩略图（而非仅文件名标识） |
| AC-02 | 用户 | 点击消息中的图片缩略图 | 图片放大至全屏查看模式 |
| AC-03 | 用户 | 全屏模式下点击右上角关闭 | 退出全屏，回到会话 |
| AC-04 | 用户 | 查看图片已被清理或链接已过期的历史消息 | 原消息位置显示占位「图片已失效，无法查看」，不出现浏览器裂图 |
| AC-05 | 用户 | 查看升级前发送的存量图片消息 | 同样按 AC-01~AC-04 展示（不依赖消息中是否存有 MIME 类型） |
| AC-06 | 用户 | 发送非图片附件 | 展示方式与现状一致，无回归 |
| AC-07 | 用户 | 三个场景中执行上述操作 | 行为与视觉表现一致 |

---

## 3. 边界情况

- 一条消息包含多张图片时，逐张显示缩略图，各自可独立放大。
- 常见图片格式（png/jpg/jpeg/gif/webp/bmp/svg）均按图片处理；识别依据以文件名后缀为准（原因见 design.md §5）。
- 图片加载中应有占位，不引起消息列表跳动。
