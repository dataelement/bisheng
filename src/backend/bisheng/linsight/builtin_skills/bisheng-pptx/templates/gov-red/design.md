# 红韵 · Gov Red

庄重、稳健的政企汇报版式：封面、目录、章节页和结尾页用深红底配金色细线，内容页白底，红色标题，金色只点关键数字和分隔。
适合党委会材料、央国企与政府部门的年度总结、工作汇报、专项工作报告。参考工程 `source-zh/` 共 12 页，全部是可编辑的原生对象。

## 沟通方式

1. 每页标题写一句判断（「五项重点任务四项完成，数字化转型一个模块延期」），不写话题词（「重点任务」）。
2. 章节结构按「总体情况 → 重点工作 → 问题与不足 → 下一步安排」组织，页眉小标题写所属章节（「二、重点任务完成情况」）。
3. 数字写清单位、期间和口径；目标值用「≥」「≤」表达。成绩和不足都要写，问题页写到原因和措施。
4. 不用党徽、国徽、旗帜等标识图形；需要时由用户自己的模板提供。

## 字体与字阶

所有文字 `fontFamily: {latin: Arial, ea: Microsoft YaHei}`。字阶（pt）：

| 角色 | 字号 | 说明 |
|---|---|---|
| 封面主标题 | 44–48 | 白色，粗体，最多两行 |
| 页面标题 `$title` | 26 | 红色，粗体，一行 |
| 小节标题 `$lead` | 15–17 | 粗体 |
| 正文 `$body` | 13–14 | 行高 1.4 |
| 标签 `$label` | 12–13 | 灰色 |
| 页眉小标题 `$kicker` | 11 | 金色，粗体 |
| 页脚 `$meta` | 10 | 灰色 |
| 指标数字 | 34–40 | 红色或白色 |
| 表格 `$gov-table` | 12 | 表头红底白字 |

## 网格与页面框架

- 画布 960 × 540，左右边距 48。
- 内容页框架（每页相同）：顶部 8pt 红色色带 + 2pt 金线；页眉小标题 y=28；标题 y=46；标题下 56 × 3 金色短线 y=88；内容区 y=112–490；页脚线 y=502，左侧单位名称，右侧页码。
- 卡片用 surface 底色加 4pt 红色左边条或顶边条；不用圆角、阴影、渐变。
