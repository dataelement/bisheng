# F074 — 中粮知识空间检索问答开放接口

> 本文只定义需求、验收标准与范围，不承载技术设计。
> 状态：Discovery 与 Spec 已于 2026-10-08 经用户确认。已进入实现与统一验证。

**关联 PRD**：本会话客户需求与确认记录（2026-10-08），见下文。
**优先级**：P1（权限与兼容验收为 P0）
**所属版本**：v3.0.0-beta1，中粮定制线；不得回流公共版本。
**依赖**：F053 开放 API 凭据与身份、F066 数据范围、F048 统一资源权限、既有知识空间检索与模型调用能力。

## 1. 需求来源与用户故事

客户新增需求：从指定知识空间中查找符合问题的文件内容，在召回后增加大模型归纳回答，一次调用即可得到答案。

用户已确认：

- 权限控制跟其他开放接口一样，知识空间和文件权限都需校验。
- 使用后台生成的开放 API Key 调用，不因持有 Key 而放开所有知识内容。
- 新接口独立增加，不能改变老接口和其他模块的原有行为。
- 按已展示的初步方案开始：单次问答、一次性返回答案与参考文件，不维护会话历史。

作为客户外部系统集成人员，我希望传入问题、知识空间范围和可用模型选择后，获得基于可访问资料生成的答案及参考文件，以便无需在外部系统另行组织检索结果和调用模型。

## 2. 范围

### 本次纳入

- 在一个或多个指定知识空间中查找与问题相关的文件片段。
- 可选按各空间已有标签缩小检索范围；沿用既有受支持的标签匹配能力。
- 根据检索内容进行单次归纳回答，并提供去重后的参考文件信息。
- 开放 API 凭据、执行身份、租户、空间和文件权限、数据范围与审计遵守既有规则。
- 无资料、资料不足、配置不可用、调用失败等异常与边界的明确反馈。

### 本次排除

- 多轮对话、会话历史管理、流式输出、后台任务与任务恢复。
- 将命中文件全部下载、解析或整篇送给模型；本次是相关片段问答，不是全文总结。
- QA 知识库、个人知识库及一般文档知识库的新问答能力；本期客户入口限定知识空间。
- 图片、音视频输入，以及生成图片、图表或文件附件。
- 完整文件目录枚举、原件下载、可点击的永久引用详情与引用持久化。
- 联网检索、助手工具、自主 Agent 规划、E+ 机器人接入。
- 新凭据体系、放宽个人访问令牌的既有能力、变更管理员或服务账号的资源授权规则。
- 改变现有召回接口、知识空间会话、助手、工作流或机器人行为。
- 将本接口自动加入远程 MCP 工具范围。

## 3. 验收标准

### 3.1 回答与来源

- **AC-01** — WHEN 合法调用提交非空问题、有效知识空间范围和可用模型选择，THE SYSTEM SHALL 在指定范围内检索资料并一次性返回文字答案与参考文件信息。
- **AC-02** — THE SYSTEM SHALL 只将通过既有可见性与业务状态规则的资料用于回答，不读取指定范围之外的空间，不引入其他工具结果作为依据。
- **AC-03** — WHEN 检索结果为空，THE SYSTEM SHALL 返回“未找到相关内容”和空参考文件集合，且不执行大模型生成。
- **AC-04** — WHEN 召回内容不足以支撑问题的答案，THE SYSTEM SHALL 明确说明依据不足；不得把资料中不存在的数值、制度、条款或结论补写为已检索到的事实。验收使用已知内容与无关问题样本。
- **AC-05** — THE SYSTEM SHALL 使参考文件信息可追溯到实际提供给模型的资料，按空间与文件去重；不得包含模型编造的文件。参考文件集合不宣称每份文件都被答案实际引用。
- **AC-06** — WHEN 只调整所选空间的传入顺序且检索候选保持一致，THE SYSTEM SHALL 不因空间排在列表前方就优先耗尽全部参考内容名额；不要求模型生成措辞逐字一致。
- **AC-07** — WHEN 调用指定合法标签筛选，THE SYSTEM SHALL 仅使用符合该空间标签条件的文件；标签无匹配时视为该空间无结果，非法或未支持的筛选条件应拒绝而非忽略。

### 3.2 权限与身份

- **AC-08** — IF 凭据缺失、无效、撤销、过期、停用或缺少所需接口能力，THEN THE SYSTEM SHALL 按既有开放 API 规则拒绝调用，不执行知识检索或答案生成。
- **AC-09** — THE SYSTEM SHALL 按既有开放 API 规则确定自身或委托执行身份、租户和数据范围；请求业务参数不得指定或伪造权限主体。
- **AC-10** — IF 任一指定空间不存在、不是本期支持的资源类型或当前主体无权访问，THEN THE SYSTEM SHALL 返回既有相应错误，不用其余空间的结果掩盖本次失败。
- **AC-11** — THE SYSTEM SHALL 对空间内文件继续执行现有文件可见性、主版本、发布和删除状态规则，不采用 E+ 机器人绑定范围内忽略个人文件权限的特殊规则。
- **AC-12** — IF 权限判定不可用或无法确定，THEN THE SYSTEM SHALL 失败关闭，不生成答案、不返回未过滤或部分过滤资料。

### 3.3 异常、独立性与兼容

- **AC-13** — IF 问题或范围不合法、模型不允许使用、模型下线或供应商配置不完整，THEN THE SYSTEM SHALL 返回明确错误，不回落到其他模型或扩大检索范围。
- **AC-14** — IF 检索、模型调用超时或失败，THEN THE SYSTEM SHALL 返回失败结果，不把服务异常转换为“未找到相关内容”，也不以部分生成内容作为成功答案。
- **AC-15** — THE SYSTEM SHALL 使每次请求独立，不读取或创建问答会话历史；先前请求不得成为下一次回答的隐式依据。
- **AC-16** — THE SYSTEM SHALL 保留现有开放接口的请求、响应、权限、排序、错误与副作用语义，并保持知识空间内部问答、助手、工作流和 E+ 机器人入口行为不变。
- **AC-17** — THE SYSTEM SHALL 沿用开放 API 调用审计，并可关联检索与模型调用的成功、失败及耗时；不得在诊断日志中输出凭据或模型密钥。

## 4. 边界情况

- 重复选择同一空间不重复计算其资料，也不重复列出参考文件。
- 空间有权访问但内部没有可检索文件时，按无结果处理，不扩大范围。
- 某空间检索失败时整体返回错误，不静默交付不完整答案。
- 数据库与索引状态存在延迟时，遵守既有检索结果最终可见性过滤。
- 多份资料存在冲突时，回答应说明差异，不将相互矛盾的内容合并成确定结论。
- 参考文件来自提供给模型的资料，不能直接据此取得原件下载权限。
- 模型服务具有非确定性；以权限隔离、实际参考资料和受控样本验收，不承诺完全杜绝生成偏差。
