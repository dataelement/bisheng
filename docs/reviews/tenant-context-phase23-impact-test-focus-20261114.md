# 租户上下文二、三阶段影响范围与测试重点

2026-11-14。本地开发交付；未合并、推送、部署或现场修数。记录见[开发交付](../../features/v3.1.0-beta1/009-managed-tenant-consistency/phase23-delivery.md)。本文尽量使用中文全称；HTTP指网页接口，WebSocket指长连接，SSE指服务器发送事件流，OpenFGA指外部资源授权服务，UNKNOWN表示事实尚不能证明，PARTIAL表示仅部分验证。

## 变化及影响

| 范围 | 新行为 | 兼容与重点 |
| --- | --- | --- |
| 超管管理视图 | 租户读写统一校验有效选择与页面目标；本人政策保持真实主属 | 所有GET也校验；旧页面需更新，不能只替换后端 |
| 普通用户/租户管理员 | 默认真实所属租户，异租户头拒绝 | 回归同主属菜单、配额、资源动作和Root合法共享 |
| 组织/人员 | 仅当前业务挂载子树；Root存储不改，Root视图排除子租户 | 树、搜索、定位、统计、归档、角色候选和移动；Root祖先移动不能间接搬其他租户 |
| 跨租户兼属 | 成员事实可见，普通政策仍按真实主属 | 兼属页不能绑定外国角色或启禁/重置外国主属账号；本人昵称和主部门不变 |
| 创建用户 | 子租户旧表单将新账号初始化到其挂载根 | Root无部门旧账号保留；错误角色/组在创建前拒绝；创建后复读主属和主部门 |
| 创建人/授权记录 | 已知人员姓名可跨主属显示；部门按业务归属解释 | Root人员创建子租户资源仍显示真实创建人，不造兼属；授权部门姓名、摘要和权限解释可读 |
| 网关 | 仍执行敏感词/部门限流，通过后端校验对象；旧组资源410 | 工作流/助手/部门分别正负配对；手工同步平台操作，旧日志明确平台汇总 |
| 两套网页与原生流 | 自举后携带目标，未知切换暂停，流/连接固定原目标 | 首次/刷新/多标签/旧应答/网络错误/取消及SSE、WebSocket |
| Worker | 关键工作流/导出/复制核对持久目标 | 切换后不串目标，错头与旧缓存拒绝；平台周期任务仍运行 |
| 历史数据 | 保留原编号、归属、菜单、绑定、用量；只读盘点 | 新门禁可能拒绝坏行；合法跨范围不判坏，未知不能自动改成当前租户 |

## 建议验收顺序

1. 匹配部署两前端、Python、Java及Worker并刷新缓存；用专用测试管理员和两个租户，不复用既有业务资源。
2. 首次登录自举→切换→工作流/工具/知识及工作台读取/创建→复读父子归属和创建人。配对缺目标、错误目标及普通人员越界请求。
3. 用Root存储挂载样本验组织树、搜索/统计、成员编辑及用户创建；检查跨租户兼属不获得角色，Root视图不显示子租户。
4. 授权名册、角色菜单、普通政策、审批及本人配额；特别核验Root创建人、共享角色所有者和业务部门名称。
5. 流/长连接建立后切换；投递旧/错目标工作流、导出和复制消息，确认拒绝不产生副作用且平台任务正常。
6. 网关敏感词/部门限流正负路径、已知无权与未知范围、退役410；检查新增校验延迟。
7. 真实MySQL/DM8逐页只读盘点及外部OpenFGA/存储验证，保留原始报告和截断位置；发现歧义另列修复单，不运行自动修数。

完整八列用例见[test-cases.md](../../features/v3.1.0-beta1/009-managed-tenant-consistency/test-cases.md)，现场步骤见[e2e-checklist.md](../../features/v3.1.0-beta1/009-managed-tenant-consistency/e2e-checklist.md)。本地测试不等于现场验收；历史角色逐行修正及行政划分承接不在本批。
