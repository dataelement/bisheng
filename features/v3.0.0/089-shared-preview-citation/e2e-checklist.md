# 文件预览与引用共享：验收清单

前后台连接同一套测试环境，使用已有的知识库、工作流、助手和会话记录。无需升级后端。建议按下面四组顺序测试。

## 1. 知识库文件预览

- [ ] Excel/CSV：表格内容正确；多工作表可以切换；原有图片可以查看。
- [ ] PDF：翻页、缩放和滚动正常；横竖混合页面没有错位。后台选择切片、反向拖动框选、定位和保存正常。
- [ ] DOCX、Markdown、TXT：正文和已有格式正常，可以滚动；代码没有额外空行。
- [ ] HTML：正文正常，允许的脚本可以运行；预览内容不能访问宿主页面或登录信息。
- [ ] 图片、音视频：保留原有查看及播放操作；转写内容正常；下载的是原文件。
- [ ] 图片或媒体第一次加载失败，切到另一份再回来可以重新加载。
- [ ] 失效或无权访问的文件：结束加载并显示提示，不停留在空白成功状态。

## 2. 会话中的引用

分别从工作流、助手、日常/任务会话及后台调试/历史记录进入。

- [ ] 来源列表可以打开；文档、网页、文章和临时上传来源没有串类型、丢编号。
- [ ] PDF 的多个引用片段正确高亮、定位；DOCX/Markdown/TXT 能定位正文，匹配不到时显示引用内容。
- [ ] 媒体引用播放原文件，同时显示转写；下载没有变成转写文本。
- [ ] 快速点击 A → B → A，再关闭预览；最终内容对应最后一次选择，关闭后不会自动重新弹出。旧请求正常返回或被取消都可以。
- [ ] 普通用户、分享页或过期来源遇到拒绝访问时，不会显示之前缓存的文件；切换账号/分享上下文后也不复用旧结果。
- [ ] 日志、审计、分享等只读入口仍只执行获准的复制/预览/下载，打开预览不会新增消息、标注或 QA。
- [ ] 后台知识引用关闭后重新打开会刷新签名；完整临时来源不依赖已失效的注册记录。
- [ ] 旧会话中的来源仍可查看；后台来源段落之间切换时，PDF 不反复重新加载。

## 3. 图表

- [ ] 会话和后台看板的 ECharts、Mermaid 正常显示；原有源码切换、缩放、导出等操作正常。
- [ ] 前后台分别启动或部署，都能访问自己的图表资源；同页多个图表不会重复插入同一脚本。
- [ ] 首次加载断网后恢复，重新打开图表可以重试。

## 4. 展示复核

- [ ] 中文、英文、日文没有翻译键或未替换参数。
- [ ] 桌面、窄屏及现有深色模式下，正文、抽屉和操作仍清晰可用；请设计人员复核视觉。
- [ ] 后台标注、QA、审计入口原有业务操作没有缺失。

自动测试与真实浏览器样本的覆盖范围见 [验证记录](verification.md)。以上复选框留给真实业务环境验收，不代表已经人工验收。
