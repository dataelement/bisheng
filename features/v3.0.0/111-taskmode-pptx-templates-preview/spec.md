# Feature: 任务模式 PPT 内置模板与在线预览

> **本文档定位 — 纯 What**。本文只回答做什么、验收标准和不做什么。How 的唯一真相在 [design.md](./design.md) 与 [tasks.md](./tasks.md)。

**关联需求**: [discovery.md](./discovery.md)（dsh-desktop 调研结论及用户决策 D1–D4）
**优先级**: P1
**所属版本**: v3.0.0（发版线 `feat/3.0.0`）
**依赖**: 既有任务模式内置技能机制、任务模式结果区预览、F089 共享文件预览（PDF 查看器）

> **范围边界**
> - **本次纳入**：
>   - PPT 技能内置 5 套场景模板：红韵（央国企与党政汇报）、蓝图（项目与技术方案）、经营（管理层经营与数据汇报）、深空（科技产品发布）、课堂（培训课件）。生成方式改为"按模板版式填写内容"。
>   - PPT 技能的交付前检查新增四项：容量超限、示例文字残留、连续同版式、封面焦点。
>   - PPT 技能的指引改为内容先行：每页先确定一句首读结论，再选版式。
>   - 任务模式结果区对 `.pptx` / `.ppt` 交付物的在线预览，含分享页。
> - **本次明确排除**：
>   - 声明式中间格式与编译器、模型专用 PPT 工具（第二期；本期继续走代码执行器）。
>   - 让用户在界面上挑选模板的入口（本期由用户在对话里说明风格或场景）。
>   - 企业或租户级模板库，以及"上传一次模板后反复复用"（另立 feature）。
>   - 用户上传模板路线的生成方式改造（保持现状）。
>   - 配图生成。
>   - 把交付前检查升级为不可绕过的工具层门禁（本期仍由技能指引要求模型执行）。
>   - 任务模式中用户上传的 pptx 的预览方式（保持现有"解析正文"预览）。
>   - 日常模式、知识库等其他入口的 pptx 预览（知识库已有预览，不改）。
>   - 管理端技能文件查看页对二进制文件显示乱码（已知限制，不修）。

---

## 1. 用户故事

- **A. 业务用户**：作为在任务模式里做汇报材料的员工，我希望说一句"做一份年度工作汇报，央国企风格"，就能拿到版式专业、页面有变化、不压字的 PPT，以便少返工、直接用于汇报。
- **B. 业务用户**：作为拿到 PPT 交付物的员工，我希望在结果区直接翻页查看，不用先下载再用 Office 打开，以便快速判断要不要让任务继续修改。
- **C. 分享接收人**：作为通过分享链接查看任务结果的人，我希望同样能在线翻看 PPT，以便在没有 Office 的设备上也能审阅。
- **D. 平台管理员**：作为维护内置技能的管理员，我希望新模板随部署自动可用，并且我对技能的定制不被升级覆盖，以便升级时不用手工处理。

## 2. 验收标准

### 2.1 内置模板与生成

- **AC-01** — THE SYSTEM SHALL 随部署内置 5 套 PPT 模板：红韵、蓝图、经营、深空、课堂。每套至少 12 个可编辑版式。每套都覆盖封面、目录、章节页、观点页、图文两栏、卡片网格、大数字指标、图表加解读、对比、流程、时间轴或路线图、表格、结尾这 13 类，各套另有符合其场景的专属版式。
- **AC-02** — WHEN 用户在任务模式中要求制作 PPT、未上传模板、也未要求自由设计, THE SYSTEM SHALL 基于一套内置模板生成。用户点名风格、行业或场景时，选用对应模板。
- **AC-03** — WHEN 用户上传 .pptx/.potx 模板并要求套用, THE SYSTEM SHALL 以用户模板为准生成，不改用内置模板。
- **AC-04** — WHEN 用户明确要求自由设计，或 5 套模板均不贴合主题, THE SYSTEM SHALL 仍能从零生成 PPT，交付前检查照常执行。
- **AC-05** — THE SYSTEM SHALL 使交付的 PPT 中标题、正文、表格和图表都是可在 PowerPoint/WPS 中直接编辑的原生对象。不得用整页图片代替文字、表格或图表。
- **AC-06** — THE SYSTEM SHALL 使交付文件不包含模板原型页。
- **AC-07** — THE SYSTEM SHALL 使模板中文文字声明东亚字体（微软雅黑或黑体）。在 Windows 版 PowerPoint 与 WPS 打开时，中文显示为模板指定字体，不回退为宋体或主题默认字体。
- **AC-08** — THE SYSTEM SHALL 在 PPT 技能指引中要求先写逐页大纲，每页包含首读结论、所选版式和支撑证据，并要求按内容关系选择版式。
- **AC-09** — WHEN 部署使用不暴露技能目录的执行环境（E2B）, THE SYSTEM SHALL 让技能向用户说明模板和检查不可用，并改走从零生成。不得反复重试或静默产出低质量文件。

### 2.2 交付前检查

- **AC-10** — WHEN 模型对生成的 PPT 运行交付前检查, THE SYSTEM SHALL 逐条报告以下四类问题，每条注明页码和元素名称：
  - 文字超出所在区域的建议字数容量。
  - 残留模板示例文字。
  - 连续 3 页及以上使用同一版式。
  - 封面缺少首读焦点：最大标题字号不到正文字号中位数的 3 倍，并且没有占画布 25% 以上的视觉元素。
- **AC-11** — THE SYSTEM SHALL 不把模板自带的结构元素（分隔线、色块、编号底图）报告为问题。对一份按模板正确填写、未改动结构的文稿，四类新检查均不报。
- **AC-12** — THE SYSTEM SHALL 保持既有检查（溢出、越界、文字重叠、字号过小、残留占位符等）的报告口径不变。本次新增的四类问题首期以"警告"级别报告，不改变"结论: 通过"的判定规则。

### 2.3 内置技能的分发

- **AC-13** — WHEN 平台启动或新建租户, THE SYSTEM SHALL 使新版 PPT 技能（含 5 套模板）对该租户的任务模式可用，模板文件在任务工作区中与源文件字节一致。
- **AC-14** — IF 管理员已修改过内置 PPT 技能, THEN THE SYSTEM SHALL 在升级时保留管理员版本，不以新版覆盖。

### 2.4 pptx 在线预览

- **AC-20** — WHEN 用户在任务模式结果区打开一个由任务生成的 .pptx 或 .ppt 文件, THE SYSTEM SHALL 在结果区逐页展示该文件，支持翻页、缩放和滚动。
- **AC-21** — WHILE 预览正在生成, THE SYSTEM SHALL 显示"正在生成预览"的状态。IF 超过 90 秒仍未生成, THEN THE SYSTEM SHALL 结束等待，按 AC-23 处理。
- **AC-22** — WHEN 同一文件的预览已经生成过, THE SYSTEM SHALL 直接展示已生成的预览，不再重新生成。这一条对其他用户、其他服务节点和重启后都成立。
- **AC-23** — IF 预览生成失败或超时, THEN THE SYSTEM SHALL 结束加载状态，显示本地化的失败提示，并提供原文件下载。不得显示空白的成功状态。失败后 5 分钟内再次请求，THE SYSTEM SHALL 直接返回失败，不重复转换（避免轮询和多个标签页反复占用转换资源）；超过 5 分钟后再次打开，THE SYSTEM SHALL 重新尝试生成。
- **AC-24** — THE SYSTEM SHALL 只向有权下载该文件的人提供预览，即任务所有者、管理员和持有效分享链接者，与现有下载权限一致。IF 请求者无权访问，或请求的文件不属于所指的任务结果, THEN THE SYSTEM SHALL 拒绝请求，且不生成预览。
- **AC-25** — WHEN 分享链接的接收人在分享页打开 pptx 交付物, THE SYSTEM SHALL 按 AC-20 至 AC-23 提供同样的预览。
- **AC-26** — WHILE 展示 pptx 预览, THE SYSTEM SHALL 提示"预览为服务器渲染，字体与排版可能与 PowerPoint 略有差异，以下载文件为准"。
- **AC-27** — WHEN 多个请求同时首次打开同一文件, THE SYSTEM SHALL 只生成一次预览，其余请求等待同一结果。
- **AC-28** — THE SYSTEM SHALL 使"下载"仍然得到原始 pptx/ppt 文件。预览不改变交付物本身，也不改变结果区其他文件类型的预览方式。
- **AC-29** — THE SYSTEM SHALL 为本功能新增的界面文案和错误提示同时提供简体中文、英文和日文。

### 2.5 交付验收

- **AC-30** — WHEN 用同一组题目（至少包含"央国企风格的企业介绍"、"项目技术方案"、"培训课件"三类）分别在改造前后的技能上各跑一次, THE SYSTEM SHALL 达到以下结果：
  - 每份 8 页及以上的文稿至少使用 5 种不同版式。
  - 检查结论无 ERROR。
  - 渲染对比由产品确认优于改造前。
  - 对比材料（逐页联系表）随验收记录归档。
- **AC-31** — THE SYSTEM SHALL 在合入前取得设计或产品对 5 套模板视觉的签字确认。

## 3. 边界情况

- 历史任务（本功能上线前生成）中的 pptx，打开时同样可以预览。
- 交付物文件名含中文或空格时，预览与下载均正常。
- 文件损坏或预览生成出 0 页时，按 AC-23 失败处理；5 分钟冷却期过后再次打开会重新尝试。
- 用户只要求改已有 PPT 的文字时，沿用用户文件，不套内置模板。
- 用户要求英文 PPT 时，模板版式同样可用，西文使用模板指定的西文字体。
- 文稿超过模板版式可承载的内容时，拆成多页或精简文案，不靠缩小字号塞入。
- 分享链接失效后，预览与下载一同不可用。
