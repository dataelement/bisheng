# 级联选择 Cascader

沿着父子层级逐步缩小范围，最后把完整路径作为值交给业务。组件库 `@bisheng/ui` 导出 **`Cascader`**；触发器和浮层沿用 Select 的实现，桌面端展开多列，手机端在同一个浮层里逐级切换。

## 基础用法

默认只选择叶子。点父项打开下一列，点叶子完成选择并关闭；选择框只回显最后一级名称，值仍是完整路径数组。

```tsx
import React from 'react';
import { Cascader } from '@bisheng/ui';

const OPTIONS = [
  {
    value: 'headquarters',
    label: '总部',
    children: [
      {
        value: 'product',
        label: '产品部',
        children: [
          { value: 'design', label: '设计组' },
          { value: 'frontend', label: '前端组' },
        ],
      },
      {
        value: 'delivery',
        label: '交付部',
        children: [{ value: 'design', label: '设计组' }],
      },
    ],
  },
  {
    value: 'east',
    label: '华东区',
    children: [{ value: 'shanghai', label: '上海团队' }],
  },
];

export default () => {
  const [value, setValue] = React.useState(['headquarters', 'product', 'design']);
  return (
    <Cascader
      options={OPTIONS}
      value={value}
      onChange={setValue}
      placeholder="请选择所属团队"
      className="w-72 max-w-full"
      aria-label="所属团队"
      emptyText="暂无数据"
      noMatchText="无匹配结果"
      loadingText="正在加载…"
      loadErrorText="加载失败，请重试"
      clearLabel="清除"
      backLabel="返回"
      searchPlaceholder="搜索团队"
    />
  );
};
```

## 手机端交互

手机宽度小于 576px 时，面板仍紧邻选择框展开，不从底部弹出，也不加遮罩。始终只显示当前一级；点父项进入下一级，二级及以下的左上角显示返回按钮，旁边显示当前父级名称。返回会恢复上一层的滚动位置和高亮，已选值保留。

面板宽度跟随选择框，紧凑触发器至少提供 160px 菜单宽度，并受视口限制；下方空间不够时自动向上展开，列表在剩余高度内滚动。选项与 Select 一样高 32px；返回使用 24px 的 small 图标按钮，导航行不加分割线。搜索位于同一浮层内。单选点叶子即关闭，多选勾选即时生效，不设「完成」按钮，点面板外、再次点选择框或按 ESC 收起。

## 多选

父项复选框默认联动所有已加载叶子；只选一部分时显示半选。标签只显示最后一级名称，同名叶子也不补上父级路径；完整层级可在面板和搜索结果中查看。

```tsx
import React from 'react';
import { Cascader } from '@bisheng/ui';

const OPTIONS = [
  {
    value: 'space-a',
    label: '产品知识空间',
    children: [
      { value: 'manual', label: '产品手册' },
      { value: 'faq', label: '售后 FAQ' },
    ],
  },
  {
    value: 'space-b',
    label: '企业知识空间',
    children: [
      { value: 'manual', label: '员工手册' },
      { value: 'policy', label: '制度文件' },
    ],
  },
];

export default () => {
  const [value, setValue] = React.useState([['space-a', 'manual']]);
  return (
    <Cascader
      multiple
      options={OPTIONS}
      value={value}
      onChange={setValue}
      placeholder="请选择知识库"
      className="w-80 max-w-full"
      aria-label="知识库"
      backLabel="返回"
      clearLabel="清除"
      removeLabel="移除"
      searchPlaceholder="搜索知识库"
    />
  );
};
```

## 长列表与逐级返回

长列表只滚动当前一级。手机上返回会保留上一层的位置，并高亮刚才进入的父项；再次打开则定位到已选项。此例关闭搜索，便于直接体验逐级浏览。

```tsx
import { Cascader } from '@bisheng/ui';

const OPTIONS = Array.from({ length: 16 }, (_, department) => ({
  value: `department-${department}`,
  label: `业务部门 ${department + 1}`,
  children: Array.from({ length: 12 }, (_, team) => ({
    value: `team-${department}-${team}`,
    label: `第 ${department + 1} 部门 · 工作团队 ${team + 1}`,
  })),
}));

export default () => (
  <Cascader
    options={OPTIONS}
    defaultValue={['department-10', 'team-10-8']}
    showSearch={false}
    className="w-72 max-w-full"
    aria-label="团队浏览"
    backLabel="返回"
  />
);
```

## 任意层级可选

每一级本身都是有效答案时才开 `checkStrictly`。单选父项左侧出现单选圆点；点圆点选择，点文字继续展开。多选时父子节点互不联动。

```tsx
import React from 'react';
import { Cascader } from '@bisheng/ui';

const OPTIONS = [
  {
    value: 'all',
    label: '全部区域',
    children: [
      { value: 'east', label: '华东区', children: [{ value: 'shanghai', label: '上海' }] },
      { value: 'south', label: '华南区', children: [{ value: 'shenzhen', label: '深圳' }] },
    ],
  },
];

export default () => (
  <Cascader
    checkStrictly
    options={OPTIONS}
    defaultValue={['all', 'east']}
    className="w-64 max-w-full"
    aria-label="区域"
    backLabel="返回"
    clearLabel="清除"
    searchPlaceholder="搜索区域"
  />
);
```

## 搜索与懒加载

可选节点超过 10 个时自动开启搜索，也可用 `showSearch` 显式控制。懒加载节点写 `isLeaf: false`，`loadData` 返回下一层；请求期间只替换当前行箭头，不冻结整张面板。未加载完整的父项不会提供“全选后代”。

```tsx
import { Cascader } from '@bisheng/ui';

const OPTIONS = [
  { value: 'north', label: '北方区域', isLeaf: false },
  { value: 'south', label: '南方区域', isLeaf: false },
];

export default () => (
  <Cascader
    options={OPTIONS}
    showSearch
    loadData={async (option) => {
      await new Promise((resolve) => setTimeout(resolve, 600));
      return [
        { value: `${option.value}-1`, label: '第一团队' },
        { value: `${option.value}-2`, label: '第二团队' },
      ];
    }}
    placeholder="请选择团队"
    className="w-64 max-w-full"
    aria-label="团队"
    emptyText="暂无数据"
    noMatchText="无匹配结果"
    loadingText="正在加载…"
    loadErrorText="加载失败，请重试"
    backLabel="返回"
    clearLabel="清除"
    searchPlaceholder="搜索团队"
  />
);
```

## API

| 属性 | 说明 | 类型 | 默认 |
|---|---|---|---|
| `options` | 层级选项 | `CascaderOption[]` | — |
| `multiple` | 多选，默认父子联动 | `boolean` | `false` |
| `value` / `defaultValue` | 单选为路径，多选为路径数组 | `CascaderPath \| null` / `CascaderPath[]` | — |
| `onChange` | 返回结构化路径和对应选项路径 | `(value, options) => void` | — |
| `checkStrictly` | 任意层级独立可选 | `boolean` | `false` |
| `expandTrigger` | 桌面端展开方式；手机始终轻点进入 | `'click' \| 'hover'` | `'click'` |
| `showSearch` / `onSearch` / `filterOption` | 本地或服务端路径搜索 | — | 可选节点 > 10 时开启 |
| `autoWidth` | 触发器随所选名称自然伸缩，仍遵守外部最大宽度；搜索时保持所选名称宽度 | `boolean` | `false` |
| `loadData` / `onLoadError` | 懒加载子节点与失败回调 | — | — |
| `size` / `status` / `variant` | 与 Select 同义 | — | `medium` / `default` / `outlined` |
| `radius` / `panelRadius` | 触发器与面板圆角 token | — | 随尺寸 / `xl` |
| `allowClear` / `onClear` | 清除当前值 | `boolean` / `() => void` | `false` |
| `open` / `defaultOpen` / `onOpenChange` | 受控展开 | — | — |
| `placeholder` / `emptyText` / `noMatchText` / `loadingText` / `loadErrorText` | 展示文案 | `ReactNode` | 英文兜底 |
| `backLabel` / `clearLabel` / `removeLabel` / `searchPlaceholder` | 手机和无障碍文案 | `string` | 英文兜底 |

`doneLabel` 仅为兼容旧调用保留，已不再渲染完成按钮。

`CascaderOption`：`value`、`label`、`children`、`disabled`、`isLeaf`、`icon`。`isLeaf: false` 且没有 `children` 表示子项尚未加载。
