2. 公共准备与数据

PREP-114

在同一租户 T1 内准备：用户 U_bind（Token 绑定）、用户 U_up（知识上传人，≠ U_bind）、用户 U_ext（带全局唯一 external_id，用于 F069）、用户 U_denied（对目标空间无写权限，用于 AC-3）。准备 SPACE 知识库 K1，使 U_bind 对 K1 有上传权，U_denied 无上传权，U_up 权限与 AC 场景一致（AC-3：U_up 有权、U_bind 无权）。创建 Developer Token：绑定 U_bind，knowledge_uploader_user_id = U_up；HMAC 秘文明文仅在 fixture 内持有。请求带 X-Developer-Token。清理：删除本用例创建的 KnowledgeFile 行与测试 Token。

证据边界：pytest 中断言 KnowledgeFile.user_id、original_uploader_id（及必要时 user_name）；MinIO/解析链可用既有 mock；不宣称 DM8/OpenFGA 真实环境已验证。
