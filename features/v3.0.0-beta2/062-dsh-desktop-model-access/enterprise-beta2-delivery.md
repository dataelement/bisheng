## 测试环境准备

沿用 F062 企业登录的 Gateway、许可证、可信服务和租户配置。数据库迁移在 beta2 的 `f062_profile_version` 上顺序增加 `f064_enterprise_market`，适用于该基线测试环境。3006 历史组合环境已有 `f063_dsh_market_merge`，迁移图需单独衔接后再部署。

已有角色策略的测试库切换部门树时，先使用 `src/backend/scripts/dsh_migrate_role_policies.py` 输出迁移计划，核对成员最终额度后添加 `--apply`。操作方法见 `src/backend/scripts/README.md`。

本次动作是源代码分支推送；当前运行环境版本由各自发布记录管理。
