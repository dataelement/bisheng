# 项目跨端实时同步：确认的需求来源

2026-11-06，用户在 Desktop 项目中提出：

> 在工作区下面还有一个项目的分类。然后再下面就是对话功能。

Desktop 项目界面完成后，用户补充：

> 功能完成了，但数据还不互通啊？我要数据和对话一样是能互通且实时同步的。

经核查，Web 和 Desktop 各自的项目列表、对话归属均为本机浏览器存储，后端尚无项目能力。已向用户说明真正互通需要补齐后端共享存储并接入 Web 和 Desktop。

用户已明确选择“由你完成三端改造（推荐）”，确认以下需求范围：同账号共享项目及对话归属、操作后自动同步、断线恢复，并保留和迁移已有本机项目；随后要求继续。

该确认属于需求发现阶段。正式规格与设计按仓库 SDD 确认点分别提交用户审阅；本文件不构成已经完成代码、部署或联合验收的声明。
