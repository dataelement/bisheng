核对日期：2026-10-16。桌面使用 bisheng-work/V1.2.0，工作目录 `.worktrees/bisheng-work-chat-work`，本地及远端基线 `5b14db873105d2b3d937e7512619e20e4914507f`，安装的 Harness 为 0.2.0-rc.2。Chat 使用 `.worktrees/bisheng-dsh-chat-3006`，后端保持 feat/3.0.0-beta4。本次修改为前端展示与空过程区域收敛。

## 知识空间交互（2026-10-16 更新）

Chat 的添加资料入口统一到“＋”：上传文件和选择知识空间。知识空间采用搜索、多选、确认添加弹窗，输入框内通过统一的横向资源卡片显示已选空间。新建与续聊均可补充知识空间；工具、技能和深度研究在新建页配置。弹窗草稿只在确认时应用，取消、关闭及 Esc 保留原选择，沿用企业可见范围和每类 50 项上限。此规则取代此前续聊隐藏全部知识入口的规则。

beta5 使用共享 Modal；3006 beta4 使用该版本现有 Dialog。Portal 容器显式取得 Chat 的主题变量，弹窗底色、输入文字和次要按钮一起适配桌面主题。

## 交互边界

- 本次没有修改登录、历史 API、消息持久化、上传请求和工具调度协议。

## 输入框与上下文资源（2026-10-16 更新）

输入框采用 DSH 的整体结构：上层显示已选资源，中层输入文字，底部左侧为“＋”，右侧为模型与发送/停止。Skill、工具和深度研究位于加号菜单内；会话创建后继续由 allowConfiguration 收起能力配置。

文件、知识空间、目录与技能共用 ContextResourceCard，宽 224px、高 56px，图标、名称、类型或大小使用一致的层级。卡片保持上传顺序，超出横向滚动；删除按钮支持悬停、键盘焦点和触屏。知识空间作为参与上下文的资源在新建与续聊中均可选择、查看和移除。

ChatResourceMenu 统一承载上传文件、知识空间、工具与深度研究，技能通过子菜单选择。KnowledgeSpaceDialog 继续使用企业可见空间列表、每类上限和确认草稿逻辑；关闭后焦点回到加号。既有组织知识库数据仍按原会话协议处理，Chat 的新增资料入口展示知识空间。

主题来源依次为桌面宿主、毕昇页面外观偏好、系统偏好。嵌入时根节点 class 与宿主同步，使 Portal 弹窗和语义颜色同源；独立网页跟随用户设置，系统变化只作用于跟随系统模式。

侧栏 Chat 行与 Work 行采用相同标题左距、32px 行高和 10px 时间。长标题在悬停或键盘聚焦时横向展示，离开复位，遵循减少动态效果偏好。桌面仍由原生侧栏管理项目归属与本地任务。

## feat/bisheng-work-103 合作边界

网页源码交付以目标分支的 beta5 逻辑为准。ChatView 保留现有会话模型选择、知识权限过滤与研究引用对照；Chat 的外观由 dsh-chat-* 类名控制。附件和知识已选项共用输入框内的横向资源卡片，Skill、工具、深度研究位于新建输入框的加号菜单内。平台基础导航继续用于独立网页；embed=dsh 入口由桌面提供左侧导航。

3006 的后端保持 beta4。本次 Git 交付覆盖 client 和文档；对目标分支的完整实机验收与环境升级分别记录。

## 桌面首次发送状态

ChatView 的消息与流式状态为欢迎页的权威状态。桌面专用可选 `dshChatPresentation.reportLanding(boolean)` 只上报展示状态；企业凭据、文件和本地执行接口继续由宿主负责。KeepAlive 页面按当前路由过滤上报。网页先显示用户消息，桌面同步收起模式选择，服务端分配会话 ID 后继续沿用现有会话同步流程。独立网页无需此接口。

## 会话创建后的能力边界（2026-10-16）

新建页配置 Skill、工具、深度研究。首次提交后，allowConfiguration 收起能力配置入口；原有配置继续生效。加号中的文件与知识空间支持后续补充，已选资源以卡片呈现。模型、发送/停止沿用既有交互。

加号右侧显示已启用的联网搜索、深度研究标签；标签取消操作与加号菜单勾选共用状态，未启用时收起。窄窗口通过标签区域横向滚动保留模型和发送按钮空间。
