# F062 平台现场 E2E 手动清单

状态：待专用集成环境执行。BASE、部署 SHA、DSH Desktop 版本、负责人、执行日期及结果填写于交接记录；不要使用真实业务用户。

## 浏览器与客户端授权（AC-01/02/03/13/32；C01–C06）

- [ ] 打开 `{BASE}/desktop-login`，未登录时复用现有平台登录/SSO；普通用户仍返回当前 auth_id，不被管理台权限重定向。
- [ ] 无 auth_id 固定入口不签票据，只提供确认平台后的深链唤起；未安装时下载配置或联系管理员/BASE 复制可用。
- [ ] 在客户端建立新 PKCE 后打开带 auth_id 的页面，显示当前真实账号/租户；未点确认前不调用成功 authorize。
- [ ] 点击拒绝，客户端收到 access_denied；不包含 identity_ticket、不新增席位。
- [ ] 点击确认，真实 loopback 收到当前 auth_id/state/ticket，客户端换证一次并存 OS 安全存储；页面可回到客户端。
- [ ] 浏览器拦截 loopback 时复制一次性票据到当前事务；过期票据从页面内存清除，必须重建事务。
- [ ] 对重复回调、错误 state、旧 auth_id 与已消费票据逐项负测；截图/console/network导出不保留真实票据或 bearer。

## 管理权限与席位（AC-08/09/11/25/26/28/29/30/33）

- [ ] Root/T1 管理员可以进入系统 DSH；普通用户/部门管理员不出现该入口，直接请求管理 API 被拒绝。
- [ ] T1 只显示本租户；Root 可查看 T1/T2 已有席位；切换租户范围重新核验。
- [ ] 通过用户名检索，验证席位状态、登录状态筛选；页面和请求均无部门筛选，300ms 防抖与游标分页符合预期；旧请求不覆盖新列表。
- [ ] 会话列表独立分页，列表没有模型/用量列；Gateway 不可用时显示不可用，不显示假零席位/假零会话。
- [ ] 同人两设备仍一席，退出一个设备另一个保留，全部退出仍占席。
- [ ] 撤销/重分配明确二次确认，操作编号不变；PROCESSING 与失败不显示成功；刷新后 GET 状态一致。
- [ ] 连续两次操作能分别查看 actor/目标/版本/前后值/committed/effective；离开页面取消轮询，回看操作可继续查。

## 模型与额度（AC-18/19/20/22/23/27/29/34）

- [ ] 用户搜索可选从未占过席位的用户；保存策略不自动分配席位。
- [ ] 合法 Root 共享上线 LLM 可选，模型按 ID 区分，同名不混淆；未验证能力由服务端拒绝并保留选择。
- [ ] 空模型集合或限额 0 显示禁止调用说明；输入非法整数不能保存。
- [ ] 并发版本冲突后保留输入、刷新核对版本；超时先查询/重试同一操作，不能伪造成功。
- [ ] 900/1000 两个在途各 300 最终实际显示 1500；已达限后的新请求 429，在途仍完整返回。
- [ ] usage 区分 live/persisted/unavailable，展示 month/timezone/as_of 和各模型量；UNKNOWN 不显示 0、不提供强制清除。
- [ ] 实际工具/SSE/取消/reasoning_content 完整用例按 [C12–C18](desktop-handoff-checklist.md) 验证。
