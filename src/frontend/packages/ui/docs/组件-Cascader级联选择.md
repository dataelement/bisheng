> 设计系统 · 级联选择 v1 · 2026-10-21 建档

> 调研来源（不进展示层）：[Ant Design Cascader](https://ant.design/components/cascader-cn/)（关联数据、多列浮层、叶子 / 父节点选择、多选、搜索、懒加载；`large` / `medium` / `small` 与 Select 同属选择器外壳；组件 token 包含 184px 控件宽、111px 选项宽、180px 菜单高）、[Arco Design Cascader](https://arco.design/react/components/cascader)（多层级选择；`mini` / `small` / `medium` / `large`；点击默认、悬停可选；多选、父节点可选、搜索、加载）、[Element Plus Cascader](https://element-plus.org/zh-CN/component/cascader.html)（逐级查看；`large` / `default` / `small`；完整路径回显、多选、任意层级选择、搜索、懒加载、独立面板）。无障碍交互依据：[WAI-ARIA Combobox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) 与 [Tree View Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/)。
> 设计师拍板（2026-10-21）：Cascader 独立成组件；触发器样式与 Select 触发器完全一致；菜单外壳、内外间距、选项行、状态、圆角、投影与 Select 菜单完全一致。

级联选择让用户沿着一条层级路径逐步缩小范围，最后选中一个或多个值。它看起来像有子菜单的选择器，但结果会回显在触发器里，不会执行「删除」「导出」这类动作。

## 1. 什么时候用

**用级联选择处理有明确父子关系的数据**，例如「部门 / 团队 / 成员」「知识空间 / 知识库」「分类 / 子分类」。用户需要先看上一级，才能理解下一级时，逐级展开比一张长列表更容易找。

- 选项是平铺列表，用 [组件-Select选择器.md](组件-Select选择器.md)。
- 选项只是分组、组名不可选，用 Select 的分组，不要为了分组做级联。
- 点选后立即执行动作，用 [组件-Dropdown下拉菜单.md](组件-Dropdown下拉菜单.md)；Cascader 只负责选择值。
- 用户需要同时看见大量分支、频繁展开收起或调整父子关系，用树形选择，不要把 Cascader 撑成树管理器。
- 数据通常以 2～4 级为宜；平均路径超过 4 级时，改用树形选择或独立选择页，避免浮层横向铺满屏幕。

| ✅ 推荐 | ❌ 不推荐 | 原因 |
|---|---|---|
| 用「总部 / 产品部 / 设计组」选择所属团队 | 把所有团队拍平成一张同名列表 | 完整路径能区分不同部门里的同名团队 |
| 用 Select 选择「公开 / 私有」 | 为两项平铺选项做两列级联 | 两项没有父子关系，逐级展开只会增加一步 |
| 用 Dropdown 放「导出为 / PDF」 | 把导出动作做成 Cascader，并在框里回显 PDF | PDF 是执行格式，不是字段当前值 |

## 2. 结构 Anatomy

级联选择由**触发器**和**级联面板**组成，两者是一个组件。

| 部分 | 是什么 |
|---|---|
| 触发器 | 收起时显示占位文字或已选路径；外观与 Select 触发器完全一致 |
| 级联面板 | 承载所有可见层级的浮层外壳 |
| 菜单列 | 一个层级一列；当前路径每深入一级，右侧增加一列 |
| 父选项 | 有下一级的选项，右侧带箭头 |
| 叶子选项 | 没有下一级、可以完成选择的选项 |
| 路径 | 从根节点到已选节点的完整层级，如「总部 / 产品部 / 设计组」 |

## 3. 类型 Type

### 3.1 单选

单选是默认类型。点父选项只展开下一级，点叶子选项才完成选择并关闭面板。

### 3.2 多选

需要从同一棵层级数据中挑多个值时使用多选。每行左侧放复选框，选完后面板保持打开；已选结果在触发器里按 Select 多选规则显示标签并折叠为「+N」。

- 勾选父节点时，默认选中它下面的全部叶子节点；只选中一部分时，父节点显示半选。
- 懒加载数据尚未完整返回时，父节点不可「全选后代」——不能把未加载的节点假装成已选。
- 多选不是批量管理器；如果用户需要跨分支查看、对比和整理大量已选项，改用树形选择或独立页面。

### 3.3 任意层级可选

默认只允许选择叶子节点。只有当每一级本身都是有效答案时，才打开「任意层级可选」：

- 单选时，每个可选节点左侧显示单选圆点；点圆点选择当前节点，点文字或右箭头继续展开。
- 多选时，父子节点的复选框互不联动；选中父节点不等于选中它的后代。
- 同一个业务里不要混用「父子联动」和「父子独立」两套含义，用户无法从相同的复选框外观判断差别。

## 4. 尺寸与触发器 Trigger

**触发器直接继承 Select，不另做一套样式。**尺寸、形态、圆角、文字、图标、清除按钮、标签折叠、校验和各状态都以 [组件-Select选择器.md](组件-Select选择器.md) 为唯一规则来源。

| 项 | 规则来源 |
|---|---|
| 描边 / 无边框 / 图标三种形态 | Select §3.1 |
| 24 / 32 / 40 三档高度与下箭头尺寸 | Select §4 |
| 触发器圆角与可配置档位 | Select §5.4 |
| 常态、悬停、聚焦、展开、只读、禁用、错误、警告 | Select §7.1 |
| 多选标签与「+N」折叠 | Select §6.2 |
| 搜索、清除与占位文字 | Select §6.1、§6.3、§6.4 |

- **禁止为 Cascader 增加专属触发器视觉参数**。同一表单里的 Select 与 Cascader 必须一眼看出是同一族控件。
- 展开时下箭头旋转 180°；面板打开期间，触发器保持 Select 的展开态。
- 单选默认回显完整路径，用「 / 」分隔；过长时单行截断，悬停显示完整路径。
- 无边框与图标形态沿用 Select 的使用限制；表单字段仍一律使用描边形态。

## 5. 级联面板 Panel

### 5.1 共用外壳与菜单项

**把每一列都当作一张 Select 菜单。**下面这些规则全部引用 Select，不在本文复制数值，避免两套样式以后各自漂移。

| 项 | 与 Select 的关系 |
|---|---|
| 底色、投影、圆角、层级、与触发器间距 | 完全同 Select §5.1 |
| 菜单内边距、选项行高度、文字、图标、截断 | 完全同 Select §5.1、§5.2 |
| 选项行圆角随面板圆角同心变化 | 完全同 Select §5.4 |
| 悬停、键盘高亮、选中、禁用 | 完全同 Select §7.2 |
| 空、加载、加载更多 | 完全同 Select §6.5 |
| 淡入、位移、淡出动效 | 完全同 Select §8 |

一列 Cascader 在视觉上应与一张 Select 菜单完全重合；只有出现第二列后，用户才看见级联结构。

### 5.2 菜单列

- **每列最小宽 160px、最大宽 240px**。面板至少与触发器等宽；触发器更宽时，把多出的宽度平均分给当前可见列，单列不超过 240px。
- 每列上下左右都保留与 Select 面板相同的内边距。相邻两列之间放 1px `border-base` 分隔线，分隔线两侧各保留一份菜单内边距。
- 每列最多同时露出 8 行，超出后只滚动当前列；切换父选项时，其他列的滚动位置不跟着跳。
- 打开新的父选项时，在右侧增加一列；改选更浅层的父选项时，替换它右侧的全部列，不保留已经失效的路径。
- 父选项右侧放 16px 右箭头，使用 `text-3`；加载子节点时，用同尺寸加载圆环替换箭头。
- 选项文字保持单行，过长时省略；悬停显示完整文字，不用加宽一列把整个面板推走。

### 5.3 面板宽度与位置

- 默认在触发器下方、左边对齐；下方空间不够时翻到上方，不盖住触发器。
- 面板随可见列数向右增长；右侧空间不足时整体向左平移，仍需离视口边缘至少 8px。
- 数据平均路径不得超过 4 级。偶发的第 5 级可以继续展开，但产品设计应优先缩短分类或改用树形选择。
- 面板内不放按钮、说明卡片或第二种选择控件；需要复杂筛选时改用独立选择页。

## 6. 内容形态 Content

### 6.1 路径回显

- 单选默认显示完整路径，如「总部 / 产品部 / 设计组」，让同名节点仍可辨认。
- 多选标签默认显示叶子名称，悬停展示完整路径；存在同名叶子时，标签显示能区分它们的最短路径，如「产品部 / 设计组」。
- 路径分隔符只负责阅读，不属于值本身；复制、提交和回调仍使用各级节点的真实值。

### 6.2 搜索

- **可选择叶子节点总数超过 10 个时默认开启搜索**，阈值与 Select 一致。
- 搜索直接在触发器里输入；搜索期间，把命中的节点按完整路径铺成一列结果，不再要求用户逐层进入。
- 搜索结果每行显示完整路径，命中叶子后按单选 / 多选规则完成选择。
- 本地搜索只覆盖已经加载的数据。服务端或懒加载场景需要搜索全部数据时，由服务端返回完整路径；不要用「无匹配结果」掩盖尚未加载的节点。

### 6.3 懒加载

- 展开未加载的父节点时，右侧箭头换成加载圆环，当前列保持可操作，避免整个面板闪成加载态。
- 加载成功后自动打开下一列；返回空数组时，把当前节点视为叶子节点。
- 加载失败时恢复右箭头，并轻提示「加载失败，请重试」；再次点击该父节点重新加载。
- 同一节点加载期间禁止重复请求。

### 6.4 空与异常

- 根节点为空时，整张面板显示「暂无数据」，画法同 Select 空面板。
- 某个父节点没有子项时，不打开空白列；将它当作叶子处理。
- 搜索没有结果时显示「无匹配结果」；加载失败不冒充空状态。

## 7. 状态 State

### 7.1 触发器

触发器所有状态完全继承 Select §7.1，不新增 Cascader 专属颜色或描边。

### 7.2 选项

| 状态 | 样式 |
|---|---|
| 常态 | 与 Select 选项一致；父选项右侧多一个右箭头 |
| 悬停 / 键盘高亮 | `fill-2` 浅灰底，与 Select 一致 |
| 已展开父项 | 保持 `fill-2` 浅灰底，让当前路径不断开；右箭头不旋转 |
| 已选叶子（单选） | 文字字重 500，右侧 16px 品牌色 ✓，不加选中底色 |
| 已选节点（任意层级单选） | 左侧单选圆点选中，不再重复显示右侧 ✓ |
| 已选 / 半选（多选） | 左侧复选框显示勾选 / 半选，文字样式不变 |
| 禁用 | `text-4`，没有悬停，不可选择；禁用父项也不可进入后代 |
| 加载子项 | 右箭头换成 16px 加载圆环；当前行保持已展开底色 |

**区分高亮与选中。**浅灰底表示「正在看的路径」，勾选或 ✓ 才表示「已经选中」；不要用两种近似底色同时表达这两个状态。

## 8. 交互 Interaction

- **默认点击展开下一级**。点击比悬停更稳定，也能直接迁移到触屏设备。
- 桌面工具栏等需要快速扫过分类的场景可以用悬停展开：指针进入父项 100ms 后打开，移向右侧子列时保留当前路径；触屏自动降级为点击。
- 单选点叶子后立即关闭面板；多选点选后保持面板打开，点外部或按 ESC 关闭。
- 默认模式下，点击父项只展开，不提交值；「任意层级可选」模式通过左侧单选圆点 / 复选框选择父项，避免把「展开」和「选择」塞进同一次点击。
- 重新打开时恢复已选路径，并把每列滚动到路径节点所在位置。
- 键盘上下键在当前列移动；右键展开父项并进入下一列，左键返回上一列；回车展开父项或选择叶子；多选时空格切换复选框；ESC 关闭并把焦点还给触发器。
- 焦点与选中是两件事：键盘移动只改变高亮，不得在经过父项时改掉已选值。

## 9. 移动端适配

通用原则见 [基础-多端适配原则.md](基础-多端适配原则.md)，Cascader 只定义层级面板的差异：

| 项 | 手机档（< 576px） |
|---|---|
| 面板 | 与 Select 一样改为底部滑入面板，宽度铺满，顶部两角 12px、底部直角 |
| 层级 | 不横向并排；点父项进入下一页，顶部显示返回按钮与当前父级名称 |
| 选项行 | 高度升到 44px，满足触屏点击下限 |
| 搜索 | 搜索框放在面板顶部；搜索结果直接显示完整路径 |
| 单选 | 点叶子后立即完成并关闭 |
| 多选 | 勾选即时生效，底部放「完成」按钮关闭面板 |

- 返回上一层时保留原来的滚动位置和选中状态。
- 手机没有悬停；即使传入悬停展开，也必须降级为轻点进入。
- 平板与桌面默认使用多列面板；空间不足时整体平移，不缩小选项行或文字。

## 10. 深浅色

- 触发器与面板颜色全部继承 Select，使用 token 自动翻转，不写 Cascader 专属 `dark:` 颜色。
- 深色模式下面板加 1px `border-base` 描边，规则同 Select §10。
- 列分隔线使用 `border-base`，随深浅色自动翻转；不要用固定灰色。

## 调研附录

### 业内共识

| 设计体系 | 组件定位 | 类型与能力 | 展开 | 尺寸 / 面板线索 |
|---|---|---|---|---|
| Ant Design 6 | 关联数据与大数据集的多级分类选择 | 单选、多选、父节点可选、搜索、懒加载、路径回填 | 点击默认，悬停可选 | `large` / `medium` / `small`；与 Select 同属选择器外壳；组件 token：控件宽 184、选项宽 111、菜单高 180 |
| Arco Design | 用多级分类分隔较多选项 | 单选、多选、严格选择、搜索、路径值、懒加载、虚拟列表 | 点击默认，悬停可选 | `mini` / `small` / `medium` / `large`；输入外壳沿用选择器体系 |
| Element Plus | 清晰层级数据的逐级查看与选择 | 单选、多选、任意层级、完整路径、搜索、懒加载、独立面板 | 点击默认，悬停可选 | `large` / `default` / `small`；虚拟列表行 34px、面板高 204px |

共同结论：Cascader 是独立组件，但触发器属于 Select / Input 家族；组件差异集中在多列面板、路径回显和父子选择关系。三家都提供悬停展开，但默认值都是点击。三家都支持父节点选择或父子解耦，说明这项能力需要显式模式，不能和默认叶子选择混在一起。

### BISHENG 取舍

1. **触发器与菜单不重新定视觉值**：设计师明确要求与 Select 完全一致；本文只定义多列结构的新增值。
2. **点击默认、悬停可选**：跟随三家共同默认值，并保留用户指向的 Dropdown 子菜单式快速浏览能力。
3. **完整路径默认回显**：层级选择的核心价值是保留上下文；只显示叶子会让同名节点失去区别。
4. **桌面多列、手机下钻**：横向子菜单依赖屏幕宽度与精确指针，手机继续横向弹出会越出视口。
5. **默认只选叶子**：父项首先承担导航职责；确实需要选父项时，用显式控件把「展开」与「选择」分开。

## 落地（给实现窗口）

1. **组件位置**：`src/frontend/packages/ui/src/components/Cascader/`，从 `src/index.ts` 导出 `Cascader`；组件只接收数据与文案 props，不引入业务状态、请求或 i18n。
2. **触发器禁止复制样式**：从 `Select/Select.tsx` 抽出同一份选择器触发器内部实现，或让 Select / Cascader 共用 `SelectionTrigger`。必须共用 `Input/shared.ts` 的 `shellStyles`、尺寸、状态链、清除按钮和图标阶梯；不得在 Cascader 里重写一组近似 class。
3. **菜单表面继续共用**：使用 `shared/menuSurface.ts` 的 `panelClass`、`optionClass`、`OPTION_ICON`、`OPTION_CHECK`、`PANEL_MESSAGE`。先把 `panelClass` 当前的菜单内边距与最大高度抽成可共用的菜单列 class；级联外壳取消整体纵向滚动与整体内边距，每个菜单列复用这份 class。禁止在 Cascader 内另写一组 `p-*` / `max-h-*` 值；这样 Select 调整间距或高度时，Cascader 会同步变化。
4. **列尺寸**：列容器 `min-w-40 max-w-60`（160～240px），基础宽度 160px；分隔线 `w-px bg-border-base`。当前可见列共同填满 trigger 多出的宽度，每列封顶 240px。面板用 `min-width: var(--trigger-width)`，碰撞边距 8px。
5. **建议数据结构**：`CascaderOption { value: string | number; label: string; children?: CascaderOption[]; disabled?: boolean; isLeaf?: boolean; icon?: ReactNode }`。单选值默认是完整路径 `(string | number)[]`；多选是路径数组。不要只回调叶子值后再让业务方反查路径。
6. **建议能力**：`multiple`、`checkStrictly`、`expandTrigger: 'click' | 'hover'`、`showSearch`、`onSearch`、`loadData`、`allowClear`、`loading`、`size`、`status`、`variant`、`radius`、`panelRadius`；视觉类 props 与 Select 保持同名同义。
7. **焦点与语义**：触发器用 `role="combobox"`、`aria-haspopup="tree"`、`aria-expanded`、`aria-controls`、`aria-activedescendant`；弹层用 `role="tree"`，节点用 `role="treeitem"` + `aria-level` / `aria-expanded` / `aria-selected` / `aria-disabled`，多选树加 `aria-multiselectable="true"`。DOM 焦点留在触发器，读屏焦点随高亮节点移动。不得复用 Dropdown 的 `menu/menuitem` 语义。
8. **搜索结果**：搜索态切成单列路径结果，但继续使用 `optionClass`；路径是展示内容，选中仍提交结构化路径。服务端搜索必须返回每项完整祖先链。
9. **懒加载与多选**：未加载完的父节点不得显示可操作的「全选后代」复选框，除非 API 同时返回完整后代选择能力；否则会产生看似全选、实际漏选的数据错误。
10. **移动端**：复用 Select 规划中的底部面板基础，不建第二套 Cascader；内部维护当前路径页，返回时恢复每级 `scrollTop`。
11. **文案**：`emptyText`、`noMatchText`、`loadingText`、`loadErrorText`、`backLabel`、`doneLabel`、`clearLabel`、`removeLabel` 全部从 props 传入，组件库不内置中文。
