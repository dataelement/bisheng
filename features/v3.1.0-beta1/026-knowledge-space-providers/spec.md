# F026：知识空间多后端与 WeKnora 接入

状态：2026-11-24 用户确认正式规格 AC-01～AC-37，进入技术设计；不代表设计或实施已获批准。优先级：P0。所属版本：v3.1.0-beta1（CNNC 分支）。

关联 PRD：[2026-11-20 产研需求稿](</Users/binfeng/Downloads/毕昇知识空间与WeKnora集成需求.md>)；[需求追踪 R01–R26](./WeKnora集成需求清单.md)。后续确认的产品口径以[集成方案 §15](./WeKnora集成实现方案.md)为准。依赖：[本版发布契约](../release-contract.md)、既有空间资源、权限、引用及知识处理能力；目标外部环境为 WeKnora v0.9.0 及达到本规格必做行为的扩展。规格确认不代表上游已有该能力。

## 1. 用户故事与范围

- 作为知识管理员，我希望在毕昇创建个人或部门空间，并看清真实生效的模型、处理状态及失败原因，不需要在两个系统间手工同步。
- 作为空间成员，我希望上传资料、查阅 Wiki 并在会话、任务和工作流中引用自己获准使用的资料，而不因存储后端不同改变权限含义。
- 作为运维人员，我希望在中断后认回原操作，恢复未完成步骤，而不是重复建库、越权放行或误删资料。

首期涵盖新建个人/部门外部空间及原生空间兼容。既有原生空间不自动迁移。外部空间不提供上传前编辑分块并冻结提交、schema增删改名及批量值迁移；完整目录移动、独立空目录、完整版本链合并及推荐在能力验证前不开放。不开启受限能力不等于可削减下列必做行为；不迁移普通文档库、FAQ和临时附件业务。

## 2. 验收标准

### 空间和模型（R01–R11）

- **AC-01** — WHEN 用户选择知识空间，THE SYSTEM SHALL 沿用部门、我创建、我加入入口；原生空间继续使用原有行为，外部空间不可用时明确报错，不切换到其他数据源。
- **AC-02** — WHEN 管理员批建部门空间，THE SYSTEM SHALL 逐部门报告建库与授权结果；一项失败重试不得重建已成功空间。成员或管理员被撤销后按剩余授权决定访问。
- **AC-03** — WHEN 创建个人或部门外部空间，THE SYSTEM SHALL 保留基础、访问分享、模型及分块设置；创建同名关联库，仅保留一个生效绑定。绑定准备中不得对外开放内容。
- **AC-04** — IF 必选对话或向量模型缺失、类型或环境不匹配、视觉模型不支持图像或可用性无法验证，THEN THE SYSTEM SHALL 明示问题且不交付就绪空间。提交前展示用途、模型版本/维度、分块和生效开关摘要。
- **AC-05** — WHEN 创建成功，THE SYSTEM SHALL 默认启用Wiki、实体关系抽取、多模态和自动标签；使用所选LLM作摘要模型，Wiki与标签默认继承，视觉模型独立。未指定的其他设置沿用环境默认值。
- **AC-06** — WHEN 管理员经毕昇更新允许的库级设置，THE SYSTEM SHALL 回读实际结果，不覆盖显式用途设置；普通成员只读。新受理任务使用新配置，历史摘要/Wiki只在独立重处理成功后更新。
- **AC-07** — WHILE Embedding已绑定，THE SYSTEM SHALL 对空库和非空库均禁止原地改绑或替换实际模型、版本、维度。变更须在新库完成重建、验证和单一生效库切换。
- **AC-08** — IF 操作响应丢失、重复提交或管理租户变化，THEN THE SYSTEM SHALL 在原租户、原目标查回并恢复，或在远端写入前拒绝不一致请求；结果未知不得视为未执行。

### 入库、治理与原文（R08、R12–R16、R19）

- **AC-09** — WHEN 使用外部空间，THE SYSTEM SHALL 只在WeKnora保存原文、历史字节、解析产物、分块、索引和Wiki；毕昇只保留授权、绑定、关联、计量与恢复所需信息。使用阶段产生的回答、引用及任务记录遵循各自访问和保留规则。
- **AC-10** — WHEN 用户上传一个或多个文件，THE SYSTEM SHALL 先取得稳定的文件版本身份，按目标空间/目录授权，默认继承分块且允许本批覆盖；上传表单不要求填标签。不支持的参数在提交前拒绝。
- **AC-11** — WHEN 远端接收文件，THE SYSTEM SHALL 将接收与解析完成分别展示；同一请求只认回自己的收据，重复内容不能泄漏无权文件。批量部分失败时保留成功项，失败文件可单独恢复。
- **AC-12** — WHEN 用户浏览空间详情，THE SYSTEM SHALL 支持文件搜索、筛选、排序和成员管理；根目录计数、空间计数与可见搜索总数分别正确，不增加同步按钮、文档分级或单文件图谱入口。
- **AC-13** — WHEN 读取原文或批量下载，THE SYSTEM SHALL 通过毕昇重新校验预览或下载的对应动作；可预览文件支持新标签页打开。旧链接或分段读取不得绕过撤权，不向客户端返回远端凭据或可绕过授权的地址。
- **AC-14** — WHEN 文件改版或删除，THE SYSTEM SHALL 阻止旧版继续贡献有效索引、标签与Wiki；多源页面仅撤回目标来源，历史字节留远端。未证明清理完成时不展示受影响旧内容，不把排队成功当作完成。
- **AC-15** — WHEN 查看失败项或恢复作业，THE SYSTEM SHALL 能按本地空间/版本与远端库/文档定位阶段、错误及尝试次数；跨代次的迟到结果不能复活已删除资源。
- **AC-16** — WHEN 接收、删除或迁移文件，THE SYSTEM SHALL 按纳管版本的原始字节执行用户/租户容量限制，保留的历史版本计入，未知结果不重复扣减或提前释放；同一逻辑版本迁移临时副本不重复收费。

### Wiki、标签（R17–R26）

- **AC-17** — WHEN 具备空间读权限的用户从右上角进入Wiki，THE SYSTEM SHALL 提供搜索、节点定位、详情及关联页面，展示页面类型、标题、摘要和Markdown；代表性资料能形成摘要页、实体页、概念页及链接。实体关系索引不作为另一个前端入口。
- **AC-18** — WHEN 两个成员同有空间读权限而原文权限不同，THE SYSTEM SHALL 展示相同派生节点、正文及连线；无权来源仅占位，直达原文件仍拒绝。无空间权限者不能通过搜索、slug或资源地址访问。
- **AC-19** — WHILE 绑定准备、Wiki生成、清理更新、无页面或查询失败，THE SYSTEM SHALL 分别呈现对应状态；恢复时只有被证明已应用的变更可解除读取限制。
- **AC-20** — WHEN 无候选的库首次有成功解析文件，THE SYSTEM SHALL 用当前生效LLM从代表性正文或摘要产生至多20个候选、归并同名和明显同义项、复用已有项；同库并发和中断恢复只发布一份初始化结果。首批全失败不得标为初始化成功。
- **AC-21** — WHEN 候选就绪，THE SYSTEM SHALL 回填首批及初始化窗口内成功文件，每篇最多3个自动标签，不含人工标签；后续上传按已发布候选分类。词表尚未完整时不能将半份候选的结果视为最终结果。
- **AC-22** — IF 标签分类失败，THEN THE SYSTEM SHALL 保留文档已解析状态及原人工标签，记录原因并允许独立重试；默认历史补标只处理有效且未成功/失败版本，重算成功文件须管理员选定，均不重建向量。
- **AC-23** — WHEN 从毕昇公共模板初始化多个部门库，THE SYSTEM SHALL 逐库独立导入并报告结果；禁止导入跨租户/私有模板。之后改删模板不影响目标标签或开关，不选模板仍能完成AC-20。
- **AC-24** — WHEN 用户编辑文档标签，THE SYSTEM SHALL 区分新增空间词、单文件替换、显式清空及批量追加；逐项判权，保留并发人工修改，过期编辑拒绝覆盖；只删空间词不能删除文档、分块或历史引用。能力不足时拒绝破坏性近似操作。
- **AC-25** — WHEN 人工选择或按标签筛选，THE SYSTEM SHALL 不受自动分类候选上限限制，翻页不丢已选项；有权文档行展示标签，普通成员不收到全库用量。改名保留身份，删除或换代后旧选择不可扩大为全库检索。

### 跨场景使用、兼容与恢复（主方案§6–§15增量）

- **AC-26** — WHEN 日常会话、任务主/子Agent、工作流、助手及开放工具检索外部空间，THE SYSTEM SHALL 以场景有效身份、所选空间、筛选及当前文件权限的交集返回当前有效版本；与原生混用不混淆来源。回答模型沿用场景配置，工作流保留原有作者共享/运行用户规则。
- **AC-27** — WHEN 带固定标签的会话转任务、继续或重新生成，THE SYSTEM SHALL 保留原选择并重验权限；筛选失效或无法解析不得发起无条件查询。重新提问才按新选择执行，部分来源失败须明示。
- **AC-28** — WHEN 单文件、目录或整空间问答产生引用，THE SYSTEM SHALL 维持各自范围，来源点击按实际查看者授权；旧引用只指向原修订或显示不可用，匿名知识引用拒绝。清除聊天记录不删除知识内容。
- **AC-29** — WHEN 使用频道手动/自动投递、网页导入或开放写入，THE SYSTEM SHALL 在形成毕昇内容副本前按真实目标受理或拒绝；网页检索和预览须绑定同一已提交快照。不支持的同步/预制块契约拒绝而不假报完成。
- **AC-30** — WHEN 用户发起删除、重试、移动、复制或受限编辑，THE SYSTEM SHALL 保留各自权限、预检与确认范围；计划过期不得按旧确认执行。未具备等价能力的操作在产生副作用前拒绝，不能把复制变为覆盖、把文件编辑变成重建。
- **AC-31** — IF 服务中断、进程重启或两侧恢复时间点不同，THEN THE SYSTEM SHALL 区分未决与失败，按原目标恢复且不重复执行；在无法证明权限与内容一致前仍隔离受影响内容。其他后端的原生空间不受回落或误写影响。
- **AC-32** — WHERE 外部空间具备可选能力，THE SYSTEM SHALL 在界面和服务端遵守同一开放条件，临时故障不得当作空数据或永久不支持。各使用入口不得借服务凭据扩大身份、跨租户访问或泄露远端敏感配置。

- **AC-33** — WHEN 外部空间使用已有元数据，THE SYSTEM SHALL 允许读取已有值，只开放已验证类型的写入和等价筛选；不支持的筛选、字段改名或批量值迁移在产生副作用前拒绝，不丢弃条件。
- **AC-34** — WHEN 输入旧客户端的上传、开放写入或分享定位请求，THE SYSTEM SHALL 保持原生空间的既有行为；对外部空间只能授权转发或写入前拒绝，不用本地暂存、重新切块或空索引伪装成功。
- **AC-35** — WHEN 管理员查看或修复部门空间，THE SYSTEM SHALL 区分空间就绪、成员授权、标签初始化与Wiki更新状态；重试单个失败步骤不重建空间，隐藏管理列表项不改变成员权限或删除内容。
- **AC-36** — WHEN 普通成员选择使用空间的入口，THE SYSTEM SHALL 分别按检索、上传、管理的实际资格展示；公开空间可被发现不等于可读取受限文件，单人置顶不影响其他成员，退出个人订阅不撤销部门授权。
- **AC-37** — WHEN 旧任务或查询晚于迁移切换到达，THE SYSTEM SHALL 不把旧库操作执行到当前库，权限未验证的旧结果不开放；恢复后同一空间只向用户提供一个已验证代次的内容。

## 3. 边界与发布门禁

后端注册不等于首期业务就绪。上传结果查回、空库模型锁、按授权分页和检索、有效版本隔离、Wiki删除收敛、空库标签初始化与人工来源保护，须有对应环境的可验证证据；无法证明时不得报告全量兼容。已确认的条件性能力按主方案§15.2处理，Native回归、非管理员双账号、部门批建丢响应及历史引用失效是必验场景。
