## 边界

只修改本地代码及本功能文档，不部署、不改线上数据、不重放历史事件。当前文件统计通过已有对账补齐新字段；历史事件未保存的来源不能追溯还原。组织按原始空间当前归属映射，不新增首次上传时的组织历史快照。原始空间记录不存在或租户不匹配时名称为空，不猜测。
