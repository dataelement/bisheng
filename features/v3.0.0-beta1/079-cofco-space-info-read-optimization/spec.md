# F079 中粮知识空间详情读取优化

**分支**：`feat/cofco-1028-3.0.0-beta1`。

**确认依据**：2026-10-30 会话中已评审的 `/info` 三项方案；用户明确回复“OK 按照这个方案修改到 1028 分支”。本文将已确认的需求和设计固化，未增加实现范围。

**版本契约**：[release-contract.md](../release-contract.md)。不新增领域对象或数据库变更。

## 范围

空间详情复用入口的可见性结果，去掉完整操作权限展开；普通用户在详情和广场均按“可见优先”展示订阅状态；补充分段耗时。按钮仍从 `my-permissions` 获取权限，超管的可访问与真实加入状态分开处理。

不包含 `/children` 查询改造、统计信息收集、索引调整、缓存、查询并行化、权限模型/授权迁移或环境部署。

## 验收标准

| AC | 要求 |
|---|---|
| AC-01 | `/info` 保留统一入口 `visible` 校验；可访问返回 `actions=["visible"]`，不调用完整动作展开；按钮权限继续由 `my-permissions` 提供。 |
| AC-02 | 普通用户具有真实可见权限时，详情与广场均返回 subscribed；历史 pending/rejected 不覆盖该展示结果，不写回申请或成员记录。 |
| AC-03 | 无可见权限但允许预览的公开/审批空间保留申请状态并返回空 actions；私密/未发布空间仍拒绝访问，空间不存在仍返回原错误；权限服务异常继续抛出。 |
| AC-04 | 创建者角色及无成员记录的部门授权用户角色判断保留；超管可以进入未加入空间，但不因身份捷径把它标为已加入。 |
| AC-05 | 保留下载 Catalog 开关、统计和展示字段、重建任务条件及租户守卫。 |
| AC-06 | 成功与失败各输出一次详情终态指标，包含总耗时和各阶段耗时；失败包含阶段、异常类型和已消耗时间，不包含 SQL、凭据或异常正文。 |

## 验证边界

离线 Service/ASGI 测试验证控制流与接口形状；真实登录、OpenFGA、达梦、浏览器跳转和性能分位数需要升级后的指定测试环境验证。不得把跳过的真实环境测试或替身耗时作为生产收益。
