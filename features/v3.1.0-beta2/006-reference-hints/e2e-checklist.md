状态：由用户在更新开发环境后自行执行（本轮明确安排）。没有向生产环境写入或删除资源。本地 ASGI 使用真实业务应用与 SQLite，认证/FGA/消息运输采用测试替身，不能据此声称环境 E2E 通过。

前置条件：专用测试租户和 `e2e-reference-` 前缀资源；租户管理员、资源 owner、无删除权限用户；两个租户；可控制的默认队列 Worker；MySQL 与 DM8 分别执行。仅清理本次前缀资源。

- [ ] AC-01/03：工作流、助手、应用、频道分别保存模型/空间引用。删除模型和空间时显示已记录提示，可以正常确认，引用方配置仍保留原 ID。
- [ ] AC-02：无引用记录的空间正常编辑元数据字段和值；不新增元数据引用，不要求模型引用准入。

- [ ] AC-06/12：第二租户和无权限用户不能查看来源详情或执行越权删除；受限来源仅显示数量。既有移动/复制占用、物理清理及 FGA 投影失败仍按业务错误处理。
- [ ] AC-07/08/09：停默认 Worker 后保存/发布各来源成功；恢复 Worker 后处理最新配置。制造任务 SQL 失败观察重试，重复处理无重复明细，删除来源后清理关系。
- [ ] AC-10/11：保留孤儿覆盖账本的测试库正常创建租户、初始化和删除资源；不执行引用迁移或回填；确认旧 Run 不被在线查询。
