# 预置工具按编辑动作授权

基于 `feat/3.1.0-beta2` 的 `2ae01dcfd3`。采用小功能流程，复用现有工具权限模型和 `edit` 动作，不修改 API 字段、数据库或默认授权。

- AC-01：普通用户被授予包含 `edit` 的权限模型（如所有者）后，可以打开并保存对应预置工具配置；不要求管理员身份。
- AC-02：仅可见、仅权限管理或无编辑权限的用户不能编辑；撤销编辑授权后，服务端拒绝后续保存。
- AC-03：搜索工具配置读取、保存、Schema 导入和试运行均校验该工具的 `edit` 动作。
- AC-04：跨租户、已删除、非预置工具不能通过预置工具配置接口编辑；预置工具仍不可删除。
- AC-05：系统预置来源仍仅投影 `visible`，新增编辑能力由显式授权获得。编辑用户读取到脱敏配置，掩码保存保留原密钥。
