## 根因与实现

1. 抓取队列在任务结束后统一折叠，失败原因只通过 Tooltip 展示。失败结束后保留展开状态，原因作为队列正文展示；人工处理入口和移除失败记录分别提供按钮，支持键盘操作。移除后可重新提交相同网址。
2. 网址直接进入抓取请求，缺少格式校验。提交前校验 HTTP/HTTPS 地址，已有域名输入形式补全 HTTPS；格式错误直接显示说明。队列保留用户输入供现有去重逻辑使用，服务请求使用规范地址。
3. 添加信息源失败统一映射成解析失败，丢失服务返回的原因。抓取和保存共用错误分类，保留服务授权、服务异常、访问限制、页面类型、额度、网络与超时信息；服务仅返回通用解析失败时，显示检查链接、页面可访问性及栏目列表页的操作指引。
4. 人工处理说明默认文案包含 `XXXX@XX`，配置为空或请求失败时直接展示。三语默认文案统一为联系管理员并提供网站及抓取内容；有效配置按原文显示，历史占位配置使用管理员指引。打开弹窗时重新获取配置，关闭后的旧请求结果由生命周期控制丢弃。

接口、权限、数据库和抓取服务契约沿用当前发布分支。服务端对抓取目标的安全校验继续由既有后端负责。
