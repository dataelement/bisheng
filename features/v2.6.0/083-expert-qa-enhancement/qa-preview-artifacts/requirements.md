# 问答附件复用统一 PDF 产物

Status: VERIFIED_LOCAL
Mode: Implement

用户已要求将专家问答预览与知识库同步，并明确要求修正每次打开重新转换的问题。

- REQ-1：知识库和问答共用 PDF 转换、结构校验及保存代码；不为问答伪造 KnowledgeFile。
- REQ-2：问答 Office 附件首次生成无用户水印 PDF 并持久化；重复预览、下载、服务重启后复用。
- REQ-3：租户、桶、对象路径、文件内容或转换格式变化不得命中旧产物；原文件必须仍可读取；损坏产物可重建。
- REQ-4：并发请求共享生成结果，转换失败可重试；取消请求不提前释放正在转换的锁。个性化水印每次独立生成。

| Acceptance | 验收 | Verification |
|---|---|---|
| AC-1 | 问答重复预览/下载只转换一次，水印依当前用户生成 | 定向服务回归 |
| AC-2 | 变更源、租户、桶/路径或格式重新生成，源删除不返回缓存 | 参数化服务回归 |
| AC-3 | 并发只生成一次；失败、损坏及锁失效不会发布无效结果 | 并发与失败路径测试 |
| AC-4 | 知识库已有生成、校验、过期任务清理行为保持 | 现有 PDF worker/on-demand 回归 |

范围：当前 Word/PPT 前端接入保持；后端 Office 附件共用产物（doc/docx/ppt/pptx/xls/xlsx/csv）。图片、视频及文本降级不变。不部署、不迁移表、不修改权限策略。
