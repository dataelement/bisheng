# F080 中粮可编辑知识空间列表

日期：2026-11-02。目标分支：`feat/cofco-1028-3.0.0-beta1`。
关联需求：本会话用户已评审优化方案、将候选集明确修改为“先获取用户可见空间 ID，再批量检查 edit”，随后授权按此方案修复。此文件记录已确认的需求，不新增产品决策。

## 验收标准

| AC | 要求 |
|---|---|
| AC-01 | 普通用户的 `/knowledge/space/managed` 返回真实可见且拥有 edit 的空间；edit-only 可进入，manage-only 不进入，成员角色不充当授权依据。 |
| AC-02 | 先完整枚举当前用户可见空间 ID；空集合直接返回；流失败、容量超限、非法 ID 均报错，不回退为全租户扫描，不静默截断。 |
| AC-03 | 仅加载可见 ID 的业务记录，每批至多 100 个权限目标；空间与模式批量读取，Catalog/动作/围栏/变更标记按批准备。 |
| AC-04 | 保留当前租户隔离、业务状态与版本验证、Catalog 发布门禁、真实可见性复核及数据范围约束；保持默认全范围超管的本租户全量列表。 |
| AC-05 | 保留字段、数据库排序、置顶、创建者/成员/直接授权角色、根文件计数及部门信息；角色补充需要的 manage_permission 不参与 edit 入选判断。 |
| AC-06 | 输出成功/错误阶段指标，包含可见数、候选数、批次数与返回数。异常继续传播，不记录 ID 列表、SQL、凭据或文件内容。 |
| AC-07 | 不变更索引、数据库 schema、权限模型、前端或部署。单元、ASGI、批量调用预算与 opt-in 真实环境测试明确区分。 |

变更范围是中粮分支列表口径修正；其他版本线是否采用 edit 口径另行决定。
