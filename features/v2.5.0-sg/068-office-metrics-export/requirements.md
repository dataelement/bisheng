## 目标与边界
为运营人员提供可核对的科室知识贡献、登录和问答报表。查询业务数据库与 ES，仅写新的本地输出目录。不修改看板、埋点、数据、索引、权限、依赖和运行配置，不补录历史，不生成 Excel，不自动评分或排名。

## REQ-001：组织与时间范围
- 无起止日期筛选。知识取当前有效库存，行为取现存全部历史；记录导出时间和来源实际覆盖范围，不声称恢复已清理记录。
- 运行时指定租户、公司组织、制造部组织；组织范围含全部子组织，制造部必须属于指定公司。
- 用户当前主组织决定归属。知识按文件上传人、登录按登录人、问答按提问人；调岗人员历史行为归入当前组织。
- 主表固定依次展示：综合管理室(制造)、汽车板室(制造)、热轧产品室(制造)、质量精益室(制造)、铁前室(制造)、生产计划室(制造)、物流管控中心(制造)、生产管控中心(制造)、智能制造室(制造)、低碳管理室(制造)。
- 制造部其他科室和直属人员另列，仍进入制造部合计。公司其他组织进入公司分母。
- AC-001：子组织人员计入正确科室；次组织不重复计数；同名不同组织不混入；固定行顺序不变。

## REQ-002：知识存量和贡献
- 仅当前有效、处理成功的文件；排除删除文件、历史版本、收藏夹、已停用空间，包含普通个人库。
- 公共库、部门库、科室库、团队库、个人库分别按逻辑文档去重；贡献数为五类库的文档集合并集，不是五列之和。
- 科室贡献比 = 本科室人员向制造部部门库贡献的去重知识数 / 制造部部门库去重知识总数。
- 制造部贡献比 = 制造部人员五类库合并去重贡献数 / 公司人员五类库合并去重贡献数。
- 制造部部门库分母按库范围确定，不偷偷限制为制造部上传人；外部人员贡献需可诊断。
- AC-002：同一文档发布、分享引用只计一个贡献；不同库列保留分布；不把同名或相同内容但无文档关联的文件擅自合并。
- AC-003：科室和制造部贡献比使用各自已确认分母，明细能重算。

## REQ-003：使用统计
- 登录次数为历史成功登录事件次数，同一用户多次登录分别计数。
- 智能、文档问答以有 AI 回答的问题为单位；同一会话多轮分别计数，每个问题去重。
- 专家问答以已提交的问题为单位，无论是否回答，一题多答仍计一次。
- 科室访问比 = 科室登录次数 / 主表十个科室登录次数之和。
- 科室问答比 = 科室三类问答数之和 / 主表十个科室三类问答数之和。
- 制造部访问比 = 制造部登录次数 / 公司登录次数。
- 制造部问答比 = 制造部三类问答数之和 / 公司三类问答数之和。
- AC-004：重复事件或问题不重计；不同问题不按会话合并；失败 AI 问答不混入；专家问题无需回答条件。
- AC-005：其他科室和直属人员进入部门合计和公司分母，但不进入十科室使用占比的分母；合计重新计算，不相加百分比。

## REQ-004：交付与可核对性
- 按用户追加要求，以单个 export_office_metrics.py 交付，不依赖其他运维脚本；运行仍使用现有毕昇项目模型、配置和依赖。
- 输出 CSV 汇总、知识明细、登录明细、问答明细、其他组织明细、指标分子分母、统计口径和来源异常说明。
- 主表列顺序：序号、科室、公共库、部门库、科室库、团队库、个人库、贡献数、贡献比、登录次数、访问比、智能问答数、文档问答、专家问答数、问答比、备注。
- AC-006：按明细的计入标志和去重键可重算主表及制造部合计；中文可读，不产生替换字符；不覆盖旧输出。

## REQ-005：失败和数据边界
- 缺失组织、组织归属冲突、历史不足和来源查询异常必须显式说明，不能伪装成零。
- 只读查询，不创建或更新 ES 索引，不调用带写入副作用的统计初始化或回填函数。
- AC-007：ES 分页不完整、分片失败、超时或必需索引缺失时，不交付伪完整主表；保留诊断并以非零状态退出。
- AC-008：跨租户数据不混入；当前主组织不明的数据单列诊断；分母为零和数据未知可区分。
