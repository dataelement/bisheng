# 使用统计多尺度热力图

日期：2026-09-15

## 布局和验收

图表保持同一容器宽度、坐标区域和绘图区高度。筛选对象与时间范围仍位于右上角，切换时间保留选中的部门或用户。

| 范围 | 每格单位 | 布局 |
| --- | --- | --- |
| 今天 / 单个自然日 | 1 小时 | 4 行 × 6 列，按从左到右、从上到下的时间顺序 |
| 最近 7 天 / 2–7 个自然日 | 4 小时 | 6 个时段行 × 日期列；最近 7 天共 42 格 |
| 最近 30 天 / 中等范围 | 1 天 | 周一至周日 7 行，列数按完整周边界计算 |
| 最近一年 / 长范围 | 1 天 | 7 行 × 周列，横向标注月份，含闰日的自定义范围保留闰日 |

- 日、周完整展示当日剩余时段，未来格使用虚线；自定义部分时段的提示显示实际统计起止时间。
- 前端按真实小时桶合并四小时格。Token、消息数、成功/失败和缺失计数保留聚合口径；全缺失 Token 继续为未知，部分缺失同时显示已记录用量与缺失标记。
- 月、年按周一对齐；范围外的周边空位保持留白。
- 相同宽度下通过行列密度区分视图；窄屏横向滚动保留时间轴。

## 接口

用户 `usage-summary` 与部门 `usage-overview` 支持可选 `granularity=hour|day`。省略参数时沿用原自动粒度；显式小时粒度允许最长 7 天，按天允许最长 366 天。部门仍按全筛选范围去重统计，成员分页保持独立。前端校验响应粒度与完整连续时间桶，服务端返回粒度不符时显示读取失败。
