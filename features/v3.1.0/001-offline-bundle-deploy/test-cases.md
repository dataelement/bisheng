# F001 测试用例（测试工程师参考）

## 依据与环境

依据本会话确认方案、spec.md 与 design.md（2026-11-27）；基线 cf8de9c0dc。PC 为 Bash/curl/Python3；Linux 预装 Docker/Compose/zstd。临时 HTTP 与模拟 Docker 自动验证不能替代真实 Linux 服务安装验收。Gateway license 与 Nexus 使用专用测试凭据，清理仅限测试临时目录。
