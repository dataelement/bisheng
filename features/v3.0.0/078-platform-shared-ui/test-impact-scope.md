# 毕昇组件库升级测试影响范围

基线：`feat/3.0.0`，`46a62373b`；整理日期：2026-10-23。

本次升级影响后台全部 13 个业务模块，也影响 client 中使用共享基础组件的页面。测试应按业务模块覆盖列表、详情、编辑页及其弹窗/抽屉，不能只检查页面外观。工作流和助手会话的共享抽离属于同期关联改动，需额外覆盖两端会话、后台调试、标注及审计入口。

## 1. 组件变更及共同测试点

| 变更范围 | 测试重点 |
| --- | --- |
| 按钮、图标按钮、业务图标 | 主要/次要/危险操作可区分；白底和主色底的图标可见；图标尺寸、间距、hover 位置稳定；loading/禁用时不能重复提交 |
| 输入框、密码、搜索、多行、数字输入 | 输入/回显/清空、密码显隐、中文输入法、Enter 提交；超长输入的提示和提交拦截；数字上下限、小数、空值及步进；失败后保留草稿 |
| Toast、Notification、Alert | 成功/失败/警告显示正确，长文案可读，提示不重复、关闭正常；固定提示不遮挡操作 |
| Checkbox、Radio、Switch | 单选/多选、全选/半选、禁用项、开关保存与回显；标签和控件对齐 |
| Select、Dropdown、Slider | 单选/多选、搜索、滚动加载、标签移除、空列表；下拉面板遮挡、焦点/键盘选择；菜单操作不误触；滑块与数字一致 |
| Tabs、Segmented、Tooltip、Tag、Badge | 切换后状态和数据正确；长标题/状态不挤成多行；提示可读且不被裁切；可关闭标签、计数和未读状态正确 |
| 主题与共享样式 | 后台自定义主色、重置默认色、刷新后回显；浅色/深色；白色图标/文字对比度；弹层层级、滚动、窄屏布局 |

这些是已迁移组件及其组合的回归要求，不表示上述每一类在每个页面都有使用。业务图标优先替换为 `bisheng-icons`，没有合适图标的旧实现仍保留。

## 4. 同期共享会话抽离的额外范围

工作流、助手以 client 展示为基准共享，不能只在 client 验收。

- 后台工作流/助手编辑中的测试会话：未保存参数生效，输入/表单/文件一致，停止/清空/重试正常，多面板互不覆盖。
- 标注会话：头像/名称、相似问和 QA 操作、问答对应正确，保存成功才更新标注状态；切换会话不串数据。
- 审计/日志会话：能复制、预览、下载；保持只读，不能发送、执行表单或出现标注写入口。
- 两端 Markdown：段落/列表/表格、代码高亮/复制/行距、公式、引用、生成文件卡片。输入区、参数表单和附件展示也需对齐。

更细的会话用例见 [共享会话验收清单](../086-shared-app-chat/e2e-checklist.md)。

## 5. 保留的旧实现及测试边界

不能把“共享库已导出组件”当作“所有业务页面已替换”。当前普通表格、普通 Dialog/确认服务、部分分页/进度/卡片等仍有旧实现调用；应测试它们与新按钮、输入、选项和提示的组合，以及新旧弹层混用的层级/焦点。

下列特殊选择器按约定保留旧实现，需回归原交互，不能按新普通 Select 的外观判定缺陷：

| 保留入口 | 必测行为 |
| --- | --- |
| 知识库选择器、工作流节点知识库选择 | 知识库/文档/空间页签、面板中的业务按钮 |
| 工作流变量选择 | 层级、变量路径、搜索/选择及值回填 |
| 看板配色色块选择 | 色块预览、选中、保存回显 |
| 品牌资源选择 | 图片/资源预览、切换和单项删除 |
| 用户列表专用筛选面板 | 多选、重置、确认后应用筛选 |

本次组件升级不要求重新评估模型效果、算法准确率或对全部后端 API 做压力测试；仍需验证页面操作实际提交成功、参数和权限行为未改变。错误透传、提示文案修复另有 [统一错误验收清单](../../../docs/superpowers/plans/2026-10-22-user-facing-error-messages-test-cases.md)，可与上述业务流程一起执行。

## 6. 测试评估建议

1. 所有开放模块至少走一次“列表 → 搜索/筛选 → 新增或编辑 → 保存 → 再打开回显”，并覆盖弹窗、抽屉中的控件。
2. 重点模块增加失败重试、重复点击、取消/切换、长文本/窄容器；工作流和看板必须实测拖动、缩放和滚动，不能只截图确认。
3. 公共组件交互选择代表页面深入验证，不必每页重复全部键盘测试；但每种特殊组合需覆盖，例如弹窗内 Select、多选带可关闭标签、禁用按钮 Tooltip、异步搜索。
4. 至少覆盖管理员与普通用户，涉及租户时增加子租户管理员；检查按钮可见性、禁用态和不可执行行为，不通过隐藏按钮推断后端权限正确。
5. 主流程使用常用桌面尺寸；抽查窄屏、浅/深色、中英日长文案、默认及自定义主色。视觉细节由设计复核，功能验收通过不等同设计已签收。

评估工时应按可访问页面数、角色/版本组合和失败场景注入条件计算；本清单不把历史“测过没问题”当作当前版本全部通过。

| 知识空间 | 列表/创建/设置、文件与文件夹、搜索标签、上传、预览、分享/授权；选择器、输入长度、标签关闭、权限弹窗 |
| 频道与文章、应用广场、技能 | 筛选搜索、配置表单、标签/开关/选项、订阅/分享、技能上传与选择等主要入口 |
| 导航、设置及个人入口 | 侧栏/历史会话、个人菜单、提示词/收藏/侧栏资源、账号/2FA、语音/模型/显示设置、Token、权限申请与审批消息 |

## 4. 同期共享会话抽离的额外范围

工作流、助手以 client 展示为基准共享，不能只在 client 验收。

- 后台工作流/助手编辑中的测试会话：未保存参数生效，输入/表单/文件一致，停止/清空/重试正常，多面板互不覆盖。
- 标注会话：头像/名称、相似问和 QA 操作、问答对应正确，保存成功才更新标注状态；切换会话不串数据。
- 审计/日志会话：能复制、预览、下载；保持只读，不能发送、执行表单或出现标注写入口。
- 两端 Markdown：段落/列表/表格、代码高亮/复制/行距、公式、引用、生成文件卡片。输入区、参数表单和附件展示也需对齐。

更细的会话用例见 [共享会话验收清单](../086-shared-app-chat/e2e-checklist.md)。

## 5. 保留的旧实现及测试边界

不能把“共享库已导出组件”当作“所有业务页面已替换”。当前普通表格、普通 Dialog/确认服务、部分分页/进度/卡片等仍有旧实现调用；应测试它们与新按钮、输入、选项和提示的组合，以及新旧弹层混用的层级/焦点。

下列特殊选择器按约定保留旧实现，需回归原交互，不能按新普通 Select 的外观判定缺陷：

| 保留入口 | 必测行为 |
| --- | --- |
| 知识库选择器、工作流节点知识库选择 | 知识库/文档/空间页签、面板中的业务按钮 |
| 工作流变量选择 | 层级、变量路径、搜索/选择及值回填 |
| 看板配色色块选择 | 色块预览、选中、保存回显 |
| 品牌资源选择 | 图片/资源预览、切换和单项删除 |
| 用户列表专用筛选面板 | 多选、重置、确认后应用筛选 |

本次组件升级不要求重新评估模型效果、算法准确率或对全部后端 API 做压力测试；仍需验证页面操作实际提交成功、参数和权限行为未改变。错误透传、提示文案修复另有 [统一错误验收清单](../../../docs/superpowers/plans/2026-10-22-user-facing-error-messages-test-cases.md)，可与上述业务流程一起执行。

## 6. 测试评估建议

1. 所有开放模块至少走一次“列表 → 搜索/筛选 → 新增或编辑 → 保存 → 再打开回显”，并覆盖弹窗、抽屉中的控件。
2. 重点模块增加失败重试、重复点击、取消/切换、长文本/窄容器；工作流和看板必须实测拖动、缩放和滚动，不能只截图确认。
3. 公共组件交互选择代表页面深入验证，不必每页重复全部键盘测试；但每种特殊组合需覆盖，例如弹窗内 Select、多选带可关闭标签、禁用按钮 Tooltip、异步搜索。
4. 至少覆盖管理员与普通用户，涉及租户时增加子租户管理员；检查按钮可见性、禁用态和不可执行行为，不通过隐藏按钮推断后端权限正确。
5. 主流程使用常用桌面尺寸；抽查窄屏、浅/深色、中英日长文案、默认及自定义主色。视觉细节由设计复核，功能验收通过不等同设计已签收。

评估工时应按可访问页面数、角色/版本组合和失败场景注入条件计算；本清单不把历史“测过没问题”当作当前版本全部通过。
