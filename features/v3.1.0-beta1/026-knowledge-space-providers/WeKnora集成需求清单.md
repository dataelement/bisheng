# 毕昇知识空间与 WeKnora 集成需求清单

需求基线：用户提供的《毕昇知识空间与WeKnora集成需求》，2026-11-20 产研评审稿。方案编制日期：2026-11-23。

本清单中的“原始需求”来自需求稿，合并同一行为的重复描述。后续用户明确：模型列表从WeKnora获取；WeKnora类型空间的内容数据全部存储到WeKnora，毕昇只做转发、权限控制及必要控制关联。此口径覆盖原稿中的原文存储待评审项；下表保留原始需求以便追踪。实现建议见[集成实现方案](./WeKnora集成实现方案.md)。本文不表示功能已经开发或验收。

| 编号 | 标题 | 原始需求描述 | 方案位置 |
|---|---|---|---|
| R01 | 系统职责 | 毕昇负责空间、成员、文件和原文访问权限；WeKnora负责处理、索引、Wiki和图谱及模型管理 | §2、§3 |
| R02 | 空间一对一绑定 | 每个毕昇空间对应一个生效WeKnora库，同名，两侧ID关联 | §4、§5 |
| R03 | 客户端页面 | 复用首页分类、创建侧栏、文件列表、成员管理和新标签页预览；不增加同步按钮、文档分级、单文件图谱 | §11 |
| R04 | 模型选择 | 创建必选可用LLM和Embedding，校验类型、状态、环境 | §5 |
| R05 | 模型用途 | 初始LLM用于摘要，Wiki和标签默认继承；VLM独立使用管理员预设 | §5 |
| R06 | 建库默认值 | 开启Wiki、实体关系抽取、多模态、自动标签，其余沿用目标环境默认值 | §5 |
| R07 | 普通图谱依赖 | Neo4j及graph_enabled、extract_config.enabled均需生效；前端只展示Wiki | §5、§13 |
| R08 | 分块继承 | 创建可调、上传继承空间、批次可覆盖，上传不填标签 | §6 |
| R09 | 创建幂等 | 失败保留重试状态，同请求复用已有记录，避免重名副本 | §5、§9 |
| R10 | 实际配置回读 | 回读模型、Wiki、图谱、图像配置；毕昇只读，不覆盖管理员修改 | §5、§11 |
| R11 | Embedding锁定 | 建库后立即锁定含空库；WeKnora普通管理及API拦截，实际模型/版本/维度变化走迁移 | §5、§12 |
| R12 | 上传与版本映射 | 毕昇登记文件版本，后台交原文，映射版本与远端文档ID，按版本去重 | §4、§6 |
| R13 | 异步与局部成功 | 分开记录接收与处理完成；批量失败保留成功项，失败文件独立重试 | §6、§9 |
| R14 | 改版和删除 | 清理旧索引、标签关联及对应Wiki来源贡献，多源页面保留其他有效来源 | §7 |
| R15 | 原文存储 | 存储归属和读取方式待评审，用户从毕昇预览下载 | §3、§4.1—§4.5、§8（后续明确：内容归WeKnora；毕昇保留控制数据，使用阶段记录单独管理） |
| R16 | 可运维 | 按空间/版本/远端库及文档ID定位状态、错误、重试次数 | §4、§9、§13 |
| R17 | Wiki读接口 | 同库ID及slug对应图谱和页面，详情source_refs关联原文件；支持搜索和展开 | §8.1—§8.3、§10.1、§11.1 |
| R18 | 空间级Wiki权限 | 图谱、标题、摘要、正文按空间读权限共享，不按来源文件裁剪；无空间权限全部拒绝 | §8 |
| R19 | 原文权限 | 文件列表、预览、下载继续执行文件权限，浏览器不能绕过毕昇 | §8 |
| R20 | Wiki状态 | 区分准备中、生成中、暂无页面、查询失败 | §6、§11.2、§14 |
| R21 | 候选标签生成 | 首批解析后从代表性正文或摘要生成可复用标签 | §9 |
| R22 | 候选归并 | 空间内合并同名和明显同义项，查询已有后创建缺失标签，每库初始化一次，并发重试复用 | §9 |
| R23 | 首批与历史回填 | 候选就绪后逐篇回填首批；后续复用原生任务；历史补标独立运行，不重建向量 | §9 |
| R24 | 标签展示维护 | 有权文档行展示，管理员在WeKnora维护，保留人工标签，失败独立重试 | §9、§11 |
| R25 | 标签评审项 | 每批候选有限、单篇最多3个为起点；候选扩展、人工确认、存量范围待评审 | §9、§15 |
| R26 | 业务共享口径 | 原文受限但派生摘要和关系仍可能空间共享，评审和上线验收确认 | §8、§14、§15 |
