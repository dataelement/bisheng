# F077 升级后验收清单

**执行状态**：待新镜像部署后执行；本地后端定向回归不等同于真实环境端到端验收。

1. 新建部门空间并配置负责人，验证权限设置显示“所有者”，不显示“创建者”；实际具备全部既有所有者操作权限。
2. 存量部门空间重复保存当前负责人，核对实际 owner、唯一负责人和审批人一致；重复保存不重复授权。
3. A 更换为 B：B 获得负责人所有者权限，A 恢复原成员权限。分别覆盖 A 原为普通成员、管理员、仅负责人，以及 A/B 有独立授权。
4. 模拟权限服务失败，确认请求报错；恢复后保存相同负责人或执行既有校准任务，确认旧负责人恢复完成，不残留负责人权限。
5. 并发更换负责人，确认过期操作拒绝，最终负责人和实际 owner 一致。
6. 停用、删除或移出企业后，确认进入待配置状态并撤销负责人所有者权限；补配后正常恢复。
7. 拒绝无效或跨企业负责人；普通空间创建者保护、频道和独立授权规则保持原状。
8. 在达梦环境验证更换、重试和周期校准；同时核对文件变更审批人及知识列表加载性能。

本次没有新增数据库结构、手工数据迁移或权限模型迁移。存量立即校准可重复保存负责人，批量校准由既有周期任务完成。
