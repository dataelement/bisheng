## 根因与实现

退出订阅已经通过成员授权同步撤销订阅来源，再删除成员记录。资料预览接口原实现仅查询文件，随后直接签发原文、转换预览及网页快照地址，因此保存的页面链接能够绕过已撤销的成员授权。路由中的空间 ID 也被丢弃。

预览现在先核对空间与文件归属，再通过统一权限入口校验当前文件的 `visible` 权限，授权通过后生成内容地址。签发地址复用已核验的文件记录。独立文件授权和继承授权交由现有权限运行时决定；下载继续使用 `download` 动作。

同步清理所改路由文件的既有静态检查问题：三个重复函数名改为对应操作名称，可选查询参数使用显式可空类型。
