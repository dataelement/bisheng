# 运输历史费用查询（本地现行合同）

2026-11-26。本地与 3.0.2 候选源码按本文件和 runtime.md；历史 D 发布记录保留在项目验证目录。本轮没有部署 D 或推送。

历史查询只返回按费用单去重的原币金额、命中运输记录和完整共享覆盖。先以主单号定位候选，再以同一记录的分单号核实；单给主单保留分单待确认。费用引用 F01 续问绑定同次查询。

用户明确请求新货运输推荐时使用 inquiry。必需起运地、目的地、型号、毛重、包装长宽高和危化属性。毛重统一 KG、尺寸统一 CM；未知毛重不能当作全匹配。全匹配失败后，按物料、毛重、尺寸依次有相同才收窄。完整推荐池仍保留明确的方式、服务商、币种及 ETD/ETA 日期保护，允许按相近经验给出有提示的候选。

当前业务撤回历史报价时间和运费开票日，不展示、不提供开票日筛选或排序。人民币开票金额、货值、运费占比、包装数量和净重均不进入当前匹配、筛选、展示或推荐排序。推荐按经验层级、同层票数、累计票数、最近 ETD、服务商与运输方式名称排序；历史金额按原币分组，不跨币种比较。history 不额外获取推荐池。

旧联调快照的字段和完整性校验保留，用于兼容原始回执与已保存状态，不代表这些列仍是业务输入。旧询价需要用毛重重新查询；旧开票日排序按来源顺序恢复；旧查询若依赖撤回的筛选则明确要求重新查询。源工作簿只读，未删除或重造历史数据。

服务与固定入口仅依赖 Python 标准库。构建工作簿快照时使用已安装 openpyxl。主要回归：`python3 -m unittest test_local test_inquiry test_tool_adapter test_display`；原生业务入口回归在相邻 transport-native-api 中运行 `python3 -m unittest test_service test_waybill`。测试为本地 HTTP、CLI 与业务代码验证，不能替代真实模型、客户正式库或 D 界面验收。
