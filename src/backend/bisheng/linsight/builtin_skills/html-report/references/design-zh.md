# 报告页设计规范

## 1. 从内容出发

动手前先回答三个问题：**这页写的是什么、给谁看、看完要做什么决定**。
同样是网页，给评审会看的审核报告、给领导看的月度汇报、给业务员查的数据看板，
信息顺序和视觉重点完全不同。每一个设计选择都要能用这三个答案解释；解释不了的就是默认习惯，要删掉。

全程用真实内容设计。不要先搭一个漂亮的空架子再往里填字：空架子的版块数量和长度
跟真实内容对不上，最后要么硬塞、要么留白。

## 2. 版式原则

- **第一屏放最关键的内容。** 报告页的第一屏是标题区加结论区：报告对象、一句话总判断、不超过 4 条要点。
  不要用大图、口号或装饰性的数字墙占第一屏。
- **只在一个地方用力。** 辨识度留给标题区和关键结论（例如结论区的底色、标题左侧的色条）。
  其余部分保持安静：统一的间距、统一的字号层级、克制的颜色。
- **结构元素要表达信息。** 边框、色条、编号、标签、分隔线都应该传递内容上的区别，不是装饰。
  编号只用于真正有先后顺序的内容（步骤、时间线）；状态色只用于状态（一致、差异、风险）。
- **对齐方式统一。** 正文、表格、列表一律左对齐；数字列右对齐；不要整页居中。
- **行长控制在 46 个汉字以内**（底座的 `--measure`）。长段落比长页面更难读。
- **动效只用于回应操作**（展开、排序后的变化），不加入场动画、悬停放大、滚动视差。

## 3. 字体与颜色

**字体**：只用系统字体栈（底座已写好：苹方、雅黑、思源、文泉驿依次回退）。
离线环境加载不到网络字体，引用了也只会回退，还会被检查工具判为错误。
层次靠字号和字重拉开：标题 600，正文 400，次要信息用 `--ink-soft` 颜色而不是更小的字号。
正文不小于 15px，说明文字不小于 13px。数字用等宽数字（底座已开 `tabular-nums`）。

**颜色**：一个强调色（`--accent`）加一组状态色。
- 强调色用于标题色条、链接、选中状态，全页出现不超过 5 处。
- 状态色（ok 绿、warn 橙、risk 红、info 蓝）只表示状态，同一状态全页用同一种颜色。
- 不用渐变、不用大面积彩色底；浅灰底（`--paper-alt`）用于结论区、表头和提示块就够了。
- 底座已带暗色模式和打印样式。改 `--accent` 时，暗色模式里也要给一个提亮的版本。

## 4. 生成式默认审美清单

下面这些是生成式页面最常见的「默认选择」：换任何题目都会出现，所以一眼就能看出是机器做的。
它们在个别场景下也可能是对的选择，但必须是为这份报告选的，而不是顺手用的。设计计划写完后逐条对照：

1. **满屏同款圆角卡片**：每段内容都装进一样的圆角、一样的阴影的卡片。报告页用分隔线和留白分组就够了，
   卡片只留给需要单独阅读的条目（例如发现项）。
2. **渐变与发光**：标题渐变字、紫蓝渐变背景、彩色光晕。
3. **装饰性数字墙**：第一屏放一排大数字加小标签，但这些数字并不是结论。
4. **无意义的编号**：01 / 02 / 03 标在并不存在先后顺序的版块上。
5. **全大写或英文小标签**：每个标题上方都有一行小号英文或全大写标签。
6. **每段都配图标**：图标不传递信息，只是为了「看起来丰富」。
7. **标题里单独高亮一个词**：把一个词换颜色或加粗，制造伪重点。
8. **整页居中**：所有文字居中对齐，长段落也居中。
9. **点号拼接的元信息**：「A · B · C」式的信息串；需要并列时用分开的字段。
10. **近黑底加荧光色**、**米黄底加陶土色**：两种最常见的「有设计感」配色模板。

## 5. 页面上的文字

文字是界面的一部分，要和间距、颜色一样克制和准确。

- **从读者的角度写。** 用读者熟悉的业务词，不用系统内部的字段名或技术术语。
- **具体胜过漂亮。** 「风险等级依据引用的制度名称不一致」胜过「存在若干合规性问题」。
- **一个元素只做一件事。** 标题说是什么，结论说怎么判断，建议说该做什么，不要混在一句里。
- **同一个东西始终用同一个名字。** 前文叫「尽调报告」，后文就不要变成「尽职调查材料」。
- **说明问题时讲清原因和处理办法**，不要只写「有误」「需关注」。

## 6. 质量底线

交付前不必说明，但必须做到：

- 手机宽度（390px）下没有横向滚动条；宽表格放进 `.table-wrap`，在容器里横向滚动。
- 链接、可排序表头、折叠标题在键盘聚焦时有可见的焦点框（底座已带）。
- 文字和背景的对比度足够；浅灰字只用于次要信息。
- 打印或另存为 PDF 时版面完整：折叠内容展开，表格行和发现项不跨页断开（底座已带打印样式）。
- 看一遍成品，删掉一个不服务于内容的装饰。
