## 4. 自审时补齐的关键边界

1. **长期浏览器绑定**：登录事务 TTL 与本地会话期限不同。将 browser_binding_hash 纳入交接、SQL 会话和退出票据；网关绑定 Cookie 不随五分钟事务消失，避免过期后无法完成远端退出。
2. **跨来源保护**：昆联来源被保留，旧 login-sync 不得先迁移 source 再铸造普通会话。签发标记与会话引用必须完整，绑定异常不能回退。
3. **投影原子边界**：SQL 目录指针及 F118 准入版本原子发布；Owner 投影单独报告并按身份失败拒绝，不宣称存在跨服务事务。相同输入不因每轮新 batch 而反复冻结全部账号。
4. **WS 实际接线**：现有 message_admission 可复用，但 BaseClient／WorkflowClient 不接受 GPTS 的执行上下文形参；文件规划和验证明确覆盖该边界。
5. **回退拒绝能力**：不能把新会话直接交给只识别旧 JWT 的后端；先隔离、持久撤销并保留严格准入版本，不能用宽松登录兜底。
6. **幂等响应**：重复交接指向同一会话、固定绝对期限，回执加密保存重签所需引用；不因丢响应重新换码或延长会话。
7. **可用工具**：网关 README 使用 Maven，未发现 mvnw，设计命令使用 mvn；新测试明确为计划，不假称已存在或执行。
