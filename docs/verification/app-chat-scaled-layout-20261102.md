## 发现和修正

用户反馈 Windows 当前仍出现问题，提出字体字号可能相关。系统缩放与客户端页面缩放具体值暂无现场信息。

当前源码在桌面嵌入模式保持桌面身份，即使内容视口很窄也会保留 240px 应用侧栏。紧凑标题栏随后仅获得剩余宽度。实际 Electron 测量：359px 的应用视口分成 240px 侧栏和 119px 对话区域；居中的标题下拉及箭头与返回按钮重叠，点击命中进入下拉元素。进一步放大页面后，返回按钮落到内容裁剪边界之外。

对照把标题从 16px Arial 改为 24px 等宽字体，失败组合相同；直接复现因素是可用内容宽度与固定侧栏并排。该实验支持缩放触发布局缺陷，Windows 用户原机的确切触发参数仍待复测确认。

AppRoot 现在按现有 767px 断点选择内容导航：窄桌面内容区复用已有历史 region，通过菜单或标题访问应用卡片与会话列表；对话获得完整宽度。放宽到并排布局时恢复原有侧栏偏好；窄布局新建对话保留该偏好。跨过 1023px 宽布局断点时关闭紧凑历史，恢复窗口后由用户重新打开。浏览器移动端继续使用系统菜单。原字体、字号、按钮视觉、来源返回解析与宿主代码沿用当前实现。
