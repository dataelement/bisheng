## 3. 自审中补齐的接线细节

1. **WS不能仅3秒轮询**：每条业务消息先准入，生成消息级不可变身份并传给ChatClient/后续任务；不覆盖共享连接的身份字段，以免影响并发旧消息。common仅接受中性回调，原Web路径默认不变。
2. **F019不新增全站影响**：服务账号用受控scope包装和权威读取，`/apps`不新增F019范围；原全局超管例外与owner-only数据/配置差异显式记录。读scope故障不能回退Root。
3. **失败发布不覆盖合法指针**：资格校验在stage前，拒绝不写current/pending/route，也不使用旧值回滚覆盖并行合法操作；预览清理单独推进，审批回调抛错。
4. **旧管理员脚本兼容明确**：多租户超管写操作需新预期租户头，单租户及普通管理员可省头。页面通过新业务scope路由复用F019底层状态，不更改其他管理页setter规则。
5. **候选和组件不另造模式**：后端按选定租户分页查询；复用现有选择器交互/样式和可注入数据源，不改其他选人默认行为。Select当前draft状态及桌面既有用法已注明，不把未完成手机模式写成已交付。
