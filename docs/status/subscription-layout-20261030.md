# 订阅首页比例调整验证 — 2026-10-30

## 问题与变更

订阅首页在 960px 内容窗口中使用三列布局，两个频道分布在前两列，页面左右留白为 12px。此次调整页面边距与栏目宽度，保持现有横线、列间竖线、编号、字体、字号、字重、行高及频道内部间距。

- 页面左右留白在 16–32px 间按容器宽度变化，上下留白为 24px。
- 栏目最小宽度为 320px，窄窗口下以容器宽度为上限；列数继续根据实际可用宽度计算。
- 960px 内容窗口中呈现两列，单频道与多频道分区沿用一致的列宽规则。
- 创建频道、频道选择、置顶和未读状态保持现有业务行为。
