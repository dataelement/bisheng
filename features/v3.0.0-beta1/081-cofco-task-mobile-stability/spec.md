# 中粮任务模式滚动与移动端精简

范围：`feat/cofco-1028-3.0.0-beta1`，任务模式前端；不调整后端协议或存储。

## 已确认的行为

- 任务输出期间切换会话再回来，自动定位最新内容并继续追底。
- 历史任务首次加载、思考和工具等子节点后续撑高页面时继续追底；用户主动上翻时停止，返回底部恢复。
- 用户于 2026-11-04 选择「手机仅保留摘要和结果」：保留问题、任务进度、最终回答/文件、待确认与错误提示；完整思考、工具入参/输出、检索详情和子代理过程留在桌面查看。

## 验收条件

1. 一个任务消息列表只有一个滚动控制者；加载分支替换、会话切换和 KeepAlive 返回均能重新绑定或恢复。
2. 自动加载增高不能误判为用户上翻；滚轮、触摸、键盘及滚动条上翻均可停止追底，布局收缩造成的滚动位置截断不应停止追底。
3. 手机复用现有 H5 布局判定（窗口宽度 <768px），首次渲染即不挂载完整过程节点，不执行过程聚合与工具正文格式化；既有展开记忆不能绕过此限制。
4. 任务运行中仍有简短活动状态；排队、附件准备、技能不可用、待用户确认、失败和手动停止提示保留。
5. 正常结果、文件预览/下载、反馈及任务进度清单继续可用；桌面完整过程保持原有行为。
6. 不删除历史数据，不声称已根治客户 WebView 崩溃；在客户受影响手机用原长会话验证。

## 验证约定

补充滚动和移动端挂载边界的回归用例，执行静态检查；按仓库既有约定，本地不运行前端测试或构建，留给镜像/CI 与手机回归。
