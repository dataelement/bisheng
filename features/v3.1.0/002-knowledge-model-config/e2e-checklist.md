# E2E 验证清单：知识模型配置收敛

目标为本分支部署后的测试环境；地址、管理员/普通成员账号、历史消息 H 和模型 A/B/C 待提供。新建测试资源统一使用 `e2e-kmc-` 前缀，测试前核对同前缀残留，测试后只清理本次创建资源并恢复本次修改的默认值/共享设置。

## Platform

- [ ] 管理员打开 `/model/management` → 系统模型配置：无工作台向量与溯源模型，其他设置可保存（AC-01）。
- [ ] 知识栏目名称为“知识模型”；切换中/英/日核对默认 embedding、文件摘要/标签、ASR 提示及 QA 名称（AC-08, AC-09, AC-10）。
- [ ] 知识默认 A、旧工作台 B 时，新建弹窗显示 A，提交后详情仍为 A（AC-02）。
- [ ] 清除默认后明确选择 C，配置授权对象并创建成功；未选择则返回 10901 且无空间残留（AC-03, AC-04）。
- [ ] 保存新默认后，对比原空间的模型、索引、状态和队列，确认不发生重建；另在专用测试空间主动换模型验证原重建流程（AC-05, AC-06）。
- [ ] 子租户继承 Root 已共享模型可创建；撤销共享后拒绝，不能使用其他租户模型（AC-07）。
- [ ] 工作流普通输出、流式结束、带选择和输入的输出都有正确引用预览/定位，无旧文件按钮；无关键词模型调用、分词任务或新 RecallChunk（AC-11, AC-12）。
- [ ] 打开有完整旧数据的历史消息 H：原按钮、会话日志和 `/resouce/:cid/:mid` 页面仍可展示关键词、调整排序、定位文件；无需生成模型（AC-13, AC-14）。
- [ ] 无权用户/其他租户请求 H 旧接口被拒绝；缺来源文件下载权限时维持遮蔽，不泄露文件链接（AC-15）。
- [ ] 在隔离测试库准备含退役字段的旧 JSON，读取/保存/模型诊断和正常引用同步后，退役字段不再构成有效来源；已有空间真实模型来源保持（AC-16）。
