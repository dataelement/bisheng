# 工作流下线后旧卡片提交处理

日期：2026-10-28

## 根因与修复

工作流 WebSocket 原先仅在初始化和状态查询时检查发布状态。保持连接的旧表单、文本输入和交互卡片通过 input 动作继续执行。前端将工作流下线错误 13010 当作普通提示处理，processing/close 又把 running 设为 true，导致停止按钮和等待状态持续显示。

- 初始化、状态查询和每次输入提交共用实时发布状态校验。下线后返回既有 13010 错误与结束事件，阻止继续派发执行任务。
- 停止标记保留到执行进程处理，随后由正常终态流程清理。
- 前端将下线错误存入会话状态，停止等待、关闭输入表单和重跑入口，并禁用历史交互卡片。后到的结束、输入和历史状态事件保留下线状态；重复提交在发送层拦截。
- 正常完成的会话设置 running=false，保留原有手动重跑；运行状态已过期的旧卡片收到明确结束事件。
- 沿用现有错误码及三语提示；构建器草稿预览沿用空 chat_id 的运行约定。现有权限入口和租户隔离保持原有职责。
