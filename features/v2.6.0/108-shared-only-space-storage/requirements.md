# F108 知识空间仅使用共享存储

**Status**: Confirmed
**Created**: 2026-09-17

用户已确认仅处理门户 SPACE 及其全部消费入口；取消显式启用，缺少初始化时明确报错，历史数据独立迁移。本次不部署、不迁移真实数据、不删除物理存储。

## Requirements

- REQ-001：SPACE 的创建、上传、重解析、检索、问答、工作流、版本与发布共享投影、全文同步只使用租户共享 ES/Milvus。移除按空间存储的运行时回退。
- REQ-002：旧全局 enabled 和租户 shared_enabled 不再控制业务路由。保留租户物理目标、模型、schema、路由版本与写冻结保护；目标未初始化或访问失败必须明确失败。
- REQ-003：NORMAL、PRIVATE、QA 保持原行为；混合 SPACE/非 SPACE 请求不能把 SPACE 下放到旧检索器。
- REQ-004：保留独立历史迁移能力和已有物理 schema，不删除 SQL 列或真实索引。不将旧索引读取用于普通运行时。保留用户现有分类浏览修改。

## 风险

旧数据未迁移或共享存储未初始化的环境不能直接部署。代码回退使用前一版本；共享写入后的数据回退需独立迁移，不能通过旧开关恢复旧库读取。
