## 1. 需求提取

### 1.1 核心实体

| 实体 | 关键状态或属性 | 主要关系 |
|---|---|---|
| 问题 | `directed/public`、未回答/待采纳/已解决、`content_locked`、租户、匿名预选项 | 提问者、邀请、回答、关联文档、转公开申请 |
| 专家 | 有效/停用、所属租户、贡献统计 | 用户、邀请、回答、审批人 |
| 回答 | 有效/删除、采纳、匿名/转公开后实名选项 | 问题、专家、评论、关联文档 |
| 评论/追问 | 匿名继承或独立选择、随回答删除 | 问题、回答、用户 |
| 采纳 | 每答唯一、每题最多 3 次 | 问题、回答、F070 积分挂钩 |
| 匿名别名 | 题内用户唯一、序号单调且不回收 | 问题、用户 |
| 转公开申请 | pending/approved/rejected/expired/ended、1/3/7 天、最多延期 3 天 | 问题、发起人、审批人 |
| 关联文档 | `{spaceId}-{fileId}`、accessible/forbidden/not_found | knowledge 权限与 durable entry |
| 通知 | 未读/已读、事件、深链 | `inbox_message`、接收人、匿名身份 |

## 4. 测试预言机定义

场景表中的“预言机”引用以下组合。每个组合都包含正向结果、持久化结果和至少一个反向检查。

| ID | 验证方式 |
|---|---|
| O-READ | API/UI 返回精确业务状态；响应中不得出现无权内容或真实身份；DB 不应因读取产生业务写入（明确计数除外）。 |
| O-WRITE | 响应业务结果与错误码；核对主表、关系表、计数和时间；拒绝路径不得新增或部分更新；随后重新读取确认。 |
| O-CONC | 统计成功/失败次数；核对唯一约束、计数、版本和最终状态；不得出现重复行、超限或丢失更新。 |
| O-ASYNC | 核对主业务状态、`inbox_message`/审计记录、接收人和匿名字段；重复投递不得重复副作用；深链重新鉴权。 |
| O-XMOD | 核对生产方事实与 knowledge/F070/message 消费结果；不得由 F083 写入不归属的数据。 |
| O-MIG | 对迁移前后样本逐字段比对；MySQL/DM8 结果一致；失败可回滚且无半迁移；旧客户端兼容行为按冻结契约验证。 |
| O-UI | 核对入口、文案、控件状态、键盘焦点和错误反馈；同时直接调用 API 证明前端隐藏不承担授权。 |
