# F073 中粮 E+ 机器人接入 — 待客户确认清单

> 依据：《中粮 E+ 开发者文档》智能机器人章（接收消息、智能机器人长连接）、客户接入示例 [wwlbotdemo](https://gitee.com/hanphycai/wwlbotdemo) 及其依赖的官方 `wecom-aibot-python-sdk` 1.0.2 源码，与 [design.md](./design.md)。

| # | 问题 | 为什么要确认 | 级别 | 结论 |
|---|---|---|---|---|
| Q1 | 回调里的 `from.userid` 与组织同步到毕昇的员工 ID 是否同源？ | 客户网关从 IAM 拉取人员，将 IAM `userid` 原样写入同步报文 `external_user_id`；毕昇既有常量 `WECOM_SOURCE='wecom'`，最终以 `(source='wecom', user.external_id=from.userid)` 精确匹配 | 已确认 | 已确认；联调仍抽查真实样本 |
| Q2 | 解密算法已从官方 SDK 源码确认（`aeskey` 为 base64、IV 取前 16 字节、填充最大 32）；确认 E+ 私有化实例与 SDK 行为一致，图文混排图片可下载解密。 | 客户测试环境需证明真实密文兼容 | 已确认 | 2026-09-28 探针图片与图文混排均解密成功 |

## 3. 上线前需客户书面确认

| # | 事项 | 说明 |
|---|---|---|
| S1 | E+ 后台机器人保持「长连接」模式，不切换为「设置接收消息回调地址」 | 切换后长连接立即失效，机器人不再收到消息 |
| S2 | 若连接地址为 `ws://`，知悉 Secret 与消息内容为明文传输 | 建议使用 `wss` |
| S3 | 机器人绑定的知识空间内容允许在该机器人所在群的全体成员中传播 | 群内回答对所有群成员可见，毕昇无法按成员逐一保密；不确认则只开单聊 |
| S4 | 知悉 E+ 协议限制：群聊不支持纯图片（需配文字 @机器人）；同一员工对同一机器人最多同时 3 条消息在途，第 4 条由毕昇直接提示稍后重试；单条回答最长约 20KB，超出截断 | 并发上限与消息长度来自 E+ 文档；第 4 条忙碌提示为毕昇策略 |
