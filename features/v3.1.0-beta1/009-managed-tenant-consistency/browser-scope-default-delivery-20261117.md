## 结果与影响范围

已去掉两套前端对生成接口清单的运行依赖。普通同源API业务默认附加服务端确认的目标，新增积分配置、模型价格以及完全没有清单条目的接口均接入。Axios、平台原生流与客户端SSE共用浏览器通道规则；已确认的管理头不发送到外部Origin，baseURL与/workspace挂载均有回归。

生成的Python/Java范围资料不参与请求是否带头的判断，仍可用于登记检查和盘点；本轮同步Python资料至976条，新增7条、未删除原行。公共客户端实际打包依赖只有4个TypeScript模块，无清单JSON。共享回归令两份清单模块一旦被导入即失败，避免恢复运行依赖。

少量会话/发现端点、平台控制面及既有公开/设备命名空间保持独立，不维护租户业务逐URL白名单。分享令牌与审批个人预览明确使用独立协议；审批预览仅新增不发送到服务端的managementContext请求选项，URL、purpose=approval、正文及原审批鉴权均未改变。后端仍是认证、范围和具体资源动作的权威。

暂停后下一次确认或重试只调用既有GET request-scope。证明仍为同一目标才恢复；读取失败或格式非法保持暂停，不调用POST建立Home/Root默认，不自动重放原失败业务请求。目标已变化则拒绝旧动作并整页刷新。切换屏障阻止中途恢复，迟到证明、成功及失败应答不覆盖或清空新确认；silent仅抑制展示，不抑制必要暂停。

修改集中在公共请求传输、确认状态、两个SSE准备调用和一个既有独立协议包装，未改变页面业务表单。Python/Java业务代码、权限/角色/额度规则、Redis格式、数据库表列、业务ID和历史归属均未修改。旧Gateway无需升级，两个原聊天回写仍由原后端身份/持久归属规则处理，无新请求头要求。
