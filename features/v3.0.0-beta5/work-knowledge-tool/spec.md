# 内置知识检索工具登记

## 范围与验收

把已有鉴权检索能力接入平台通用工具执行器，工具键为 `bisheng_knowledge_search`，显示名称为“知识库检索”。桌面 DSH 继续通过现有登录代理调用 `/api/v1/knowledge/space/retrieve`；云端工具在服务端调用同一检索服务。

- AC-01：内置工具种子目录包含名称、说明及 query / space_ids 输入；已有数据库通过幂等登记脚本补齐。
- AC-02：同步和异步通用执行入口绑定真实调用用户与当前租户；模型参数只包含查询和资源 ID。
- AC-03：每次检索复用空间、知识库、文件权限及主版本过滤；权限异常向调用方传播。
- AC-04：返回与桌面 API 相同的 chunks 字段及文档来源；空结果返回空数组。
- AC-05：保留原任务专用 search_knowledge_base 和桌面适配器。通用工具的登记与新云端 Work 调用端接线分别验收。

## 实现决定

使用平台 ToolExecutor 的受信执行上下文，完整身份只在服务端生成。工具与 HTTP 接口共享结果序列化服务。沿用既有工具 use 权限检查与执行审计。已有部署的数据登记走人工运维脚本，默认预览，显式 --apply 执行，随后同步系统工具权限投影。执行检索要求当前租户与构造时的租户一致。
