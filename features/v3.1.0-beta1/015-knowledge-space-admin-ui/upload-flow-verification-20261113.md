## Chromium 本地检查

本机临时 Vite 仅监听 127.0.0.1:3017，移除所有远端 API 代理，使用本地 fixtures；结束后删除临时入口/配置并停止服务。

1. 初始四个步骤显示正常，未选择文件时直接上传/下一步禁用。
2. 选择 Markdown 后仅暂存；点击下一步，回显切分长度 300、重叠 0、关闭的保留图片设置。
3. 改成 456 后进入左右原文/分段界面，使用真实 Vditor 编辑分段。
4. 编辑后立即点击确认，第一次点击被同步保存锁阻断；保存成功后再确认，唯一注册请求携带 chunk_size=456、preview_id 与 expected_revision=1。
5. 第四步显示原注册 ID 对应的处理状态；在 1024px 宽度检查交互结构和原文/分段区域。

已观察到旧预览组件额外读取 `/llm/workbench`，本地 fixture 未模拟该接口所以返回 404；上传/预览/分段保存/最终注册均 200。没有将这次模拟报告写成控制台全无错误。实际 Office/PDF/媒体原文和服务端最终 chunks 仍需部署环境验证。
