出发前 · 备三样东西

01

一个 AI 编程工具

会用 Cursor、Claude Code、通义灵码之类的 AI 编程工具就行——应用的代码交给它写,你只描述想要什么。

02

bisheng 命令行

从你们自己的平台下载安装,不用连公网。装好后运行 bisheng --help 能看到 login / deploy。装法见第 1 站。

03

一把服务账号密钥

找管理员领一把 bs-sak-… 密钥(只有管理员能发放,只显示一次记得存好)。应用会归在管理员指定的人名下。

这条线 · 6 站到达

1

装好命令行,登录平台

先从平台下载命令行装上,再用管理员给你的密钥登录一次。凭据会记在你本机,后面不用再输。登录后平台还会自动把《部署纳管》技能装好,并接到你的 AI 编程工具上(Claude Code、Codex)——AI 靠它才知道平台的规矩。登录的最后几行会写清楚接进了哪些工具,如果显示一个都没接上,先照提示处理再往下做,否则 AI 是"盲写"。

终端
# 1. 从你们自己的平台下载并安装命令行(不连公网)
#    -OJ 让 curl 用平台给的正确文件名(pip 认这个名字)
$ curl -OJ http://你的毕昇地址/api/v1/dev-toolkit/cli/download
$ pip install ./bisheng_cli-*.whl

# 2. 用管理员给的密钥登录(应用会归到指定的资源归属人名下)
$ bisheng login http://你的毕昇地址 --api-key bs-sak-…
2

让 AI 做出你的应用

上一步接好技能之后,新开一个 AI 会话(已经开着的要重开,它读不到新装的技能),然后用大白话说你要什么——"做个部门费用报销的小工具""做个数据看板""做个满意度问卷"。AI 会照着平台的规矩,把应用和配置一起写好。部署前让 AI 对照技能自检一遍,它会自己把不合规矩的地方改好。

技能

用 Claude Code 或 Codex 的,登录时已自动接好,重开会话即可;想手动更新,运行 bisheng skills sync。用 Cursor、Cline 等其它工具的,首次 bisheng deploy 会在项目里写一个 AGENTS.md 指明技能位置,让 AI 读它就行。平台的规矩、清单怎么写、常见问题都在技能里,你不用懂,AI 懂就够了。

3

一键部署

在应用目录里跑一条命令。平台会自动帮你打包 → 构建 → 启动检查,最后生成一张发布审批单。中间那些活儿你都不用管。

终端
$ bisheng deploy
  打包 → 上传 → 构建 → 启动检查
  ✓ 平台已接收   审批单已生成:等待管理员通过
4

等管理员审批

发布要过一道审批。管理员在审批中心 → 待我审批里点「通过」,你的应用就会自动上线。想看进度,回「构建 → 应用」,卡片上会显示「已上线」。

5

授权给大家

上线 ≠ 公开。刚上线时只有你自己能进。到「构建 → 应用」找到它,点卡片上的齿轮 → 管理权限 → 添加权限,把「查看者」授权给需要的人:选部门 / 用户组,想全员就勾顶层部门 +「包含子部门」。

别走捷径

授权就在这个界面点几下完成,一步到位——不用找后台、也不用改配置。

6

抵达 · 大家用起来

被授权的人打开应用中心,就能在「探索更多应用」里看到你的应用,点「进入应用」在新标签打开。用过一次,它还会自动出现在每个人的「最近使用」里。

你的应用 · 应用广场LIVE
入口应用中心 → 进入应用
谁能看到你授权过的部门 / 用户组
下次更新改完再 bisheng deploy 发一版

卡住了怎么办?

本地跑得好、平台上起不来,几乎都是没照平台的规矩来。这些规矩和常见问题都写在《部署纳管》技能里——把报错贴给你的 AI,让它对照技能排查,通常一两轮就好。你不需要自己读懂它。技能没接上或想更新,运行 bisheng skills sync——它会重新下载并接进本机的 AI 编程工具,最后一行写明接进了哪些。

就这么多。你已经会部署了。

从一个想法,到全公司都能点开用的应用——写代码交给 AI,打包、构建、上线交给平台。你只管说你想要什么。
