## 0. 范围和确认记录

### 0.1 已确认的发现阶段结论

用户选择下一批开发「昆联知识库检索节点」，并确认「每个节点选择一个知识库，先走通主流程」。继续采用默认可用的 Mock，真实接口替换位置保留 TODO，真实环境验证标为待执行，不部署。

用户补充要求参考现有知识库检索节点。本稿据此对齐用户问题、检索范围、输出变量和下游使用习惯，保留已确认的首批单库范围，不将已有节点的全部能力自动纳入本期。

用户已确认规格和设计，并授权实施 Mock 阶段。任务进度及验证结果见 [tasks.md](./tasks.md) 和 [verification.md](./verification.md)。

### 0.2 本次纳入

- 新增独立的「昆联知识库检索」节点，能够与现有输入、输出和大模型节点连接。
- 每个节点选择一个当前用户有权使用的昆联知识库，配置查询文本和返回结果数量。
- 查询支持常量或上游变量，按现有节点习惯提供检索结果变量，包含片段内容和来源信息，可交给输出或大模型节点。
- 支持保存草稿、发布校验、节点试运行和完整 Workflow 运行。
- 区分正常命中、成功但无匹配、无权、资源不可用、输入错误、调用失败和超时。
- 提供默认可用的模拟知识库、文档片段及成功和失败样例，并清楚标识模拟来源。

首批最小流程为「开始 → 输入 → 昆联知识库检索 → 输出」；查询使用常量或开始节点变量时可以省略输入节点。需要生成回答时，可在检索与输出之间连接已有大模型节点，生成能力沿用原节点。

### 0.3 本次不包含

- 单个节点选择多个知识库、跨库合并排序、混合检索本地与昆联知识库。
- 昆联知识库创建、文档上传、导入、同步、分块、索引和删除。
- 新增查询改写、重排模型、复杂过滤表达式、检索算法或检索效果调优功能。
- 新增文件下载、文档预览、对象存储通道或完整的外部引用跳转系统。
- 长任务、异步检索、回调、人工交互和自动重试恢复。
- 新增 SSO、用户同步、通用令牌交换接口或本地昆联权限镜像。
- 改造已有本地知识库检索、QA 检索、知识库问答及平台 Agent 节点的业务行为。

昆联知识库及文档仍由昆联管理，Workflow 继续由毕昇管理。本稿不定义新的独立领域对象、权限模型或跨特性不变量。

### 0.4 与现有知识库检索节点的对齐

已核对现有[节点定义](../../../src/frontend/platform/src/controllers/API/workflow.ts)、[检索运行实现](../../../src/backend/bisheng/workflow/nodes/knowledge_retriever/knowledge_retriever.py)及[通用检索行为](../../../src/backend/bisheng/workflow/common/knowledge.py)。下表是源码核对结论与本期需求边界，不是功能测试通过记录。

| 方面 | 现有节点行为 | 昆联节点首批要求 |
| --- | --- | --- |
| 配置组织 | 用户问题、检索范围、元数据过滤、高级检索配置、输出。 | 沿用用户问题、检索范围和输出的组织及操作习惯；仅展示本期实际支持的检索设置。 |
| 用户问题 | 从上游选择问题变量，可配置多个问题，并关联各自结果变量。 | 沿用上游问题变量选择和结果变量联动；本期仅一个问题，另保留常量输入，不扩展批量问题。 |
| 检索范围 | 可选择本地文档知识库、知识空间或会话临时文件，支持多选。 | 仅选择一个昆联知识库，不混入本地库、知识空间和临时文件。 |
| 结果变量 | 每个问题对应一个检索结果，内容为包含文本和来源元信息的片段集合。 | 保持“问题 → 对应检索结果变量”的使用方式，以片段集合为核心输出，便于既有下游节点引用。 |
| 空问题 | 已配置问题在运行时解析为空时，不发起实际检索，返回空片段集合。 | 身份和配置校验通过后沿用该行为；缺少问题配置、变量不存在或非法类型仍报错。 |
| 高级检索 | 提供关键词／向量权重、重排、结果文本长度和用户鉴权开关。 | 首批不复制这些本地专用设置；昆联实际用户鉴权始终有效，不提供关闭开关。 |
| 数量与长度 | 当前高级设置中的结果长度控制文本规模，不等同于命中条数。 | 本期返回结果数量明确表示片段条数，不冒充已有结果长度；昆联是否支持其他限制待确认。 |
| 引用与异常 | 结果携带来源及引用标识；当前实现存在将异常文本放进结果的处理。 | 沿用来源可追溯的目标；外部来源保持昆联身份，调用失败必须呈现失败，不输出成功片段。 |

本稿仍只定义用户可观察行为。具体组件复用、输出命名及结构兼容、外部来源与已有引用机制的适配由设计阶段确定，不在此承诺直接套用本地文件引用或检索算法。

## 1. 用户故事与需求

### 1.1 用户故事

| 角色 | 目标 | 业务价值 |
| --- | --- | --- |
| 工作流编辑者 | 选择一个昆联知识库，以常量或上游问题发起检索 | 在画布中直接使用昆联知识内容 |
| 工作流发布者 | 发布选库和检索配置明确的流程 | 后续运行使用已发布配置 |
| 工作流运行者 | 检索本人有权访问的片段，并查看结果来源 | 共享流程仍遵守本人的数据权限 |
| 开发和联调人员 | 通过模拟样例验证配置、运行及失败处理 | 外部协议未齐备时仍能推进开发 |

### 1.2 需求标识

| ID | 需求 |
| --- | --- |
| REQ-01 | 提供独立节点和按当前用户、当前租户过滤的知识库选择，区分目录空、无权和查询失败。 |
| REQ-02 | 每个节点仅配置一个知识库，配置可保存、重新打开，并在变更后重新检查有效性。 |
| REQ-03 | 参考现有用户问题配置，支持单个常量或上游变量，校验实际输入和返回结果数量；有效变量解析为空时跳过检索并返回空结果。 |
| REQ-04 | 沿用现有问题与检索结果变量的对应方式，核心结果为含文本及来源元信息的片段集合；可阅读文本与命中数量均来自同一集合，无匹配作为成功空结果处理。 |
| REQ-05 | 发布前校验配置和资源可用性，发布后固定选库和检索配置，不承诺未获支持的知识内容快照。 |
| REQ-06 | 配置、发布、试运行和正式运行使用相应实际操作者的可信身份，保持本地与昆联权限边界。 |
| REQ-07 | 明确处理拒绝、资源失效、上游失败、格式异常、超时和停止，不产生伪成功或迟到输出。 |
| REQ-08 | 在既有运行界面展示节点状态、结果及可定位的关联信息，保护凭据和无权内容。 |
| REQ-09 | Mock 默认可用且明确标识，待替换内容带 TODO，模拟证据与真实联调证据分别登记。 |
| REQ-10 | 新节点参考现有检索节点的配置及结果变量使用习惯，可以串联现有节点，并保持已有 Workflow 和本地知识库节点行为兼容。 |

### 1.3 用户可配置和查看的内容

| 内容 | 业务规则 |
| --- | --- |
| 节点名称 | 用于画布和运行记录定位。 |
| 知识库 | 每节点一个，从当前用户有权使用的昆联知识库中选择。 |
| 用户问题 | 参照现有问题变量选择方式，本期仅一个问题；选择上游变量或填写非空常量。有效变量运行时解析为空时返回空结果，不发起实际检索；首批不提供批量问题。 |
| 返回结果数量 | 限制片段条数的正整数，受允许上限约束；默认值与上限在设计阶段确定并展示，不与现有结果文本长度混用。 |
| 检索结果变量 | 对应当前问题的片段集合，包含文本和来源元信息；可在既有变量选择器中被大模型、输出等下游节点选用。 |
| 便捷结果 | 同一片段集合的可阅读文本、来源信息及实际命中数量，方便展示和判断；不形成另一套独立检索结果。 |
| 来源与状态 | 能识别 Mock 或真实调用，并区分成功空结果与失败。 |

身份、租户和调用凭据由可信上下文确定，不能通过节点业务配置指定用户、认证头、令牌或任意检索地址。

### 1.4 结果与引用的业务含义

与现有知识库检索节点一致，本节点只返回知识片段，不负责调用大模型生成问答结论。一个已配置问题对应一个可下传的检索结果变量，核心内容为片段集合；可阅读文本、来源和命中数量都是该集合的表达，不改变同一组结果的含义。命中数量与返回片段一致，且不超过所配置的返回数量。

每条片段应能追溯到昆联知识库和对应文档、片段或等价来源定位。展示已有的文档标题、定位信息；相关性分数及更详细位置仅在上游提供并明确含义时展示，不自行补造。缺少足以追溯来源的必要信息时，应按异常结果处理。

首批保证来源信息可查看、可作为变量下传。外部文档不伪装成本地知识文件；没有可用且已确认的地址时，不生成预览或下载链接。已有大模型节点可以消费检索文本，但本期不新增自动回答或外部文档预览能力。

成功但无匹配时，返回空命中、空检索文本、空来源集合和零命中数量，下游仍可继续。已配置的有效问题变量值为 null、空文本或仅含空白的文本时，参照现有节点跳过实际检索，并给出同样的成功空结果。问题未配置、变量失效、除 null 外的非文本值和无权／调用异常不转换成成功空结果；首批也不复制现有节点对任意非文本值转字符串的宽松行为。

## 3. 边界情况

| 情况 | 期望行为 | 对应 AC |
| --- | --- | --- |
| 用户有 Workflow 权限，但没有该昆联知识库或部分文档权限 | Workflow 授权不扩大昆联权限；按昆联授权结果拒绝或仅返回允许的片段，不泄露被过滤内容。 | AC-11、AC-12 |
| 目录能看到知识库，执行时权限已变化 | 执行按当前权限判断，列表可见不作为永久执行许可。 | AC-10、AC-11 |
| 用户信息在单租户／多租户下形态不同 | 兼容当前合法登录方式；缺少前端可选字段不应导致单租户 Mock 永远空白，也不能据此绕过多租户隔离。 | AC-01、AC-02、AC-12 |
| 返回少于请求数量的命中 | 接受有效结果，保留真实数量，不补造片段；无匹配的成功与服务异常分别判断。 | AC-05、AC-08 |
| 已配置问题变量运行时为空 | 身份和配置有效时不调用昆联检索，返回成功空结果；未配置问题或变量不存在仍是配置错误。 | AC-04 |
| 上游提供分数但未确认可比性，或未提供页码、链接 | 不自行比较、补造分数或来源位置，不因缺少可选展示信息否定有效命中。必要来源定位仍须具备。 | AC-07、AC-13 |
| 昆联知识库没有内容版本能力 | 固定发布的资源选择和检索配置；每次检索读取当时有权访问的内容，不强制虚构知识库版本。 | AC-09、AC-10 |
| 多轮运行、超时或停止后收到旧结果 | 本轮结果不复用前轮命中，旧结果不覆盖新执行或已结束状态。 | AC-14、AC-18 |
| 只有持服务凭据、没有实际用户的调用 | 本期不默认支持；需要明确服务主体和数据范围时另行确认，不能默认为管理员范围。 | AC-12 |

验证按独立风险组织，同一条有效证据可以覆盖多项 AC，不按条目重复运行同一测试。本期规格编写仅进行 V0 文档静态检查，不能计作上述行为验证通过。

Mock 阶段完成须具备正常入口的配置、发布、节点试运行和完整最小流程证据，覆盖独立的失败与拒绝风险，并保留所有待替换 TODO。仅展示下拉选项或直接调用测试替身，不构成最小流程完成。

真实环境验收须在 EXT 契约和环境齐备后，验证一次真实命中、一次成功空结果，以及 A／B 数据范围差异和明确拒绝；同时补齐真实失败、超时及资源失效证据。缺少协议、账号或环境的项继续标为 NOT_RUN，不以 Mock 结果代替。
